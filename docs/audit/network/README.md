# Дом `network` — зонд-снимки состояния сети и нормы исходящего

> Канон формы — заседание [`network-container`](../../meeting/network-container/MEETING_VERDICT.md)
> (M0–M7, обе ратификации владельца 13.08). Такт 2 из [#1449](https://github.com/officefish/Membrana/issues/1449).
> Плоскость отчётов `docs/audit/`; жанр — как [`llm-calls`](../llm-calls/): дом + закрытая
> схема + закрытый список запрещённых полей. **Дом ничего не чинит** (#1425): маршруты
> лечатся своими работами, здесь — наблюдение и нормы.

## Единица звена (В1)

**Зонд-снимок** — результат одного акта наблюдения органом (`net:diag`, `llm:probe`,
`infra:probe`, `net:http`, `outbound-self-check`, …). Один род записи. Маршрут —
атрибутивный блок внутри снимка; правило — не единица ленты; агрегаты — производные
мастерской. Схема закрыта — [`schema.json`](schema.json); поле вне схемы не создаётся
(В3, слой 1 защиты шва).

## Словарь состояний (В2)

`status` ∈ **`ok` · `degraded` · `down` · `unknown` · `partial`** (отображение из
`net:diag` тождественное; неизвестное значение органа → `unknown`, оригинал — в
`organ_raw_status`). Отдельная ось `outcome` ∈ {`executed`, `failed`}: «проверка не
состоялась» — не шестое состояние; при `failed` поле `status` не интерпретируется.
Владелец словаря — архитектор дома; расширение — **только ADR-записью в этом доме**
с органом-источником, значением и правилом отображения.

## Граница с infra-policy (В3)

Разрез «норма vs наблюдение»: [`docs/security/infra-policy.json`](../../security/infra-policy.json)
владеет декларациями об узлах (что должно быть); снимок — наблюдённое (что было), ни
одного поля-декларации. Ссылочность односторонняя: снимок → `infra_node_id`
(непрозрачный ключ); обратных ссылок нет; связь строит мастерская при агрегации.

## Слои дома (В5)

| Слой | Род | Судьба |
|---|---|---|
| `analysis/YYYY-MM-DD/probes.jsonl` | лента снимков, append-only | источник истины; горячие 90 дней, старше — перекладка скриптом по требованию в `analysis/archive/YYYY-MM/` |
| `registry/*.json` (проекции зондов: `{probe_id}.json`, `summary.json`) | overwrite-проекция | пересчитывается каждой успешной ночью; при пропуске ночи не трогается (`meta.generated_at` делает пропуск видимым) |
| `registry/egress-rules.json`, `registry/machine-policy.json`, `registry/network-policy-violations-budget.json` | **рукописные нормы** | пересчётом НЕ трогаются — контракт скрипта пересчёта обязан это оговаривать (хвост сборки, аудит M6–M7) |
| `cache/` | транзит скрипта зондирования | gitignore |

Слой `specimens/` не создаётся — у зонд-снимков нет семантики «образца».

## Запрещённые классы полей (В1, закрытый список)

1. Секреты и credentials (токены, пароли, ключи, `Authorization`, userinfo в URI).
2. Приватные локальные пути (home/operator-specific absolute paths).
3. Сырые тела запросов/ответов и пакетные payload.
4. Нередактированные полные дампы заголовков/env.

Допустимы: нормализованные outcome/code, метрики, id органа, санитизированный target.

## Такт и канал находки (В4)

Базовый такт **01:00** (до vitest 02:00 и tests-nightly 03:00) + условный пуск
гейт-событием «правка серверных вызовов». Канал находки: тихая запись — night-report
(вход утра, PR #1851); промоут — night-triage (#1889, PR только при кандидате).
Держатель-кандидат — Ожегов (назначение за владельцем). Без прод-замера ритм идёт:
снимки пишутся штатным словарём, baseline появится с прод-замером.

## Нормы (В6, В7)

- [`registry/egress-rules.json`](registry/egress-rules.json) — правила исходящего
  трафика данными (класс K1 мигрирован словом; поведение кода не менялось).
- [`registry/machine-policy.json`](registry/machine-policy.json) — политика машин
  (`allowedExits` декларативное: источник истины направлений — egress-rules) и
  легальные исключения зуба bare-fetch.
- [`registry/network-policy-violations-budget.json`](registry/network-policy-violations-budget.json)
  — warn-храповик легаси (бюджет 4, названы поимённо).

Зубы (`scripts/check-bare-fetch.mjs`, T_night/T_gate) — поставки #1912 и #1913.

## Мастерская

Ровно три глагола — `audit` (лента → свод), `decompose` (срез → раскладка), `inspect`
(одна запись → карточка); глаголов починки нет. Движки мастерской — отдельная поставка;
до неё дом — «дом без мастерской», законное состояние по атласу.
