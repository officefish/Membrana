## Deletion Procedure

1. Владелец ратифицирует поимённый список.
2. Перед каждой целью повторно проверить PR state, branch tip и worktree occupancy через `yarn neighbors`.
3. Удалить ровно одну branch ref; worktree removal не подразумевается.
4. Выполнить пост-чек всех живых worktree по ADR-0020 и записать результат.
5. При первой находке остановить весь проход.
