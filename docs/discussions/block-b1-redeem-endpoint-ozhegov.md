## Контекст-прогон (до кода, след в op-log/ozhegov ~17:18Z)

Форма: путь POST `v1/membranes/me/tariff/promo-redemptions` под общим `SessionGuard`;
actor/membrane — из сессии (резолюция публичным `getOrCreateMembraneForUser`), в DTO
запрещены; DTO = ровно `{code}` с транспортной валидацией формы; статус-коды: 200 и на
успех, и на доменный отказ (клиент читает `reason`, не HTTP-код), 4xx — только транспорт;
код не логировать; GET-«проверялку» не заводить (второй фасад на одно действие).

## Ревью-проход (по построенному, ~17:27Z)

зафиксировано в шапке контроллера как публичный HTTP-контракт (менять через ADR);

нужен `AuthService`). Идемпотентность `getOrCreateMembraneForUser` на каждый POST —
норма того же пути, что `membranes/me`. **LGTM по границам.**
