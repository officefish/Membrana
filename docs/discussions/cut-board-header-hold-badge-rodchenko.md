## Корень наложения

Корень назван верно: левая `flex-1 min-w-0` без `overflow-hidden`, все дети `shrink-0` кроме крошки — сумма превышает коробку, вытекает вправо (`overflow: visible`), правая `shrink-0` стоит позже в DOM и рисуется поверх. Замер не исключил одного: не проверено, не даёт ли сам `.badge` daisyUI внутреннего `white-space: nowrap` + мин-ширины от содержимого — это к форме починки (см. ниже), не к корню.

## Форма починки b1

Правильно уступать бейджу удержания, а не прятать INFO/Copy trace в меню и не разводить шапку на две строки:

- Удержание — редкое состояние, галка INFO и Copy trace — постоянные инструменты смены; прятать постоянное ради редкого — хуже, чем усечь редкое.
- Вторая строка шапки меняет геометрию канваса и ломает контракт `headerContentOffsetClass` — это уже другой спринт.

Форма: `overflow-hidden` на левой группе (жёсткая гарантия клипа) + бейджу `min-w-0` вместо `shrink-0` + внутренний `<span className="truncate">` для текста (daisyUI `.badge` сам не усекает). Полный текст уже в `title`/`aria-label` — приёмка b3 это проверит.

## Структурный зуб без раскладки

Jsdom раскладку не считает, поэтому зуб честен только по исходнику и классам:

- класс левой группы содержит `overflow-hidden` (вынести в константу в `types/board-ui.ts`, чтобы зуб был по значению, не regex);
- бейдж удержания: `className` НЕ содержит `shrink-0`, содержит `min-w-0`, внутри есть элемент с `truncate`;
- `title`/`aria-label` бейджа несут полный заголовок+причину (регрессия на укорочение).

Пересечение boundingBox — только на b3 глазами владельца; Playwright не трогаем (нужен посев эпизода, не проверено).
