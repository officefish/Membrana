По существу, до кода:

2) **Строго меньше, без магических допусков.** Прецедент isStale — как раз про то, что владелец календарных чисел не давал; вводить ε сейчас — это ввести число, которое некому ратифицировать. Если позже появится джиттер часов между источниками следов — заводим отдельный предикат `clock_skew` с явным ε и отдельной ратификацией, не смешиваем.
