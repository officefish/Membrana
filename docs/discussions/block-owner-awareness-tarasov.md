## Положение

Генератор честен — беда в том, что ему подают устаревший источник. Гейт выбрал `mfcc-mic-plugins`, но `main-day-assertions.json` всё ещё держит вчерашнюю `mfcc-spectral-core`. Обновить assertions при выборе гейта — это компетенция гейта, но это вне твоей зоны. **Однако генератор может стать оборонительнее, не нарушая канона.**

---

## Решение

**Генератор читает `morning-gates-state.json` и при расхождении между выбором гейта (сегодняшним) и `sources[0]` — молча предпочитает выбор гейта.**

Рациональность:

1. **Гейт позднее по времени** — это последнее волеизъявление владельца за сегодня.
2. **Честность не страдает** — мы не синтезируем, берём из того же источника истины (owner-choice), только актуального.
3. **Обратная совместимость** — если `morning-gates-state.json` пуст или дата не сегодняшняя, генератор работает как сейчас.
4. **Не ломаем «sources пуст → синтез»** — срабатывает только при наличии owner-choice в гейте.

---

## Логика

В `_main-day-issue.mjs` строка ~61 (где читаешь `main-day-assertions.json`):

```ts
const assertions = readJson('docs/tasks/main-day-assertions.json');
const gateState = readJson('docs/tasks/morning-gates-state.json');

let magistral = assertions.sources[0]?.claim;

// Если гейт выбрал магистраль сегодня, и это свежее,
// и расходится с assertions — предпочесть гейт
if (gateState.magistralChosen?.date === TODAY &&
    gateState.magistralChosen.id !== magistral?.id) {
  magistral = { id: gateState.magistralChosen.id, source: 'gate-override' };
}
```

При синтезе (`sources` пусто) условие не срабатывает — всё как было.

---

## Расхождение vs молчание

**Молча предпочесть.** Логирование (не ошибка, просто факт) опционально:

```ts
if (/* расхождение */) {
  console.log(`[info] magistral from gate override: ${gateState.magistralChosen.id}`);
  magistral = ...;
}
```

Но в `main-day-issue.md` не пишем. Документ остаётся источником истины; гейт обновит assertions потом (или не обновит — это его проблема, не генератора).
