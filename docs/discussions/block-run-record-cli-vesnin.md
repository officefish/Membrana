# Блок run-record-cli — контекст Веснина

Дата: 2026-08-03, вечер (перенос с завтра — слово владельца «есть ресурс делать сегодня»).

Я расширял библиотеку блоком 1 — CLI пишу тем же словарём, вторых диалектов нет
(причина разреза 3а/3б у резчика).

## Решения

1. **Команды**: `open · close · amend` — ровно три события журнала, ничего сверх.
   Статусы и валидация — ТОЛЬКО библиотекой (`buildProcedureRunRecord` бросает на
   чужой статус); CLI не заводит ни одного собственного значения — буква DoD.

2. **Время**: `--at <ISO>` опционален, по умолчанию — системные часы в момент вызова.
   Это не «выдумать время», это замер события; выдумкой была бы подстановка чужого
   или прошлого времени — она возможна только явным `--at`, и ответственность на
   том, кто его передал. Прецедент ratifyPlan («зуб не подставляет now() за
   владельца») — про слово ВЛАДЕЛЬЦА; здесь событие самой цепочки.

3. **runId по умолчанию** — `<procedureId>-<дата события>`: словарь уже в ленте
   (`ritual-day-2026-08-03`). `--run` переопределяет.

4. **Суточное шардирование против ленивого закрытия.** Лента дневная
   (`defaultTrailPath`), а обрыв утра должен ловиться «со следующего утра» (DoD 3б) —
   следующий open живёт уже В ДРУГОМ файле, и внутрифайловое ленивое закрытие
   openProcedureRun его не увидит. Поэтому `open` в CLI перед открытием ПРОМЕТАЕТ
   ленты за 7 суток назад от даты события: незакрытые прогоны той же процедуры
   закрываются fail/orphaned В СВОЁМ файле (append туда законен — лента файла
   append-only, день файла — день ОТКРЫТИЯ прогона, событие закрытия датировано
   честно). Названный долг: структурного `orphanedBy` у кросс-файлового закрытия
   нет — `closeProcedureRun` поле не проносит, расширять библиотеку — вне зоны
   блока; ссылка на вытеснившую запись едет строкой в evidence. Кандидат в ADR
   завтра вместе с остальной схемой @1.1.

5. **close по procedureId**, не по runId: цепочка вечера не обязана помнить утренний
   runId — она закрывает «открытый прогон этой процедуры», ища его с сегодняшнего
   файла назад по тем же 7 суткам. Два незакрытых одной процедуры — ошибка входа,
   CLI отказывает и называет оба, не выбирает молча.
