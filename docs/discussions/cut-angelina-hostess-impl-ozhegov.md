### Отклонено — «M4-остаток уходит в `void/`»

Резчик приговорил ратифицированные вердикты владельца. Правило кладбища
(`docs/void/README.md`, вердикт M5): «Приговор выносит только закрытый вердикт с
ответственным; GC исполняет, не судит». Вердикты M4 закрыты как **принятые**, а не
отклонённые. Отменить принятое может владелец, не резчик и не агент. Выношу вопросом на
гейт, в нарезку не беру.

### Находка, меняющая форму спринта

Ядро ждёт след вида `{status: 'rejected', verdictClosed: true}`. Такого следа в дереве нет
ни одного — замерено прибором по обоим реестрам:

```
следов проверено: 1188 | приговорённых (isDead): 0
следов с полем verdictClosed: 0
```

Значит порт, нарезанный как предложил резчик, — станок, который печатает «перенесено 0»
каждый вечер и не может напечатать иное **по построению**. Это ровно тот класс, который
сессия закрывала сегодня утром на гейте: механизм, не краснеющий на порче, ничего не
удостоверяет. Прежде порта нужен источник приговора: у следа должно появиться состояние
«отвергнут», а у отвержения — закрывающий вердикт с ответственным.

Где ему жить — вопрос владельцу: жизненный цикл инсайта (`docs/insights/registry.json`,
65 записей, статусы `adopted`/`draft`/`deferred`/`archived`/`researched`/`reviewed`) — это
канон, и добавление в него терминального «отвергнут» меняет канон, а не код.
