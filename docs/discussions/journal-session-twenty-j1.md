**Вопрос:** Блок j1 ратифицированной нарезки. Ответь по Q1–Q5 формулами и предикатами: что именно считаем, из каких готовых функций собираем, где границы и какие отказы. Своих копий формул не заводим.

**Ответ:**

Слушаю пять вопросов, отвечаю предикатами и формулами. Начну с главного: фон сеанса — это статистика по кадрам, а не по трекам. `estimateNoiseFloor` принимает `rmsHistory` — скармливай ей кадровые RMS **всех треков подряд** (single pass, 720×~100 кадров). Пик трека — максимум `frameLoudness(samples, peakWeight)` по кадрам трека, не `rms`, ибо `frameLoudness` учитывает пики, а RMS их сглаживает. Мера «над фоном» — **дБ**: `20·log10(peak / floor)`, ибо отношение (ratio) нелинейно к усилению. Порог отбора — `peak > floor·10^(ΔdB/20)` при ΔdB = «громко» (задай ΔdB явно, я не угадываю).

Q2: границы события — по кадровой огибающей `frameLoudness`: начало — первый кадр, где `L > floor·10^(ΔdB/20)` и это не одиночный выброс (проверь след. кадр); конец — последний такой кадр подряд. Смещение в треке — `startFrame·frameSize/sampleRate`. Точка — `{trackId, startSec, endSec}`, не «весь трек».

Q3: вектор признаков — `[spectralCentroid, spectralRolloff (85%), spectralFlatness, zeroCrossingRate]`, нормированный на `[0,1]` по диапазону сеанса. Метрика — евклид по нормированным (косинус тут плох: centroid и rolloff — не углы). Порог — отсекай всё, где дистанция < 0.05·maxDist (жадный отбор: берёшь громчайший, выкидываешь ближайших, повтор). Кластеризация избыточна для 20 из 720.

Q4: **только flatness нельзя** — он различает тон/шум, но не структуру. Пара `(spectralFlatness, spectralFluxL2)`: flatness < 0.3 — тональная, fluxL2 > μ_flux + 2σ_flux — всплеск без рисунка. Граница не константа из воздуха: берём квантили по сеансу (например, нижняя квартиль flatness и верхняя квартиль flux из здорового фона) — это «онтология сеанса», а не моя прихоть.

Q5: отказы — **не возвращаем нуль, возвращаем структурированный отказ**: `{status: 'insufficient', reason, metrics}`. Причины: сеанс < минимальной длительности (задай `minDurationSec`, я не знаю), `estimateNoiseFloor` вернул пол 0.005 (это сам по себе сигнал «мало кадров»), все треки немые (`peak < floor·10^(ΔdB/20)` для всех) — тогда возвращаем `{status:'no-candidates', topK:[]}`. Меньше двадцати — отдаём сколько есть, помечаем `shortfall: 20−n`.

Формула итоговая: `op = argmax_t frameLoudness(t)`, отбор — `op` по убыванию, фильтр — `20·log10(op/floor) > ΔdB ∧ flatness < Q1_flat ∧ fluxL2 > Q3_flux`.
