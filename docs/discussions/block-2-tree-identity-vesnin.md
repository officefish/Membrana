# Блок 2 `foreign-tree-identity` — прогон контекста Веснина

**Спринт:** `worktree-foreign-resolution-probe` ([#1647](https://github.com/officefish/Membrana/issues/1647)).
**Исполнитель:** vesnin. **Дата:** 2026-08-08.

## Сделано

Чужое дерево теперь называется по имени и ветке: «37 пакетов ведут в „Membrana-tooling“ ·
ветка fix/office-image-followup». Иссью просило знать, куда и на какую ветку уходит
резолюция; без этого вердикт `foreign` заставлял искать виновника руками, а состояние
динамическое — ролями меняются при каждом `yarn install`.

Ядро `worktree-identity.mjs` чистое: перечень деревьев приходит значением, git спрашивает
порт. Недоступный git даёт пустой перечень, и тогда чужие пакеты честно зовутся
неопознанными — не приписываются кому попало.

## Ловушка, ради которой ядро отдельное

Имя одного дерева бывает **префиксом** другого (`Membrana` и `Membrana-tooling`).
Сопоставление «по началу строки» приписывает пакет ближайшему по имени дереву и врёт
уверенно — ровно на этом 08.08 сорвался живой замер строки 10. Сравнение идёт по сегменту
пути; отдельный зуб держит именно этот случай.

Вложенные деревья (`.worktrees/X` внутри основного) разрешаются в пользу **самого глубокого**
совпадения: иначе пакеты вложенного дерева уехали бы его хозяину. Дерево вне перечня зовётся
неизвестным.

## Зубы

**8/8.** Держат: префиксную ловушку, вложенность, смешанные разделители и регистр диска,
детерминированный порядок владельцев, признание неизвестной ветки вместо выдумки, пустую
сводку на своём дереве.
