# Блок b2-sprint-experience-seam — конспект контекста dynin (s-queue-2026-08-11)

След прогонов: `op-log/dynin/2026-08-11.jsonl` (origin `ask-persona`, два захода:
диагноз шва и ревью диффа).

## Предмет

Карточка `fix-sprint-experience-dead-ends`: живой путь записи «предсказание ↔
исход» держал две правды пути ленты (`RECORDS_PATH` писателя против копии
константы в гейте) и не вычислял `seq` — вторая запись окна получала id первой,
и append-дедуп молча её глотал (вещдок 10.08: исход после перерезки не доехал).

## Сделано

1. **Один путь**: `FORECAST_RECORDS_REL_PATH` переехала к роду
   (`lib/sprint-experience/forecast-record.mjs`); гейт
   (`forecast-record-gate.mjs`) реимпортирует и реэкспортирует для живых
   потребителей; `RECORDS_PATH` писателя строится из константы.
2. **`seq` по ленте**: чистая `nextForecastSeq(records, key)` (префикс id,
   числовой хвост, max+1); живой путь `buildLiveRecord` читает ленту перед
   `makeForecastRecord`.
3. **Дефолт `seq=1` снят** (вердикт контекста: «дефолт — не значение, а
   надежда, что хвост пуст; надежда — не предикат»). Фикстуры дефолтом не
   пользовались (передают явный id) — правка не вышла за зону.
4. Зубы: идентичность реэкспорта (`===`), рост `seq` по ленте с проверкой id,
   изоляция чужих окон/мусорных хвостов, бросок без id и seq. 47 зелёных +
   соседи гейта 83.

## Ревью диффа (review_pass)

Дифф в зоне (4 файла зоны), за зону не вышел; асимметрия ошибок названа:
ложный плюс строгости дёшев (тест ловит сразу), ложный минус дефолта дорог
(тихое поглощение записи ловится только расхождением счётчиков). Вердикт:
соответствует //dod b2.

## Открытый вопрос контекста (не блокер, наблюдение)

stop-путь пишет в ту же ленту; при повторном stop одного окна дефолта больше
нет — вызов без явного seq теперь падает с причиной, мина снята конструкцией.
