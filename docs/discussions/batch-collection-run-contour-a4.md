# a4 · Родченко · вход кабинета

**Предмет:** запуск по выбранной коллекции и видимый полный/частичный исход.

Server backend вызывает существующую plugin-request дверь. Кабинет показывает агрегат,
построчные статусы, причины и p50/p95; полный буфер предупреждает, что read-only прогон не
освобождает место, но не блокирует команду. Заполненность берётся из `isBufferQuotaFull`, а не
из общей пользовательской квоты.

**Evidence:** media backend tests 5/5; panel tests 3/3; typecheck cabinet/media; targeted ESLint.

**Gap:** при 1057 строках таблица результата остаётся одной прокручиваемой DOM-таблицей без
виртуализации. Это допустимо для текущего лимита 2000, но метрика интерфейса не снималась.
