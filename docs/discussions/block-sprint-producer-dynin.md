## 2. Решения по проводке (моя зона: sprint-cut-check.mjs, execution-gate.mjs, sprint-producer.test.mjs)

**Словарь.** `procedureId = "membrana-local-sprint"` — имя УЖЕ в ленте 03.08
(рукописная запись спринта); второй диалект для того же предмета не завожу.
`runId = sprintId` — буква DoD блока 2.

**Лента.** Путь детерминирован планом, не часами процесса:
`defaultTrailPath(plan.ratification.at → YYYY-MM-DD)`. Ratify и gate выводят один и
тот же путь из одного и того же поля — open и close гарантированно встречаются в
одном файле, даже если close случится назавтра.

**Ratify → open.** `--ratify` при УЖЕ стоящей ратификации отметку владельца НЕ
переписывает (перештамповка `at` инструментом задним числом — подделка слова
владельца), но обеспечивает open-запись в журнале: это и есть требуемая
идемпотентность — «находит открытую, не плодит вторую». Третий случай — прогон уже
закрыт — тоже не плодит второй open: спринт прожит, запись стоит.

**Gate → close.** Закрывает ТОЛЬКО при существующей open-записи и только при
exitCode 0/1: exit 2 значит «проверка не состоялась» — утверждать в журнале нечего.
Маппинг: exit 0 → `pass`; exit 1 → `fail`, `gaps` = уникальные имена вердиктов
остановленных блоков (`plan_lied`, `stale_trace`, …) — читатель ленты видит РОД лжи
без открытия отчёта. Время close: `--now` гейта, иначе системное время CLI —
поведение `--now` расширяется («шапка отчёта» → ещё и время close-записи), это
названо в usage, не молчит.

**Следствие для THIS спринта (DoD «Общий»).** Ратификация run-journal-producer
случилась в 17:31, до рождения производителя. После блока 2 прогоняю
`sprint:cut --ratify` повторно: отметка не тронется, open-запись появится с честным
`at` = 17:31 из плана; финальный gate свода закроет её без руки. Отпечатались оба —
DoD доказан на самом спринте.

**Отказ.** Обёртку-раннер и запись «каждого прогона gate» не строю: mid-sprint
прогоны гейта — рабочие замеры, а прогон спринта в журнале один; его открывает
ратификация и закрывает вердикт. Это то же «событие вместо мутации», что у Веснина,
приложенное к жизни спринта.
