# Перепрогон вещдока 02.08 новым гейтом: пропуск наконец назван пропуском

Блок `evidence-rerun` спринта `gate-honest-pair-completeness` ([#1641](https://github.com/officefish/Membrana/issues/1641)).
Держатель — Ожегов: пропуск 02.08 его, и перепрогон его же — по требованию резчика блоком,
а не строкой DoD.

## Что перепрогонялось

Спринт `memory-report-surfacing` (02.08): два блока за Ожеговым, контекст держателя прогнан
только по блоку A (`report-surfacing-render`), блок B (`report-surfacing-wire`) писался без
прогона контекста — в ленте у него ровно один `review_pass`. След задним числом не ставился.

## Было — 02.08, гейт до #1641

```
report-surfacing-render · ozhegov · honest_pair — 2 вещдоков рода context_run/review_pass
report-surfacing-wire   · ozhegov · honest_pair — 1 вещдоков рода review_pass
итог: остановок 0 из 2 блоков · зелёных 2 · находок 0 · код возврата 0
```

Пропуск виден в самом тексте («1 вещдоков рода review_pass») — и вердикта не меняет. В
итоговой строке блок неотличим от полностью честного.

## Стало — 03.08, гейт с девятым вердиктом

```
report-surfacing-render · ozhegov · honest_pair — пара полна (context_run + review_pass): 2 вещдоков
report-surfacing-wire   · ozhegov · incomplete_trace — след валиден и свеж, но пары нет:
    отсутствует context_run (есть только review_pass); добыть недостающий род
    или признать, что работа шла без него
итог: остановок 1 из 2 блоков · зелёных 1 · код возврата 1
```

Команда воспроизведения:

```bash
yarn sprint:gate --plan docs/sprint/cut/memory-report-surfacing.json \
  --traces docs/sprint/trail/memory-report-surfacing.jsonl
```

## Что означает красный, и чего он НЕ означает

Красный вердикт говорит: у блока B нет вещдока прогона контекста до работы — и его
действительно не было, это признано в самом иссью. Красный НЕ говорит, что работа плоха:
`team-memory-report.mjs` прошёл ревью и живёт в стволе. Лента 02.08 не правится и след задним
числом не ставится — вердикт остаётся красным как честная запись того, как шла работа.
Ровно для этого класс `stop` и выбран: «несыгранный матч при сданной тренировке».

## Симметрия

Блок A, где пара была, остался `honest_pair` — ужесточение не тронуло честное. Это то же
свойство, что показал замер перекраски на всей истории: 124 из 125 блоков сохранили вердикт,
перекрасился ровно один — этот.
