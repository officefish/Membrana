# Блок t1-fixture-bridge — конспект контекста dynin (sprint-cut-teeth-live-2026-08-11)

След прогона: `op-log/dynin/2026-08-11.jsonl` (origin `ask-persona`).

## Предмет

Мост зубов формы cut-плана к живым модулям: `scripts/lib/sprint-cut/test-support/live-fixtures.mjs`.
Без него переход зубов с дублёров заносит в тест формы обвязку соседей
(ISO→epoch ms, реестр персон, закрытые роды) — зуб формы становится
интеграционным тестом соседа.

## Сделано

- `liveTrail(acts, {personas})` поверх живого `readTraceCorpus`: акты блока по
  времени + ошибки входа рядом; ФС/сети/часов нет.
- `liveActualChangedLines(facts, blockId)`: три исхода — `null` (факта нет),
  `0` (факт есть, ноль строк), **бросок** (факт битый).
- `liveOutcome(v)` поверх живого `verdictFor`: `fit` бинарен, порог числом в
  записи, времени исхода нет; нечисловой порог — явный отказ.
- `FIXTURE_PERSONAS` + реэкспорт `TRACE_KINDS`: параллельной онтологии мост не
  заводит.

## Ревью (review_pass) — судьба всех пяти замечаний

Приняты в код все: (1) стабильность при равных `at` названа инвариантом в
JSDoc и проверена (`x1,x2` — порядок появления); (2) битый факт больше не
смешивается с отсутствующим — бросок с причиной; (3) нечисловой порог даёт
отказ вместо рассинхрона `fit ↔ threshold`; (4) реэкспорт словаря — принято
как есть; (5) частичный успех корпуса подтверждён замером: испорченная строка
даёт 1 ошибку и НЕ прячет здоровый акт того же блока.

Ответы на встречные вопросы: (а) кейс равных `at` в живом корпусе есть —
воспроизведён фикстурой, инвариант закреплён; (б) `threshold=null` контрактом
исключён — мост подставляет канонический порог, нечисловой отвергает.
