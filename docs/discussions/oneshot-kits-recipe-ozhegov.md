## 2026-08-03 16:24 UTC · ozhegov

**Вопрос:** Ты — исполнитель шота H kits-recipe. Контекст до execute. Предмет: пре-пуш зуб китов трижды за два дня останавливал отгрузку, и трижды ремонт руками одинаков: yarn kits:pins --id <кит> --write → git add MANIFEST → отдельный коммит формы «chore(kits): опись <кит> догнала <предмет>». Зуб печатает через repinHint только команду. Владелец ратифицировал допечатку ПОЛНОГО рецепта: команда + «отдельным ревьюируемым коммитом» + шаблон сообщения по форме трёх влитых. Вопросы: 1) рецепт целиком в repinHint (ядро lib) или командная часть в ядре а шаблон коммита в CLI — где граница словарно; 2) шаблон с плейсхолдерами (<кит>, <предмет>) или подставлять живые имена китов из broken; 3) не перегружаем ли вывод — рецепт из трёх строк на каждом падении против одной сегодня.

**Ответ:**

**Контекст → решение → затронутые пути → риски.**

[1] id=ozhegov-2026-07-30-workshop-wires-m5-kit-frame · почему: лемма «кит vs фрейм процедуры»; здесь то же разведение: `repinHint` (ядро, печать) и рецепт коммита (процедура) — не один словарь.

**Термин:** «рецепт» — омоним двух лемм: (1) **команда** `yarn kits:pins --id <кит> --write` — исполняемый шаг, живёт в ядре lib, печатается в `repinHint`; (2) **процессная норма** «отдельным ревьюируемым коммитом, сообщение по форме X» — правило процедуры, живёт в CLI/доке, не в ядре. Граница: ядро знает *как чинить опись* (команда), CLI знает *как легально влить* (коммит). Смешивать — нарушение связанности: ядро не должно знать про git-процедуру.

**Ответы:**
1. **Команда — в ядре** (`repinHint`), **шаблон коммита — в CLI** (константа/утилита, не в lib).
2. **Плейсхолдеры** `<кит>`, `<предмет>` — без живых имён: ядро не знает broken-набор, а живое имя в hint делает вывод зависящим от данных, не от словаря. Подстановка — на стороне CLI из `broken`.
3. **Не перегружаем:** рецепт — 2 строки: строка команды (уже есть) + строка «влить отдельным ревьюируемым коммитом: `chore(kits): опись <кит> догнала <предмет>`». Три строки — порог, но каждая имеет функцию; сократить до двух, убрав повтор «команда».

**Затронуто:** пакет зуба (ядро, `repinHint`), CLI (шаблон-константа, формат вывода). **Риск связанности:** низкий при соблюдении границы ядро=команда, CLI=процедура.
