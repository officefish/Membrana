# Блок ritual-wiring — контекст Ожегова

Дата: 2026-08-03, вечер (перенос с завтра — слово владельца «есть ресурс делать сегодня»).

Глаголы package.json — мой предмет. Решения врезки:

1. **Обе цепочки получают open в начале и close в конце** — буква DoD. Утро:
   open ДО первого шага (обрыв на любом шаге оставляет сироту — её найдёт
   завтрашний open через границу файлов, это и есть требуемое «ловится со
   следующего утра»); close — ПОСЛЕ `ritual-deliver-to-main`, статус `pass`
   законен: `&&`-цепочка довела до конца. Вечер симметрично вокруг
   `ritual-evening-run`.

2. **Сторожа не глушат**: open/close идут БЕЗ `|| true`. Глушёный open ломает
   пару (close отказал бы «закрыть нечего» в самом конце, ПОСЛЕ доставки — худшее
   место), а молчаливый пропуск записи — ровно та болезнь, против которой спринт
   (47 версий документа дня, ноль записей). Сломанный журнал утром — честный
   красный владельцу, не вечерняя загадка. Прецедент M1-C того же рода: нет
   инструмента → СТОП, не импровизация.

3. **Вещдоки** — существующие носители, без выдумки: утро open —
   `docs/tasks/morning-ritual-steps.json` (манифест утра, есть до старта); утро
   close — `docs/MAIN_DAY_ISSUE.md` (рождён цепочкой); вечер open —
   `docs/MAIN_DAY_ISSUE.md` (к вечеру есть); вечер close — `docs/HANDOFF.md`.

4. **Зуб сверяет цепочку ПО ФАКТУ package.json** (как прецедент
   prepush-env-guard): читает строку глагола и проверяет порядок — open раньше
   первого шага, close позже deliver; никакой проверки «по догадке» через
   отдельный конфиг, который может разъехаться с глаголом.

5. Коммит package.json — поимённо (файл горячий, //zone-note плана).
