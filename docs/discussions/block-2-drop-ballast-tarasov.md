# Блок 2 `drop-probe-ballast` — прогон контекста Тарасова

**Спринт:** `dockerfile-copy-manifest-drifts` ([#1797](https://github.com/officefish/Membrana/issues/1797)).
**Исполнитель:** tarasov. **Дата:** 2026-08-08.

## Задача блока

Снять `COPY scripts/llm-probe.mjs` — единственный балласт по замеру, опираясь на прибор
блока 1, а не на слово. Строка стояла с комментарием «снятие необратимо и проверяется только
сборкой образа»; блок 1 сделал её проверяемой.

## Что нашлось при снятии — заряженная дыра в прод-образе

Снятие строки из build-стадии обнажило сцепку: runtime-стадия несла
`COPY --from=build /app/scripts/llm-probe.mjs`, то есть сборка упала бы на копировании
несуществующего файла. Проверка сцепки привела к настоящей находке.

`scripts/lib/dreams-tick.mjs:19` — **статический** импорт `../network/lib/classify.mjs`.
Правка 07.08 (`e3c0fb59`, #1773) добавила этот файл **только в build-стадию** (строка 36) и
не перенесла в runtime-стадию, которая ведёт свой отдельный список `COPY`. В образе,
собранном из `main`, файла нет — первый вызов снов падает `ERR_MODULE_NOT_FOUND`.

Не сработало лишь потому, что офис после 07.08 не пересобирался: `office.mmbrn.tech/health`
на 08.08 даёт uptime ≈ 8.8 суток, `GET /v1/dreams/digest/2026-08-08` отвечает `200` — живой
контейнер несёт код, где `classify` ещё не импортировался. Дефект был **заряжен** и ждал
ближайшего деплоя. Починка 07.08 оказалась половинной, и класс сработал второй раз молча.

## Поправка к замеру 08.08 — назвать, а не замолчать

Утренний замер дал «расхождение 0» и был **неполон**: он строил граф против списка
**build-стадии**. У runtime-стадии свой список, и расхождение живёт именно там. Отчёт по
иссью на этот счёт исправлен. Вывод для канона: у многостадийного Dockerfile столько
манифестов, сколько стадий, и проверять надо итоговый образ — что смоук блока 1 и делает.

Это же наполовину снимает аргумент против сторожа графа импортов: сторож поймал бы дыру,
только если бы сверял ОБЕ стадии. Смоук оказался сильнее не по случайности — он смотрит на
собранный артефакт, а не на список.

## Сделано

- Снят `COPY scripts/llm-probe.mjs` из build-стадии и `COPY --from=build … llm-probe.mjs`
  из runtime-стадии — балласт по замеру, ни один копируемый модуль его не импортирует
  с 07.08.
- Добавлен `COPY --from=build /app/scripts/network/lib /app/scripts/network/lib` — закрывает
  заряженную дыру.
- Комментарии переписаны под новое положение: полнота списка проверяется исполнением
  (`office-image-smoke.yml`), правило для будущего правщика названо явно — «добавляя модуль,
  ничего больше делать не нужно; удаляя — дождись зелёного смоука».

## Гап

Локальной сборкой не проверено: docker daemon на машине не запущен. Обе правки проверяются
CI-смоуком блока 1 на этом же PR — он собирает образ и поднимает контейнер, поэтому
`missing-module` был бы виден до мерджа. Деплой офиса — отдельным шагом после мерджа,
процедурой `deploy-office-vds` (слово владельца 08.08).
