## 1. Опись снимка дня — выходит или получает вторую форму

**Верно выходит.**

Причина: список артефактов (`deliver-list-flags`) — это **реестр вещей, которые идут в ствол через сделку «проверка свежести»**. Проверка — это `<!-- Сгенерировано: … -->` в Markdown. JSON снимка этой проверки не проходит по определению: JSON **не** содержит комментарии в этом формате.

Давать ему вторую форму провенанса (например, читать `dayKey` и `archivedAt`) значило бы:
- завести **второй движок валидации** (по датированности вместо комментария);
- позволить JSON жить по другим правилам, чем остальные артефакты;
- размыть **один контракт** («свежесть = дата в комментарии файла») до **двух** — это нарушение лексической точности.

JSON снимок — отдельный артефакт, который управляется **другой процедурой** (архивированием в `media`). Он не входит в `deliver-list-flags`.

**Вывод: + верно.**

## 2. Признак `when` в записи артефакта — на месте ли

**Нет, это хромает.**

Причина: `deliver-list-flags` — это **описание что**, а не **описание когда**. Каждая запись должна отвечать на вопрос: «Какой артефакт идёт в ствол?»

Признак `when: 'bridge-open'` — это **условие доставки**, которое касается **логики движка** (`ritual-deliver-to-main.mjs`), а не реестра вещей. 

Правильнее:
- `deliver-list-flags` содержит **безусловный** список (конспект либо есть, либо его нет — факт, не условие).
- **Условность** — это дело **движка доставки** (блок 2), где уже лежат решения типа «если мостик открывали, включи проверку».

Перейти на `when` в реестре — это стушевать **разницу между описанием** (реестр) и **исполнением** (движок). Список теряет однозначность.

**Вывод: нет, признак не на месте. Выносить в движок доставки (блок 2).**

## 3. Перенос записи целиком (`...a`) вместо двух полей — не протечка ли

**Протечка есть, но она вторична относительно проблемы выше.**

`...a` копирует **всё**, что было в исходном объекте. Если исходная запись содержала поля, которые не должны быть в финальном списке (внутренние служебные, временные флаги), они проскочат в ствол.

Правильнее:
```js
{ rel: a.rel, label: a.label }  // или деструктур
```

Это явно, закрывает ровно то, что нужно, и защищает от случайной протечки.

**Но:** прежде всего нужно решить **основное** — вернуть условность в движок (блок 2), а реестр очистить до безусловного списка фактов.

**Вывод: верно переделать на явный выбор двух полей, но это следствие архитектурной ошибки выше.**
