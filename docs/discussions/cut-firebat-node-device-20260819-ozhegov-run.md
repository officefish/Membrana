# Конспект резчика — firebat-node-device (Ожегов, 19.08)

> Прогон контекста резчика через `yarn ask ozhegov` в четыре захода (флаг `--save` конспект
> не записал — находка тулинга, конспект восстановлен координатором из ответов дословно по
> смыслу). Подпись нарезки без следа запрещена инвариантом процедуры — это и есть след.

## Заход 1 — уточнение предмета
Резчик спросил: физический узел или device-board/agenda; транспорт — интернет или LoRa/mesh.
Ответ координатора: физический узел Firebat (Windows Home за роутером, пишет 48 кГц,
отправляет сам), логическое представление уже есть (устройство field-node-2026-08 на media);
транспорт — только исходящий поверх интернета: poll · WebSocket · обратный туннель.

## Заход 2 — леммы и критерии
Леммы: узел (физический хост) · устройство (запись) · исходящий канал (направление
инициативы, не транспорт) · транспорт (носитель) · наблюдение (что уезжает).
Критерии транспорта: poll — NAT прозрачен, задержка = период опроса; WS — near-realtime,
нужен reconnect и состояние сокетов; туннель — обслуживание, не данные. Ставка резчика до
уточнений: WS для наблюдений. Два уточнения: бюджет задержки; приёмник — media или новый
transport-service.

## Заход 3 — ответы и семь блоков
Координатор: near-realtime в этом спринте не требуется (узел — сборщик записей для
калибровки; команда «снять пробу» терпит секунды) → poll достаточен; приёмник — background-
media (там устройства, коллекции, приём WAV). Резчик дал семь блоков: adr · key-contract ·
wire-dto · home-module · amplifier-satellite · installer · observability; риски связанности
(media/firebat не импортируется из клиента и детекторов; ключ узла ≠ nodeId наблюдения).
Две поправки координатора: «усиление+спутник» — это ручка gain + файл-спутник записи, НЕ
модуль (резчик понял как poller/буфер/GPS); персоны только из реестра голосов (fedorov,
musician не существуют). Ответы: установщик — первая сборка apps/membrana-studio + служба;
poller — однофайловый скрипт без зависимостей (класс field-capture.mjs).

## Заход 4 — подтверждение формы
Резчик подтвердил семь блоков b1–b7 с пятью словарными оговорками, все приняты в план:
(1) ADR фиксирует леммы одним списком, «ключ узла ≠ nodeId» отдельным абзацем;
(2) исходы poll — закрытый словарь ok | stale_key | backoff, без синонимов, единый на тракт;
(3) граница дома — packages/background-media/src/modules/firebat-node/ с экспортом через
index.ts, devices не просачивается; (4) PowerShell установки службы — в scripts/ монорепо,
не в apps/membrana-studio; (5) спутник — шаблон в docs/field/firebat-node.md (одна строка
на запись), чтобы приёмка ссылалась словом.
Порядок b1 → b2 → b3 → b4 → b5, b6 параллельно, b7 замыкает — согласован.
