# Нарезка s-queue-2026-08-11 — конспект резчика (vesnin, 11.08)

Прогон контекста резчика по промпту `docs/prompts/S_QUEUE_2026_08_11_PROMPT.md`
и вещдокам аудита 11.08 (`docs/audit/tasks/analysis/registry-audit-2026-08-11.md`).

## Маршрут: спринт, не шоты

Слово владельца — «делаем сначала s», семь строк. Анти-цепочка шота
(`evaluateOneShotS`: ≤3 выстрела / ≤8 файлов / ≤200 строк суммарно за 7 суток)
делает красный на семи строках предсказуемым до первого выстрела. Штамп 10.08
(«прогонять S ради предсказуемого красного = церемония») применяется дословно —
маршрут спринт, прецедент `s-queue-tail-2026-08-10`.

## Решения нарезки

1. **Блок = строка очереди.** Семь строк — семь блоков; каждый закрывает свою
   карточку реестра архивом со свидетельством. Слияние строк в общие блоки
   («все доки одним блоком») отвергнуто: у строк разные предметы и разные
   исполнители, общий блок размыл бы honest_pair.
2. **Порядок: b1 первым, но НЕ гейтом.** Уточнение прогона контекста
   ([запись](cut-s-queue-20260811-vesnin-run.md)): зубы b2–b6 — `node --test`
   по корневым скриптам, резолюция `@membrana/*` им не нужна — жёсткой
   зависимости от b1 нет. b1 — самостоятельный вердикт среды с явным
   контрактом: вход — инвентарь симлинков, выход — honest_pair на вещдоке
   (инвентарь до/после + зелёный однопакетный typecheck office/harmonic),
   инвариант — node_modules в дифф не входит, зона — только коммитуемые файлы.
   Первым идёт по цене ошибки (среда врёт всем), не по зависимости.
3. **Исполнители по природе находки:** кодовые швы (b2, b3, b5, b6) — контекст
   dynin (инструментальный слой, scripts/lib); среда и политика (b1) — dynin с
   вердиктом в CONTRIBUTING; слова и нормы — контекст ozhegov. Обе грабли b7
   одной природы (лексической: ASCII-семантика `\w`/`\b` в регулярке и сверка
   латинских имён с русскими склоняемыми — обе про сверку текста, не про
   поведение процесса) — смешанного контекста нет, блок один. Провод
   регенерации реестра (b4) — dynin; потребитель реестра назван: снимок
   `SCRIPTS_LIST.md` читают tooling:overview-контур и грабля дрейфа #1265 —
   b4 не висит.
4. **b5 остаётся S, guard — в блоке:** обёртка над готовым ядром
   `secret-redact.mjs`, не новый резак. Guard записан в //dod блока (не только
   в сопроводиловке): любая правка самого ядра = стоп и перерезка, не
   продавливание S-ярлыка.
5. **Зоны узкие, package.json — только строки глаголов.** Общий корневой файл
   в зонах b4 и b5 — по одному глаголу каждый; конфликт исключается порядком
   исполнения (b4 раньше b5 или наоборот — безразлично, строки разные).
6. **node_modules вне git** — b1 меняет невидимое для диффа состояние; его
   honest_pair держится на вещдоке (вывод инвентаря до/после + зелёный
   однопакетный typecheck), зона в плане — только коммитуемые файлы.

## Вне предмета (переподтверждено)

Сервера нет ни в одном блоке. Магистраль дня и `tw-declared-verbs-honest-no`
не входят. Правка чужих деревьев (`Membrana-grok`) запрещена — b1 чинит СВОЁ
дерево (симлинки локального node_modules), чужое не трогает.
