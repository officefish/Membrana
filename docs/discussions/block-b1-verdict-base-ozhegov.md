   - Совпадающие `sha` + совпадающие `base` → `pass`.
   - Совпадающие `sha` + разошедшиеся `base` → `unknown/verdict-base-drift` (порядок: раньше truncated).
   - Старый маркер (`base` отсутствует) → `unknown/legacy-verdict-without-base`, никогда `pass`.
   - `currentBase` недоступна → `unknown/base-verification-unavailable`.
   - Порядок веток зафиксирован тестом: `sameSha=false` побеждает `base-drift`, `base-drift` побеждает `truncated`, `truncated` побеждает BLOCK, BLOCK побеждает pass — пять фикстур, по одной на переход.

**Место ветки** — верное. Между `sameSha` и `scope.truncated`: сначала «тот ли head», потом «та ли база», потом «весь ли объём». Порядок от грубого к тонкому, без пересечений смыслов.

**Ядро без git** — да, `currentBase` параметром. Сервис остаётся чистым, побочные эффекты у вызывающего. Норма соблюдена.
