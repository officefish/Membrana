# Контекст резки — вёрстка кабинета, замечания владельца 23.08

| Поле | Значение |
|---|---|
| источник | замечания владельца по итогам первого боевого прогона чарт-листа |
| резчик | rodchenko (вёрстка) |
| предмет | пять замечаний о вёрстке кабинета, не о чарт-листе |

## Пять замечаний дословно

1. Нужно кликать по наименованию плагина, чтобы появился виджет — **лишнее действие**.
   Активной галочки в списке плагинов должно быть достаточно.
2. Не нравится **дополнительный скроллбар** в основном списке журнала — его быть не должно.
3. Должна быть **кнопка над списком**, сворачивающая основной список журнала.
4. Оба списка равны по ширине; **поле для плагинов забирает всё пространство** и не скроллится.
5. **Левый основной сайдбар** тоже не должен скроллиться.

## Два уточнения, взятые до кода

**Что при двух включённых плагинах.** Гнездо под основным блоком было одно, потому что показ
выбирался кликом. Со снятием клика вопрос встаёт впервые. Ответ владельца: **показывать всех
стопкой**, один виджет под другим.

**Что значит «поле для плагинов забирает всё пространство».** Ответ владельца: **виджет списка на
всю ширину** — список выборки растягивается вровень со списком журнала. Сайдбар настроек остаётся
узким справа.

## Что этим отменяется — названо, а не обойдено

Почва разводила **включённость** и **показ** намеренно: включённость есть операция реестра дома
(M5′), показ — дело страницы. Разведение снимается **словом владельца**: лишнее действие названо
лишним, и владелец вчера действительно не смог найти показ — плагин был включён, а виджета не было.

Дом по-прежнему владеет включённостью; меняется только то, что страница из неё выводит.

Вместе с этим падает второе правило почвы: **«свернуть основной блок нельзя, пока нет виджета»**.
Оно держалось на том, что сворачивать имеет смысл только ради виджета. Замечание 3 говорит
обратное: сворачивать список — самостоятельное желание. Правило снимается, зуб переписывается.

Оба правила отменяются, а не ломаются: за ними стоит слово владельца, а не забывчивость.

## Почему отдельным спринтом

Замечания касаются **вёрстки кабинета в целом**, а не чарт-листа: скроллбары журнала и левый
сайдбар существовали до плагина и переживут его. Смешать их с починкой измерения значило бы
получить нарезку, где одна половина про числа, а другая про пиксели, и ни одну нельзя закрыть
отдельно.

Выкатка — общая, одна на оба спринта.
