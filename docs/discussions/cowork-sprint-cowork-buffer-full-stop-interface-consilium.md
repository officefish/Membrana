## Что дала изоляция — находки, которых не было в постановке

1. **Пакет словаря — не `core`.** Бриф назвал замер (`background-media` не зависит от `core`),
   A выбрал `plugin-contracts` и объяснил цену: ноль строк в общих файлах, кроме бареля. C ждал
   `@membrana/core` — ровно тот случай, ради которого шов оставлен открытым; гасится заменой
   импорта и двумя строками зависимостей.
2. **Статус ответа нельзя выставить декоратором.** A нашёл кодом: `@HttpCode` не работает, потому
   что `FastifyAdapter.reply()` ставит статус маршрута ПОСЛЕ хендлера; ручка отвечает через
   `@Res()` и явный `reply.status(200|201)`. Для C это стало правилом «судить по телу `ok`, не по
   коду» — и C независимо построил разбор именно так.
3. **Эпизод — на субъект, не на прибор.** A ключует эпизод `deviceId × subject`: буфер и
   хранилище одного прибора — два независимых факта с двумя id. C строил «один эпизод на
   прибор». Конфликта нет благодаря I5: при удержании POST = 0, второй id физически не приходит;
   но контракт это называет явно (I6), а не оставляет в коде.
4. **Скалярная колонка на `Membrane` ломает чужой модуль.** B обнаружил: любая новая колонка
   `Membrane` в кабинете роняет перегрузку `requireOwnedMembrane` в `sample-library.service.ts`
   (TS2394). Обошёл таблицей `MembraneBufferPolicy` — и это оказалось лучшей моделью (строка на
   мембрану с `binding`, отсутствие строки = `stop`). Хрупкость записана долгом X-2.
5. **Носитель эпизода — память процесса.** A назвал носитель в CONCEPT, а не решил молча (как
   требовал бриф): рестарт media = новый `overflowId`. Порт `OverflowEpisodeStore` оставлен под
   долговечную реализацию; B такую таблицу не строил (в его EXPECTATIONS её нет — A просил
   «опционально»). Принято как ограничение спринта с долгом I3; владельцу — знать.
6. **Шов зеркала внутри клиента.** C нашёл сборкой: панель плагина говорит по локальному
   `bufferPolicy` (умолчание `auto-cleanup`), а носитель судит по эффективной политике
   (умолчание `stop`) — до интеграции возможна картинка «панель говорит „автоочистка“, прибор
   удержан». B независимо написал то же требование с другой стороны («плагин перестаёт быть
   хозяином»). Бриф отдал это интеграции заранее — адаптер BC-2.
7. **Репродукция гипотезы обрыва закрыта зубом.** C: 30 минут живого heartbeat без импорта клипа
   → 0 строк `telemetry-track/v1`; один импорт → одна строка. Вещдок (2) вердикта M4 есть в
   коде, не в словах.
