# a2 · Дынин · контракт запуска

**Предмет:** JSON-safe вход, исход, inputHash, лимит и именованные отказы batch-run.

Контракт закреплён в `plugin-contracts`: исход содержит результат каждой пробы и агрегат, а
отказы различают пустой набор, ошибку чтения, недоступный детектор и превышение лимита.
Fingerprint строится существующим `inputHashOf`, без второго адресного носителя коллекции.

**Evidence:** typecheck `plugin-contracts`; тесты executor 7/7 проверяют пустой вход, лимит,
недоступность анализатора, локализованную ошибку чтения и стабильность fingerprint.

**Gap:** транспортный тип media-library зеркалит канон вручную; отдельная зависимость пакета на
`plugin-contracts` не вводилась ради одного DTO.
