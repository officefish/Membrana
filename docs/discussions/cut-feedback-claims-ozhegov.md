## Термины (иначе поплывём)

- **Класс** — предикат «что это»: `symbol`, `path`, `card`, `pr`, `doc`, `verb`, `literal`.
- **Адрес проверки** — файл/индекс, где класс имеет право искать факт.
- **Вердикт** — `holds | violates | unknown`; `unknown` не красный.

## Ответы по развилкам

1. **Классы v1 (пять, оффлайн):** `symbol` (grep по `packages/**/src`), `path` (fs-exists), `card` (`docs/tasks/registry.json`), `doc` (fs-exists в `docs/**`), `verb` (whitelist `package.json` scripts). Всё остальное — `unknown`. Классификатор — таблица правил по форме токена + чек по адресу; неоднозначность (символ ИЛИ путь) → **два прогона, любой `holds` побеждает**, оба `violates` → `violates`, иначе `unknown`.

2. **«Использование символа» — берём, жёлтым.** Подкласс `symbol.used-outside-def`: rg по имени, вычитаем файл определения; ноль — жёлтый (`violates.soft`). Красный не ставим: символ существует, ложь тонкая, и риск ложной тревоги выше, чем на классе `symbol.exists`. Прецедент 03.08 — ровно про это.

3. **PR-содержимое — `unknown` в v1.** Сеть в вечернем гейте = флап от офиса (долг `office-unstable-933` живой). Класс `pr` v1 проверяет только формат `#\d+` и наличие в git-логе мерджей; содержимое — отдельным долгом, когда появится офлайн-кэш PR.

4. **Оба, но раздельно.** Секция `## Probe: проверка утверждений` в хвост протокола — всегда (адрес + SHA по строке DoD). Блокировка ласточки — только при ≥1 `violates` (hard, не soft): предикат `evening:gate` читает секцию. Жёлтые (soft) и `unknown` ласточку не держат — иначе гейт врёт про враньё.

5. **Не роняет.** Probe пишет секцию и возвращает exit 0 всегда; ронять протокол нечем — он уже сгенерирован. Останавливается **отправка**, не цепочка. Это тот же контракт, что у утреннего probe (НЕ ЧИНИТ, НЕ РОНЯЕТ).
