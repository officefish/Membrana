**Ответ:**

Отвечаю по существу, коллизия за коллизией. Держим норму: «держатель кадра» — это роль в словаре манифеста, а не «кто нажал кнопку в конкретном прогоне». Смешивать эти два значения нельзя — это как раз тот случай, где одно слово тянет два смысла.

**1) Форма по коллизиям**

- **execute:** беру вариант (а) — `holder: tarasov` + поле `note` (или `assigns: executor`). Определение: держатель кадра execute — тот, кто **актом называния** назначает исполнителя; сам исполнитель прогона — это `executor` в записи прогона (зона M2). Вариант (б) с Весниным ложный: `leadPersona` — «первый кадр», а не «назначение», подменять смысл нельзя. Вердикт M1 не искажён: три точки записи сохраняются.
- **owner-ratify:** оставляем **гейтом**, не кадром. `waitsFor: owner` уже есть, resume гейта и есть вторая точка записи. Кадров два (first-frame, execute), точек записи три (first-frame → resume(owner-ratify) → execute). Это чище и словарно честнее: «утверждение владельцем» — не работа персоны из закрытого списка, а условие перехода.

**2) Шаги first-frame и ядровые ключи**

Кладу `steps` (find · stamp-s · predicate-s · checklist) **прямо в объект кадра** — валидатор лишние поля кадра пропускает, чек-лист остаётся при кадре, как и велит M1. Ядровый `steps` **убираю совсем**: `trigger` и `gates` остаются — двух ключей из трёх достаточно, находки не будет. Это и корректнее по смыслу: «шаги» здесь — шаги первого кадра, а не самостоятельная фаза процедуры.

**3) Что обязано быть в README**

- Раздел «Словарь ролей прогона» с двумя разведёнными терминами:
  - **Держатель кадра execute** (`tarasov`) — назначает исполнителя, отвечает за акт называния; живёт в `MANIFEST.json`.
  - **Исполнитель прогона** (`executor`) — тот, кто фактически прошёл кадр; живёт в записи прогона, фиксируется по вердикту M2.
- Явная фраза: «`holder` в манифесте ≠ `executor` в записи прогона».
- Пояснение, почему `owner-ratify` — гейт, а не кадр (owner вне PROCEDURE_PERSONAS; акт утверждения — условие, не работа персоны).
- Список трёх точек записи в общую ленту с указанием их источника (два кадра + resume гейта).

Уточнение, пока не начал править файлы: подтверди, что имя поля назначения в кадре execute — `assigns: executor` (читается как словарная статья), а не `note` (слишком общий термин, тянет любые смыслы).
