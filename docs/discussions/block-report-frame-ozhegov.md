## 2. Кадр или достаточно шага?

**Ответ: шага достаточно.**

**Причина:** Кадр нужен, если единица **переиспользуется** в разных процедурах или служит **границей ответственности** между ролями. Доклад капитану — одноразовый акт утренней магистрали, не абстрактная многоприменяемая процедура. Шага хватает.

Кадры остаются: `night-report` · `repo-hygiene` · `canon-cascade` · `magistral-gate` · `deliver-to-main`. Если позже понадобится отдельная процедура «подготовка доклада» — тогда выделяем кадр и извлекаем шаг туда как модульный.

## 3. Обязательный вызов зуба: где и как

**Место встаёт:** Внутри исполнения шага `owner-checklist`, как **pre-condition gate**.

**Форма:**

```json
{
  "id": "owner-checklist",
  "kind": "mechanic",
  "criticality": "critical",
  "pre": {
    "gate": "run-report-check",
    "script": "yarn report:check",
    "onFail": "block_step"
  },
  "label": "Доклад капитану: …",
  "verify": "чеклист собран по MORNING_REPORT_FORMAT.md, `yarn report:check` выполнен успешно, доклад отправлен до свайлоу",
  "produces": ["morning-report-artifact"],
  "blocksOn": "main-day-issue"
}
```

**Что происходит при находке в `yarn report:check`:**
- Скрипт возвращает **exit code ≠ 0** и выдаёт дифф-отчёт (`found issues in: …`).
- Шаг блокируется, не переходит на `ally-swallow-draft`.
- Исполнитель (ты) получает квитанцию `rejected_precondition` с `reasonCode: report_format_invalid` + path к находкам.
- Действие: амендировать чеклист и повторить шаг.
