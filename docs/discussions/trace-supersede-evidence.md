# Вещдок #1638: изъятие следа прошло без следа — и почему дверь открывается временем, а не фактом акта

Блок `evidence-note` спринта `gate-stale-supersede-by-recut` ([#1638](https://github.com/officefish/Membrana/issues/1638)).

## Вещдок иссью, усиленный разведкой 03.08

Иссью описывает тупик на спринте `subconscious-lift-c3` (блок `lift-retrieval-port`, 02.08):
после честной перерезки и перепрогона контекста гейт дал `stale_partial` при свежей полной
паре, и строку протухшего следа пришлось изъять из ленты руками.

Разведка перед нарезкой проверила изъятие по git-истории — и нашла хуже заявленного:

```bash
git log --all --oneline -S 'tr-port-vesnin-run-v1' -- docs/sprint/trail/subconscious-lift-c3.jsonl
# ожидание: пусто (0 коммитов) — строка не существовала в ленте ни в один момент истории

grep -c "recut_act" docs/sprint/cut/trail/subconscious-lift-c3.jsonl
# ожидание: 0 — перерезка актом не записана
```

Обе команды прогнаны при чеканке этой ноты (03.08, ветка спринта): обе дают ноль.

**Изъятая строка `tr-port-vesnin-run-v1` не существует даже в git-истории**: ленту почистили до
первого коммита. Самый опасный приём — правка ленты вещдоков руками — не оставил следа нигде,
кроме прозы в иссью. И второе: в ленте актов того спринта **нет `recut_act`** — перерезку тоже
не записали. Тупик не просто опасен; он уже дважды сработал молча в одном эпизоде.

## Почему дверь открывает ВРЕМЯ акта, а не факт акта

Это несущее решение спринта (слово резчика 03.08), и оно записано здесь затем, чтобы через
полгода его не «упростили».

Условие отзыва протухшего следа: `t_stale.at ≤ recut_act.at ≤ revisionAt(block)` — акт лежит
**между** протухшим следом и ревизией предмета, то есть судит именно тот контракт, который
след успел застать.

Голый факт «в ленте актов есть `recut_act` этого спринта» был бы дырой трижды:

1. **старый акт легализует всё** — единожды записанная перерезка распахивала бы дверь на весь
   спринт навсегда, и отзыв стал бы неотличим от изъятия по последствиям;
2. **чужая перерезка отзывает чужие следы** — акты не несут `blockId` (они про план целиком),
   и блочность держится только временной сверкой: у блока с прежней ревизией окно
   `[след, ревизия]` другое, акт свежей перерезки соседа в него не попадает — доказано зубом;
3. **изъятие остаётся выгоднее** — если дверь открывается слишком легко, дисциплина записи
   актов не вырастает; если только точным актом — запись акта становится единственной дорогой.

Требование «свежий след после акта» отдельной проверки не требует: свежесть определена как
`t.at ≥ revisionAt`, а `revisionAt ≥ act.at` уже входит в формулу.

Допуск ε = 0 сознательно: старые ленты с грязными метками времени (Z-суффикс на местном
времени — такие есть в лентах 02.08) дверь не откроют, и не должны: дверь для будущих
перерезок с честными метками, а не амнистия задним числом.

## Что дверь НЕ ослабляет — три зуба-часовых

| случай | вердикт | зуб |
|---|---|---|
| протухание без акта | `stale_partial`, как раньше (#1566) | «без акта — прежний stale_partial» |
| перерезал и не перепрогнал | `stale_trace`, как раньше | «дверь открывает только перепрогон» |
| отозвали, но свежий след один | `incomplete_trace` (#1641) | «после отзыва состав судится полной строгостью» |

Отзыв — всегда **поимённая дисквалификация** (`eg-superseded-by-recut`) с причиной в отчёте:
лента неприкосновенна, аудит остаётся. Ровно этим он отличается от изъятия, которое не
оставляет ничего.
