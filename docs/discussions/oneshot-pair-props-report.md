## Сделано

**Свойство 1 — порядок внутри пары.** Находка `eg-order-review-before-run`: ревью раньше
ПЕРВОГО прогона контекста того же субъекта. Семантика «первого» несущая (слово Ожегова):
«последнего до ревью» тихо разрешал бы «прогнали → отревьюили → прогнали ещё раз» — это другое
свойство, закрытое композицией. Попутно словарная правка: `ORDER_REVIEW_EARLY` →
`ORDER_REVIEW_BEFORE_SIGN` — «early» не несло опоры «раньше чего», и с появлением второй
точки стало бы неразличимо. Пара находок различается опорной точкой: sign | run.

**Свойство 5 — ревизия между следами пары — СНЯТО из списка пределов.** Зуб-сценарий закрепил:
`run → перерезка → review` не даёт `honest_pair` ни одной дорогой — без акта `stale_partial`,
с актом дисквалификация и `incomplete_trace` (нужен новый прогон). Композиция #1641 + #1638
закрывает свойство без новой механики.

## Замер порядка пары (секция pair-order)

Команда: обход `docs/sprint/trail/*.jsonl`, по блоку — первый `context_run` субъекта против
каждого его `review_pass`.

```
лент: 33 · блоков: 140 · ревью раньше первого прогона: 1
  one-shot-recut.jsonl · shot-predicate-moments · tr-b3-dynin-review
```

**Вердикт по замеру: канала находки достаточно.** 1 из 140 — редкость; поднятие до вердикта
не предлагается. Единственный случай — свежая лента соседней сессии от 03.08: находка теперь
скажет об этом вслух при её гейте. Если частота вырастет — поднятие до вердикта отдельным
решением владельца, с замером перекраски, как у девятого.
