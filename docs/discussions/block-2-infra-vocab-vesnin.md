# Блок 2 `infra-vocab-and-teeth` — прогон контекста Веснина

**Спринт:** `llm-probe-still-lies-net` ([#1804](https://github.com/officefish/Membrana/issues/1804)).
**Исполнитель:** vesnin. **Дата:** 2026-08-08.

## Поправка к замеру спринта — названа, а не замолчана

Замер объявил `infra-policy` **третьим словарём исходов**. При чтении кода это оказалось
неточным: словарь жил только в JSDoc функции `linkStatus`, а сам код никогда его не
разбирал — он различает `ok` / `skipped` / всё прочее и красит. То есть третьим словарём
файл был **на вид**, для читателя, а не на деле. Это меняет предмет блока: не «свести
словарь», а назвать вещь своим именем — таблица представления, а не суждение о причине.

Зато мест, где слово `net` писалось руками, в `infra-probe` нашлось **четыре**, и одно из
них было прямой ложью: отказ `gh api` (нет авторизации, нет бинаря, исчерпан лимит) звался
сетью, хотя сеть там никто не мерил.

## Сделано

**`tcpProbe`** различает причины, которые раньше звались одним словом: строка не URL →
`unknown_protocol` (зонд даже не начинался), молчание в срок → `timeout_idle`, имя не
разрешилось → `dns_fail`, отказ соединения → `tcp_fail`. Они чинятся по-разному — первое
правкой полиси, второе ожиданием, третье и четвёртое сетью, — и одно слово на четыре
причины и есть та ложь, которую снимает спринт.

**`http-health`** больше не лепит `http-N` и `net (…)`: статус уходит классификатору
(пришёл статус ⇒ транспорт работает), отсутствие ответа судится по коду ошибки.

**`gh-api`** при отказе даёт `unknown_protocol` — честное незнание вместо выдуманной сети.

**`no-key`** в двух местах заменён на `auth_missing_key`; вызов через прокси помечается
`viaProxy: true`, поэтому классификатор отличает «посредник не дошёл до цели» от ошибки
самого провайдера и не зовёт гео-блоком отказ через прокси.

**`infra-policy`**: JSDoc переписан — функция объявлена таблицей представления, принимающей
id исхода #1449. Поведение не менялось: менять его было бы работой сверх ратифицированной.

## Зубы

У `infra-probe` их было **ноль** — при том, что модуль импортирует классификатор напрямую и
решает, красное ли звено. Прибор без зубов судил инфраструктуру и не отвечал ни за одно своё
слово. Теперь их шесть, и они держат контракт словаря: ни одного литерала вне перечня #1449,
ни одного слова прежнего словаря, разделённые исходы TCP-зонда, отказ `gh` не зовётся сетью.

У `infra-policy` добавлен зуб полноты: **каждый** исход закрытого перечня получает
определённый цвет, ни один не проваливается в «не знаю». Пример с `dpi-block` в старом зубе
заменён — он учил отменённому слову.

**29/29 зелёных** по трём файлам блока.

## Живой прогон

`yarn infra:probe` по всем 13 звеньям: anthropic, openrouter (99.44 кр.), xai, deepseek
(49.75 USD), perplexity, office-vds, proxy-nl, github — `ok`; voyage — `known-blocked`
(отдельный статус, не зелёный); четыре звена — честный `skipped` с причиной. Ни одного
ложного `net`. `yarn infra:probe --summary` без сети тоже цел.
