- **#2009 — два блока, две персоны.** (7) smoke: `AppModule.compile()`-зуб в обоих сервисах +

- **Гейт секретов — один блок (ozhegov).** Дизайн-конфликт решается так: рез НЕ вливается в

  печатает резаное; exit по детектору не меняется) — «сканер имеет резак» выполняется буквально,
  две ответственности остаются разделёнными флагом, а не слиянием. Датированный проход — на
  грязной фикстуре (не прод), манифест `docs/security/rotation-manifest-2026-08-20.md`

  скрипты утра поле не читают — эскалация владельцу с ценой, не выдумывание формы).
- **PR:** вердикты — двумя PR по три (≈360 строк каждый, порог 400 держится); smoke+канон —
  один PR (#2009 в упоминании); гейт секретов — свой PR. Всего четыре.
