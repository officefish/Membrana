## Итог одной строкой

Из одиннадцати партий **восемь уже несли вердикт тимлида**, привязанный к голове PR;
непроверенных было **две** — обе прогнаны и обе LGTM. Одиннадцатая позиция вообще не
ревью-долг: это **локальный коммит, не доехавший до main**, и он утянул с собой архив дня.

## Как проверялось

Артефакты `docs/discussions/pr-*-code-review.md` в `.gitignore` — по ним судить нельзя:
они локальные и у соседней сессии их не видно. Источник истины — **commit status
`review/teamlead` на голове PR**, тот же, по которому пускает шип-гейт:

```
gh api repos/{owner}/{repo}/commits/<headRefOid>/status \
  --jq '[.statuses[]|select(.context=="review/teamlead")|.state]|first'
```

## Почему счёт разошёлся

Снимок смешал два разных факта: **«диффа нет в дневном дайджесте»** и **«ревью не
было»**. Первое верно для всех одиннадцати — дайджест их не разворачивал. Второе верно
для двух. Сам риск в снимке сформулирован точно («merge-уверенность только после
`code-review:pr` **или уже прошедшего CI+human LGTM**»), но в строку DoD ушёл список из
десяти номеров без различения — и наутро долг выглядел в пять раз больше настоящего.
