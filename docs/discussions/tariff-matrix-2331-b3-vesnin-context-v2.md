## 2026-09-08 16:56 UTC · vesnin

**Контекст:** GitHub Issue #2331: «Матрица тарифов как единственный источник правды: гранулы по ресурсу + шаблон в контейнере strategic-docs, сетка — производная (сессия Б, спринт)»
**Вопрос:** Прогон контекста по РАТИФИЦИРОВАННОЙ версии плана tariff-matrix-2331 для блока b3 matrix-template-release (ты — ответственный контекст; ратификация владельца 08.09 19:54 после перерезки b3: в зону добавлен движок scripts/strategic-docs-generate.mjs + зуб). Причина перерезки: движок склеивал тела гранул через пустую строку и не подставлял их в каркас шаблона (против дизайна контейнера «каркас остаётся в шаблоне» и твоего слова «шапка таблицы в skeleton»), таблица рассыпалась; лечение — renderBody: renderBySkeleton(template) (готовый рендер по каркасу из tasks-readme-engine), зуб регрессии: шаблонам из одних плейсхолдеров подстановка даёт тот же текст с точностью до пустых строк, матрице — таблицу вплотную к шапке, порча «вернуть склейку» → красный. Старые релизы (readme-main, development-matrix, affine-surface-policy) изменились только пустыми строками. Подтверди или поправь конструкцию: (1) правка движка в этом спринте — уместна ли или это отдельный билет; (2) риск для других потребителей движка (tasks-readme использует свой renderBySkeleton — тот же); (3) версия релиза = pins, указатель короткий, meta.surface только github. Коротко, вердикт формы.

**Ответ:**

Конструкция принимаю как есть. Правка движка в этом спринте уместна: это не побочный рефакторинг, а необходимое условие DoD b3 — «матрица собирается шаблоном». Отдельный билет создал бы разрыв между формой (каркас в шаблоне) и реализацией, ровно тот случай, когда граница пакета обязана следовать функции.

Риск для других потребителей оцениваю низким: renderBySkeleton — общий механизм, «старые релизы изменились только пустыми строками» — это приемлемый шум, не порча контракта. Единственное, что проверю на ревью: зуб регрессии ловит именно возврат к склейке, а не отсутствие рендера вовсе.

Версия = pins, указатель короткий, meta.surface только github — форма верная: релиз описывает источник, а не транспорты.

Вердикт: форма подтверждена, нужен ADR? Нет. Нужен консилиум? Нет. Затронутые модули: `scripts/strategic-docs-generate.mjs` (движок), контейнер strategic-docs (шаблон, гранулы), зуб сверки.
