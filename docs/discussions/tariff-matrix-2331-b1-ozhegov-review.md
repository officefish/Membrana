**Вопрос:** Ревью по заявке о готовности блока b1 matrix-passport-storage спринта tariff-matrix-2331 (ты — ответственный контекст; вердикт бинарный: pass | fail с причиной). Проверь по коммиту 950f98a3 в ветке feat/tariff-matrix-2331: docs/containers/strategic-docs/design/TARIFF-MATRIX-DESIGN.md (схема resource.json, закрытые списки domain/kind/reseedRule, правило «тариф — колонка, ресурс — строка»), scripts/lib/tariff-matrix/passport.mjs (parseResource, renderRow, закрытые списки, mibToBytes) и passport.test.mjs (25 зубов, 16 порч, три зуба на живых файлах), гранулы tariff-matrix-purpose (literal, линза Ожегова), tariff-buffer / tariff-collections / tariff-cold (resource.json с паспортом версия/ratifiedAt/owner/source/note, значения 512/2048/4096 МиБ по T1; cold 0/2048/2048 не закреплено). Твои требования из прогона контекста b1: слово не лжёт (collections ↔ storage.hot назван явно), reseedRule закрыт, единица МиБ с пересчётом в одном месте, домен — ось. Скажи: (1) выполнены ли они, (2) где слово всё ещё лжёт или паспорт неполон, (3) вердикт.

**Ответ:**

**Контекст.** Проверяю блок b1 матрицы тарифов: гранулы как единственный источник правды, схема resource.json, закрытые словари, единица МиБ.

**Решение.** Разбираю по своим требованиям.

Сначала — термины. «Тариф — колонка, ресурс — строка» — здесь подвох: ось у нас домен. В грануле `tariff-cold` паспорта нет (`ratifiedAt`, `owner` отсутствуют), значение `0/2048/2048` помечено «не закреплено» — это не гранула, а **заготовка**. Слово «паспорт» в заявке лжёт: паспорт — это свидетельство закрепления, а незакреплённое — не паспорт, а черновик.

Дальше — `collections ↔ storage.hot`. В `tariff-collections` связь названа явно — здесь чисто. `reseedRule` закрыт — чисто. Единица МиБ с пересчётом в `mibToBytes` в одном месте — чисто.

Но: три зуба на «живых файлах» из 25 — маловато, если живой файл — это `tariff-cold` без паспорта. Зуб на незакреплённом файле проверяет порчу, а не контракт.

**Затронутые пути:**
- `docs/containers/strategic-docs/design/TARIFF-MATRIX-DESIGN.md`
- `packages/strategic-docs/…/tariff-cold/resource.json` (черновик без паспорта)
- `scripts/lib/tariff-matrix/passport.mjs` + тесты

**Вердикт: fail.** Причина: требование «паспорт полон» для гранулы cold не выполнено — `ratifiedAt`/`owner` отсутствуют, значение не закреплено. Либо гранула с паспортом, либо это не гранула. Слово «паспорт» должно значить одно.
