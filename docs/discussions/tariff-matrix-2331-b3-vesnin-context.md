**Контекст:** GitHub Issue #2331: «Матрица тарифов как единственный источник правды: гранулы по ресурсу + шаблон в контейнере strategic-docs, сетка — производная (сессия Б, спринт)»
**Вопрос:** Прогон контекста перед блоком b3 matrix-template-release спринта tariff-matrix-2331 (ты — ответственный контекст). Предмет: шаблон docs/containers/strategic-docs/templates/tariff-matrix/template.json (skeleton с плейсхолдерами: purpose, затем строки таблицы «тариф × ресурс» из function-гранул ресурсов, примечания), релиз releases/tariff-matrix/ (README.md + release.json с pins) через yarn strategic-docs:generate, корневой указатель docs/TARIFF_MATRIX.md по образцу docs/DEVELOPMENT_MATRIX.md, строки в README/WORKSHOP контейнера. Вопросы: (1) таблица «тариф × ресурс»: строки — ресурсы, колонки — тарифы (T14: тариф — колонка); каждая гранула ресурса рендерит СВОЮ строку функцией — но шапка таблицы и разделитель должны быть в одном месте: в skeleton шаблона (литерал) или отдельной гранулой tariff-matrix-header? Как избежать, чтобы порядок колонок жил в семи гранулах; (2) release.json несёт pins по версиям гранул — достаточно ли этого как «версии матрицы» для пересева (b4 читает release.json → гранулы) или релизу нужен собственный semver в шапке README; (3) указатель docs/TARIFF_MATRIX.md — только ссылка на релиз и команду регенерации, или сюда же ссылку на глагол пересева и сетку; (4) нужен ли шаблону meta.surface strategy.mmbrn.tech при замороженной публикации. Коротко, по пунктам, вердикт формы в конце.

**Ответ:**

Конструкция. Вопросы по пунктам — сразу к форме.

**(1) Шапка и порядок колонок — в skeleton шаблона, литералом.** Гранула ресурса не знает о соседях; порядок тарифов — свойство композиции, а не ресурса. Семь гранул, каждая со своим порядком — это семь источников правды, декор без конструкции. Skeleton держит заголовок и порядок колонок, гранула возвращает только свою строку.

**(2) Release.json с pins — достаточно.** Пересев (b4) читает release.json → гранулы по версиям. Собственный semver в шапке README — избыточен: версия матрицы уже выражена набором pins. Один источник версии, не два.

**(3) В указатель — ссылку на релиз + команду регенерации.** Глагол пересева и сетку — нет: указатель ведёт к источнику истины, а не к производным. Сетка — предмет задания В, её контракт появится там.

**(4) Нет.** meta.surface нужен для публикации; публикация заморожена с 26.07 — пустое украшательство. Опустить.

**Вердикт: форма принята** — шапка в skeleton, pins как версия, указатель короткий. ADR не нужен, решение в рамках контейнера.
