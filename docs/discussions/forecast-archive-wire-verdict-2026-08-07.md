# Вердикт по проводу «предсказание ↔ исход» в архив персоны (долг `#forecast-record-no-wire-to-archive`)

**Дата разбора:** 2026-08-07 · строка 8 десятки дня.

## Формулировка долга неверна: провод есть

Долг говорит: «род записи построен, но **провода в архив персоны нет**». На 07.08 это ложь.

| Что | Где | Состояние |
|---|---|---|
| адаптер | `scripts/lib/sprint-experience/forecast-to-archive.mjs` | 9 экспортов, 230 строк |
| зуб | `scripts/lib/sprint-experience/forecast-to-archive.test.mjs` | есть |
| вызов на живом пути | `scripts/sprint-experience.mjs:351` — `toArchive([built.record], args.plan)` | есть |
| записи в архивах персон | `docs/virtual-team/memory/archive/tarasov.jsonl` | **14 записей класса `forecast`** |

Провод построен под #1590 и **доехал**: 14 записей за 01.08 (4), 02.08 (7), 03.08 (3),
покрывают 13 нарезок. Комментарий в коде (`sprint-experience.mjs:309`) прямо говорит
«долг `#forecast-record-no-wire-to-archive` закрыт этим шагом» — но в журнале попугая долг
всё это время числился `open`. Это тот же класс, что ловился 03.08: **маркер закрытия жил в
коде, а не в реестре.**

## Что «только Тарасов помнит» — не дефект

Первое подозрение при виде «14 у Тарасова, 0 у остальных пяти» — захардкоженный автор.
Проверено: `plan-to-forecast.mjs:40` берёт `personaId: plan?.cutBy`, а по 47 планам нарезки
`cutBy` = `tarasov` в **44**, `vesnin` в **3**. Атрибуция честная — это правда о том, кто режет.

Отсюда следствие, которое стоит назвать: **род записи по построению учит только резчика.**
Промахи ревьюера, гейта, автора блока в этот архив не попадают вовсе — не потому что провод
плох, а потому что предмет записи один: точность нарезки.

## Настоящий дефект: шаг ничем не обязателен и остановился

| Мерка | Значение |
|---|---|
| нарезок всего | 47 |
| нарезок с записью рода | 13 |
| **нарезок без записи** | **34** |
| последняя запись | **2026-08-03** |
| прошло с тех пор | 4 дня, включая сегодняшние нарезки |

Замер объёма — сырьё для записи — снят для 12 спринтов (`docs/sprint/experience/segments-*.json`),
журнала `forecast-records.jsonl` на диске нет вовсе.

Причина видна прямо:

- **Ни один гейт не требует записи.** Ни `task-closure-review`, ни `sprint-cut`, ни закрытие
  задачи не упоминают forecast. Закрыть спринт без записи рода — законно.
- **Есть штатный отказ без отчётности:** флаг `--no-archive` (`sprint-experience.mjs:81`)
  пропускает архив, печатая строку. Никто не считает, сколько раз им воспользовались.
- Шаг стоит последним в цепочке `sprint:cut → sprint:gate → sprint:experience` и теряется
  ровно так, как теряется любой необязательный хвост.

Поэтому «персона не запоминает свои промахи» — по итогу **верно**, но не по названной причине.
Провод есть; по нему три дня ходили и перестали.

## Что делать (решение владельца)

Предмет для следующего шота — предикат, а не провод:

1. **Гейт закрытия спринта требует запись рода** — либо она есть, либо назван отказ с причиной
   (как это уже сделано в `RESPONSIBILITY_WAIVER_REASONS` для гейта исполнения).
2. **`--no-archive` считается** — молчаливый отказ становится видимым.
3. Отдельным вопросом: 34 непокрытые нарезки — добирать задним числом (замер объёма для
   большинства уже снят) или считать окном, которое закрылось.
