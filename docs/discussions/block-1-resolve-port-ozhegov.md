# Блок 1 `resolve-port` — прогон контекста Ожегова

**Спринт:** `worktree-foreign-resolution-probe` ([#1647](https://github.com/officefish/Membrana/issues/1647)).
**Исполнитель:** ozhegov. **Дата:** 2026-08-08.

## Сделано

Глагол `yarn worktree:resolve` — провод к ядру, построенному 03.08 и четверо суток
недоступному. Корень дерева спрашивается у git (глагол зовут из любого места), пакеты
собираются из `node_modules/@membrana` с разыменованием симлинков, суждение выносит
`classifyResolution`.

Отказ порта отделён от вердикта кодами возврата: `0` — своя резолюция, `1` — чужая
(состояние дерева, не сбой прибора), `2` — замер не состоялся (нет git, нет `node_modules`).
Молчаливого зелёного нет: сводка печатается всегда, включая `own`.

## BLOCK-условие резчика — и зуб, который его держит

Порт не судит сам. Отдельный зуб проверяет исходный код: ни `isInside`, ни `path.relative`,
ни сравнения `realPath` с корнем — только вызовы ядра.

Первая формулировка зуба запрещала любой `startsWith(` и покраснела на честном разборе
вывода `git worktree list --porcelain`. Уточнена по существу (запрещено сравнение ПУТЕЙ, а не
строк вообще), а не ослаблена. Второй заход добавил шаблон `treeRoot)`, который ловил
законные вызовы ядра, — тоже снят.
