**Вопрос:** Ты исполнитель шота «манифест ротации» (назначен тимлидом; он оговорился «Осечкин», роль структурщика однозначна — поправка записана). Твой профильный контекст ПЕРЕД execute, коротко по трём пунктам:

1) Предикат амнистии scripts/lib/secret-amnesty.mjs: amnestyLifted(input) — от чего он ЧЕСТНО зависит? Кандидат: {manifestPath существует ∧ manifest датирован ∧ rotationConfirmed: слово владельца с датой}. Амнистия — «предикат, не дата» (критерий гейта). Что в input, что бросает, что false?

2) Манифест в docs/security/rotation-manifest-2026-08-03.md: какие поля обязательны читателю-владельцу, который по нему будет ротировать? (файл, правило, ЗАМАСКИРОВАННЫЙ фрагмент — сам секрет в манифест не пишем, иначе манифест сам станет утечкой).

3) Скан docs/archive read-only резаком: cuts[] может быть пуст (архив чист) — что тогда манифест честно говорит и что предикат?

**Ответ:**

Контекст принят, поправка «Осечкин → Ожегов» записана. По трём пунктам — как словарные статьи.

**1) `amnestyLifted(input)` — предикат, не дата**

Определение: «амнистия снята» ⇔ владелец подтвердил ротацию по актуальному манифесту. Только это.

- `input`: `{ manifestPath: string, now: Date, ownerConfirmation: { by: string, at: Date, manifestSha256: string } }`.
- Бросает (это ошибки входа, не `false`):
  - `manifestPath` не существует / не читается → `ManifestMissingError`;
  - манифест без даты/невалидный front-matter → `ManifestMalformedError`;
  - `ownerConfirmation.manifestSha256` не совпадает с фактическим хэшем файла → `ConfirmationMismatchError`.
- Возвращает `false`: манифест валиден, но `ownerConfirmation` отсутствует либо `at < manifest.date` (подтверждали прошлую итерацию).
- Возвращает `true`: файл есть, датирован, хэш совпал, `by` непуст, `at ≥ manifest.date`.

Дата в имени файла — лишь навигация; критерий гейта — предикат.

**2) Обязательные поля манифеста (для владельца-ротатора)**

Три колонки на запись `cuts[i]`, плюс шапка:
- шапка: `date`, `owner`, `scope: docs/archive`, `tool: <резак>@<version>`, `commit`;
- `file`: путь в `docs/archive/...`;
- `rule`: идентификатор правила детектора (например, `aws-access-key-id`, `generic-jwt`) — не regex целиком, а имя статьи;
- `masked`: замаскированный фрагмент вида `AKIA••••••••••••ABCD` (сохраняем префикс/суффикс ≤ 4 символов для опознания, середина — `•`);
- `line` / `byteRange`: где искать;
- `action`: `rotate` | `revoke` | `rotate+revoke`;
- `status`: `pending` | `confirmed` (заполняет владелец).

Чего в манифесте **не должно быть ни при каких условиях**: сам секрет, обратимая маска, полный regex, достаточный для реконструкции. Иначе манифест — вторичная утечка.

**3) Пустой `cuts[]`**

Манифест честно говорит: `cuts: []`, `scope`, `tool@version`, `commit`, `scannedAt` — «архив просканирован такой-то версией резака, находок нет». Это валидный документ.

Предикат: `amnestyLifted` при пустом `cuts[]` всё равно требует `ownerConfirmation` — владелец подтверждает, что видел нулевой результат данной версией сканера. Иначе амнистия автоматизируется молчанием, а это ровно тот случай, ради которого мы и делаем гейт.

Уточнение к тимлиду: имя предиката — `amnestyLifted` или `isAmnestyLifted`? В одном доме два имени для одного смысла держать не буду.
