## Предмет

Карточка `tests-container-cross-package-imports`: `resolveImport` открывался
`if (!spec.startsWith('.')) return null` — рёбра `@membrana/*` в граф не
попадали, `.tsx` в кандидатах не было; gate-ярус молча недобирал зависимые
тесты.

## Сделано

1. `workspacePackageDirs(repoRoot)`: карта `@membrana → каталог` по
   workspaces-глобам корневого package.json (формы `dir/*` и буквальный путь),
   кэш с каноничным ключом (realpath). Живое дерево: 40 пакетов.
2. `resolveImport`: воркспейс-спек `@scope/pkg[/подпуть]` — подпуть через общие
   кандидаты, голое имя через `main` → `src/index` → `index`; `node:*` и
   сторонние пакеты рёбрами не становятся.
3. `.tsx`/`index.tsx` в общем списке кандидатов (`RESOLVE_EXTS`, порядок —
   контракт, `.ts` раньше `.tsx`, закреплён зубом).
4. Попутный дефект, всплывший зубом: `existsSync` на голом base отдавал
   КАТАЛОГ как ребро — введён `firstFileOf` (только `isFile`); дефект жил и до
   b3.
5. Контракт названных ограничений в JSDoc: `exports` пакета игнорируется (граф
   про исходники), dist-layout не перебирается, неподдержанных глоб-форм в
   дереве нет.
