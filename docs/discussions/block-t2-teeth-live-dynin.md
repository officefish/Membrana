# Блок t2-teeth-on-live-and-demolition — конспект контекста dynin (sprint-cut-teeth-live-2026-08-11)

След прогонов: `op-log/dynin/2026-08-11.jsonl` (origin `ask-persona`).

## Предмет

Оба зуба формы cut-плана переходят с дублёров на живые модули через мост t1;
каталог `scripts/lib/sprint-cut/stubs/` сносится последним действием блока
(условие из шапок дублёров: снос вместе с переходом, не раньше).

## Сделано

- **Зуб ленты вещдоков** на живом `readTraceCorpus`: порядок по времени
  (обратный порядок строк → `t-early`, `t-late`), пусто = «вещдоков нет»,
  `null` = «факта нет», `0` = законный ноль (дублёр этого случая не различал).
- **Новый зуб частичного успеха**: битая строка даёт `E_TRACE_FIELDS_MISSING`
  и НЕ прячет здоровый акт того же блока — свойство живого корпуса, которое
  дублёр не проверял вовсе.
- **Зуб исхода** на живом `verdictFor`: бинарность, порог числом в записи,
  времени исхода нет; граница закреплена ПАРОЙ (`ровно порог → fitted`,
  `порог+1 → overflowed`) — правка сравнения на `>=` теперь роняет зуб;
  добавлена проверка целости порога (точное равенство законно).
- **Зуб сноса** двухслойный: география (каталога нет) + топология (ни одного
  `from '…/sprint-cut/stubs…'` в дереве). Самопопадание снято: свой файл
  исключён из git-поиска и проверяется построчно по строкам, начинающимся с
  `import` — иначе предикат ловил бы собственный текст.

## Ревью (review_pass) — судьба замечаний

Приняты в код все три: инвариант границы парой значений; топологический зуб
рядом с географическим; «канонический порог» живёт в общем модуле
(`day-work-diff.mjs` → мост t1 → зуб), своей константы зуб не заводит —
дрейфа между зубом и продовым кодом нет.

Ответы на встречные вопросы: (1) `0` — это ноль СТРОК в факте объёма блока, не
ноль актов; ветка живёт в `liveActualChangedLines`, различение
`null`/`0`/бросок закреплено зубом t1; (2) порог целый (`OVERSIZED_CHANGED_LINES`),
поэтому точное равенство законно и tolerance не нужен — целость проверяется
тем же зубом.
