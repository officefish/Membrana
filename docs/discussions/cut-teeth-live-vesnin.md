# Нарезка sprint-cut-teeth-live-2026-08-11 — прогон контекста резчика (vesnin, 11.08)

След прогона: `op-log/vesnin/2026-08-11.jsonl` (origin `ask-persona`).
Предмет: карточка-долг `sprint-cut-teeth-to-live-modules` (#1855), взята по
слову владельца «с конца делаем по очереди».

## Конструкция (ответ контекста)

Работа мелкая по объёму, но семантически двухслойная: (а) удалить дублёров,
(б) переписать два зуба так, чтобы **инвариант проверки** сохранился под
живыми модулями.

**Инвариант зубов формы — сохранить обязаны:**
- сортировку `actsForBlock` по `at` (epoch ms после нормализации корпусом);
- различение «нет наблюдения» (`null`) и «есть, но 0» — не сплющивать в `0`;
- бинарность вердикта `fitted|overflowed` + `threshold` числом;
- отказ `INPUT_ERRORS` при недостающих полях;
- отсутствие времени исхода в записи рода.

## Три рассмотренные формы

- **B1 — «снос + два зуба» одним куском.** Атомарно, но обвязка живых модулей
  (ISO→ms, knownPersonas) заезжает внутрь теста формы — риск «зуб формы стал
  интеграционным тестом соседа» реализуется.
- **B2 — фикстур-мост отдельным блоком, зубы поверх него, снос с последним
  потребителем.** Выбрана.
- **B3 — оставить дублёров, обернуть вызовами живых.** Отвергнута: возвращает
  два источника истины.

## Решение

Форма B2. ADR и консилиум не нужны — правила границ не двигаются, удаляется
дублирующий слой.

**Перерезка до ратификации:** первая редакция плана резала B2 на три блока
(мост · зуб ленты · зуб исхода + снос); `sprint:cut` дал `zones_overlap` —
второй и третий писали в один файл `scripts/sprint-cut-check.test.mjs`. Оба
зуба живут в одном доме, значит и блок один: t2 объединён с t3. Существо B2
сохранено — мост остался отдельным блоком-движком, режется первым.
