## Магистраль

**Защита `main` — не флаг, а живая, машиночитаемая, самопроверяемая конституция.**  
Слово капитана 26.07 («защищено = true» сейчас врёт о содержании) и утренний code-review сходятся на одном звере — «Немой носитель» (B12, #1221). Главный риск: декларация без живого зуба. Критерий успеха к вечеру:

- В корне репозитория лежит **машиночитаемая полиси** (`BRANCH_POLICY.md` или контракт в `docs/`), которая перечисляет **обязательные проверки** (включая основную сборку — build, lint, typecheck, test), запрет force-push и осознанный отказ от required review с причиной (если отказ есть).
- Существует **проверка** (скрипт `scripts/check-branch-policy.mjs` или интеграция), которая:
  - Сверяет заявленные правила с реальными настройками GitHub (через `gh api`).
  - Падает (exit code ≠ 0), если GitHub-факт расходится с заявленным в полиси.
- Полиси явно оговаривает статус `scan` и требует его — это минимум, который уже принуждается гейтом.

Сегодня мы делаем не просто «улучшить CI» — мы отделяем **живую защиту** от декоративной галочки «защищено». Это фундамент, без которого все последующие процедуры (ядро настроек из магистрали 26.07) повисают в воздухе.

> «Магистраль дня» взята из `sources[0].claim` файла `main-day-assertions.json`. Владелец 26.07 выбрал магистраль — универсальное ядро настроек процедуры (фаза Ф1 эпика #1220). Однако утренний ритуал 27.07 (стендап + ревью + слово капитана) **сужает**:
> *   Без работающей защиты `main` любая процедура (включая ядро) — это процедура без конституции. Любой PR может быть влит в обход правил.
> *   Слово капитана 27.07 прямо бьёт в этот гвоздь: «защищено = true сейчас врёт — замер показал обязательным только scan».
> *   Вчерашнее ревью (DAILY_CODE_REVIEW) подсветило `--auto` под новыми правилами как риск («проверить»).

> Следовательно, **единственный сильнейший прогресс дня** — поставить живую защиту `main`, без которой ядро процедур будет висеть на гнилом фундаменте. Это не конфликт с магистралью владельца (ядро Ф1), а её **пререквизит** на сегодня.
