# Стендап Membrana — 2026-10-05

---

## Фокус дня

**Владелец 05.10: магистраль — понижение тарифа со старшего на младший с заморозкой избыточных данных (ручной выбор вне топ-3).**

Это решение принято вне автоматического топ-3 реестра — значит, владелец видит операционный риск, который счётчик приоритетов не поднял: буфер давит на квоту (1727 проб / 797 МБ), и без заморозки избыточных данных следующий день начнётся с инфраструктурного инцидента, а не с продуктовой работы. Главный риск сегодня — заморозка задевает данные, нужные активным задачам (`assets-container`, `mfcc-compare-sprint`), поэтому Тарасов определяет границу «что замораживаем» до того, как Дынин и Ожегов трогают данные; без этого вердикта исполнители работают вслепую. Критерий успеха к вечеру: тариф понижен, манифест замороженных данных зафиксирован письменно, активные задачи дня подтвердили, что их датасеты вне зоны заморозки.

Роли по задаче: **Тарасов** — вердикт о границе заморозки (что именно замораживаем, какие данные неприкосновенны для активных задач); **Дынин** — техническое исполнение заморозки и верификация, что буфер укладывается в новый лимит после операции; **Ожегов** — проверка, что сервисы, читающие замороженный контейнер, не сломают связность (хуки/сторы не тянут данные напрямую из зоны заморозки); **Тарасов** — LGTM по итогу, после которого день считается закрытым по магистрали. Параллельно Дынин закрывает P0 C9 (#2582, проверка plain-text секретов) — это не опционально, выполняется первым действием до любой работы с данными.

## Что сознательно не делаем

- **Не берём `angelina-hostess-impl` и `assets-container` в параллельную магистраль** — стол не чист (P0 C9 открыт, граница заморозки не зафиксирована); расширять фронт до закрытия этих двух блокеров запрещено.
- **Не пишем ADR по контракту шины `chart-list-plugin` сегодня как главную работу** — Родченко остаётся в блоке, ADR переходит в перспективный слот; Тарасов даёт LGTM только после того, как магистраль заморозки закрыта.
- **Не запускаем DSP-бенчмарк** (harmonic / cepstral / flux) — потолок эшелона 0 зафиксирован, без смены датасета или fusion повтор ничего не добавляет.
- **Не разбираем #2562** (`header-badge-narrow`, 406 строк) — первый из 20 неразобранных PR, открывается только после закрытия P0/P1, которые сегодня идут следом за магистралью.
