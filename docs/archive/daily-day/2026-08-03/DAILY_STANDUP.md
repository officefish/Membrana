# Стендап Membrana — 2026-08-03

---

## Фокус дня

**Написать резак секретов в `scripts/night-triage-secret-scan.mjs` и пройти гейт `secret-parser-built`.**

Гейт заблокирован третий день подряд: скрипт является только детектором, функции redact/mask/replace отсутствуют (кристалл `session-backup-requires-secret-redaction` держит это как факт). Без резака амнистия на правку архива не снимается, бэкап сессий тащит сырые транскрипты на сервер, и `archivarius-sessions-container` — единственная задача с полной предусловной цепочкой — остаётся заблокированной. Это наименьшая работа с наибольшей разблокирующей ценностью в сегодняшнем реестре: сам резак — чистая функция `redact(transcript) → { redacted, manifest }` без файловой системы в ядре (что совпадает с сильной стороной Математика), один датированный проход с манифестом ротации засвеченных ключей — достаточный вещдок. Критерий успеха к вечеру: `night-triage-secret-scan.mjs` принимает транскрипт и возвращает редактированную копию плюс манифест; один прогон зафиксирован с датой; `main-day-assertions.json` перечеканен под актуальный гейт. Главный риск: простой regex-проход не накрывает многострочные секреты — нужно решить до кода, достаточно ли конечного автомата или требуется полноценный парсер состояний (зонд из DAY_PLAN.md: `redact(transcript)` в изоляции без файловой системы отвечает на этот вопрос за 15 минут).

## Что сознательно не делаем

- **Не трогаем все 16 oversized PR разом** — только точечный ревью #1584 если останется время после гейта; пакетный просмотр без фокуса создаёт иллюзию прогресса без закрытых задач.
- **Не запускаем DSP-бенчмарки (harmonic / cepstral / spectral-flux) на free-v1** — потолок зафиксирован, повтор не даст новых данных; детекционная полоса сегодня поддерживающая, не магистральная.
- **Не берём `angelina-hostess-impl` и `agent-tooling-night-build` параллельно с гейтом** — оба L-задачи без завершённого предусловия (`secret-parser-built`); старт до прохода гейта расщепит магистраль четвёртый день подряд.
- **Не перезапускаем `yarn code-review` утром** — вчерашний `DAILY_CODE_REVIEW.md` прочитан, вечерний ритуал на своём месте; дублирование ревью в утреннем слоте нарушает ритм (консилиум `standup-charge-2026-07-16`).
