# Порядок полевой съёмки

Этот порядок делает записи разных дней сопоставимыми. Он не выбирает материал для
обучения и не запускает детекторы.

## Перед серией

1. Зафиксировать одну цепь: микрофон, интерфейс, вход, высоту микрофона и усиление.
2. Проверить питание, отсутствие клиппинга и назвать оператора, место, погоду и ветер.
3. Выбрать высоты источника для серии. Если высота управляется, снять не меньше двух;
   внутри одного прохода высоту не менять.
4. Любая смена аппарата, входа или усиления начинает новую серию. Такое изменение
   нельзя прятать в примечании к прежней серии.

## Один проход

- Одна запись длится 60 секунд.
- Дистанции: 20, 50, 100 и 200 метров.
- На каждой дистанции снимается пара: целевой источник и похожий трудный фон без цели.
- Внутри точки цель и фон чередуются, чтобы погода не досталась только одному классу.
- Записей без цели должно быть не меньше, чем записей с целью.

Нужны три прохода по одной серии:

1. `20 → 50 → 100 → 200` м;
2. `200 → 100 → 50 → 20` м;
3. `20 → 50 → 100 → 200` м.

Разворот среднего прохода отделяет влияние времени и ветра от влияния дистанции.

## Имена файлов

Основа имени содержит UTC-время, класс, короткое имя источника, дистанцию и повтор:

```text
20260819T090000Z_target_drone_d050_r01.wav
20260819T090000Z_target_drone_d050_r01.sidecar.json
```

У WAV и спутника одна основа. Переименовывать только один файл запрещено.

## Спутник

`declared` заполняет оператор: что снимали, аппарат, дистанцию, высоту источника,
место, погоду, ветер, оператора и усиление. Усиление записывается воспроизводимой
меткой ручки или режима; выдумывать dB нельзя.

Для фоновой записи без отдельного источника `what` начинается с `background:`, а
`distanceM` и `heightM` равны `null`: это «не применимо», не неизвестный ноль.

`measured` создаёт инструмент из WAV: время, длительность, частоту, каналы, формат,
размер, peak, RMS и SHA-256. Ручной ввод в этот раздел запрещён.

## Отбор

Для калибровки сохраняется случайная фоновая выборка независимо от результата
детектора. Кандидаты детектора могут идти отдельным потоком, но не заменяют случайный
фон. Это не обязанность спутника и не повод заводить второй реестр.
