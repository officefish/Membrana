## Магистраль

**`tariff-promo-server-wiring`** — замкнуть провод готового тарифного домена до серверного роута и клиентского приёмника.

Домен решения существует и покрыт тестами: `decideTransition(grid, request, promo, now)` с закрытым списком причин отказа (`promo_revoked` / `promo_already_redeemed` / `promo_expired` / `promo_target_mismatch` / `promo_downgrade_forbidden`), флаг `spendPromo`, модель `PromoCode` в `schema.prisma:270`, 16 зубов теста — всё есть. Но `decideTransition` не вызывает никто: все 16 упоминаний символа живут внутри собственного теста домена. Задача дня — не дописывать логику, а замкнуть провод: серверный обработчик вызывает `decideTransition`, Prisma-транзакция атомарно списывает попытку промокода, клиент получает различимую причину отказа из закрытого списка.

**Критерий успеха к вечеру:** `grep -r decideTransition packages/ apps/` показывает вызов вне тестового файла домена; хотя бы один интеграционный зуб проходит по реальному маршруту сервер → домен → БД; `yarn typecheck` зелёный во всех затронутых пакетах.
