## Инварианты, которые я держу и понесу на Interface Consilium

| Инвариант | Моё значение | Чем НЕ является |
|---|---|---|
| **Идентификатор блока** | `cutBlockId` — стабильный слаг блока нарезки внутри окна, `^[a-z0-9][a-z0-9-]*$`, уникален в пределах `sprintId` | не путь к файлу, не имя персоны, не номер PR. Омоним разведён явно: **блок нарезки ≠ блок коворка** |
| **Идентификатор персоны** | `personaId` — канонический слаг из `docs/virtual-team/memory/*.md` (`tarasov`, `angelina`, `vesnin`, `ozhegov`, `dynin`, `kuryokhin`, `rodchenko`, `farrell`) | не имя модели, не `sessionId`, не отображаемое имя. | **Владелец времени** | **данные**. Хронология из полей записи; обязательный порядок `predictedAt < observedAt`, `stoppedAt ≤ resolvedAt`. Границы окна `[openedAt, closedAt)` приходят от соседа вместе с `sprintId` | не мои часы. `Date.now()` и `Math.random()` в блоке отсутствуют; `now` — параметр |
| **Единица объёма** | **изменённые строки**: `changedLines = insertions + deletions` по `git diff --shortstat` одного сегмента ревью (squash-мёрж = один PR). Порог одной проверки ревью — **400** (`OVERSIZED_CHANGED_LINES`), в функцию идёт параметром | не файлы, не коммиты, не токены, не только добавленные строки |

## Что мне нужно от соседей

| От блока | Что | Форма (сигнатура/схема) — **моё допущение** | Инварианты (единицы, частоты, порядок, владелец времени) |
|---|---|---|---|
| `cut-contract` | **План нарезки** — предсказание тимлида, вход `cutAccuracy` | `{ sprintId, authorPersonaId: 'tarasov', ratifiedBy: 'owner' \| {none}, createdAt, blocks: [{ cutBlockId, contextPersonaId, claim: 'fits' \| 'does-not-fit' }] }` | План адресуем и **неизменяем после ратификации**; `createdAt` = мой `predictedAt` и обязан быть **раньше** любого исхода; `cutBlockId` уникален в пределах `sprintId`; `claim` — перечисление, не число строк |
| `cut-contract` | **Факт ратификации владельцем** плана нарезки | поле `ratifiedBy` + ссылка на носитель согласия (`Ref`) | Нератифицированный план в мерку не входит → причина `forecast-not-ratified`. Молчание ратификацией не является |
| `execution-gate` | **Привязка сегментов ревью к `cutBlockId`** — источник `changedLines` | `[{ cutBlockId, sha, pr \| null, changedLines: int }]` | Привязка **явная**; по путям файлов я не угадываю. Нет привязки → исход не определён (`no-attribution`), не 0. Единица — изменённые строки (см. выше) |
| `execution-gate` | **Журнал остановок ведущей** — предсказание Ангелины, вход `falseStopRate` | `[{ stopId, personaId: 'angelina', sprintId, stageId, objectRef: Ref, stoppedAt, resolvedAt \| null, resolution }]` | Остановка **обязана** нести `objectRef` — без названного объекта полезность невычислима, это дефект записи, а не неизвестный исход. `stoppedAt ≤ resolvedAt`. Неразрешённые в знаменатель не входят и печатаются отдельной строкой |
| `execution-gate` | **Лента вещдоков окна** — источник `changes(objectRef)` для предиката полезности | `[{ objectRef: Ref, at: ISO, kind: 'new-ref' \| 'contract-version' \| 'sha' \| 'status' }]` | Изменение **адресуемо**; свободный текст изменением не является. Полезность остановки считается по этой ленте, **не по слову ведущей** — иначе метрика становится льстивой |
| `execution-gate` | **Признак «окно шло без ведения»** (M6) | `{ leadPersonaId: PersonaId \| { none: причина } }` | Отсутствие ведущей даёт `no-lead-appointed`, а **не** хорошую цифру |
| любой сосед | **Разрешимость `evidence`** (ссылка резолвится) | резолвер `Ref → { resolved: boolean, why? }` | Неразрешимый вещдок отправляет прогон в `waiting` с причиной, а не выбрасывает его молча |
| координатор / интеграция | Точка **эмита** записей рода при закрытии окна + провода (`package.json`, ритуалы, хуки) | адаптер зовёт `makeForecastRecord` и пишет в `docs/virtual-team/memory/archive/<persona>.jsonl` | Вшивание — адаптер Phase 4; блок общих корневых файлов не трогает |
| координатор | **`COWORK_SPRINT_BRIEF.md` спринта** — его нет на ветке блока | документ по шаблону регламента | Дедлайн интеграции и интеграционный smoke мне неизвестны; работаю по `AGENT_PROMPT.md`. Заявлено блокером, обходом не лечится |
| Interface Consilium | **Дискриминатор рода в архиве памяти**: живая форма несёт `class: position` + `kind: verbatim`, вердикт M8 говорит `kind: execution` | одно поле-дискриминатор на весь архив | Односторонне не решаю. Мой выбор до консилиума: `class: 'forecast'` (живая форма — авторитет для живого архива) |

| `cut-contract` | **Требования потребителя к плану нарезки**: какие поля обязаны быть, чтобы `cutAccuracy` считалась | таблица выше, строка 1 | Нет поля → метрика честно не определена с названной причиной, а не домысливается |
| `execution-gate` | **Требования потребителя к журналу остановок и ленте вещдоков** | таблицы выше, строки 4–5 | Полезность остановки — предикат по следам; самозаверение исключено конструкцией |
| интеграции / ритуалу | **Две чистые функции метрик** | `computeCutAccuracy(records, { threshold })` · `computeFalseStopRate(stops, changes)` → `{ defined: true, value, numerator, denominator, pair } \| { defined: false, reason }` | Без сети/git/`Date.now()`; `defined ⇔ denominator > 0`; рядом с `defined:false` процент **не печатается**; `?? 0` в метриках запрещён |
| интеграции | **Обязательные пары против Гудхарта** | `cutAccuracy` ↔ `blocksCount`, `overflowRate` · `falseStopRate` ↔ `stopsCount`, `unresolvedCount` | Объёмная величина в одиночку не выводится; доля печатается со счётчиками |
| пред-спринтовому фрейму тимлида | **Номинация 5–7 удачных прогонов** | `nominateRuns(runs, { min: 5, max: 7 }) → { ready, waiting, thin }` + снимок `docs/sprint/experience/RUN_NOMINATIONS.md` | **Только номинация** — в канон пишет человек по слову владельца; функция чистая и файлов не пишет; порядок детерминирован; при `< min` — `thin: 'корпус тонкий: N из 5'`, **добора неточными нет** |
| всем | **Алфавит причин отсутствия** | `no-cut-forecast` · `no-observed-outcome` · `forecast-not-ratified` · `no-attribution` · `no-stops-recorded` · `stops-unresolved` · `no-lead-appointed` | Ратифицированный запрет M5: «чисто» при пустом корпусе = «корпуса нет». Ноль остановок ≠ «ложных нет» |

  разрешается адаптером на интеграции, а не догадкой по путям файлов внутри моего блока.
- Дискриминатор рода в архиве памяти (`class` vs `kind`) — открытый шов, см. последнюю строку
  первой таблицы.
