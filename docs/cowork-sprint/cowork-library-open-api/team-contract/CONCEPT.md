# Concept — Block `contract`

Блок исполняет вердикт **M2 заседания `library-open-api`** («форма контракта наружу») и
только его. Существо M1 (ось владения), M3 (срок ключа) и M4 (границы выемки) блок не
решает: он оставляет для них ровно те швы, которые форма обязана иметь, и закрывает их
исполняемыми стабами в своей зоне.

## Граница блока

Блок отвечает за **форму ответа**: какими адресами библиотека называется наружу, каким
ключом называется проба, какие поля едут, как читатель узнаёт полноту и чем «нет такого»
отличается от «не твоё».

Блок **не** отвечает за: кто владелец трека (M1), сколько живёт ключ и чем он выдаётся
(M3), какие селекторы и квоты допущены (M4), HTTP-транспорт, Nest-контроллеры, чтение
хранилища. Общая точка `packages/services/media-library/src/index.ts` остаётся
integration-owned и в Phase 2 не трогается — экспорты внесёт координатор.

Production-код блока живёт только в `packages/services/media-library/src/open-api/**`.
Зубы — в `packages/services/media-library/test/open-api*`.

## Адресация — внутренние пути сохранены

Вердикт M2 дословно: контракт наружу **сохраняет внутренние пути без слоя трансляции**.
Блок не строит переименований и не заводит «внешних» идентификаторов:

| Операция | Путь |
|---|---|
| Наборы прибора | `/v1/devices/{deviceId}/collections` |
| Пробы набора | `/v1/devices/{deviceId}/collections/{collectionId}/samples` |
| Тело пробы | `/v1/devices/{deviceId}/samples/{sampleId}/blob` |

`deviceId` — технический ключ прибора, `collectionId` — группировка; единицу владения из M1
(`Device.membraneId`) это не трогает и не подменяет. Расхождение с тезисом Т1 шторма
(«открытое API не мыслит устройствами») названо эпиком явно; блок исполняет вердикт, а не
тезис.

**Ключ пробы — `sampleId` во всех ссылках.** `title` изменяем (`MakeTrack <uuid>`,
переименовывается человеком) и ключом быть не может. Пути строятся функциями, а не
конкатенацией на стороне читателя, чтобы «ключ = id» держался кодом, а не памятью.

## Поля — ровно одиннадцать постоянных

Наружу едут `id`, `collectionId`, `title`, `class`, `label`, `source`, `durationSec`,
`sampleRate`, `channels`, `createdAt`, `sizeBytes`.

**Не едут:** `storageRef` — внутренний путь хранилища; `notes` — пометки человека.

Сериализатор — **allow-list, а не deny-list**: он собирает выход из перечисленного списка
имён, а не вычёркивает запрещённые из входа. Deny-list протекает при каждом новом
внутреннем поле; allow-list не протекает никогда. Именно поэтому список имён —
единственный источник и для типа, и для сериализатора, и для схемы OpenAPI: разойтись им
негде.

Плюс **временное поле ключа** — двенадцатое и необязательное (см. «Шов имени»).

## Полнота — инвариант, вычислимый читателем

Обёртка списка несёт ровно четыре поля: **`items`, `total`, `page`, `limit`**.

```
items.length < limit                          → страница последняя
items.length === limit && page * limit < total → есть следующая
```

**Флага `hasMore` нет намеренно.** Флаг — это второе высказывание о том же факте, и он
способен разойтись с `items`/`total`: тогда читатель верит флагу и ошибается. Инвариант
разойтись не может — он вычислен из тех же чисел, которые читатель уже держит в руках.

Отсутствие флага в блоке **проверяемо, а не описано**: у обёртки есть валидатор формы,
который закрытым множеством имён отвергает любой посторонний ключ и отдельно называет
нарушение «флаг полноты» для `hasMore`/`hasNext`/`hasNextPage`/`more`/`nextPage`.
Внутренний `PaginatedSamples` пакета несёт ещё и `totalPages`; наружу он не едет —
вердикт назвал четыре поля, а производное число, посчитанное дверью, ровно так же
способно разойтись с `total`, как и флаг.

## Отказы разведены

`404` — такого нет. `403` — есть, но закрыто. Слипание уместно для публичного входа без
авторизации; здесь партнёр **уже опознан**, и скрывать от своего факт существования его же
ресурса значит дезориентировать — он будет чинить опечатку в идентификаторе вместо того,
чтобы просить доступ.

Оба отказа несут одну форму тела (`code`, `message`), и `code` — закрытое перечисление.
Блок фиксирует **разведённость** как свойство контракта: ни один путь не вправе объявлять
только один из двух кодов, и ни один из них не вправе означать оба смысла сразу.

## Шов имени временного поля ключа

M2 назвал рабочее имя `trackUrl`; лемма M4 записала `temporaryKey?`. Ни одна комната не
назначала имя окончательно и ни одна не знала о варианте соседа. Сведение — Phase 3.

**Мой выбор для себя: `temporaryKey`.** Довод — в разделе «Выбор имени» файла
`EXPECTATIONS.md`. Здесь важно другое: имя живёт **одной именованной константой**
`TEMPORARY_KEY_FIELD`, из которой выводятся и тип (mapped type по литералу), и
сериализатор, и схема OpenAPI, и зубы. Смена имени на интеграции стоит **одну строку**.

## Стабы соседей

Форма обязана уметь показать поле ключа, не зная, чем оно выдаётся, и уметь отказать
`403`, не зная, чем считается владение. Оба соседа замещены исполняемыми стабами в
`test/open-api.stubs.ts`: стаб выдачи ключа и стаб решения о доступе. Стабы не импортируют
чужой код, не входят в production graph и на интеграции удаляются.
