## Шов, который назначать запрещено: имя поля с ключом

Эпик фиксирует висяк дословно: M2 назвал рабочее имя **`trackUrl`**, лемма M4 записала
**`temporaryKey?`**; ни одна комната не знала о варианте соседа. Ниже — **моё ожидание,
объявленное односторонне**, с доводом. Назначение — не здесь.

**Ожидаю:** два обязательных поля в объекте пробы —

```ts
trackUrl: string;                  // адрес, по которому идут анонимно
trackUrlExpiresAt: string | null;  // ISO-8601; null — ТОЛЬКО снятый человеком срок
```

Довод (четыре, по убыванию силы):

1. **Имя должно называть то, что в поле лежит.** M2 постановил: партнёр «берёт URL из списка и
   идёт туда анонимно» — то есть наружу едет **адрес**, а не секрет, который читатель сам
   вставит куда-то. `temporaryKey` называет секрет и тем обещает сборку URL на стороне
   читателя, которой по вердикту M2 нет.
2. **`temporary` — обещание в имени, которое поле не держит.** Право владельца снять срок
   закрыто штормом; при снятом сроке ключ ровно НЕ временный, и имя начинает лгать в самом
   чувствительном месте контракта. `trackUrl` верно при обоих состояниях.
3. **Опциональность (`?`) вредна именно здесь.** Отсутствующее поле неотличимо от «ключ не
   выдан», «квота исчерпана» и «сериализатор забыл». Поле обязано присутствовать всегда —
   отказ выдать ключ обязан быть отказом, а не пропуском ключа.
4. **Срок — отдельным полем, а не внутри query-string.** Тот же принцип, которым M2 отверг
   `hasMore`: читатель обязан мочь **вычислить сам**, когда ссылка умрёт, не разбирая чужую
   строку запроса. `null` в этом поле — единственная наружная форма «срок снят человеком», и
   приходит она только из `source === 'lifted'`.

Если консилиум назначит `temporaryKey`, блок переживает это адаптером на шве: внутри
генератора имя поля не зашито, выдача возвращает `{ url, expiresAt }` — переименование живёт
в сериализаторе списка (зона соседа), не в носителе срока.

## Дельта Phase 2 (что уточнилось при постройке)

- **Снятие срока обязано нести провенанс.** `{ mode: 'lifted' }` без `liftedAt`/`liftedBy`
  резолвер трактует как **порчу**, а не как снятие: «явное движение человека» без подписи
  неотличимо от повреждённой записи. Ожидание к кабинету поднято в таблицу выше.
- **Порядок проверки токена зафиксирован: поколение → подпись → срок.** Иначе ротация не
  гасила бы невыдохшие ссылки первым вопросом, и «гасит разом» стало бы «гасит по мере
  истечения». Зуб идёт именно на это.
- **`membraneId: null` — не «умолчание», а отказ выдать.** Прибор без мембраны законен (M1),
  но ссылка без оси владения не выдаётся вовсе: подстановка `DEFAULT_TRACK_KEY_TTL` тут была
  бы угадыванием владельца. Вердикт `unknown_membrane`.
- **Единица — секунды, без исключений.** Терпимость к вводу (число, числовая строка,
  абсолютная ISO-дата в будущем) есть, но наружу и внутрь блока едут только секунды и ISO-дата
  истечения; смешанных единиц в контракте нет.
- **Порча-зуб построен на живом исходнике**, а не на копии: тест читает
  `track-key-ttl.ts`, вырезает fail-closed ветку по якорю и проверяет, что перебор порчи
  краснеет. Зуб падает и в обратную сторону — если якоря нет (ветку уже сняли или
  переименовали), тест говорит об этом прямо.

## Пробелы (фиксируются, не блокеры)

- **Имя поля с ключом не назначено** — и назначать здесь запрещено. Моё ожидание объявлено
  выше; расхождение с `temporaryKey?` держится адаптером в сериализаторе.
- **Квоты выдачи в стволе нет** (M4: «фактически предел бесконечен»). Блок её не строит —
  вне зоны; названа точка вшивания и порядок «квота → выдача».
- **Хранилища ключа мембраны в стволе нет** — `prisma/schema.prisma` трогать запрещено
  правилом изоляции. Блок работает через интерфейс хранилища (`TrackKeyStore`), Prisma-адаптер
  и миграция — интеграция.
- **Блока настроек срока в кабинете нет** — форма записи объявлена односторонне и заменена
  стабом; согласование формы с кабинетом за рамками коворка.
