# Interface Contract — `cowork-library-open-api`

Выработан на Interface Consilium 02.09 ([протокол](../../discussions/cowork-sprint-cowork-library-open-api-interface-consilium.md)).
Основание — три `EXPECTATIONS.md`, вскрытые одновременно после freeze-тегов.

Контракт **обязателен для интеграции**. Блоки на Phase 4 не переписываются: расхождения
гасятся адаптерами. Потребность переписать блок = дефект резки brief и пишется в
`RETROSPECTIVE.md`, а не лечится втихую.

## 1. Сигнатуры на швах

### Шов `ownership → contract` (кто отбирает → кто оформляет)

```ts
// отдаёт ownership
resolveDeviceOwnership(device: { id: string; membraneId?: string | null }): OwnershipAxis
//   → { kind: 'membrane', membraneId, deviceId, derivedFrom: 'device.membraneId' }
//   | { kind: 'absent', deviceId }

listOwnedSamples(device, { page, limit, createdFrom?, createdTo? })
//   → { items, total, page, limit, scope: 'membrane' | 'empty' }

requireMembraneOwner(device, operation: string): string
//   иначе бросает MembraneOwnerRequiredError { code: 'OWNERSHIP_MEMBRANE_ABSENT', deviceId, operation }
```

```ts
// принимает contract
toPublicSample(internal, temporaryKeyValue): PublicSample   // allow-list по PUBLIC_SAMPLE_FIELDS
toPageEnvelope(...)                                          // ровно items/total/page/limit
refusalForOutcome(outcome: 'allow' | 'forbidden' | 'absent')
```

**Адаптер А1 (дверь):** страница `ownership` → обёртка `contract`, **отбросив `scope`**.
**Адаптер А2 (дверь):** внутренний `PaginatedSamples` → наружная обёртка, **отбросив `totalPages`**.

### Шов `key-ttl → contract` (кто выдаёт ключ → кто его везёт)

```ts
// отдаёт key-ttl
DEFAULT_TRACK_KEY_TTL = 900        // секунды, всегда секунды
MAX_TRACK_KEY_TTL = 2_592_000      // 30 суток; сверх потолка — порча, не длинный срок

resolveTrackKeyTtl(stored: unknown, { now }): { seconds: number | null; source; reason }
//   ИНВАРИАНТ: seconds === null ⟺ source === 'lifted'

issue({ membraneId, sampleId }): { url, expiresAt, generation, ttl }
rotate(membraneId): { generation, rotatedAt, killedGeneration }
```

**Адаптер А3 (сериализатор):** `{ url, expiresAt }` → поле(я) наружного объекта пробы (см. §2).

### Шов `ownership → key-ttl` (ось → масштаб срока и квоты)

`membraneId` берётся **у `ownership`** и никогда не выводится генератором.
`requireMembraneOwner` вызывается **до** `issue`; исключение не гасится в `catch`.
`membraneId: null` → вердикт `unknown_membrane`, **отказ выдать**, а не подстановка умолчания.

## 2. Поле ключа — решено частично, число полей эскалировано

| Что | Решение | Основание |
|---|---|---|
| **имя** | **`trackUrl`** | `temporary*` становится ложью при снятом сроке — законном состоянии (право владельца закрыто штормом). Имя, способное стать ложью, не берётся |
| **обязательность** | **обязательное**, `?` снят | отсутствующее поле неотличимо от «не выдан» / «квота исчерпана» / «сериализатор забыл» — класс `hasMore` |
| **число полей** | **ДВА — решение владельца 02.09** | эскалация S-C2 закрыта; см. ниже |

### Решение владельца: два поля

```ts
trackUrl: string;                  // адрес, по которому идут анонимно
trackUrlExpiresAt: string | null;  // ISO-8601 UTC; null — ТОЛЬКО снятый человеком срок
```

Контракт наружу становится **11 + 2**, и это **осознанное расширение вердикта M2**, а не
умолчание сборки. Основание принято от `key-ttl`: читатель обязан мочь вычислить срок жизни
ссылки сам, не разбирая чужую query-string, — ровно та логика, которой M2 отверг `hasMore`.

Расширение зафиксировано здесь явно, потому что вердикт M2 называл **одно** поле, «заменяющее
собой `storageRef`». Ни одна комната двенадцатого поля не назначала; назначил владелец на
консилиуме, и запись об этом обязана пережить спринт.

Уточнение к оценке `contract`: его «цена смены — одна строка» верна для переименования, но не
для смены арности — второе поле стоит строки в кортеже, в схеме и в зубе длины.

Цена смены у `contract` — константа `TEMPORARY_KEY_FIELD` (одна строка) **для переименования**;
переход к двум полям дороже на одно поле в кортеже и в схеме. Это уточнение к оценке блока:
его «одна строка» считалась для переименования, не для смены арности.

## 3. Инварианты потока данных

| Инвариант | Владелец | Почему |
|---|---|---|
| **Порядок: существование → владение** | дверь (интеграция) | иначе `403` перестаёт доказывать существование, и разведённость ломается при зелёном зубе `contract` |
| **Выборка без мембраны → пустая страница, НЕ ошибка** | `ownership` | M1 дословно; хранилище при этом не спрашивается ни разу |
| **Операция без владельца → `409`** | дверь (интеграция) | ресурс существует и не закрыт — он не привязан; `403`/`404` тут лгут |
| **Единица срока — секунды, везде** | `key-ttl` | смешанных единиц в контракте нет; наружу — ISO-8601 UTC |
| **Владелец времени — вызывающий** | вызывающий слой | `resolveTrackKeyTtl` не читает `Date.now()` внутри; часы подаются |
| **Порядок проверки токена: поколение → подпись → срок** | `key-ttl` | иначе ротация гасит не «разом», а «по мере истечения» |
| **`Device.membraneId` в рантайме никто не пишет** | все | ось, меняющаяся под запросом, перестаёт быть осью |
| **Полнота вычисляется читателем; канон — `hasNextPage`** | `contract` | закрывает ровно полную последнюю страницу без нового поля |
| **Тело списка — credential-bearing, `no-store`** | **маршрут `background-media` (назначено на интеграции)** | до консилиума исполнителя не было ни у кого |

## 4. Глоссарий стыка

| Термин | Значение — одно на все блоки |
|---|---|
| **владение** | `Device.membraneId`. НЕ `deviceId` (адресация), НЕ `collectionId` (группировка) — никогда, в том числе запасной веткой |
| **отсутствие владельца** | `null`, `undefined`, `''`, строка из пробелов — всё это одно состояние; законное, не порча |
| **выборка** | чтение списка. Без владельца → пусто |
| **операция** | действие, требующее владельца. Без владельца → `409` |
| **срок снят** | `seconds === null`, и **только** при `source === 'lifted'` с подписью `{ liftedAt, liftedBy }`. Без подписи — порча, а не снятие |
| **ротация** | одно движение гасит ВСЕ ссылки мембраны: все наборы, все роды, приёмный лоток включительно |
| **поштучный отзыв** | **не существует как глагол** — следствие предъявительской конструкции; сторожит зуб, не комментарий |
| **связка ключей** | тело списка с ключами. Не метаданные каталога: не в логи, не в кеш посредника, не пересылать целиком |

## 6. Интеграционный smoke — один сценарий через все швы

1. Прибор **с** мембраной → список: ось отбирает по `membraneId`, дверь отдаёт
   `items/total/page/limit` (без `scope`, без `totalPages`), каждая проба несёт 11 полей и поле
   ключа; `storageRef` и `notes` отсутствуют.
2. У ключа, чей ttl не задан, срок = `DEFAULT_TRACK_KEY_TTL`, а не `null`.
3. Прибор **без** мембраны → **пустая страница**, `200`; хранилище не вызвано.
4. Операция, требующая владельца, на приборе без мембраны → **`409`** с именем операции.
5. Чужой существующий ресурс → `403`; несуществующий → `404`. **Проверяется, что порядок
   именно «существование → владение»**, а не только коды.
6. Ответ со списком несёт `no-store`.
7. Ротация мембраны → все ранее выданные ссылки мертвы **разом**, включая невыдохшие.
8. Читатель считает полноту по `hasNextPage`; ровно полная последняя страница даёт «следующей
   нет».

DoD Phase 4: этот smoke зелёный **и** собственные зубы всех трёх блоков зелёные в собранной
ветке (67 + 29 + 80).
