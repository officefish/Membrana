# Дом процедуры и режим исполнения (Ф2 / #1220)

Канон ядра (`trigger` · `steps` · `gates`) — [`CORE.md`](./CORE.md). Здесь —
два поля, которые ядро намеренно не взяло: `home` и `mode`.

## Кит ≠ дом

| | Кит (`kitVersion`) | Дом (`home`) |
|--|--------------------|--------------|
| Природа | иммутабелен по версии (пины SHA) | живое пространство имён |
| Контракт | `kits/<id>/MANIFEST.json` + опись | **форма дома** (`HOME.form.json`): что лежит, кто пишет |
| Пины | да | нет — дом меняется каждый день |

Расширения в доме **добавляют, но не переопределяют** базовое. Иначе гарантия
ядра исчезает (прецедент: панельный overlay каналов).

## `home`

| `kind` | Поля | Смысл |
|--------|------|--------|
| `path` | `path`, `form`, `holder`, `writers[]` | объявленный дом в репо |
| `none` | `why` | легально нет git-дома |

### `path`

| Поле | Правило |
|------|---------|
| `path` | каталог от корня репо; обязан существовать |
| `form` | путь к `*.form.json` (контракт формы); файл обязан существовать |
| `holder` | ∈ Persona — держатель дома (обычно = `leadPersona`) |
| `writers[]` | кто законно пишет; элемент `{ procedureId, via }` |

`via` — объявленная команда/движок процедуры-писателя (не прямой edit файлов
соседом). Живой пример: дом мостика пишут `bridge` (`yarn bridge`) и
`ritual-evening` (шаг `bridge-close`).

### Форма дома (`*.form.json`)

Версия живёт **в форме** (`formVersion`), не только в ссылке из манифеста.
Канон версий — [`VERSIONS.md`](./VERSIONS.md) (Ф4).

```json
{
  "formVersion": "1.0.0",
  "compat": ["1.0.0"],
  "mustExist": ["state.json", "DEBTS.md"],
  "extensionsMayAdd": true,
  "extensionsMayNotOverride": true
}
```

| Поле | Смысл |
|------|--------|
| `formVersion` | semver поколения формы; обязан ∈ `compat[]` и ∈ окно слоя |
| `compat[]` | окно совместимости поколений этой формы |
| `mustExist[]` | относительные пути от `home.path`; каждый обязан существовать как файл |
| `extensionsMayAdd` | соседи/расширения могут класть новое |
| `extensionsMayNotOverride` | расширение не перебивает базовое (норма) |

Legacy `{ "version": 1 }` без `formVersion` — дефект до миграции
(`migrateHomeForm`). Инстансы прогона (`docs/bridge/<date>/CONSPECTUS.md`) —
**не** элементы формы: они появляются и уезжают; форма держит каркас дома.

## `mode`

| Значение | Смысл |
|----------|--------|
| `orchestrated` | исполняется/будет исполняться кожухом (расписание, журнал) |
| `mirrored` | может идти локально, состояние отражается в единый источник правды (git) |
| `local` | только локально / агентская сессия, без кожуха |

Поле optional. Отсутствие — не дефект (миграция по касанию). Пилоты Ф2 несут
его явно.

## Зуб в обе стороны

1. **Объявленный дом** (`home.kind=path`) → каталог существует ∧ форма
   резолвится ∧ `mustExist[]` на месте. Иначе — отказ схемы.
2. **Живой дом без декларации** → находка. Реестр известных живых домов:
   `KNOWN_LIVING_HOMES` в `scripts/lib/validate-procedure.mjs`. Сегодня:
   `docs/bridge` (с 22.07). Функция `auditProcedureHomes(repoRoot)`.

## Пилоты Ф2

| Процедура | home | mode |
|-----------|------|------|
| `bridge` | `docs/bridge` + форма + writers (bridge, ritual-evening) | `mirrored` |
| `ritual-evening` | `none` — прогоны в seanses/archive, не пространство имён | `local` |
| `ritual-dreams` | `none` — volume office, не git-дом | `orchestrated` |

После Ф5 (#1284) `home`+`mode` несут **все** built-контейнеры; единственный
объявленный path-дом по-прежнему мостик. Снимок — [`CORPUS.md`](./CORPUS.md).
