# Версии, совместимость, миграции (Ф4 / #1220)

Пять версионируемых сущностей слоя — **одним взглядом**. Канон фазы эпика
[#1220](https://github.com/officefish/Membrana/issues/1220); срез [#1227](https://github.com/officefish/Membrana/issues/1227)
не шире процедурного контура.

## Инвентарь

| Сущность | Где живёт сейчас | Текущая | Окно compat | Ломающее |
|----------|------------------|---------|-------------|----------|
| **Парсер** лицензии | `PARSER_VERSION` в `procedure-contract-stamp.mjs` ∧ `contracts.registry.json` | `1.0.0` | `compat[]` в реестре | схема штампа / правила лицензии |
| **Генератор** | команда в штампе и в реестре (`generator`) | по команде | наследует парсер | смена выхода без bump парсера |
| **Контракт** | штамп `parser@…` в голове файла | наследует парсер | `registry.compat` | дрейф тела / чужой парсер |
| **Кит** (поставка) | `kitVersion` → `kits/<id>/MANIFEST.json` + пины SHA | pin | `yarn kits:audit` | смена пина без аудита |
| **Форма дома** | `formVersion` **в** `*.form.json` (в самом доме) | `1.0.0` | `compat[]` в форме | `mustExist` / правила override |

Версия формы **не** только ссылка из контейнера: дом читается сам по себе
(`docs/bridge/HOME.form.json` → `formVersion`).

## Окно совместимости

Без явного окна каждое изменение — выбор «сломать всё или не менять никогда».
Правило слоя:

1. Текущее поколение **и** предыдущее (если ещё в `compat[]`) принимаются зубом.
2. Вне окна — отказ (не «подозрение»).
3. Выкинуть поколение из `compat[]` можно только вместе с **миграцией**.

Сейчас узкое окно: только `1.0.0` (парсер и форма). Расширять — осознанно.

## Миграция — обязательство

Ломающее изменение приходит **пакетом**: diff канона + код перехода + зуб,
который ловит немигрированное. Паттерн в дереве — миграции инсайтов
(`insight-lifecycle-migrate`).

| Переход | Команда / код | Зуб |
|---------|---------------|-----|
| Legacy-штамп `<!-- generated: … -->` → `<!-- contract: parser@… -->` | `yarn procedures:license --write` (`migrateLegacyContractText`) | `--check`: legacy = недействителен |
| Форма `{ "version": 1 }` → `{ "formVersion": "1.0.0", "compat": […] }` | `migrateHomeForm` в `procedure-home-form.mjs` | `validateProcedure` / `homeFormProblems` |

Новый ломающий bump формы или парсера **обязан** добавить строку в эту таблицу
и тест на переход. Добрая воля «перегенерируем потом» — не норма.
