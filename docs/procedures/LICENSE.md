# Лицензия контракта процедурного слоя (Ф3 / #1220)

Срез эпика [#1227](https://github.com/officefish/Membrana/issues/1227) **внутри**
`docs/procedures/`: не весь репозиторий, а проекции слоя, которые машина уже
читает как правду. Сквозной механизм #1227 — отдельно и шире.

## Два класса

| Класс | Кто пишет | Машина |
|-------|-----------|--------|
| **prose** | человек / агент | читает для людей; **не исполняет** как источник истины |
| **contract** | только генератор | исполняет / сверяет, если лицензия валидна |

Контракт без удостоверенного происхождения **недействителен** — не
«подозрителен»: исполнять нельзя.

Ручные манифесты (`MANIFEST.json`) пока остаются **prose со схемой**
(`validateProcedure`): их форма проверяется, но лицензию парсера они не
получают — не порождены генератором. Перевод в contract — отдельное решение.

## Лицензию выдаёт парсер

Парсер (`scripts/lib/procedure-contract-license.mjs`) держит версию и сверяет
результат с требованиями. Версию наследуют генератор и выходящий контракт.

### Оба признака обязательны

| Признак | Смысл | Провал |
|---------|--------|--------|
| **происхождение** | кем порождён (команда + source в штампе) | рукопись, случайно похожая на контракт |
| **соответствие** | байт-в-байт совпал с пересборкой из source | дрейф / кривой генератор |

Вместе: **контракт воспроизводим**.

### Корень доверия — человек

Цепочка не уходит в бесконечность. Здесь корень явный: закрытый словарь
категорий (`vocabulary.json`) расширяется только ADR + LGTM владельца
(вердикт M2). Это решение записано в `contracts.registry.json` → `rootOfTrust`.

## Реестр и зуб

| Артефакт | Назначение |
|----------|------------|
| [`contracts.registry.json`](./contracts.registry.json) | список licensed-контрактов слоя |
| `yarn procedures:license` | выдать/проверить лицензии |
| `yarn procedures:license --check` | зуб CI: все контракты valid |

Штамп в голове файла:

```html
<!-- contract: parser@1.0.0 · generated: yarn vocabulary:generate · source: docs/procedures/vocabulary.json — руками не править -->
```

Legacy-штамп `<!-- generated: … из … — руками не править -->` принимается
парсером 1.0.0 (окно совместимости), но генераторы пишут уже новый формат.

## Пилоты Ф3
