# Ядро настроек процедуры (Ф1 / #1220)

Публичный контракт минимальных полей, которые процедура **гарантирует**.
Смена имён или смысла = ломающая версия. Расширять неохотно.

Образец формы шагов — [`docs/tasks/evening-ritual-steps.json`](../tasks/evening-ritual-steps.json)
(единственный живущий машинный манифест шагов до этой фазы).

## Поля

| Поле | Смысл | Обязательность |
|------|--------|----------------|
| `trigger` | как запускается | в ядре |
| `steps` | последовательность с id и критичностью | в ядре |
| `gates` | где поток обязан остановиться и ждать человека | в ядре |

Поля Р1 (`id`, `leadPersona`, `kitVersion`, `engines`, `precedents`) и очередь
кадров (`preflight` / `frames` / `post`) — **не** ядро: они уже закрыты вердиктами
procedural-layer / procedure-frames. `mode` и `home` — [`HOME.md`](./HOME.md)
(Ф2 #1220).

## Легальное «нет»

У каждого поля ядра обязан быть отказной носитель с причиной — иначе заполнение
порождает заглушки (#1219). Общий вид:

```json
{ "kind": "none", "why": "одна непустая причина, почему поля честно нет" }
```

`why` пустой / отсутствует / шаблон вроде `"TODO"` / `"n/a"` — дефект схемы.

## `trigger`

| `kind` | Поля | Смысл |
|--------|------|--------|
| `schedule` | `cron` (строка), `timezone?`, `note?` | расписание (cron office / внешний кожух) |
| `captain-word` | `command?` (yarn/CLI), `note?` | явное слово капитана / агента |
| `procedure-event` | `procedureId`, `event`, `note?` | событие другой процедуры |
| `none` | `why` | легальное отсутствие триггера |

## `steps`

| `kind` | Поля | Смысл |
|--------|------|--------|
| `ref` | `path` (от корня репо) | единый источник — внешний JSON с массивом `steps` |
| `inline` | `items[]` | шаги в манифесте |
| `none` | `why` | легально нет машинных шагов |

Элемент шага (`items[]` или элемент массива `steps` у `ref`):

| Поле | Правило |
|------|---------|
| `id` | kebab-case, уникален в пределах процедуры |
| `criticality` | `critical` \| `noncritical` (по умолчанию у живых манифестов — critical) |
| `whyNoncritical` | **обязан** при `noncritical`, запрещён при `critical` |

`ref`: файл существует; корень JSON содержит массив `steps`; каждый элемент
проходит ту же суб-схему (лишние поля файла-источника допустимы — ядро читает
только id/criticality/whyNoncritical).

## `gates`

| `kind` | Поля | Смысл |
|--------|------|--------|
| `inline` | `items[]` | точки паузы на человека |
| `none` | `why` | потока с машинной паузой нет |

Элемент гейта:

| Поле | Правило |
|------|---------|
| `id` | kebab-case, уникален в пределах `gates` |
| `waitsFor` | `owner` \| `human` |
| `resume` | непустая строка: как поток возобновляется |
| `note?` | уточнение (где живёт гейт, если вне `steps`) |

Проверка на бумаге 26.07: гейт магистрали (`magistral-choice`) описывается ядром
утренней процедуры; гейт отчёта партнёрам (`partner-swallow`) — вечерней. Натяжек нет.

## Зуб

Живёт в `scripts/lib/validate-procedure.mjs`:

1. **Нет ни одного поля ядра** → находка (`findings[]`), `valid` не роняется
   (миграция по касанию; Ф5 заполнит корпус).
2. **Частичное ядро** (есть одно/два из трёх) → дефект схемы (отказ).
3. **Полное ядро** → суб-схема; провал → `manifestSchemaOk=false`.
4. Пилоты Ф1 (`ritual-evening`, `bridge`, `ritual-dreams`) обязаны нести полное
   валидное ядро — жёсткий тест в `scripts/validate-procedure.test.mjs`.
