## Тезисы (только подтверждённые владельцем)

1. **Т1 — пульс.** При включённой уборке тревога, если успешного прогона нет дольше 2 ч (один пропуск ежечасного запуска допустим, два — сигнал). _Подтверждено владельцем 08.10 («1 ок»)._
2. **Т2 — осиротевший файл.** До 5 попыток, затем «безнадёжный» (dead_letter); в v1 — только видимость в панели, оповещения позже. _Подтверждено владельцем 08.10 («2 да»)._
3. **Т3 — удаление прибора.** Запрещено, пока у прибора есть замороженный архив; пользователю — объяснение и ссылка на архив; каскад `onDelete: Cascade` архива от прибора снять. Альтернативы (передача уборщику, отвязка) отклонены. _Подтверждено владельцем 08.10 («3 тоже да»)._
4. **Т4 — приёмка уборки живым сценарием, не счётом холостых прогонов.** Аккаунт september: на старшем тарифе забить буфер → понизить на средний (лишнее в архив) → дождаться удаления по графику (уборка включена, без ручного запуска) → аудит удаления по журналу, базе и диску → тот же круг со среднего на младший. _Подтверждено владельцем 08.10 (сценарий; уточнение «от среднего к младшему»)._ Буфер заполняется записью с прибора (прибор будет в сети). _Уточнено владельцем 08.10 («а»)._
5. **Т5 — где журнал.** График удалений — отдельная вкладка в панели офиса; в «Пользователях» — только пометка в таблице «архив ждёт удаления». _Подтверждено владельцем 08.10._
6. **Т6 — выключено = тишина.** При выключенной уборке прогоны не пишутся (решение 05.10 сохранено); вкладка «График удалений» показывает режим по флагам. _Подтверждено владельцем 08.10 («поддерживаю»)._
