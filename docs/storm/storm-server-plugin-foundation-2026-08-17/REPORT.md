## Что породил шторм (сжато)

1. **Определение** (Т1): плагин = возможность модуля, изолированный блок под версией,
   включаемый/выключаемый; общие библиотеки изоляцию не нарушают.
2. **Два темпоральных режима** (Т2): постфактум по накопленному · накопительный/живой
   (тренды в реальном времени); повод (запрос/подписка) — часть крепления.
3. **Одиннадцать свойств основы** (Т3): три рода плагинов внутри крепления; модули-дома
   (журнал · коллекции); общий дом результатов «модуль → плагин → версия → коллекция →
   прогон»; два отпечатка в каждом результате (вход + конфигурация); первая волна — шесть
   детекторов; данные для картины, не картина; повод обязателен; заморозка состояния при
   выключении; сходимость живого и пересчёта как зуб; окно накопления; сдача основы
   только с первым живым плагином.
4. **Развилка решена** (Т4): у сервера **свой набор контрактов**; `packages/agenda`
   и 21 клиентский плагин не трогаются; свойства переносятся как принципы, не как код.
