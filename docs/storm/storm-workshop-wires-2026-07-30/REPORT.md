## Что установлено (10 тезисов владельца)

| # | Тезис |
|---|-------|
| T1 | Провод — **хук на старте сессии**, а не ссылка в документе: сразу список мастерских, описание, ссылка на документацию; греп — последним |
| T2 | Хук **в тот же момент валидирует инвентарь**; инвентаризация двухуровневая (холодная сессия + неделя); минимум — список и «с чем работает» |
| T3 | Первое представление дают **фундаментальные документы**, они же несут паттерн: сначала искать инструмент мастерской |
| T4 | Профиль сессии **неизвестен**; дополнительные инструменты приходят **через вызов процедур** — это фрейм процедуры |
| T5 | Это фрейм **`kit`**, а не «провода»; набор кита **не обязан** лежать в одной мастерской |
| T6 | **Неприпаркованных скриптов быть не должно**; контейнер `scripts` своей мастерской распределяет их по домам |
| T7 | Подходящего дома может не быть — тогда **парковка показывает, каких контейнеров не хватает** |
| T8 | `network` — контейнер, и он есть: **дом может существовать, не будучи виден в списке мастерских** |
| T9 | **Дом лучше, неймспейс — обязательный минимум** (для прикладных и для двумерных контейнеров); оба обязаны быть в **справочнике** и находиться его инструментами; справочник — **атлас** |
| T10 | Мастерская скриптов **покрывает аудит скриптов**: говорит прямо, есть ли бесхозные, и **подсвечивает, в каких наборах** лежит скрипт |

## Три слоя недостачи — замерено, не оценено

| слой | величина |
|---|---|
| контейнеры без манифеста мастерской | **33 из 45** (`docs/**` с README) |
| мастерские без кита | **10 из 12** (`kit: null`) |
| скрипты без парковки | **476 из 604 (79 %)**; как **инструмент** кита (в `roots`) — только **36 (6 %)** |
| справочник (атлас) знает | **12** контейнеров; понятия «неймспейс» — нет |
| мастерская скриптов | манифеста **нет**; глаголов T10 не существует |

Слои **вложены**: парковать некуда, пока нет китов; кит не объявишь, пока дом не мастерская;
дом не найдёшь, пока справочник ищет по манифестам. Отсюда порядок работ — следствие
замеров, а не предпочтения.
