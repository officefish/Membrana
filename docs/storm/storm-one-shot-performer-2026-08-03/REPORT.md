## Рамка, установленная на открытии

Предмет ýже, чем читался в #1651: **судья у шота уже есть** — по T4 шторма 23.07 штамп S
ставит тимлид поверх чистой функции, самоаттестация исключена. Открытым был не «судья и
делатель», а исполнитель шага `execute`: кто он, кто его называет, чем доказывается
причастность.

## Подтверждённые тезисы

| # | Тезис |
|---|---|
| **Т1** | Исполнитель шота — обязательный **профильный контекст**, а не лицо: разделение покупает другую линзу, не другую голову. Все персоны играет одна сессия, и честнее спрашивать «через что обязан пройти execute», а не «кто в каком гриме» |
| **Т2** | Существо требования к объёму — **шот проходит одним прогоном ревью**. 400 строк — граница oversized-ревью, *диагностика* требования, не порог шота. Порог предиката S остаётся **200 строк / 8 файлов** |
| **Т3** | Шот может состоять из нескольких фаз, но исполняется **всегда одним исполнителем** |
| **Т4** | **Исполнителя назначает тимлид** |
| **Т5** | Несколько совершенно разных по тематике блоков — уже не шот, а **спринт**: граница формата проходит по тематической однородности |
| **Т6** | Однородность судит тимлид, но ему нужно **измеримое основание** — предикат под суждением, а не вкус (тот же образец, что штамп S) |
| **Т7** | Фазы шота = **пункты ратифицируемого чек-листа**, не сущность манифеста. Держатель, след и вердикт есть только у шота целиком: один исполнитель, одна зона, одна ратификация, один след контекста |
| **Т8** | Шот **копит прогоны и формирует портфолио**, и это опирается на **фреймы процедуры**. `home: none` остаётся про отсутствие пространства имён, но накопление появляется: прогоны в общей ленте, портфолио на фреймах |

Провенанс каждого тезиса — в [`THESES.md`](./THESES.md); Т1 и Т7 рождены голосом
питомца (`origin: pet`, вне гейта) и подтверждены владельцем — в основаниях подтверждение,
не реплика.

## Фактура сверх тезисов (найдено по ходу, не рождено)

Предикат S (`scripts/lib/one-shot-s-predicate.mjs`) уже умеет больше, чем помнила беседа:

- **меряет диффом** — число файлов и строк: годится и для прогноза при штампе, и для факта
  при «код дописан», прибор один;
- **`pathFamily` и смежность путей** — готовое измеримое основание для Т6, строить не надо;
- **анти-цепочка** — три смежных шота за 7 суток либо 8 файлов / 200 строк суммой по окну =
  отказ: Т5 уже защищён с обратной стороны, спринт, нарезанный на шоты, ловится.

Вывод фактуры: достраивать надо **манифест процедуры, не приборы**.

## Смещение предмета — названо честно

Заявленная тема — «исполнитель для одноразового прохода». Фактический предмет к закрытию —
**манифест шота целиком**: исполнитель оказался одним из четырёх хвостов, и решился быстрее
прочих (Т1+Т4 на втором вдохе). Смещение произошло словом владельца (Т2, Т5, Т8 — его
требования к формату), зафиксировано, не замолчано.
