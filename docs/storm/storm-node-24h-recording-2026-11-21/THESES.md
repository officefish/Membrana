# Шторм: беспрерывная работа с записями на одном приборе полные сутки

- **Статус:** CLOSED (седьмой вдох, развилка названа владельцем: «на заседание») · открыт 2026-11-21 словом владельца («Идем в шторм»; предмет — «Бесперрывная работа с записями на одном приборе полные сутки.»)
- **Предмет:** один прибор (Студия + служба узла на Windows-ПК) сутки напролёт пишет и слушает без присмотра человека; магистраль `node-permanent-duty`.

## Тезисы (только подтверждённые владельцем)

1. **Т1 — прибор прежде всего детектор.** Доска запускает разные сценарии; постоянная запись на сервер — лишь один из режимов работы и не обязательна. Шторм говорит о сценарии с постоянной записью. _Слово владельца 21.11._
2. **Т2 — запись живёт сессиями с выборкой.** На сервере задаются длительность сессии и объём выборки. По итогам сессии из буфера отбирается заданное число записей по одному из трёх существующих критериев отбора (превышение над фоном `loudness-over-floor` · спектральное разнообразие `spectral-variety` · похожесть на дрон `drone-likeness` — тот же словарь, что у отбора при понижении тарифа). Результат выборки кладётся в библиотеку. Пример: сессия 4 ч, выборка 200 записей, самые громкие. _Слово владельца 21.11._
3. **Т3 — политика сессий у каждого прибора своя, задаёт пользователь в кабинете.** Сейчас запись идёт с одного прибора, но под одной мембраной будет несколько приборов, все работают с одним сервером, и для каждого прибора задаётся своя политика поведения (длительность сессии, объём и критерий выборки). _Слово владельца 21.11._
4. **Т4 — после сессии буфер освобождается.** Остаток буфера после выборки удаляется, в холодный архив не уходит. _Слово владельца 21.11 (К5 вариант «а»)._
5. **Т5 — библиотека живёт кольцом дежурств; место докупается.** Память библиотеки не бесконечна: если для выборки нового дежурства не остаётся места, удаляются самые старые дежурства. Память библиотеки можно будет увеличивать дополнительно — это одна из дополнительных услуг. _Слово владельца 21.11._
6. **Т6 — сейчас запись нужна для библиотек звуков; детекция — особый сценарий будущего.** Детекция дрона — особый сценарий: когда-нибудь он станет основным, и в журнал будут записываться только звуки дронов по мнению прибора. Но прибор нужен и для создания библиотек звуков: сейчас нам нужны записи для формирования баз звуков для будущих детекторов. _Слово владельца 21.11._
7. **Т7 — сессия — папка в библиотеке, кольцо трогает только их.** Выборка каждой сессии лежит в библиотеке отдельной папкой с подписью (прибор, время сессии, «N из M», критерий). Кольцо (Т5) удаляет только такие папки целиком; наборы пользователя и записи, вынесенные из сессий, не трогает. Политика сессий строится по образцу политики буфера (#2308): у прибора своя, мембрана может задать общую. _Слово владельца 21.11: «про кольцо все верно»._
