# `forecast` — четвёртый род записи памяти: «моё предсказание ↔ его исход»

> Словарная статья блока `experience-loop` (Cowork Sprint `cowork-honest-sprint`, Phase 2).
> **Один источник значений слов блока.** Ничто в `scripts/lib/sprint-experience/**` не имеет
> права заводить своё значение слов «предсказание», «исход», «остановка», «объём».
>
> Формы плана нарезки, журнала остановок и ленты вещдоков — **односторонние допущения**
> (`../../cowork-sprint/cowork-honest-sprint/team-experience-loop/EXPECTATIONS.md`), сведение на
> Interface Consilium. В Phase 2 блок живёт на своих стабах и только на них.

## 1. Зачем род

Три известных рода отвечают на «что было»: **позиция** (`class: position`), **след исполнения**
(вердикт M8), **оценка чужого** (ревью, фидбек). Четвёртый отвечает на другое — **«насколько я
умею предсказывать»**, и потому он единственный, где автор судит **самого себя**, и единственный,
который **учит**: в остальных трёх нет собственной ошибки.

Отсюда две конструктивные особенности, которых нет ни у одного из трёх:

1. **Два момента времени в одной записи** — `predictedAt` и `observedAt`, с обязательным порядком.
   Трём известным родам достаточно одного момента.
2. **`predicted` неизменяем после фиксации.** Автор, правящий предсказание, увидев исход, всегда
   прав, и запись перестаёт учить. `predictedAt < observedAt` + append-only — не гигиена, а
   условие существования рода.

## 2. Поля

```
ForecastRecord = {
  id           : '<personaId>-<sprintId>-<subject>-<seq>'   // стабилен и адресуем
  class        : 'forecast'          // дискриминатор рода (см. §6 — шов)
  subject      : 'cut' | 'stop'      // 'cut' → тимлид/нарезка · 'stop' → ведущая/остановки
  personaId    : PersonaId           // держатель предсказания
  sprintId     : string              // окно, к которому предсказание относится
  predicted    : Predicted           // ЗАФИКСИРОВАНО ДО РАБОТЫ, immutable (deep-frozen)
  predictedAt  : ISO                 // из данных, не из системных часов
  ratifiedBy   : 'owner' | { none: причина }
  observed     : Observed | { none: причина }   // ИСХОД, из следов, ПОСЛЕ работы
  observedAt   : ISO | null
  outcome      : 'hit' | 'miss' | 'not-observed' // «почти» не существует (M3)
  evidence     : Ref[]
  provenance   : { planRef, traceRef, sessionId? } // сессия — транспорт, не автор (M8)
}

Ref = { type: 'path'|'sha'|'pr'|'card'|'artifact', value: string }
```

`subject: 'cut'` — предсказание тимлида о нарезке:

```
Predicted = { blocks: [ { cutBlockId, contextPersonaId, claim: 'fits' | 'does-not-fit' } ] }
Observed  = { blocks: [ { cutBlockId, changedLines: int, verdict: 'fitted' | 'overflowed' } ] }
```

`subject: 'stop'` — предсказание ведущей об остановке этапа:

```
Predicted = { stopId, stageId, objectRef: Ref, claim: 'stage-not-passed', stoppedAt: ISO }
Observed  = { resolvedAt: ISO|null, changes: Ref[], useful: boolean|null }
```

Решения по полям, которые надо помнить, читая код:

- **`claim` — перечисление, а не число.** Мерка ревью бинарна, и заявка обязана быть в той шкале,
  в которой придёт исход. Число строк живёт **только** в `observed`: оно наблюдение, не заявка.
- **`claim: 'does-not-fit'` существует** — легальное «нет с причиной» для заведомо переполненного
  блока. Без этой ветки честное «не влезет» пришлось бы прятать в пустое поле, а пустое поле —
  не отказ.
- **`objectRef` у остановки обязателен.** Остановка без названного объекта делает предикат
  полезности невычислимым: это **дефект записи**, а не запись с неизвестным исходом. Валидатор
  отвергает такую запись, метрика на такой вход **бросает**, а не подставляет ноль.
- **Отсутствие всюду выражено формой `{ none: причина }`** (приём живого `case-store.mjs`), не
  `null`-ом и не пропуском поля: отказ обязан быть читаемым, а пустота неразличима от забывчивости.
- **`sessionId` — только в `provenance`.** Персона держит предсказание, сессия его набирает.

## 3. Две метрики: два автора, две мерки

| | `cutAccuracy` (тимлид) | `falseStopRate` (ведущая) |
|---|---|---|
| Сигнал | **бинарен** на блок | **не бинарен** — доля |
| Предикат | `changedLines > threshold ? 'overflowed' : 'fitted'` | `useful ⟺ ∃ изменение в `(stoppedAt, resolvedAt]`` |
| Направление | выше — лучше | **ниже** — лучше |
| Обязательная пара | `blocksCount`, `overflowRate` | `stopsCount`, `unresolvedCount` |
| Знаменатель | блоки с наблюдаемым исходом | **разрешённые** остановки |

Одна мерка на два сигнала была бы либо бинаризацией доли (потеря), либо усреднением бинарного
(подгон) — поэтому род один, а функций две, и они лежат в разных файлах.

**Единица объёма — изменённые строки:** `changedLines = insertions + deletions`. Не файлы, не
коммиты, не токены, не «размер на глаз». Порог одной проверки код-ревью — `OVERSIZED_CHANGED_LINES`
(**400**), **импортируется** из `scripts/lib/day-work-diff.mjs` и уходит в функцию **параметром**.
Своего порога блок не заводит и файл ревью не правит.

**Полезность остановки считается по ленте вещдоков окна, а не по слову ведущей.** Изменением
является адресуемое событие из закрытого перечня `new-ref | contract-version | sha | status`.
Неадресуемое «что-то поправили» изменением не является — иначе предикат становится вежливостью.
Отмена или переделка этапа полезной **тоже** является, но приходит она как `status`-изменение в
ленте: признавать её по полю `resolution` (слово ведущей) блок отказывается — это лазейка
самозаверения.

## 4. Что означает ОТСУТСТВИЕ метрики

Ратифицированный запрет (вердикт M5, 30.07): **«чисто» при пустом корпусе — это «корпуса нет».**
Ноль записей опыта ≠ «учиться нечему»; ноль остановок ≠ «ложных нет».

```
Metric = { defined: true, value, numerator, denominator, pair }
       | { defined: false, reason: AbsenceReason }

defined ⇔ denominator > 0
```

Закрытый алфавит `AbsenceReason`:

| Метрика | Причина | Что означает |
|---|---|---|
| `cutAccuracy` | `no-cut-forecast` | предсказания нарезки нет |
| | `no-observed-outcome` | нарезка есть, ревью до блоков не дошло |
| | `forecast-not-ratified` | план не ратифицирован владельцем |
| | `no-attribution` | сегменты ревью не привязаны к `cutBlockId` |
| `falseStopRate` | `no-stops-recorded` | остановок ноль — **не** «ложных нет» |
| | `stops-unresolved` | все остановки не разрешены |
| | `no-lead-appointed` | окно шло «без ведения» (M6) |

Правила вывода, стоящие под зубами `scripts/sprint-experience.test.mjs`:

1. **Рядом с `defined: false` процент не печатается никогда** — ни `0%`, ни `—%`, ни `n/a`.
   Зуб строже: в графе значения неопределённой метрики не должно быть **ни одной цифры**.
2. **Подстановка нуля (`?? 0`, `|| 0`) в метриках запрещена** — зуб `no-nullish-zero-in-metrics`
   читает исходники метрик. Подстановка превращает «не наблюдали» в «наблюдали ноль».
3. **Обе метрики неопределены → отчёт говорит «КОРПУСА ОПЫТА НЕТ»** — не «всё хорошо» и не молчание.
4. Доля печатается **со счётчиками**; `без исхода: k` и `не разрешены: k` — обязательные строки,
   иначе промах прячется в «ещё не доехало» и в «ещё в работе».

## 5. Номинация 5–7 прогонов

Отбор **только номинирует**: `nominateRuns` — чистая функция, файлов не пишет вовсе, `docs/cases/**`
не касается. Запись в канон делает человек по слову владельца (норма живого снимка
`docs/cases/registry/NOMINATIONS.md`). Снимок рендерит отдельный шаг → `RUN_NOMINATIONS.md`.

Единица отбора — **прогон** (окно), а не запись: образец нарезки это целый план из нескольких
блоков. Промахи из памяти не исчезают — их читает журнал персоны; в пред-спринтовый фрейм едет
образец.

Допуск: предсказание до работы (+ратификация для `cut`) · исход наблюдаем и вещдоки разрешаются ·
содержательность (`blocksCount ≥ 2` / `stopsCount ≥ 2`) · для `cut` — `cutAccuracy = 1`.

**Порога по `falseStopRate` НЕТ** (решение владельца 30.07, `OWNER_ANSWERS.md` §3): номинировать
без отсечки, метрику печатать **рядом** с номинацией, порог назначить позже по накопленным данным.
Прежний `≤ 0.2` снят **вместе с самим порогом**, а не заменён другим числом: ложных остановок не
измерено ни одной, а число до первого измерения — изобретение. Качество прогона несут **порядок**
(точность → содержательность → свежесть → `id`) и напечатанная рядом метрика.

`cutAccuracy = 1` остаётся: это не назначенная граница, а конец собственной шкалы — «все блоки
совпали».

Окно 5–7 — **достаточность, а не квота.** Годных меньше пяти → снимок говорит
`корпус тонкий: N из 5`; **добора неточными прогонами нет** — тот же запрет M5, применённый к
отбору. Годных больше семи → восьмой уходит в `waiting` с причиной `beyond-read-budget`, а не
исчезает молча: чтение идёт **перед** спринтом, в холодном контексте, и восьмой выталкивает бриф.

## 6. Инварианты и открытый шов

| Инвариант | Значение | Чем НЕ является |
|---|---|---|
| Идентификатор блока | `cutBlockId`, `^[a-z0-9][a-z0-9-]*$`, уникален в пределах `sprintId` | не путь, не имя персоны, не номер PR. **Омоним разведён:** блок нарезки ≠ блок коворка |
| Идентификатор персоны | `personaId` — слаг из `docs/virtual-team/memory/*.md` | не имя модели, не `sessionId`, не «Ангелина» |
| Владелец времени | **данные**: `predictedAt < observedAt`, `stoppedAt ≤ resolvedAt`; границы окна даёт сосед | не системные часы. `Date.now()`/`Math.random()` в блоке отсутствуют, `now` — параметр |
| Единица объёма | `changedLines = insertions + deletions`, порог 400 параметром | не файлы, не коммиты, не токены |

**Открытый шов Phase 3.** Живой архив несёт `class: position` + `kind: verbatim`; вердикт M8
говорит `kind: execution`. Дискриминатор рода односторонне **не решается**: здесь выбран
`class: 'forecast'` (живая форма — авторитет для живого архива), сведение — на Interface Consilium.

## 7. Как запустить (Phase 2 — только `node`, без `yarn`)

```bash
node scripts/sprint-experience.mjs --list-stubs
node scripts/sprint-experience.mjs --record cut-exact --dry-run
node scripts/sprint-experience.mjs --record no-stops        # ноль остановок → слова, не 0%
node scripts/sprint-experience.mjs --nominate rich --now 2026-07-30T19:00:00Z
node --test scripts/sprint-experience.test.mjs
```

Записи `yarn sprint:experience` в `package.json` **нет и в Phase 2 не будет** — провода вносит
адаптер интеграции. Дом журнала рода в Phase 2 — своя зона (`--out`, по умолчанию
`docs/sprint/experience/forecast-records.jsonl`, в репозиторий не коммитится); настоящий дом —
`docs/virtual-team/memory/archive/<persona>.jsonl` через адаптер Phase 4.
