## Фокус дня

**Построить живой `ingest`-эндпоинт `archivarius-sessions-container` с подтверждённым trace в вечернем протоколе.**

Три дня подряд магистраль стартовала без исполняемого тела `yarn main-day-probe` — посылки фиксировались как `unknown`, а не `holds`/`violated`, и работа не начиналась. Сегодня цепочка разрывается в конкретной точке: сначала проверяем существование скрипта `main-day-probe` в `package.json` (буквально: `cat package.json | grep main-day-probe`), получаем письменный вердикт по трём посылкам (`sessionIngest`, `span-schema.ts`, `searchSpan`), и только тогда — первая строка кода. Параллельно: ревью oversized PR #1907 и #1908 до старта реализации, потому что Vesnin зафиксировал скрытый C1-риск в фундаменте archivarius ещё вечером 13.08 — без этих ревью ingest-слой кладётся на непроверенный фундамент. Критерий успеха к вечеру: вечерний протокол команды содержит **живой trace** вызова `sessionIngest` с реальным span (uuid, timestamp, sessionId, maskedPayload) — или письменный диагноз блокера с указанием PR и причины.
