## Фокус дня

**Закрыть ворота вехи `secret-parser-built`: резак в `night-triage-secret-scan.mjs` + датированный манифест ротации ключей.**

Веха `secret-parser-built` — единственный активный гейт горизонта (`STRATEGY_DAY.md`); пока он не закрыт, амнистия на правку архива не снята, а значит ни работа с архивом сессий, ни следующий шаг (`batch-collection-run-contour`) не открываются. Code-review зафиксировал два независимых риска, которые прямо блокируют старт новых задач: красный билд `@membrana/media-library-service` / `@membrana/background-media` и B5-риск в trail (ретрай `r2` без диагноза gap `morning-care`). Оба нужно устранить **до** основной работы дня — иначе любая новая задача стартует в нестабильной среде.

**Критерий успеха к вечеру:**
1. `night-triage-secret-scan.mjs --cut` на fixture-файле с синтетическим секретом: вырезает, возвращает ненулевой статус при dry-run без резака.
2. Датированный манифест ротации засвеченных ключей зафиксирован одним коммитом.
3. Билд `@membrana/media-library-service` + `@membrana/background-media` — зелёный (`yarn turbo run build test --filter=...`).
4. Gap `morning-care` в trail разобран: либо добавлена `friction`-запись с причиной, либо зафиксировано «причина не воспроизводится».

**Главный риск:** манифест ротации может вскрыть незакрытые секреты в истории сессий — тогда масштаб прохода вырастет с «один коммит» до «несколько затронутых файлов»; держим под контролем объём через `grep` до начала резки.
