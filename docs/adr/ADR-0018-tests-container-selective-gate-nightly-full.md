# ADR-0018 — Мердж-гейт выборочный, полный набор ночной; дом тестов — корневой `tests/`

> **Статус:** DRAFT · 2026-07-26
> **merge файла ≠ принятие решения** пока статус DRAFT — решения действуют после LGTM владельца.
> Эпик `tests-container` · фазы [#1291](https://github.com/officefish/Membrana/issues/1291), [#1292](https://github.com/officefish/Membrana/issues/1292), [#1293](https://github.com/officefish/Membrana/issues/1293)

## Контекст

Замер 26.07 после перехода `test:scripts` на открытие по дереву ([#1263](https://github.com/officefish/Membrana/issues/1263)):
**222 файла, 2000 проверок, 1 мин 02 с локально**; в CI работа «Lint, typecheck, test, build» —
2–9 минут, и она идёт **на каждый коммит каждой ветки** при 12 живых рабочих деревьях.

Слово владельца: «из-за каждого коммита гонять 2000 тестов это не дело; полные прогоны будут,
но они будут ночными».

Одновременно вскрылся факт, который делает наивный выбор опасным: **11 тестов в `scripts/lib/**`
(81 проверка) не гонялись в CI неизвестно сколько недель** — гвард покрытия читал только верхний
уровень `scripts/`. То есть состояние «мы это не гоняем» у нас уже существовало, и существовало
**молча**.

## Решение

1. **Мердж-гейт — выборочный.** Мердж блокируют `smoke` (предикаты, которыми стоят ритуалы дня)
   и `gate` (изменённое и зависимое от него).
2. **Полный набор (`full`) — ночной**, на `main`; живые ветки — по требованию
   (`workflow_dispatch`), чтобы ночь не распухла на 12 деревьев.
3. **Ночь исполняется только от пина** (`pinned`, кит `kits/tests-master`) — требование
   [`PINNED_SUBGRAPH_VERSIONING`](../patterns/PINNED_SUBGRAPH_VERSIONING.md): автономный прогон
   без владельца рядом обязан быть воспроизводим.
4. **Результат ночи приходит в утро через фрейм процедуры**, а не письмом: фрейм `night-report`
   процедуры `ritual-day` получает носитель (`pins` с `anchor` + `segmentHash`), красный садится
   в `gates` утра как **блокер дня**. Устаревший отчёт — отдельный, отличимый блокер.
5. **Дом контейнера тестов — корневой `tests/`** монорепозитория (сетапы, селектор, отчёты,
   харнесс). `docs/procedures/tests/` — **определение** процедуры, не дом её содержимого.
   Юнит-тесты остаются рядом с кодом; массового переноса нет.
6. **Оснастка дома — мастерская** ([`HOME_WORKSHOP`](../patterns/HOME_WORKSHOP.md)):
   `tests/workshop.manifest.json`, `worksOn` — ровно один дом, кит — `kits/tests-master`.

## Обязательное условие честности

**Выборочный гейт легален только вместе с отчётом «что не гонялось».** Без него решение
узаконивает ровно тот дефект, который сегодня нашёлся случайно: набор молча сужается, а зелёный
продолжает выглядеть полным. Это же требует и `HOME_WORKSHOP` (дефект №3 паттерна — «немой отказ
оснастки: тихо пустой результат вместо видимой ошибки»), поэтому `verbs.audit` дома тестов
отвечает на вопрос «что не гонялось», а не только «что прошло».

## Предусловие

Ночь на `main` включается **после защиты `main`** (слово владельца 26.07). Тот же ход
разблокирует серверное автослияние `--auto` ([#1261](https://github.com/officefish/Membrana/issues/1261)):
без required-checks в защите auto-merge не встаёт — 26.07 флаг поэтому откатывался на локальное
ожидание. Настройка branch protection — ход владельца, не скрипта.

## Альтернативы и почему отклонены

| Альтернатива | Почему нет |
|---|---|
| Оставить полный прогон на каждый коммит | 2–9 минут × каждый коммит × 12 деревьев; владелец назвал это неприемлемым |
| Делить набор по темам (группы #1263) | тема ≠ риск; группы — сырьё для сетапов, но не критерий блокировки мерджа |
| Выбор без отчёта об исключённом | воспроизводит сегодняшний дефект (81 проверка молчала недели), только узаконенно |
| Отчёт ночи письмом / в почту | молчащий канал (прецедент `night:research` в вечном `pending`); утро должно **останавливаться**, а не читать письма |
| Дом тестов в `docs/procedures/tests/` | это определение процедуры; дому содержимого нужен основательный корневой каталог (решение владельца) |

## Следствия

- `smoke`/`gate` становятся контрактом мерджа **для всех сессий** — отсюда ADR, а не молчаливая правка CI.
- Появляется новый дом первого ранга (`tests/`) и новый кит (`kits/tests-master`).
- `homePath` в реестре процедур обязан начать работать: сегодня
  [`scripts/lib/procedural-workshop.mjs`](../../scripts/lib/procedural-workshop.mjs) игнорирует
  поле и жёстко склеивает `docs/procedures/<id>`, то есть дом вне `docs/` был бы объявленной ложью.
- Ночной красный получает адресата и цену: день не начинается, пока он не разобран.

## Проверяемость

| Утверждение решения | Чем доказывается |
|---|---|
| `gate` меньше полного набора | замер числа файлов на типовой правке (#1292) |
| селектор не врёт | правка модуля → его тест в `gate`; несвязанная правка → нет (доказать падением) |
| ничего не выпадает из всех сетапов | программная сверка «объединение сетапов ⊇ полный набор» |
| ночь воспроизводима | в отчёте назван SHA-пин кита; режим `pinned` |
| фрейм несёт носитель | `auditPins` ловит подсаженный дрейф отрезка |
| красный останавливает утро | подсаженный красный отчёт → утро не идёт дальше |
