# Прецедент 2026-07-29: приветствие — устаревшая картина из кеша памяти и локального дерева

<!-- Автор: Claude Code (Fable 5), сессия 29.07 в основном дереве Membrana (ветка feat/tooling-friction-2607, tip 26.07). -->

## Что случилось

На «Доброе утро!» владельца сессия по норме (прецедент 22.07) не запустила ни одной команды — но **озвучила картину «что сегодня в воздухе»**, собранную целиком из кеша:

1. **«по карте вчера: … на сегодня намечены Grok в overlay и отвязка feedback»** — из файла памяти `project_evening_llm_channels_gap` (чеканка **24.07**, формулировка «карта **на завтра**»). Реально этот план исполнен **28.07** (`yarn ask` и вечерний фидбек на панельной цепочке, прямые вызовы ловит зуб `llm-panel-wire`).
2. **«ветка сейчас feat/tooling-friction-2607, в ней незакоммичен affine-push.mjs»** — из снимка локального git; локальное дерево стояло на **26.07 19:31**, что не было названо.
3. «Вчера» в реплике на деле означало 25–26.07: **дыра 27–28.07 — два полных рабочих дня** (конституционный день мостика 27.07, топ-10 дня 28.07 закрыт 10/10) — была невидима и никак не оговорена.

Владелец поймал: «скорее всего твои задачи уже устарели, прочитай хендоф».

| Источник картины | Штамп времени | Что из него было озвучено |
|---|---|---|
| память `project_evening_llm_channels_gap` | modified **2026-07-24**, внутри «карта **на завтра**» | «на сегодня намечены Grok в overlay + отвязка feedback» — как актуальный план 29.07 |

Ключевая деталь: даже прочитанный до слова владельца **локальный** HANDOFF не спас бы — он тоже от 26.07. Свежесть точки входа определяется **origin/main**, то есть требует fetch.

## Корень

**Холодная сессия озвучила картину состояния из пассивного кеша как факт «сегодня».** Два усиливающих дефекта:

- **Память с относительной датой.** «Карта на завтра» без абсолютной даты и без обновления после исполнения читается новой сессией как вечное «завтра». Норма памяти («convert relative dates to absolute») была нарушена при чеканке 24.07.
- **Норма приветствия истолкована как «говори из кеша».** «Ноль команд до слова владельца» — правильно; но она не разрешает *утверждать непроверенное*. Легальные формы: молчание о состоянии, либо картина со штампами дат («по памяти от 24.07», «локальное дерево на 26.07»). Слова «сегодня в воздухе» / «на сегодня намечены» — нелегальны без верификации.

Класс — `cold-start`, рецидив: 21.07 и 22.07 холодные сессии шли по устаревшему *скиллу*, здесь — по устаревшей *памяти + локальному снимку*. Общая форма: кеш без даты пожирает актуальность.

## Фикс (в сессии)

- По слову владельца: `git fetch` → чтение `origin/main:docs/HANDOFF.md` (28.07) → исправленная картина в чате с явным «моя картинка была устаревшей на два дня».
- Файл памяти `project_evening_llm_channels_gap` перечеканен: план исполнен 28.07, относительная дата убрана, указание на панельную цепочку и зуб `llm-panel-wire`.

## Что вёл хорошо (не потерять)

- Ноль команд до слова владельца — норма 22.07 удержана.
- После сигнала владельца хендоф не принят слепо: замечено, что локальный от 26.07, сделан fetch, найден свежий 28.07 в origin/main.
- Отставание признано явно, без сглаживания.

## Профилактика

- **Приветствие холодной сессии:** присутствие + (опционально) картина, где у каждого пункта — штамп даты источника; «сегодня/вчера/намечено» без верификации — запрещённые слова.
- **Первое действие после слова владельца:** fetch + HANDOFF с origin/main (или агент `hermes`) — до любых утверждений о состоянии.
- **Гигиена памяти:** планы («карта на …») чеканить с абсолютной датой и статусом; при исполнении — обновлять или помечать исполненными. Относительная дата в файле памяти = дефект чеканки.
