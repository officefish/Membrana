## Хронология: три вопроса, три глагола

### Вопрос 1 — «Есть ли сейчас в проекте бесхозные скрипты?»

```bash
yarn scripts:orphans          # scripts/scripts-orphans.mjs
yarn scripts:orphans --json   # полный перечень
```

Вывод:

```
scripts:orphans · знаменатель 972 (инструменты ∪ тесты)
⚠ правил членства ноль — сиротство ниже означает «правила ещё нет», а не «место потеряно»
✖ бесхозных 47 из 972
```

`--json`: `status: has_orphans`, `counted: 47`, `denominator: 972`, `registryState: ok`.

**Существенное:** все 47 сирот без исключения — `*.test.mjs` (проверено фильтром по `--json`,
non-test пуст). Бесхозных **инструментов** ноль. Цифра «47» читается как поломка, но
предупреждение самого прибора говорит обратное: правил членства для тестов ещё не написано,
поэтому весь класс падает в остаток ровным слоем и будет расти вместе с числом тестов.

## Профилактика

- Справочный вопрос о скриптах — **узкий глагол**, не обход дерева: `scripts:orphans`
  (сироты), `scripts:sets-of <file>` (наборы), `tooling:atlas --check` (дрейф справочника),
  `tooling:overview` (общий обзор).
- Вывод глагола читать **целиком**: строка `⚠` меняет смысл строки `✖`. Докладывать
  предупреждение вместе с цифрой, а не цифру отдельно.
- Пока правило членства для `*.test.mjs` не написано — 47 сирот это **отсутствие правила**,
  а не потерянные файлы; чинить надо правило, а не файлы.
- Коллизию «хук против канона» держать в поле зрения: до записанного приоритета каждый
  агент решает её заново, и решения будут расходиться.
