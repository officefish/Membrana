## Инварианты подтверждены

- **Вход не перезаписан:** оба оригинала после прогонов побайтно целы (`Вход не изменён.`
  в stdout; проверено чтением).
- **Чистые строки уцелели:** строка без секретов дошла до копии нетронутой.
- **Манифест не является утечкой:** значения не приводятся — только правило, строка,
  длина (`> Значения не приводятся намеренно` в шаблоне манифеста).
- **Известное поведение, не дефект:** незакрытый `-----BEGIN … PRIVATE KEY-----` режется
  до конца блока и может поглотить соседние строки; манифест честно помечает
  «PEM без END-маркера». Для реального PEM (с END) рез точечный — покрыт зубами
  `secret-redact.test.mjs` (18/18).
