# Матрица тарифов

**Зачем.** Матрица отвечает на один вопрос: что получает пользователь на каждом из трёх
тарифов — «Датчик», «Блокпост», «Наблюдательный пункт». Строка — ресурс (буфер записи,
коллекции, приборы, наборы звуков, инструменты), колонка — тариф. У каждой строки есть
паспорт: кто и когда закрепил значение, откуда оно взято и каким правилом уезжает в
техническую сетку. Значение без даты закрепления — честно не закреплено, а не «примерно так».

**Статус.** С 8 сентября 2026 матрица — единственный источник правды о тарифах (шторм
«тариф как единая правда», тезисы T13–T16). Техническая сетка, из которой права читает
кабинет, — производная: её пересевают из этого документа, руками её не правят. Числа посева
базы до отдельного задания живут своей замороженной жизнью — расхождение с матрицей
печатается списком, а не прячется (консилиум 08.09 о судьбе скаляров).

> Этот документ собран генератором из гранул контейнера `docs/containers/strategic-docs/`.
> Чтобы изменить значение — правьте `resource.json` нужной гранулы и пересобирайте релиз;
> правка самого релиза будет перезаписана и ничего не изменит.

Основания: шторм `storm-tariff-single-truth-2026-09-08` (линейка владельца T1, системные
наборы вне квоты T2/T10, устройство матрицы T13–T16), консилиум
`tariff-matrix-scalars-fate-2026-09-08`, заседание `tariff-grid` 29.07 (приборы, инструменты).

## Матрица «тариф × ресурс»

Строка — ресурс, колонка — тариф (T14). Порядок колонок — по старшинству тарифа и живёт здесь, в шаблоне; гранула ресурса знает только свою строку.

| Ресурс | Датчик | Блокпост | Наблюдательный пункт |
|---|---|---|---|
| Буфер записи | 512 МиБ | 2048 МиБ | 4096 МиБ |
| Коллекции (горячая память) | 512 МиБ | 2048 МиБ | 4096 МиБ |
| Холодное хранилище | нет (не закреплено) | 2048 МиБ (не закреплено) | 2048 МиБ (не закреплено) |
| Приборы | 1 прибор | 4 прибора | 9 приборов |
| Сценарии | 3 сценария | 3 сценария (не закреплено) | 3 сценария (не закреплено) |
| Наборы звуков | набор датчика | набор блокпоста | набор блокпоста (заглушка) |
| Системные наборы | да, вне квоты | да, вне квоты | да, вне квоты |
| Тренды спектра | да | да | да |
| Словарь YAMNet | да | да | да |
| Тембральный портрет (MFCC) | нет | да | да |
| Пеленг и позиция | нет | при готовой сети | при готовой сети |
| Своё производство | нет | да: свой набор, свои детекции, сценарии на своих | да: свой набор, свои детекции, сценарии на своих |

**Легенда.** «(заглушка)» — тариф пока пользуется чужим набором, свой не назначен; «(не закреплено)» — значение владельцем не названо и взято как нижняя граница или как в прежней сетке; паспорт каждой строки (версия, дата закрепления, владелец, источник, правило пересева) — в `resource.json` её гранулы.

**Пересев.** Техническая сетка `docs/tariffs/tariff-grid.json` — производная этого релиза: `yarn tariff:reseed` собирает её из `release.json` и гранул, зуб `yarn tariff:grid` держит сетку равной релизу. Правки — только через гранулы и пересборку (T16).
