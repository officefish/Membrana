## Route: `one shot`

Use when there is one intention, one executor and one review boundary. The
reviewer must be able to complete the whole assessment in a single session
without hand-off.

Required evidence: focused scope, clear ownership, focused tests/checks and a
concise final note naming skipped team responsibility.

Do not use when the intent is diffuse, several owners are involved, seams are
unclear, the reviewer delegates or queues follow-up, procedure/accountability is
the product, or the owner asks for sprint.
