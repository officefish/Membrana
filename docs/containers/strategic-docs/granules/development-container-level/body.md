## Container Level

Containers are chains or systems of sprints. They are horizontal siblings, not
"bigger local sprint" synonyms.

`standing artifact` means a completed artifact that can be used or inspected by
the next stage without waiting for the whole container: code, tests, docs,
dataset slice, report or checkpoint.

`stage-completion-checklist` means the handoff object for a relay stage: changed
artifact, verification command/result, known gaps and next-stage input.

| Container | Distinguishing Field |
|---|---|
| `cowork` | Parallel isolation; seams are intentionally negotiated late. |
| `challenge` | Battle of alternatives; value is selection by judge. |
| `hackathon` | Relay; exactly four stage-completion-checklist handoffs. |
| `marathon` | Long finish discipline; each stage leaves something standing and can yield. |

If the intended container is not named before cutting work, default to
`membrana-local-sprint` or `one shot`, whichever the route matrix allows.
