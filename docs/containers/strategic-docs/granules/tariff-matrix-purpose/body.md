# Матрица тарифов

**Зачем.** Матрица отвечает на один вопрос: что получает пользователь на каждом из трёх
тарифов — «Датчик», «Блокпост», «Наблюдательный пункт». Строка — ресурс (буфер записи,
коллекции, приборы, наборы звуков, инструменты), колонка — тариф. У каждой строки есть
паспорт: кто и когда закрепил значение, откуда оно взято и каким правилом уезжает в
техническую сетку. Значение без даты закрепления — честно не закреплено, а не «примерно так».

**Статус.** С 8 сентября 2026 матрица — единственный источник правды о тарифах (шторм
«тариф как единая правда», тезисы T13–T16). Техническая сетка, из которой права читает
кабинет, — производная: её пересевают из этого документа, руками её не правят. Числа посева
базы до отдельного задания живут своей замороженной жизнью — расхождение с матрицей
печатается списком, а не прячется (консилиум 08.09 о судьбе скаляров).

> Этот документ собран генератором из гранул контейнера `docs/containers/strategic-docs/`.
> Чтобы изменить значение — правьте `resource.json` нужной гранулы и пересобирайте релиз;
> правка самого релиза будет перезаписана и ничего не изменит.
