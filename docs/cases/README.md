# docs/cases — контейнер кейсов

Дом-контейнер кейсов: записанных **удачных** импровизаций и прогонов. Кейс — **зеркало
прецедента** ([`docs/precedents/`](../precedents/README.md)): там разбор «что сломалось и
почему», здесь — «что сработало и чем доказано». Одна семья: оба про прогон, оба append-only,
оба с закрытыми перечнями, оба ссылаются на процедуру. Спека — Issue
[#1298](https://github.com/officefish/Membrana/issues/1298) (принята капитаном 26.07).

Прогон отвечает «процедура прошла?», кейс — «получилось ли хорошо?». Кейс свидетельствует,
а не поставляет (поэтому не кит) и не разбирает поломку (поэтому не прецедент).

## Подвал кейса: два слоя (спека 26.07)

### 1. Опознание — делает кейс адресуемым

| Поле | Смысл |
|------|-------|
| `id` | идентификатор = имя файла без `.md` |
| `date` | когда произошло (`YYYY-MM-DD`) |
| `home` | какая процедура/формат породили эпизод — из перечня `HOMES` |
| `span` | **указатель в архив**: `{session, reply, time}` |
| `actors` | кто участвовал (капитан, агент, роль) |
| `evidence` | список **id из индекса вещдоков** [`docs/evidence/registry.jsonl`](../evidence/registry.jsonl) |

Всё здесь либо выводится, либо **честно пусто**. Пока архив не отдаёт адресуемый отрезок
(кристалл `session-archive-must-yield-addressable-span`, эпик
[#1229](https://github.com/officefish/Membrana/issues/1229)) — в `span` стоит легальное
«нет», не выдуманная ссылка. Отрезки сессий приходят как вещдоки-изъятия от архивариуса
(`--store archivarius`) — кейсу нужен только их id.

### 2. Метки для расчёта — по ним агент считает

| Поле | Смысл |
|------|-------|
| `mechanism` | что произвело ценность — **только из** [`mechanisms.json`](./mechanisms.json) |
| `repeatable` | `repeatable` · `conditional` · `one-off-luck` |
| `cost` | цена измеримым: `{metric: passes|hours|attempts|runs|sessions, value: N}` |
| `proofs` | число и вид доказательств: `{count: N, kinds: [...]}` — питает треугольник намерения |
| `firmness` | твёрдость намерения, шкала 1–5 |
| `links` | связи: прецеденты, задачи, инсайты, кристаллы (опц.) |

**Метки — из закрытых перечней.** Свободный текст в поле оценки = зверь «Проза»
([#1204](https://github.com/officefish/Membrana/issues/1204)) на уровне данных: статистика
превращается в вымысел. Расширение перечня механизмов — **ADR + слово владельца**, как
`classes.json` прецедентов.

**Легальное «нет».** У каждого обязательного поля (кроме `id`) допустима форма
`{"none": "<причина>"}` — иначе обязательный подвал сам производит заглушки (зверь
«Заглушка», [#1219](https://github.com/officefish/Membrana/issues/1219)). `none` без
причины — находка валидатора.

## Форма записи

Один кейс = один файл `<id>.md`: мета-блок + человеческая проза (что происходило, чем
ценно, чего не хватает для повторения).

```
<!-- case-meta
{
  "id": "2026-07-26-<slug>",
  "date": "2026-07-26",
  "home": "bridge",
  "span": {"none": "архив не отдаёт адресуемый отрезок (#1229)"},
  "actors": ["капитан", "агент мостика"],
  "evidence": {"none": "вещдок-изъятие от архивариуса ещё не создан (#1229)"},
  "mechanism": "guard-over-yes",
  "repeatable": "repeatable",
  "cost": {"metric": "passes", "value": 1},
  "proofs": {"count": 1, "kinds": ["protocol"]},
  "firmness": {"none": "шкала не размечалась в эпизоде"},
  "links": ["issue:#1298"]
}
-->
```

Значения мета не должны содержать литерал `-->` (закрывает HTML-комментарий).

## Реестр и инструмент

Источник истины — сами файлы кейсов, **append-only**: правка задним числом запрещена,
поправка — новой записью со ссылкой (`links`). Снимок
[`registry/CASES.md`](./registry/CASES.md) — производный, руками не править.

```bash
yarn case:register --new <slug> --mechanism <key>   # каркас записи + пересбор снимка
yarn case:register --validate                       # audit: подвалы полны, evidence-ссылки живы
yarn case:register --rebuild                        # пересобрать снимок
yarn case:inspect <id>                              # паспорт кейса
yarn case:decompose --by mechanism|repeatable|home  # декомпозиция
yarn case:portfolio                                 # сводка: механизмы × ценность, что везение
yarn case:generalize                                # номинация повторяемых в кандидат-гранулы
```

`generalize` — **только номинация** (снимок [`registry/NOMINATIONS.md`](./registry/NOMINATIONS.md)):
кейс с `repeatable: repeatable` и живыми вещдоками становится кандидат-гранулой для каркасов
промптов; в канон ничего не пишется автоматически. Кейс без вещдоков честно помечается
«не готов к номинации».

## Границы

- Кейс — свидетельство удачи, не разбор поломки (прецедент) и не обобщённый класс (бестиарий).
- Пересказ кейсом не является: смысл, вынесенный агентом, — интерпретация. До адресуемого
  архива (#1229) первые кейсы записаны пересказами **по слову капитана 26.07** — их `span`
  несёт честное «нет».
- Требования к рефакторингу персонажей выводятся из кейсов **отдельной задачей** — здесь
  только материал.
