# Ранний мостик: формат взаимодополняющих голосов (имя Фаррелла, «капитан/владелец», «билет Фаррелла»)

**Что происходило.** Первый показанный капитаном кейс — мостик, где родились имя Фаррелла,
различение «капитан/владелец» и «билет Фаррелла». Три голоса не дублировали друг друга,
и ни один не был гейтом: «я детектор, он сирена». Попугай поднимал долги **из вещдоков
дня**, не выдумывал; секретарь фиксировала провенанс решений, не чинила их.

**Чем ценно.** Ценность создал **формат**: взаимодополняющие роли без права блокировки,
реплики заземлены в вещдоках, решения несут провенанс. Разбор этого кейса — материал для
окончательных требований к рефакторингу персонажей (выводятся отдельной задачей, не здесь).

**Чего не хватает, чтобы повторить.** Носители: голоса объявлены прозой и машинно не
поднимаются (зверь B9, прецедент `2026-07-25-bridge-room-declared-cast-without-carriers`).
Формат дал ценность — носители сделали бы его воспроизводимым; потому «условно», не
«повторяемо».
