# docs/evidence — индекс вещдоков

Мастерская индексации вещдоков (#1303, слово капитана 26–27.07): **индекс — суть,
склад — сменная деталь.** Байты живут в хранилище (сейчас local/Downloads, целевое —
Affine-склад статики), строки — здесь. Индекс переживает склад.

**Несущий предикат дома:** вещдок без **хеша** и без **адреса** — не вещдок.
Хеш даёт тождество, адрес — достижимость, описание — смысл. Тот же закон, что у
описей китов и паспортов гранул — третье появление за два дня, сквозной закон дома.

## Реестр

`registry.jsonl` — append-only, одна запись = одна строка JSON. Правка строк запрещена;
исправление — новой записью. Слои раздельны: `measured` пишет машина, `about` —
интерпретация человека/агента, помечена полем.

## Команды

```bash
yarn evidence add <file> --id <slug> --source "…" [--about "…"] [--store affine --ref <adr>]
yarn evidence verify   # local: пересчёт хешей; affine/url → honest unknown, НЕ «ок»
yarn evidence list
```

`verify`: `ok` · `hash-mismatch` · `unreachable` · `unknown` (склад вне зоны обвязки —
сверка не прогонялась, это не «ок»). Дубль содержимого под разными id — находка,
решает человек. Битая строка реестра — находка с номером, не молчаливый пропуск.
