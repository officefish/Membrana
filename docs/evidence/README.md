# docs/evidence — индекс вещдоков

Мастерская индексации вещдоков (#1303, слово капитана 26–27.07): **индекс — суть,
склад — сменная деталь.** Байты живут в хранилище (сейчас local/Downloads, целевое —
Affine-склад статики), строки — здесь. Индекс переживает склад.

**Несущий предикат дома:** вещдок без **хеша** и без **адреса** — не вещдок.
Хеш даёт тождество, адрес — достижимость, описание — смысл. Тот же закон, что у
описей китов и паспортов гранул — третье появление за два дня, сквозной закон дома.

## Реестр

`registry.jsonl` — append-only, одна запись = одна строка JSON. Правка строк запрещена;
исправление — новой записью. Слои раздельны: `measured` пишет машина, `about` —
интерпретация человека/агента, помечена полем.

## Команды

```bash
yarn evidence add <file> --id <slug> --source "…" [--about "…"] [--store affine --ref <adr>]
yarn evidence verify   # local: пересчёт хешей; affine/url → honest unknown, НЕ «ок»
yarn evidence list
```

`verify`: `ok` · `hash-mismatch` · `unreachable` · `unknown` (склад вне зоны обвязки —
сверка не прогонялась, это не «ок»). Дубль содержимого под разными id — находка,
решает человек. Битая строка реестра — находка с номером, не молчаливый пропуск.

## Приём внешнего документа (готовность к Affine-статике)

Порядок один для чека, фотографии и документа партнёра — **байты к нам, потом опись**:

```bash
# 1) положить файл в дом вещдоков (не оставлять в Downloads — путь машины не переносим)
cp <файл> docs/evidence/store/<slug>.<ext>
# 2) принять: sha считается ОТ ФАЙЛА, ref пишется repo-relative
yarn evidence add docs/evidence/store/<slug>.<ext> --id <slug> --source "от кого, когда, что" --about "смысл; ЧУВСТВИТЕЛЬНОЕ: … — если материал внешний"
# 3) пересобрать опись
yarn evidence index
```

**Байты чувствительного материала в репозиторий НЕ кладутся.** Репозиторий
`officefish/Membrana` — **публичный**: всё, что попало в `docs/evidence/store/`, видно
миру. Поэтому для внешнего чувствительного материала действует иной порядок: файл
остаётся вне репо (машина владельца / приватный склад), запись несёт
`sensitive: {reason, decidedAt}`, а опись **не печатает его адрес** — тождество держит
`sha256`, смысл `about`. Переносимость такой записи невозможна по природе — это
**легальное «нет» с причиной** (норма B10), зуб её не красит, но и зелёной не считает.
Живой образец — `bpla-guidance-methodology-partner-r3` (поправка -r3 отменила -r2:
байты, положенные было в store, изъяты до коммита). Чек оборудования — не чувствителен,
его байты в репо законны.

**Чувствительность обязательна для внешних материалов** (слово капитана 28.07): в
`about` прямо сказать, что именно чувствительно и где проходит граница наших работ.
Образец — запись `bpla-guidance-methodology-partner-r2`: алгоритмы наведения названы
вне зоны Мембраны, полезный слой (угловая геометрия без дальности) выделен отдельно.
Молчание о чувствительности — дефект приёма, а не «нейтральность».

**Поправка вещдока — только новой записью** `<id>-rN` (append-only): старая строка
остаётся историей, живой считается последняя в цепочке. Так исправлены абсолютные пути
27–28.07 (`ozon-receipt-3765-field-kit-r2`, `bpla-guidance-methodology-partner-r2`).
Зуб `portabilityProblems` красит живую запись с абсолютным путём и называет команду поправки.

**Опись**: `yarn evidence list --by kind|source|date` — человекочитаемо в терминал;
`yarn evidence index` — производный снимок [`INDEX.md`](./INDEX.md) (руками не править,
`--check` ловит отставание). Вид записи (`изъятие` | `поступление`) выводится из адреса —
это проекция таксономии четырёх домов ниже, не новое поле.

Affine-склад пока **не трогаем** (#1305/#1304 — другая линия): сегодня приём и опись
на нашей стороне, `--store affine` станет нормой, когда путь будет решён.

## Место в атласе и таксономия доказательной базы

Контейнер зарегистрирован в атласе контейнеров автоматически — через
`workshop.manifest.json` (глаголы: audit=verify · decompose · inspectElement · list;
`kit: null` честно — набор соберётся при серверной фазе). Сущность дома —
**EvidenceRecord**: `id`-слаг (имя для ссылок) + `sha256` (отпечаток-тождество) +
`location` (адрес) + `source` (провенанс); `measured` пишет машина, `about` — помеченная
интерпретация.

Четыре дома доказательной базы и кто на кого ссылается:

| Дом | Материал | Вопрос |
|---|---|---|
| сессии (#1229) | прожитый разговор | «что происходило?» |
| прецеденты | разбор сломавшегося | «что сломалось и почему?» |
| кейсы (#1298) | разбор сработавшего | «что сработало и повторяемо ли?» |
| **вещдоки (этот)** | поступления мира и изъятия из сессий | «**чем доказано?**» |

Разборы **ссылаются** на вещдоки (`evidenceIds[]`); вещдок не ссылается ни на кого.
Кристалл — утверждение, вещдок — предмет: кристаллы опираются на вещдоки, руда → огранка.
**Ссылка ≠ вещдок** (капитан, 27.07): координаты отрезка сессии — адрес, вещдоком отрезок
становится через **акт изъятия** — копия байтов + хеш + координаты источника в провенансе.
Изъятие переживает архив и защищает от переписывания прошлого; ссылка — нет.
