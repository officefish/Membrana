# CURRENT_TASK — вспомогательный буфер холодной сессии

Этот файл не назначает магистраль и не дублирует её постоянным текстом. Канонический
вход текущего дня — [`MAIN_DAY_ISSUE.md`](./MAIN_DAY_ISSUE.md); состояние задач —
[`tasks/registry.json`](./tasks/registry.json). При расхождении этот буфер проигрывает им.

## Текущий снимок

На 2026-09-26 `MAIN_DAY_ISSUE.md` называет магистралью
`cabinet-registration-rollout` (Issue #2369). Это датированный снимок, а не обещание,
что тот же фокус останется следующим утром.

## Вход для новой сессии

1. Прочитать свежесть и `primaryFocusId` в [`MAIN_DAY_ISSUE.md`](./MAIN_DAY_ISSUE.md).
2. Проверить задачу в [`tasks/registry.json`](./tasks/registry.json) и её целевой промпт.
3. Использовать этот файл только для временных заметок, которых ещё нет в каноне.

Старый указатель на `detector-scoreboard` снят: он описывал июльскую фазу Ф1 и
дезориентировал холодные сессии после смены магистрали.
