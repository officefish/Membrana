## Ловушки, проверенные боем 04.08

- **База уезжает под медленным CI большого PR** — три круга посадки #1711 и два у #1721.
  Лечится `yarn task:pr-land <N> --execute`; конфликты append-only JSONL (журнал,
  оп-логи) — union обеих сторон, НЕ выбор стороны. **Ветку PR не убирать до
  `gh pr view <N> --json state` = MERGED** — поспешная уборка закрыла PR дважды за день.
- **`pr:ship --merge-only` резолвит PR по ТЕКУЩЕЙ ветке** — фоновый мердж при
  переключённой ветке бьёт мимо. Ветко-зависимое — только последовательно.
- **Windows-алиас `python` молча глотает heredoc-скрипты** — файл не пишется, коммит
  берёт болванку (BLOCK #1696). Писать файлы инструментом, свой `print` проверять глазом.
- **Локальный curl к 127.0.0.1 уходит в прокси окружения** — 502/400 на живом сервисе;
  `--noproxy "*"` или `NO_PROXY`.
- **HTTP 413 на батчах спанов** — счёт спанов ≠ счёт байтов; лимит теперь маршрутный
  (25 МиБ только на `POST /v1/archivarius/ingest`), деление батча в тракте есть.
- **Пре-пуш валит отгрузку на сетевом снимке старше 48 ч** — `yarn network:snapshot`, штатно.
- **Авто-open журнала = дерево ритуала «грязное» своим же трейлом** — вылечено #1689
  (манифест утра знает продукт), но следить: у каждой цепочки свой манифест.
