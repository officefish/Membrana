## Ловушки (проверены боем, стоят времени)

- **Squash-мердж + доборный коммит = вечный конфликт**: после каждой посадки партии —
  `git rebase origin/main` ДО следующего коммита; force-push запрещён политикой, лечение
  расхождения — новая ветка `-rN` (вчера дважды).
- **Не переключать ветку и не коммитить в дерево, пока pr:ship в полёте** — хвосты рвутся
  (вчера один шип потерял push из-за перебазировки под ним).
- **Отказ хука приходит видом успеха**: коммит отклонён — стейдж остаётся; проверять
  `git status`, не exit-код (вчера: README задачника из registry, норма #1201).
- **Дрейф описей китов**: правил движок — сразу `yarn kits:pins --id <кит> --write`.
- **Гейт ласточки требует пятистрочное зеркало + коды только в «Детали:»** —
  черновик писать сразу по `yarn morning:gate swallow --skeleton`, не подгонять тремя заходами.
- **Капитан сидит в основном дереве**: markdown-ссылки на файлы чужого worktree у него
  мертвы — черновики на «ок» показывать текстом в чат.
- **Потолок расходов Anthropic до 01.08**: рабочие звенья deepseek/grok; `yarn ask` и
  фидбек теперь на панельной цепочке (вчерашний ремонт), прямые вызовы ловит зуб
  `llm-panel-wire`.
- **Отрицательный результат поиска — не доказательство отсутствия**, пока не перечислены
  формы записи.
- **Office не превращает markdown в ссылки**: в ласточку — коды `#N` в строке «Детали:»
  (слово капитана 27.07), не сырые URL.
