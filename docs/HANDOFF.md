## Ловушки (проверены сегодня, стоят времени)

- **Согласие владельца на отправку переживало смену дня.** Утром `canSend` был `TRUE` по «ок» от 22.07. Предикаты не знают о дате, `telegram:swallow` их не спрашивает. Пока не починено — **проверять состояние гейтов глазами** перед любой отправкой наружу.
- **Освобождение `main` не решает всё:** переключиться нельзя, если в общем дереве лежат чужие незакоммиченные правки, а `main` те же файлы менял. Законный выход — эскалация владельцу, не переключение веток (25.07 так был снесён контекст соседней сессии).
- **Две сессии в одном дереве** — файлы соседа уцелели только потому, что были неотслеживаемыми. Разводить по деревьям заранее.
- **Фоновый запуск с выводом в `tail` даёт пустой лог** (буферизация) — писать в файл.
- **`gh` транзиентно таймаутит** — факт мерджа проверять состоянием (`gh pr view N --json state,mergeCommit`), не exit code.
- **`pr:ship` может проиграть гонку с main** на плотном трафике: CI идёт минуты, за это время общая ветка уезжает. Выигрывает серверное автослияние.
- **Anthropic исчерпан до 01.08**: рабочие каналы — grok (вечернее ревью, профилактика утра) и deepseek. Строгие форматы (консилиум, заседание, генератор задачи дня) на них не тянут.
- **Linear-карточки руками не заводить** — зеркало от GitHub-иссью; номер проставлять `task:register --linear`, и **не забывать `--lead`**: повторный register без него обнуляет ответственного.
