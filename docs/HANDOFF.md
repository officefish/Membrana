## Ловушки (проверены вчера, стоят времени)

- **Не путать «защищено» с «безопасно»**: защита main требует только `scan` — PR с красной
  основной сборкой мержится. До закрытия №1 CI-дисциплина держится только `pr:ship`.
- **Дрейф описей китов ловится только в CI**: правил движок — сразу
  `yarn kits:pins --id <кит> --write` (вчера три перепина за сессию).
- **`package.json` — файл-перекрёсток**: список тестов правят все, вчера три конфликта за вечер.
- **Отказ хука приходит видом успеха**: коммит отклонён, следующий шаг печатает «всё
  актуально». Проверять состоянием, не кодом возврата.
- **Отрицательный результат поиска — не доказательство отсутствия**, пока не перечислены формы
  записи (стоило неверного прецедента: искал `bridge close`, в манифесте — `bridge.mjs close`).
- **Office не превращает markdown в ссылки**: в ласточку — голые полные URL; `live-links --check`
  этот случай не ловит (зелёный гейт ≠ кликабельность).
- **Потолок расходов Anthropic до 01.08** (кредиты есть, лимит месяца): рабочие звенья —
  deepseek и grok; overlay code-review до ремонта №7 усекает цепочку до занятого поставщика.
- **Извлечение памяти персон стоит в вечерней цепочке ДО ласточки** — канон требует обратного
  порядка (в память только показанное партнёрам).
