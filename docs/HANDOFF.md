## Ловушки, проверенные боем 02–03.08

- **Утренний гейт переносит магистраль через сутки — рецидив.** Сегодня генератор снова подал
  вчерашнюю `subconscious-lift-c3`, при том что она **закрыта** и её критерий успеха достигнут
  вчера же. Гейт при этом честен: говорит «протухло, ждёт owner-choice». Долг
  `gates-state-magistral-carryover` от 28.07 сработал в третий раз.
- **Русское «Закрывает #N» в теле PR не закрывает иссью.** GitHub понимает только английские
  ключи (`closes`/`fixes`/`resolves`). Отсюда вся строка 5 десятки.
- **`pr:ship` требует `--no-commit`, если коммит уже сделан** — иначе падает на пустом
  `git commit`, и отгрузка не начинается.
- **`git checkout -- <файл>` сносит свою работу вместе с пробной порчей.** Проверять зуб
  порчей — правильно; откатывать её надо копией файла, не через git.
- **Пре-пуш валит отгрузку на снимке сети старше 48 часов** — «воспоминание выдаёт себя за
  факт». Лечится `yarn network:snapshot`, это штатно.
- **Локальный typecheck в параллельном дереве недостоверен** — см. строку 7; на локальную
  зелень по межпакетным правкам не ссылаться, проверять CI.
- **Ревью блокирует по ложной посылке** — 02.08 объявило `//`-ключи JSON невалидными для
  `JSON.parse`. Это ключи, а не комментарии. Утверждение проверяемо — проверять до правки.
