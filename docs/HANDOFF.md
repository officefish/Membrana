- **`pr:ship --execute` на уже закоммиченной ветке падает** — тогда push + `gh pr create`
  + `pr:ship --merge-only --execute`.
- **Merge-гейт требует вердикта `yarn code-review:pr <N>`** даже для бумажных PR.
