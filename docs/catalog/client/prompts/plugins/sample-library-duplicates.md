# Плагин «Дубли набора» (sample-library-duplicates)

Пятая панель библиотеки сэмплов (#2109): пары похожих проб ТЕКУЩЕГО набора — показать и
ждать слова, а не удалять по унаследованному порогу.

Пары считает сервер: панель заказывает витрину `membrana.showcase.library-duplicates` на доме
`background-media/collections` и показывает группы «представитель + похожие» с моментом
каждой пробы (отсев ко времени слеп — человек соседство по времени слышит первым). Порог
похожести унаследован от отбора без перепроверки для стирания, и панель печатает это словом.

Что умеет человек: «послушать подряд» — представитель, затем похожие (общее ядро
`playSequence` в `@membrana/sample-playback-service`, одно на Studio и кабинет); «удалить» —
только на похожей пробе, только по клику, только с подтверждением, по одной. Никакого
«удалить все дубли»: цена ошибки остаётся ценой одной пробы.

Доступен только при серверной библиотеке (media-server) — сервис отвечает named-отказом.
