# Плагин «Разбор сеанса» (sample-library-session-digest)

Панель библиотеки сэмплов (#2039): двадцать опорных звуков ночи — лицом. Заказывает отчёт
`membrana.report.session-digest` по ТЕКУЩЕМУ набору и окну ночи (даты в поясе человека —
общее ядро близнецов) и показывает два списка с прослушиванием: опорные (тональные — годные
образцом в датасет) и негативный материал (широкополосные — не выброшены, а названы).

Паспорт печатается: чем считали и какие пороги слух ещё не называл — поимённо, а не общим
флагом. Отсев похожего — тем же ядром, что чарт-лист; колонка «похожих» показывает, что дедуп
работал. Ядро отчёта живёт на media и здесь не трогается.

Доступен только при серверной библиотеке (media-server) — сервис отвечает named-отказом.
