# task:handoff — актуальный хендоф со сверкой каждой строки

Глагол мастерской задач (zone `workshop`, карточка `tw-handoff-status`). Формат
утверждён капитаном 13.08: хендоф — точка входа новой сессии, но он протухает за
сутки, и показ без сверки транслирует ложь холодной сессии.

```bash
yarn task:handoff                # показать сверенный хендоф
yarn task:handoff --no-network   # без сети: Issue честно ❓, реестр работает
```

## Что делает

1. Читает `docs/HANDOFF.md`; штамп последней правки берёт у git (не mtime).
2. Разбирает очередь-таблицу (`| N | **\`id\`** [#NNN] — … |`) — id и все Issue строки.
3. **До показа** резолвит каждую строку живым состоянием:
   - карточка — по `docs/tasks/registry.json` (active/archived + свидетельство архива);
   - Issue — батчем `task-states` (норма #1322: списком, не поштучно).
4. Рисует пять секций: шапка с отставанием · слово о сверке · таблица · итог N/M ·
   живой остаток кустами (сцепленные `prefix-*` строки вместе — материал топ-3).

## Вердикты строки (закрытый словарь)

| Знак | Вердикт | Значит |
|------|---------|--------|
| ✅ | closed | карточка в архиве (дата + первая фраза свидетельства) либо Issue закрыт при отсутствии карточки |
| 🔴 | alive | карточка активна / Issue OPEN |
| ⚠ | mismatch | **Issue закрыт, карточка активна** — класс #1330 (13.08): не гасится приоритетом, разбор рукой |
| ❓ | unknown | сеть не дала состояние / строке нечем свидетельствовать — отсутствие ответа ≠ состояние |

## Границы

- Глагол read-only: реестр и хендоф не правит, находки только называет.
- Хендоф без очереди-таблицы — не ошибка: «сверять нечего, читать файл целиком».
- ❓/⚠ — данные отчёта, не сбой (exit 0); нечитаемый вход — exit 2.
