# Промпт: Союзное слияние всех append-only журналов (Б, после #2147)

> Task-промпт. Реестр: `union-merge-all-jsonl` · размер **S** · форма **шот**.
> Issue: [#2096](https://github.com/officefish/Membrana/issues/2096). Исполнитель — сессия Б после пяти зубов.

## Контекст

#2100 завёл `merge=union` для трейла `docs/procedure-runs/trail/*.jsonl` — он не конфликтует.
Но 24.08 конфликтовала `docs/network/history/2026-08.jsonl`, ведущая склеивала руками; сторож
`verify-journal-merge.mjs` этот путь не знает. Append-only журналов в `docs/` больше одного.

## Что построить

1. Инвентарь append-only журналов `docs/**/*.jsonl` (вещдоки, op-логи персон, история сети,
   трейл, sent-log ласточек) — списком в сторож.
2. `.gitattributes`: `merge=union` на класс (шаблоном или перечислением); исключения — журналы,
   где порядок строк несёт смысл, названы явно.
3. Сторож расширить на инвентарь: файл класса без `union` → красный.

## Границы

- Содержимое журналов и писателей не трогать; на JSON-объекты (`registry.json`) `union` не ставить.

## DoD и порча

- `git check-attr merge <путь>` = `union` для каждого из инвентаря.
- **Порча:** снять атрибут с одного журнала → сторож красный с именем файла.
