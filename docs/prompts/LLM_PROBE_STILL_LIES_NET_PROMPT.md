## Контекст

`scripts/llm-probe.mjs` (глагол `yarn llm:probe`) нёс **собственный** классификатор исходов, и
его ветка ошибки кончалась catch-all `return 'net'`: любая строка, не подошедшая под три
регулярки, объявлялась сетевой. Цена класса измерена — сны девять дней подряд писали
`deepseek:net · grok:net · gemini:net`, и диагностика двое суток искала несуществующий сетевой
фильтр, тогда как причины были разные: у одного провайдера не было ключа, у двух других API
вернул HTTP 404 «модель снята».

Верный классификатор в репозитории уже есть — `scripts/network/lib/classify.mjs` (контейнер
network, #1449) с явным инвариантом **«ответил статусом ⇒ транспорт работает»**, закрытым
перечнем из 15 исходов и честным `unknown_protocol` вместо выдуманной сети. Сны переведены на
него 07.08 (#1773), зонды — нет.

Не трогаем: транспорт по сути (какие провайдеры, URL, прокси-логика), сны, перечень
`docs/network/outcomes.yml`.

### Что построить (продуктовое описание)

1. `yarn llm:probe` и `yarn infra:probe` называют причину отказа **одним словарём на весь
   репозиторий** — исходами #1449. Слова `net`, `tls-fail`, `blocked-html`, `auth/geo`,
   `no-key` наружу больше не выходят.
2. Незнакомая ошибка называется незнакомой (`unknown_protocol`), а не сетью. Никто больше не
   уходит чинить сеть, которая работает.
3. Отказы, где сеть **не измерялась вовсе** (нет ключа, не ответил `gh`, строка не URL),
   перестают маскироваться под сетевые.

### Архитектура / контракт

| Слой | Путь | Ответственность |
|------|------|-----------------|
| Предикат | `scripts/network/lib/classify.mjs` | ЕДИНСТВЕННЫЙ судья причины. Не менять. |
| Транспорт зонда | `scripts/llm-probe.mjs` → `probeOnce` | Отдаёт наблюдение, включая `errorCode` |
| Обёртка | `scripts/llm-probe.mjs` → `classifyOutcome` | Тонкий переход к предикату, без своего разбора |
| Потребитель | `scripts/infra-probe.mjs` | Тот же словарь во всех ветках зонда |
| Представление | `scripts/lib/infra-policy.mjs` → `linkStatus` | Красит вердикт, не судит причину |

**Запрещено:**

- заводить второй разбор причины где-либо, кроме `classify.mjs`;
- отображать новый исход обратно в `net` «ради совместимости» — это сохранение той же лжи;
- писать свой список транспортных исходов: брать `TRANSPORT_OUTCOMES` у классификатора;
- расширять `outcomes.yml` тихо — исход вне перечня есть находка для #1449.

### Тесты

| Область | Минимум |
|---------|---------|
| Транспорт по коду | `ENOTFOUND → dns_fail`, `ECONNRESET → tcp_fail`, `ABORT_ERR → timeout_idle` |
| Честное незнание | незнакомая ошибка и пустой вход → `unknown_protocol`, НЕ `net` |
| Инвариант #1449 | нет ключа → `auth_missing_key`, 404 снятой модели → `model_removed`, 402 → `billing_exhausted` |
| Отсутствие своего словаря | ни одно слово прежнего словаря не выходит наружу; всякий исход лежит в `OUTCOME_IDS` |
| Список «мёртвых» | каждый исход из `TRANSPORT_OUTCOMES` при живом прокси даёт перехват (поведением, не сверкой строк) |
| Представление | таблица `linkStatus` полна по закрытому перечню: ни один исход не проваливается в «не знаю» |

- [ ] Ни одного литерала старого словаря в исполняемом коде обоих зондов.
