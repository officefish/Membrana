## Фаза 1 — разбор и план (код не писать)

1. **Почему книга сделанного не сработала 01.10.** Воспроизведи вход вечера 01.10. Что именно

   команда и её вывод. Кандидаты, их надо различить замером:
   - (а) книга берёт ревью oversized-PR из `docs/discussions/` — а это в `.gitignore`;
   - (б) книга не читает `docs/local-sprint/*/CLOSURE.md` и решения спринта;
   - (в) LLM получает книгу, но промпт ставит посылки MAIN_DAY_ISSUE выше;
   - (г) окно «за неделю» или фильтр отсекли PR этого дня.
2. **Почему ревью дня и ревью PR не видят сделанного.** `day-work-diff` не разворачивает oversized
   и ничего не даёт взамен. `code-review:pr` читает документы дня — откуда: из рабочего дерева или из ствола?
3. **Посылка → DoD.** Где ссылка на несуществующий файл или номер из MAIN_DAY_ISSUE становится
   «не сделано» в вечере и в ревью? Предикат «упомянутого адреса нет на стволе → не DoD, а посылка
   под вопросом» уже есть в `feedback:claims`. Можно ли его результат подать во вход оценки,
   а не только дописывать после?
4. **План спринта** только на то, что замер подтвердил, по образцу
   `docs/sprint/cut/device-quota-after-tariff-2538.json`:

     влитым oversized-PR и CLOSURE — вход вечера не несёт его итога;

     опровергнутых стволом.

   `yarn sprint:cut --plan …` должен дать только `plan_unratified`. **Не ратифицировать.**
