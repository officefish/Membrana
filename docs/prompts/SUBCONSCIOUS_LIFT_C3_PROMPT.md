## Контекст

Двухконтурная память персон спроектирована заседанием из шести комнат и сшита. **Построено
пять комнат из шести.** Не построена ровно та, ради которой контур называется двухконтурным:
подъём из подсознания.

| комната | состояние на 01.08 |
|---|---|
| C1 подсознание — архив append-only, `verbatim\|summary+fullRef`, `erase` вне схемы | стоит |
| C2 приоритизация — `selectOperational`, `importance.json`, pinned вне бюджета | стоит |
| **C3 всплытие** | **нет вовсе — предмет этой задачи** |
| C4 активный цикл — слоты сжатия и прогрева | стоит |
| C5 метрики и оп-лог — `metricsSnapshot`, `sunkUnsurfaced`, словарь 10 глаголов | стоит |
| C6 extractor — тонкий CLI, `scripts/persona-memory/lib/`, миграция day-zero | стоит |

**Почему не построено — и это не забывчивость.** Фазы стройки P0–P6 (протокол M6) покрывают
`schema → append → selectOperational → проекция → эмиттеры оп-лога → миграция → врезка`. Это
стройка записи и extractor'а. Лифта в них нет ни одной фазой: комнату спроектировали и не
запланировали к постройке.

**Три вещдока состояния, замерены 01.08:**

1. Три глагола из десяти в закрытом словаре `OP_VERBS` не имеют источника вовсе —
   `cloud_query`, `reject`, `surface_invoke`. Все три принадлежат всплытию.
2. Третья строка кристалла token-121 у каждой персоны без исключения: «всплывало сегодня:
   контур не поставлен (#1366 ч.2)».
3. В архиве **1458 записей** (`position`, `routine` и одна `forecast`), прочитана ни одна.
   `sunkUnsurfaced` построен, и считать ему нечего: утонуть может лишь то, что могло всплыть.

**Что НЕ переизобретать.** Контракт ратифицирован в M3 целиком — квоты, оси, инварианты, имена
полей, запреты. Отклонение есть перерешение ратифицированного вердикта, а не свобода
исполнителя.

## Что сделать — по ратифицированному вердикту M3

### 1. Лифт отдельным модулем

`buildSubconsciousCloud(personaId, topic, opts) → Cloud`. Чистый retrieval и fusion.
**Два модуля, не комбайн:** лифт не импортирует промпты персон, не пишет журнал и не пишет
оперативную O; персона не ходит в сырой `jsonl` в обход лифта.

Имена полей стабильны — на них встанет зуб: `cloudId`, `queryPlan`, `items[]`, `emerged[]`,
`rejected`. `CloudItem`: `{ id, provenance, class?, lifecycle?, importance?, snippetRef,
scores?: ordinal }`. Snippet берётся из `summary` (C1); полный текст персона дотягивает по
`fullRef` **только для выбранных**. Экономия токенов при этом не предлог сужать `why`.

### 2. Мультизапрос — закрытое множество осей v1

`Q1 topic` (повестка комнаты) · `Q2 contrast` (отрицание, оппозиция) · `Q3 dispute` (маркеры
конфликта в meta или лексике summary). `Q4 analogy` — **слот v2, не делать**.

Без LLM-порта `Q2` = шаблонные антонимы либо negation lexicon, **fail-open в reduced plan**,
не молчаливая пустота. `queryPlan` пишется всегда: какие оси бежали и сколько hit'ов до MMR.
Без него «архив пуст» неотличимо от «мультизапрос сломан».

### 3. Слоты, квоты, ранг

- `similar ≤ 5` — MMR внутри слота: `argmax [λ·sim(a,q) − (1−λ)·max sim(a,b)]`.
- `contrast ≤ 3`.
- `outsider = 1..2` — из хвоста: `sim < τ_out ∧ id ∉ similar ∪ contrast`.
- `|items| ≤ 10`.
- Ординальные флаги 0/1, НЕ обученные веса: `hasConflict`, `hasOwnerQuote`, `isPinned`,
  `classRank` (из C2: `insight|precedent` > `position` > `routine`), `recencyBucket`.
  Comparator лексикографический по флагам и sim-bucket, затем MMR на `similar`.
- λ и τ_out — **именованные константы**; значения калибрует C5, здесь только имена.

De-dup обязателен: `notAlreadyOperational(id)` — из облака вычитается всё, чей провенанс уже
в оперативной проекции. Иначе «всплытие» есть эхо свежего стека.

### 4. Акт — за персоной, никогда за лифтом

Лифт подаёт облако; выбирает и объясняет **персона**: `emerge(item, why)` либо
`reject_cloud(reason)`. Строка протокола: `[память:подсознание] …`, для отказа —
`[память:подсознание] cloud_rejected reason: «…»`. **Строка без `why` невалидна.**

Потребители: секретарь консилиума и `yarn ask` получают облако входным блоком к персоне.
Секретарь **не выбирает за роли**. Гости (Фаррелл) вне автоматического лифта v1. Ангелина не
судит облако советующих.

### 5. Включение — обязательный последний блок (норма #1565)

Ядро без вызова повторит ровно тот дефект, из-за которого контур и стоит непоставленным.
Признак включения проверяемый и уже существует: **три глагола получают источник**, а третья
строка кристалла перестаёт говорить «контур не поставлен».

## DoD

- [ ] Зуб падает **до** лифта: `cloud_query`, `reject`, `surface_invoke` без источника —
      красный доказан прогоном, а не рассуждением (зверь B6 «Молчаливый зелёный»)
- [ ] `|items| ≤ 10`, `|outsider| ≤ 2`; пустой слот остаётся пустым, а не добивается padding'ом
- [ ] `∀ e ∈ emerged: e ∈ items ∧ why(e) ≠ ∅` — подлог памяти невозможен механически
- [ ] `rejected ⇒ emerged = ∅`
- [ ] `queryPlan` присутствует всегда; «архив пуст» и «мультизапрос сломан» различимы
- [ ] `notAlreadyOperational` вычитает эхо оперативной проекции — зуб на фикстуре
- [ ] `Q2` без LLM-порта даёт reduced plan с пометкой, а не молчаливую пустоту
- [ ] Лифт не пишет `why` и не пишет O — зуб на границу
- [ ] После включения три глагола имеют источник, число названо цифрой
- [ ] Третья строка отчёта памяти перестаёт говорить «контур не поставлен»

## Out of scope

- **v2, именованные слоты — не делать:** `Q4 analogy`, обученные λ и τ, fine-tune эмбеддингов,
  serendipity сверх двух аутсайдеров, cross-persona lift.
- Калибровка чисел — предмет C5; здесь только имена констант.
- Второй RAG-стек: порт retrieval **один**, backend `archive` против оперативных документов —
  стратегия, а не новый стек. Цена дубля — два словаря близости.
- Расписание, *когда* звать лифт — предмет C4; здесь только *что* происходит в акте.
- Машинный pre-rerank: если появится — только опциональной стадией **внутри** лифта, с
  пометкой в `queryPlan`, и акт всё равно за персоной.
- Перестройка `DAY_MEMO`, UI пульта, витрина.
