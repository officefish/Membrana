## Контракт

1. **Шапка**: заголовок `docs/HANDOFF.md` + последний коммит файла (git, не mtime) +
   отставание в днях с честным словом о сверке.
2. **Сверка ДО показа**: каждая строка очереди резолвится живым состоянием —
   карточка по `registry.json`, Issue батчем `task-states` (#1322: списком, не
   поштучно; honest unknown на сеть).
3. **Таблица**: № · `id` + Issue · ✅/🔴/⚠/❓ · свидетельство (дата архива + первая
   фраза заметок / состояние Issue). ⚠ mismatch = «Issue закрыт, карточка активна»
   (класс #1330) — не гасится приоритетом, называется для разбора рукой.
4. **Итог**: N из M закрыты · живых K; живой остаток кустами (`prefix-*` для
   сцепленных строк) — материал завтрашнего топ-3.
5. Read-only: реестр и хендоф не правится; ❓/⚠ — данные отчёта (exit 0), вход
   нечитаем — exit 2.
