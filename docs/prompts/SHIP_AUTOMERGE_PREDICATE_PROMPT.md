## Контекст

readAutoMergeAllowed читает allow_auto_merge репозитория (=true) и решает идти серверным путём, после чего GitHub отказывает: «Protected branch rules not configured for this branch (enablePullRequestAutoMerge)» — серверное слияние требует настроенных правил защиты ветки. #1269 обработал случай выключенной галки, этот случай — нет (вещдок 26.07, PR #1275).

Попутно: --merge-only не пушит локальные коммиты и падает на «has diverged from local branch» — либо пушить, либо останавливаться с этим текстом.

Не трогаем: настройку правил защиты — это решение владельца, не кода.
