## Правила входа (обязательные, холодной сессии без контекста)

1. **Работать в ОТДЕЛЬНОМ worktree** (скилл `membrana-worktree`), не в основном дереве
   `Membrana` — там живёт сессия мостика. Ветка — от свежего `origin/main`
   (`git fetch` первым действием).
2. Коммитить **только свои файлы поимённо**, никогда `git add -A`.
3. Мердж **только `yarn pr:ship`** (`--type … --message … --no-commit --keep-branch
   --execute`; ссылка на issue без закрытия — `--issue-mention N`). Факт мерджа проверять
   `gh pr view <N> --json state`, не exit code.
4. Каждый блок — отдельная ветка/PR, не смешивать.
5. Ловушки среды: PowerShell 5.1 портит UTF-8 без BOM — файлы править только Write/Edit
   инструментами, не Get/Set-Content; отказ git-хука приходит «видом успеха» — проверять
   `git status` после коммита; CI-падение `@membrana/background-media` на «Unexpected end
   of JSON input» после «Prisma schema loaded» — транзиентное, лечится
   `gh run rerun <id> --failed`.
