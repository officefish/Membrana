# Промпт: Приём записи — измеренное перебивает объявленное (В3)

> Task-промпт. Реестр: `capture-measured-over-declared` · размер **M** · форма **шот**.
> Issue: [#1950](https://github.com/officefish/Membrana/issues/1950). Исполнитель — сессия В (Codex).

## Контекст

Приём пробы в `packages/background-media` верит объявленным полям (длительность, частота,
каналы) и не сверяет их с байтами WAV. 22.08 первый трек сценария ушёл как 44,1 кГц при
объявленных 48 (#2046); класс «объявленное перебивает измеренное» назван в #1950.
Есть разбор WAV-заголовка (`packages/plugin-handlers/src/wav.ts`) и контракт отказа куска B (#2135).

## Что построить

1. При приёме измерять из WAV частоту, каналы, разрядность, длительность (по размеру данных);
   расхождение с объявленным → **отказ** рода «сломан» с полями `declared` / `measured`.
2. В метаданных пробы хранить **измеренные** значения; объявленные — как `declared`.
3. Порог расхождения длительности — ±1 кадр буфера.

## Границы

- Не трогать квоты, коллекции, витрины; лежащие пробы не пересчитывать (миграция — отдельно).

## DoD и порча

- Зубы: честный 48k/16/mono → принят; заголовок 48k при 44,1k данных → отказ с обоими значениями.
- **Порча:** убрать сверку частоты → тест красный.
- Прод не трогать; выкатка media — ведущая в окно, не во время сеанса (#2048).
