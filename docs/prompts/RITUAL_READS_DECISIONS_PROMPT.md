   origin/main` → 0. Ещё 28.09 вечер (18:05Z, после мерджа) просил тест «ровно на `NIGHT_RUN_MAX_AGE_MS = 36 ч`»

   29.09 15:13+03. Зуб утверждений: `aria-current` → «сомнение: карточки в реестре нет» — адрес не тот.
3. **Утро 30.09**: `scripts/day-plan.mjs` третий день подряд предлагает кандидатом `batch-collection-run-contour` —
   спринт закрыт 29.09 (close-запись `pass` в `docs/procedure-runs/trail/2026-09-29.jsonl`, стек #2517–#2521 влит).
   Кандидаты — `candidatesFromRegistry`: только `status === 'active'`; карточка `active`, 4/4 фазы `active`.

планов с ратифицированными `//decisions` / `//recut-*` за окно 7 дней — 3.

## Тесты (зуб без порчи — не зуб)

| Область | Минимум |
|---------|---------|
| b1 | план без `ratification` или с `by ≠ owner` — не решение; `//recut-*` с ратификацией — решение; close-запись `fail` — «закрыт красным», отдельно от `pass`; карточка `archived` — не stale; фаза `active` при архивном эпике — stale по фазе |
| b2 | на фикстурах 29.09 промпт несёт «aria-current … снят» из `//decisions` a11y и «batch-collection-run-contour: прогон закрыт 29.09, карточка не архивирована»; порядок: книга сделанного → Решённое → свежесть входов → документы дня; битый план → строка «не прочитан: <файл>», не исключение |
| b3 | карточка `active` L + close-запись её спринта → не в top-3 и названа в посылке; без записи → в top-3; порядок остальных не меняется |
| b4 | `NIGHT_RUN_MAX_AGE_MS = 36 ч` → `symbol`, при нуле вхождений — «не подтверждено»; `aria-current` при решении в окне — причина несёт «решение: sample-library-paging-a11y //decisions …»; вне окна — причина прежняя; порча: убрать `decidedIn` из вещдока → строки нет |
| b5 | живые прогоны на сегодняшних файлах, выдержки в `CLOSURE.md` |

## Развилки на слово владельца (спринтом не решаются)

1. Исключать карточки закрытых спринтов из кандидатов магистрали (умолчание спринта) или только помечать.
2. Кто архивирует карточки закрытых спринтов — 4 закрытых прогона, 0 архивных карточек.
3. `//recut-*` = решение владельца наравне с `//decisions` (умолчание спринта — да: перерезка снимает согласие и ратифицируется заново).
4. Носитель решений, принятых вне спринтов (тело PR #2506) — нужна ли машинная форма («## Решения» в теле PR) или это остаётся прозой.
5. Новый исход «противоречит решённому» в зубе утверждений — тронет предикат вечернего гейта; спринт только аннотирует причину.
