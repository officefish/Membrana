## Контекст

**Что уже есть (18.08, сверено):** узел Firebat (Windows Home, за вторым роутером) пишет
48 кГц в заводском режиме карты Scarlett Solo **без драйвера Focusrite** и сам отправляет
записи на медиа-сервис (`scripts/field-capture.mjs`, переносим одним файлом; две записи
приняты: `62fe8ea1…`, `c4cfbf06…`). SSH-сервер на узле стоит, но **вход снаружи закрыт**
каскадом роутеров — и это норма поля: на полигоне и улице сеть тоже чужая.

**Чего нет:** приложения, которое живёт на узле постоянно и **само** держит канал к
серверу; установщика клиента (`apps/membrana-studio` → `yarn package`, ни разу не
собирался, `release/` отсутствует); отдельного ключа на загрузку (сейчас на узле служебный
токен всего медиа-сервиса — риск при потере устройства без присмотра).

## Что построить

1. **Канал изнутри наружу.** Узел устанавливает исходящее соединение к нашему серверу
   и держит его; сервер через него даёт команды (снять пробу, сменить окно, отдать
   диагностику), узел через него отправляет записи и состояние. Форма транспорта — по
   выбору исполнителя с обоснованием (постоянный WebSocket к office/media · обратный
   SSH-туннель к VDS · очередь заданий с опросом) — но **никаких входящих портов на узле**.
2. **Установщик**, который ставит приложение как службу/автозапуск Windows с нужными
   правами (звук, сеть, автостарт) — одним прогоном, без ручной настройки. Первая сборка
   `electron-builder --win nsis` в истории проекта: ждать сюрпризов, каждый называть.
3. **Отдельный ключ узла** — только на загрузку в свою коллекцию, не служебный токен;
   отзываемый.
4. **Рабочее усиление** — выставить с запасом (щелчок 18.08 дал −1 dBFS), записать в
   спутник узла; больше не менять всю неделю.

## Запрещено

- Открывать входящие порты / пробрасывать порты на роутерах — канал только исходящий.
- Ставить Focusrite Control на узел — он срезал частоту до 44,1 на ноутбуке; заводской
  режим пишет 48 кГц.
- Класть служебный токен медиа-сервиса в установщик — только ключ узла.
- Отбирать записи выводом детектора (норма съёмки 16.08).
- Менять серверные контракты приёма (норма #1950 — измеренное не подменяется объявленным).

## Definition of Done

- [ ] Узел после перезагрузки сам поднимает канал к серверу — без экрана и без рук.
- [ ] С сервера отдана команда «снять пробу N секунд» → запись принята сервером с
      измерением; id записи в отчёте.
- [ ] Установщик собран (`release/`), поставлен на узел, служба/автозапуск активны — вещдок
      скриншотом/логом узла.
- [ ] Ключ узла заведён и работает; служебный токен с узла убран.
- [ ] Усиление записано в спутник узла; `docs/LIVE_SERVICES.md` обновлён (узел как
      устройство, канал, держатель).
- [ ] PR ≤ 400 строк каждый, `yarn pr:ship` после ревью, ссылка на Issue (завести с первым PR).

## Формат отчёта

Ступень, до которой дошли · форма канала и почему · id принятой по команде записи ·
что с установщиком (собран / поставлен / сюрпризы) · усиление · что не вышло.
