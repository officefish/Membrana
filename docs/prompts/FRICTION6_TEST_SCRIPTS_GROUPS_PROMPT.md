## Контекст

`test:scripts` держал **210 путей одной строкой** в `package.json`. Любая ветка, добавившая
тест, правила ровно эту строку — канонический файл-перекрёсток. 26.07 это дало четыре
конфликта подряд: PR #1248, #1253, #1269, #1283. Ревью ветки назвало зверя **B2** ещё до
первого из них.

**Решение 17.07 (заседание scripts-boundary) уважаем, а не отменяем.** Тогда выбрали ручной
список: «явный список — сознательный контроль, флейки можно исключить строкой», а гвард
`test-list-coverage` держал его честным. Цели были две: (а) никаких молчаливых сирот,
(б) возможность исключить осознанно.

**Что вскрылось при работе:** гвард читал только верхний уровень `scripts/`, поэтому
**11 тестов в `scripts/lib/**` (81 проверка) не гонялись в CI вообще** — ровно тот дефект,
от которого он защищал, на каталог глубже. Проверено: все 81 зелёные, то есть их включение —
чистый выигрыш, а не ремонт.

### Кто ты

Ты — **координатор виртуальной команды Membrana** под руководством **Vesnin** (Teamlead). Перед кодом — краткий план (1–2 абзаца + список файлов). Соблюдай [`VIRTUAL_TEAM_PROMPT.md`](../VIRTUAL_TEAM_PROMPT.md) и [`TASK_PROMPT_WORKFLOW.md`](./TASK_PROMPT_WORKFLOW.md).

---

### Что построить

1. **Чистое ядро плана** (`scripts/lib/test-scripts-plan.mjs`): `groupOf(path)`,
   `planTestRun({files, group, skips})`, список групп, карта исключений `путь → причина`.
   Ни ФС, ни процессов — чтобы инварианты проверялись без запуска раннера.
2. **Тонкий раннер** (`scripts/test-scripts-run.mjs`): рекурсивное открытие
   `scripts/**/*.test.mjs`, `--group <имя>`, `--list`, запуск `node --test` найденным набором.
3. **`package.json`**: `test:scripts` → раннер; ярлыки `test:scripts:<группа>` и
   `test:scripts:list`. Никаких путей в `package.json` — иначе перекрёсток вернётся.
4. **Гвард покрытия переписать** под новый инвариант: открытие рекурсивно; `run ∪ skipped`
   равно множеству файлов на диске; каждое исключение несёт внятную причину; группы разбивают
   набор без пересечений и без остатка; `test:scripts` действительно делегирует раннеру.

---

### Запрещено

- Терять хотя бы один тест: множество после перехода обязано быть **надмножеством** прежнего.
  Сверять программно, а не глазами.
- Исключать файл без причины в карте (исключение без объяснения через месяц неотличимо от
  забытого файла).
- Пустой прогон выдавать за успех: пустая группа — почти наверняка опечатка, это ошибка.
- Прятать секрет-тесты внутри крупной группы: правило `security` проверяется первым.
- Менять состав самих тестов и чинить «по пути» найденных сирот, если они падают, — сначала
  назвать факт числом, потом отдельным решением.

---

### Тесты

| Область | Минимум |
|---------|---------|
| Надмножество | список после ≡ список до плюс ранее не гонявшиеся; ни один не пропал |
| Рекурсия | `scripts/lib/**` попадает в набор |
| Ничего не теряется | `run ∪ skipped` = диск |
| Причины | каждое исключение с непустым объяснением |
| Группы | разбиение без пересечений и без остатка; неизвестная группа → ошибка |
| Делегирование | `test:scripts` не содержит путей |

### Definition of Done

- [ ] `yarn test:scripts` зелёный и гоняет **не меньше** файлов, чем прежний список (число в отчёте).
- [ ] Программная сверка «было ⊆ стало» приложена к карточке.
- [ ] Гвард покрытия переписан и падает на подсаженном файле вне плана.
- [ ] Время прогона не выросло существенно (замер до/после).
- [ ] `package.json` больше не содержит путей тестов.
- [ ] LGTM Teamlead.

- Разбор и починка ранее не гонявшихся тестов, если они окажутся красными (тогда — карточка).
