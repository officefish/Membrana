# Задание сессии E: правда утра — стендап берёт магистраль у владельца; трение попадает в журнал (23.09)

**Основание:** два предложения команды в вечернем фидбеке 22.09 (Teamlead; Структурщик и Математик), приняты владельцем утром 23.09. Подкрепление магистрали дня `cabinet-registration-rollout`.

**Зачем:** три утра подряд (21–23.09) генератор стендапа назначал магистраль сам — `tariff…`, `secret-parser-built`, `angelina-hostess-impl`, — а владелец выбирал другую из замороженного топ-3; расхождение ловилось руками ведущей и попадало в план дня как «стендап ≠ выбор владельца». Второе: журнал прогонов за 22.09 несёт `"friction": []` при реальном сбое (панель не ответила стендапу, второй прогон утра, коллизия номеров `sequence` в одном файле) — следующий читатель прочтёт «ноль трений».

**Дерево:** своё, отдельное, от свежего `origin/main`. Ветка вида `fix/standup-owner-choice-and-friction`. Коммиты только своих файлов поимённо.

## Часть 1 — стендап берёт магистраль из выбора владельца

**Факт ствола:** `scripts/_daily-standup.mjs` строит запрос к модели «Дай фокус дня для стендапа…» (строка ~372) и вставляет ответ под заголовок «## Фокус дня» (строка ~381); файл `docs/tasks/main-day-assertions.json` (`sources[0]` с `origin: owner-choice@chat/magistral-<дата>`, `date`, `author: human`) стендап не читает. Свежесть выбора уже умеет считать `scripts/lib/main-day-magistral-freshness.mjs` (заведён 02.08) — переиспользовать, не дублировать.

**Что построить:**
- перед запросом к модели стендап читает `main-day-assertions.json` → `sources[0]`; если выбор **сегодняшний** и `author: human` — фокус дня задаётся текстом из `sources[0].claim` (первое предложение до слова «ЗАМЕР» или до 300 знаков), модель получает его как **данность** («фокус дня уже выбран владельцем: …; не выбирай другой, только разложи по ролям») и не вправе назначить иной;
- если сегодняшнего выбора нет — под «## Фокус дня» пишется ровно: «Магистраль владельцем ещё не выбрана (owner-choice отсутствует на <дата>); стендап фокус не назначает» — и модель фокус **не сочиняет**; остальные разделы стендапа (роутинг, «что не делаем») строятся как раньше;
- в шапке стендапа — источник фокуса: `owner-choice@chat/magistral-<дата>` или «нет».

**Границы:** `scripts/_daily-standup.mjs`, новый `scripts/daily-standup-focus.test.mjs` (по образцу `scripts/standup-plan.test.mjs`, `node --test`), при необходимости `scripts/lib/main-day-magistral-freshness.mjs` — только чтение. Не трогать `main-day-issue`, `main-day-probe`, гейты.

**Зубы (красные до правки):** сегодняшний `sources[0]` → заголовок фокуса несёт его текст и источник; вчерашний `sources[0]` → строка «не выбрана», модель фокус не получает; отсутствие файла → та же строка, не падение. Модель в тестах — подмена, не сеть.

## Часть 2 — запись трения в журнал прогонов

**Факт ствола:** `scripts/lib/procedure-run-journal.mjs` знает фазу `friction-amend` (`RUN_PHASES`, строка 54; `normalizeFriction`, строка 68; `friction-amend` без `evidence` отвергается, строка 127–128) — но команды, которая эту фазу пишет, в `scripts/` нет (`grep friction-amend scripts/*.mjs` → только библиотека и тесты). Дозапись — только append-only по контракту журнала; старые строки не править.

**Что построить:**
- `scripts/procedure-run-friction.mjs` + строка `"procedure-run:friction": "node scripts/procedure-run-friction.mjs"` в `package.json`: `--run <runId> --symptom "…" --root "…" --evidence <путь или команда>` → дописывает в `docs/procedure-runs/trail/<дата>.jsonl` строку фазы `friction-amend` через библиотеку (не руками), с отказом без `--evidence`;
- тест `scripts/procedure-run-friction.test.mjs`: строка дописана, форма по `normalizeFriction`, без evidence — отказ, старые строки нетронуты;
- **дозаписать три трения** этим инструментом: 22.09 — второй прогон утра (`ritual-day-2026-09-22-r2`) и коллизия `sequence` (B10 из ревью 22.09; evidence — `docs/DAILY_CODE_REVIEW.md` архив за 22.09 или строка журнала); 23.09 — стендап упал `panel_unreachable` при живом офисе, повтор прошёл (evidence — `docs/procedure-runs/trail/2026-09-23.jsonl`, строка `close … fail`); 22.09 вечер — доставка `deliver-to-main` упала на пороге размера без причины (evidence — строка `close` вечера 22.09).

**Границы:** новый скрипт и тест, `package.json` (одна строка), `docs/procedure-runs/trail/2026-09-22.jsonl` и `2026-09-23.jsonl` — только дозапись инструментом. Библиотеку журнала не менять; если контракт `friction-amend` не позволяет что-то из перечисленного — вопрос ведущей, не правка библиотеки.
