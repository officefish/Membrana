`yarn worktrees:align` (#1738) выравнивает рабочие деревья к `origin/main`.
Живой мутирующий прогон 11.08 под owner-гейтом доказал поведение по существу —
fast-forward на 168 коммитов, союз реестра на 1096 карточках, откат merge на

## Промпт целиком (для вставки агенту)

### Кто ты

Ты — **координатор виртуальной команды Membrana**. Перед кодом — краткий план
(1–2 абзаца + список файлов). Соблюдай [`VIRTUAL_TEAM_PROMPT.md`](../VIRTUAL_TEAM_PROMPT.md).

### Дефект 1 — гард охвата стоит ПОСЛЕ мутации

`scripts/lib/worktree-align/wip-snapshot.mjs` сначала делает защитный коммит,
затем сверяет охват и бросает `E_SNAPSHOT_NOT_TAKEN` («в коммит попало сверх
списка… охват расширять запрещено»). Коммит при этом **остаётся**.

Корень глубже опечатки: сухой прогон показывает владельцу **каталоги**
(`docs/local-sprint/<id>/`, `.playwright-mcp/`, `docs/archive/daily-day/<date>/`),
а `git add` раскрывает их содержимое — список согласования и фактический охват
расходятся по построению, и владелец даёт гейт не на то, что будет закоммичено.

Вещдоки прогона 11.08:
- главный чекаут `Membrana` — остался коммит `f798b4d9 chore: wip snapshot
  before main-align` (16 файлов, 900 строк чужой работы);
- `Membrana-llm-panel` — тот же отказ на `docs/archive/daily-day/2026-08-11/`.

**Что построить:** охват сверяется ДО мутации (раскрытие каталогов поимённо —
`git add --dry-run` либо `git status --porcelain` с рекурсией), и сухой прогон
печатает владельцу уже раскрытый список файлов. Расхождение «показано ↔
закоммичено» становится невозможным по построению, а не по бдительности.

### Дефект 2 — исключение рвёт обход

Отказ снимка на одном дереве уходит наружу и обрывает цикл: остальные деревья
не обрабатываются вовсе. После второго прогона невыровненными остались
`Membrana`, `meeting-static-container-20260803`, `read-api`, `product`.

**Что построить:** проблемное дерево пропускается с причиной — рядом с
существующими `unregistered` / `tracked-deletions` / `not-behind`, — обход
продолжается, находки копятся в отчёт. Ненулевой код возврата выносится по
итогу обхода, а не по первому исключению.

### Тесты

| Область | Минимум |
|---------|---------|
| Гард охвата | фикстура с грязным каталогом: план сухого прогона несёт файлы поимённо; при расхождении охвата мутации НЕ произошло (коммита нет) |
| Продолжение обхода | фикстура из трёх деревьев, среднее даёт отказ снимка: третье обработано, отчёт несёт причину пропуска среднего |
| Код возврата | отказ хотя бы одного дерева → ненулевой код ПОСЛЕ полного обхода |

### Definition of Done

- [ ] Охват сверяется до коммита; при расхождении дерево не мутируется вовсе.
- [ ] Сухой прогон печатает файлы поимённо (каталоги раскрыты).
- [ ] Отказ дерева не рвёт обход; причина попадает в отчёт рядом с прочими.
- [ ] Зубы на все три области зелёные; `yarn test:scripts` зелёный.
- [ ] Живой сухой прогон на дереве разработчика приложен к PR.

### Out of scope

- Семантика выравнивания (что считать `behind`, `ff` против merge).
- Merge-драйвер реестра и разрешение конфликтов.
- Массовый мутирующий прогон — он идёт отдельно, под owner-гейтом, после починки.
- Разбор коммита `f798b4d9` в чужом дереве: оставлен по слову владельца 11.08.
