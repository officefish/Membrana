# Промпт: Узел к дежурству — предикат готовности Firebat (Г4)

> Task-промпт. Реестр: `node-duty-ready-predicate` · размер **S** · форма **шот**.
> Issue: [#2049](https://github.com/officefish/Membrana/issues/2049). Исполнитель — сессия Г. Срок — до дежурства пт 28.08.

## Контекст

Узел Firebat (Windows Home) ставится `scripts/firebat-service-install.ps1` (комплект + `.env` с
ключом узла + задача планировщика при входе). К дежурству узел не готов по трём переключателям:
сон/гибернация не отключены, автовход не включён, служба стартует только после входа (#2049).

## Что построить

1. `yarn node:duty-ready` (PowerShell + обёртка): три предиката «да/нет» с причиной — сон и
   гибернация выключены (`powercfg`), автовход (`AutoAdminLogon`), задача планировщика есть и включена.
2. Инструкция владельцу: какие переключатели повернуть руками (без секретов в репо).
3. Вывод одной таблицей, exit ≠ 0 при любом «нет» (fail-closed).

## Границы

- На узле ничего не менять автоматически — только читать и называть; сценарии борда не трогать.

## DoD и порча

- Зуб на разбор вывода `powercfg`/реестра — фикстурами.
- **Порча:** подменить «гибернация включена» → предикат красный с причиной.
- Приёмка: на Firebat три «да» до 28.08.
