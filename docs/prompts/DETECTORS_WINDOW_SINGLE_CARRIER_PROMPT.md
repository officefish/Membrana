## Контекст

Строка 8 топ-10 на 02.08 просит свести три копии `prepareFftSamples`
(`harmonic · cepstral · spectral-flux`). Разведка даёт другое число и другой предмет.

**Копий не три, а четыре, и четвёртая — в самом `@membrana/detector-base`.** Обход кадров
живёт там приватной функцией `iterWindows` (`analyze-sample.ts:63-72`), телом совпадающей с
`fftFrames` детекторов до символа:

```ts
if (samples.length < fftSize) return;
for (let start = 0; start + fftSize <= samples.length; start += hop) {
  yield samples.subarray(start, start + fftSize);
}
```

Замер по дереву: `base/analyze-sample.ts:69`, `harmonic/src/core/sample-window.ts:36`,
`cepstral/…:41`, `spectral-flux/…:53`.

**Это меняет задачу к лучшему.** Не «завести общий модуль и переселить туда три копии», а
«носитель механики уже есть, он держит её приватно — открыть и перестать копировать». Все три
детектора **уже зависят** от `@membrana/detector-base` (`"@membrana/detector-base": "*"` в
каждом `package.json`), новых рёбер графа не появляется.

**Почему отдельным спринтом, а не попутной правкой.** Свод трогает `analyzeSample` — путь,
которым идут бенчмарк и UI-плагин библиотеки образцов. Хендоф прямо запрещает делать это
попутно; дом задачи — [#1572](https://github.com/officefish/Membrana/issues/1572).

**Что копии успели разойтись** (02.08, спринт `detectors-judge-whole-record`): свод спектров у
всех троих разный по природе — `harmonic` усредняет арифметически, `cepstral` геометрически
(`log(mean) ≠ mean(log)`, иначе пик квефренции размывается), `spectral-flux` не усредняет вовсе
и подаёт кадры в трекер по одному. **Единый носитель обязан сохранить эту разницу, а не
унифицировать её:** объединять надо обход и подготовку, а не свод.

## Что построить

1. **Публичный носитель в `@membrana/detector-base`**: `prepareFftSamples`, `fftFrames`,
   `averageMagnitudes`, `geometricMeanMagnitudes` — с доказательной шапкой, объясняющей, почему
   сводов два и когда какой законен.
2. **`analyzeSample` перестаёт держать свою копию** — зовёт `fftFrames`. Числа бенчмарка не
   сдвигаются: поведение при `samples.length < fftSize` и шаг по умолчанию сохраняются точь-в-точь.
3. **Три детектора удаляют свои `sample-window.ts`** и импортируют из базы; их собственные зубы
   переезжают на общий носитель либо остаются там, где проверяют поведение ДЕТЕКТОРА, а не окна.

**Запрещено:**

- Унифицировать свод спектров: арифметическое, геометрическое и «не сводить вовсе» — три разных
  ответа на три разные природы, и это не дублирование.
- Менять сигнатуру `analyzeSample` и его умолчания (`DEFAULT_ANALYZE_FFT_SIZE`, `hopRatio`).
- Заводить новый пакет: носитель есть, рёбра графа уже проложены.
- Трогать `SpectralFluxTracker` (`@membrana/fft-analyzer-service`) — вне зоны.
