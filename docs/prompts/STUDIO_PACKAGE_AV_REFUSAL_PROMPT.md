# Промпт: Установщик Studio — честный отказ при AV-блокировке + fallback на артефакт CI (Г3)

> Task-промпт. Реестр: `studio-package-av-refusal` · размер **S** · форма **шот**.
> Носитель: хвост [#2147](https://github.com/officefish/Membrana/issues/2147) (шестая строка). Исполнитель — сессия Г.

## Контекст

25.08 `yarn studio:package` падал двумя классами: (1) протухший по содержимому dist зависимости
при свежей дате — зуб 5 недели без повторов (#2159, Б); (2) `electron-builder`:
`open …\win-unpacked\d3dcompiler_47.dll: Access is denied` — антивирус держит свежезаписанный
бинарь, воспроизводится в чистом каталоге; CI этого не знает. Установщик взяли из артефакта CI.

## Что построить

1. `scripts/studio-package.mjs`: классификатор отказа electron-builder — `EACCES`/`Access is denied`
   на файле в `win-unpacked` → **честный отказ** с именем файла и подсказкой: «антивирус держит
   `<путь>`: исключение или повтор; либо установщик из артефакта CI для головы `<sha>`».
2. Флаг `--from-ci` (или готовая команда `gh run download` в подсказке) — fallback одной командой.
3. Классификатор — чистая функция над текстом вывода, тестируется без сборки.

## Границы

- Конфигурацию electron-builder и подпись не менять; чужие классы отказов не глушить тем же словом.

## DoD и порча

- Зуб: текст с `Access is denied` на `.dll` → класс `av-locked` и путь.
- **Порча:** убрать классификатор → тест красный.
