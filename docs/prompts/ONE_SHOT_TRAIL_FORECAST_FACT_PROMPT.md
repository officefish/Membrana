### Что построить (продуктовое описание)

1. **Расширение записи следа** `docs/audit/one-shot-trail.jsonl`: поля `executor` (кто
   играл), `forecast` (обещанные строки/файлы из штампа S), `actual` (факт из диффа
   мердж-коммита, `git diff --stat <parent> <merge>`). Существующие записи без новых полей
   остаются валидными; `trail check` (JSONL, non-decreasing timestamps, идемпотентность по
   `path|slug|headRev`) продолжает работать.
2. **Глагол `one-shot:trail brief`** — 3–5 строк консистентного формата (всегда одни поля,
   один порядок): сколько шотов, зон, исполнителей, держатся ли форкасты. Содержательно с
   первого дня: не «13 шотов», а «13 шотов · 5 зон · N исполнителей · форкасты: M/K
   держатся».
3. **Дисциплина всплытия** — словом в доке глагола: сводка вкладывается руками в тройной
   акт Тарасова и в предложение кандидатов владельцу; в утро и хендоф — НЕ вкладывается.

### Порядок (из ревью)

- Расчёт факта — только в `scripts/` (чистый утилитарный слой), не в приложениях.
- Формат `brief` согласовать актом Тарасова (какие поля важны для вердикта) ДО того, как
  сводка начнёт вкладываться в его вопросы.
- Первый шаг математики — сверка да/нет (`actual − forecast`), без скоринга; скоринг —
  после накопления статистики (≥2–3 недель).

---

### Тесты

| Область | Минимум |
|---------|---------|
| `trail check` | старые записи валидны, новые поля не ломают идемпотентность |
| `brief` | формат стабилен (одни поля, один порядок), пустой/тощий портфель — содержательная строка, не молчание |
| Факт из диффа | parent/merge берутся верно, отсутствие мерджа → `actual` отсутствует, а не ноль |
