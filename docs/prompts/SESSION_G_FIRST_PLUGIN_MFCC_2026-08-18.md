## Задача

### PR-3 · `membrana.handler.mfcc` — первый живой (главное дня)

1. Манифест: `HandlerManifest { id: 'membrana.handler.mfcc', version, kind: 'handler',
   mountTarget: 'background-media/collections', triggers: ['collections.sample_added'],
   windowSize? }` — id ОБЯЗАН проходить regex M1 (`mfcc-detector` — не проходит, три
   сегмента с точками обязательны).
2. `PluginExecutor.execute(ctx)`: читает пробы коллекции **только на чтение**, гонит
   существующий mfcc-детектор, возвращает `RunResult`. Никакой записи в `samples`/
   `collections` (норма #1950 — структурное условие).
3. Живой прогон на коллекции «Полевые записи 2026-08» через `request` хоста →
   `RunRecord` в `plugin-results` с **честным следом** (M6′):
   `address = { pluginId, version, collectionId, runId, mountTarget }` ·
   `fingerprints = { inputHash, configHash }` · `resumeMode: 'fresh'` · `completedAt` · `kind`.
   **Без** `StateRecord` (нет накопления) и **без** `ConvergenceRecord` (нет пары
   live/recompute) — их отсутствие норма, не дефект.
4. Предъявление: читаемый документ из `plugin-results` (не лог, не скриншот) — id
   прогона в отчёте владельцу.

### PR-4 · Манифесты и заглушки остальных пяти

5. `HandlerManifest` для harmonic, cepstral, spectral-flux, template-match, yamnet

6. Регистрация всех шести в хосте `collections`; `getRegisteredPlugins()` отдаёт шесть.
