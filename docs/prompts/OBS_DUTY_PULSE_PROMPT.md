## Промпт целиком (для вставки агенту)

### Что построить

1. Издатель в процессе узла/борда в режиме duty-записи: раз в 60 с `DutyPulseSample`
   `{ts, probes_total, step_s (null при <2 проб), media_used_mb, media_cap_mb}` на
   **локальную** ленту (append/ring). Издание не зависит от кабинета.
2. Локальный детектор: `stale` при возрасте тика > 60 с, `silent` при > 120 с;
   переход alive→silent → **одно** происшествие через контракт куска B (#2119),
   дедуп до выхода из silent.
3. Read-model для витрины дежурства (optional): три числа + возраст тика,
   состояния `ok | stale | silent`.

### Не входит (вердикт M1b)

Спектр/SNR/детектор/FAR · gain/клиппинг · CPU/temp/uptime · статусы кабинета ·
поток пульса в Сентри · разрывы >12 с как штатное поле (только офлайн-разбор).

### Definition of Done (5 предикатов вердикта M1b)

- [ ] Тик ≤ 60 с при живой записи и **лежащем кабинете**.
- [ ] Витрина: три числа + возраст; `ok|stale|silent` по порогам 60/120 с.
- [ ] Тишина > 120 с → одно происшествие в картотеке (через контракт B), без размножения.
- [ ] При нормальном тике записей пульса в картотеке нет.
- [ ] Издание не тянет поля детектора и кабинет; `yarn turbo run …` зелёный (scope) · LGTM Teamlead.

### Out of scope

Номер происшествия (B) · `/health/deep` (D) · сторож диска (A) · прод-деплой без слова владельца.
