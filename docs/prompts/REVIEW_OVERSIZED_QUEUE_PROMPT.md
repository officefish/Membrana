# Промпт: Очередь oversized на точечное ревью считается прибором, а не глазом

> Task-промпт. Размер: **S**. Артефакт: **1 PR**.
> Реестр: `id` = `review-oversized-queue` в [`docs/tasks/registry.json`](../tasks/registry.json).

---

## Контекст

Строка 2 топ-10 на 02.08 просит точечно ревьюить oversized PR по одному в день, называя
16 таких в стволе. **Замер 02.08 даёт другое число: 185 oversized-коммитов с 20.07, артефакт
ревью есть у 17, без него — 168.** Это четвёртая за день строка десятки, чьё обоснование не
воспроизводится по дереву.

**Очередь из 168 без разбора природы бесполезна.** Классификация по составу файлов: **60 —
только `docs/`**, 6 — только код, 119 — смешанные. Ежевечерние ритуальные PR попадают в
oversized закономерно, и ревью #1624 это уже признало прямо: «объём обоснован природой
ежевечернего ритуального PR, oversized-флаг по регламенту — P1 recommend split, не авто-BLOCK».
Ставить их в одну очередь с кодом значит утопить шесть кодовых в шестидесяти архивных.

**Что уже есть.** Порог `OVERSIZED_CHANGED_LINES = 400` и предикат `isSegmentOversized` живут в
[`day-work-diff.mjs`](../../scripts/lib/day-work-diff.mjs) — единственный носитель мерки, и
копировать 400 к себе запрещено. Артефакты ревью лежат по образцу
`docs/discussions/pr-<N>-code-review.md`. Механизма очереди нет: «какой сегодня» решается
глазом, и потому не решается никак — за двенадцать дней ревьюировано 17 из 185.

**Норма дня, обязательная к исполнению.** Прецедент 02.08
[`2026-08-02-review-blindness-scales-with-diff`](../precedents/2026-08-02-review-blindness-scales-with-diff.md):
ревью выносило блокер об отсутствии того, что лежало в дереве. Любое утверждение вида
«такого нет» проверяется командой ДО того, как попадёт в артефакт.

## Что построить

1. **Предикат очереди.** Дано: коммиты с их файлами и объёмами. Получить: класс каждого
   (`code` · `docs` · `mixed`), риск (изменённые строки КОДА, а не всего), и порядок.
   Артефакт ревью в `docs/discussions/` снимает элемент с очереди.
2. **Глагол.** `yarn review:oversized` печатает очередь с числами и явно называет, сколько
   отброшено как `docs` и почему — молчаливое сокращение выборки запрещено.
3. **Первое ревью — прогоном, а не обещанием.** Верхний элемент очереди ревьюируется сегодня,
   артефакт кладётся по образцу. Без него спринт закрылся бы зелёным, не создав того, ради
   чего заведён (норма #1565).

**Запрещено:**

- Переобъявлять порог 400 — импортировать `OVERSIZED_CHANGED_LINES`.
- Молча отбрасывать классы: отброшенное называется числом и причиной.
- Утверждать в ревью отсутствие чего-либо, не проверив командой.
- Чинить найденное в том же PR: ревью — чтение, находки идут карточками.

## Тесты

| Область | Минимум |
|---------|---------|
| класс | только docs → docs; только код → code; смесь → mixed |
| риск | считается по строкам кода, а не по всему диффу |
| снятие | элемент с артефактом ревью в очередь не входит |
| порядок | детерминирован при равном риске |
| пустой вход | очередь пуста — это утверждение, а не молчание |

## Definition of Done

- [ ] `yarn review:oversized` печатает очередь и число отброшенных с причиной.
- [ ] Артефакт первого точечного ревью лежит в `docs/discussions/`.
- [ ] Каждое утверждение об отсутствии в нём проверено командой, команда приведена.
- [ ] LGTM Teamlead.

## Out of scope

- Автоматический выбор «сегодняшнего» по календарю.
- Ревью более одного элемента.
- Починка найденного.
