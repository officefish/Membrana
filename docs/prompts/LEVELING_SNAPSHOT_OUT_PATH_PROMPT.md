# Промпт: Снимок выравнивания ломается на абсолютном --out (клеит путь к корню репозитория)

> **Task-промпт для агента-разработчика** (Cursor IDE / Claude / другой LLM).
> Процесс постановки: [`TASK_PROMPT_WORKFLOW.md`](./TASK_PROMPT_WORKFLOW.md).
> Скопируй блок **«Промпт целиком»** в начало диалога. Размер задачи: **S**.
> Ожидаемый артефакт: **1 PR — --out принимает абсолютный путь**.
> Реестр: `id` = `leveling-snapshot-out-path` в [`docs/tasks/registry.json`](../tasks/registry.json).

---

## Контекст

yarn membrana-leveling:snapshot --out <абсолютный путь> падает: путь приклеивается к корню репозитория (ENOENT mkdir C:...Membrana-toolingC:Users...). Обход в сессии 26.07 — относительное имя с игнорируемым расширением .tmp, то есть временный файл внутри дерева.

То же проверить у соседнего workspace-level (--snapshot/--out).

Не трогаем: формат снимка и гейт диспозиции.
