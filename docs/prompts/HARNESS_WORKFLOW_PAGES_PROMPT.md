# Промпт: Harness Mintlify — страницы мастерских и процедур

> Task-промпт `harness-workflow-pages`. Размер: **L**.
> Ожидаемый артефакт: отдельный PR второго `membrana-local-sprint`.
> Родитель: `dual-mintlify-product-harness`, Issue
> [#1622](https://github.com/officefish/Membrana/issues/1622).

## Статус входа

Этот спринт зарегистрирован, но **не открыт для исполнения**, пока Product-спринт
не закрыт. Перед кодом нужно заново прочитать состояние `origin/main`, PR #1613 и
PR #1620, выполнить свежую нарезку и получить отдельную ратификацию владельца.

`apps/docs-harness` уже существует и закреплён за `harness.mmbrn.tech`. Материал
нужно собирать из живых реестров, манифестов, гранул и канонических документов,
а не переносить ручной список из чата.

## Промпт целиком

После закрытия `product-mintlify-container` открой отдельный
`membrana-local-sprint` и доведи `apps/docs-harness` до документации рабочего
контура Membrana:

1. Создай индекс мастерских и индекс процедур.
2. Для **каждой** мастерской из живого реестра создай отдельную страницу.
3. Для **каждой** процедуры из живого реестра создай отдельную страницу.
4. На странице покажи назначение, вход, этапы/команды, гейты, выходные артефакты,
   примеры и портфолио, если они действительно существуют.
5. Если примеров или портфолио нет, покажи честное состояние и заведи машинно
   проверяемый вход в марафон `workflow-examples-marathon`, не сочиняя пример.
6. Страницы и навигацию генерируй из канона; drift должен ловиться check-mode.
7. Product-предметы не должны появляться в Harness-навигации.

## Архитектурный контракт

| Слой | Путь | Ответственность |
|------|------|-----------------|
| Harness surface | `apps/docs-harness/**` | Документация мастерских и процедур |
| Workflow canon | `docs/procedures/**`, workshop manifests/registries, strategic-docs granules | Источники предметов и фактов |
| Generator | определить свежей нарезкой | Одна проекция страниц и navigation fragments |
| Example debt | `workflow-examples-marathon` | Накопление недостающих реальных примеров |

## Definition of Done

- [ ] Каждая живая мастерская имеет отдельную Harness-страницу.
- [ ] Каждая живая процедура имеет отдельную Harness-страницу.
- [ ] Индексы вычисляются из того же канона и не заменяют предметные страницы.
- [ ] Наличие портфолио и примеров вычисляется и сообщается честно.
- [ ] Пробелы заведены в `workflow-examples-marathon` без выдуманных материалов.
- [ ] `harness.mmbrn.tech` остаётся единственным Harness-доменом.
- [ ] Device Board, узлы и тарифы отсутствуют в Harness-навигации.
- [ ] Генератор, check-mode, corpus test, link/Mintlify checks зелёные.
- [ ] Desktop/mobile/a11y проверены визуально.
- [ ] Назначенные ответственные увидели код, sprint gate и closure review дали LGTM.

## Запреты

- Не начинать до закрытия Product и новой owner-ratification.
- Не мёржить PR #1620 в смешанном виде; пересобрать его полезную дельту по границе Harness.
- Не включать Device Board, узлы и тарифы.
- Не объявлять задуманный марафон реализованной процедурой.
- Не создавать ручной закрытый перечень параллельно живому реестру.
