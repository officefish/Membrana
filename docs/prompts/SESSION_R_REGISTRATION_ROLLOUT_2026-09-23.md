Файл `.env` под `.gitignore` (`.gitignore:33`) — в свежем дереве его НЕТ. Замер 23.09: в `practice/Membrana` и `practice/Membrana-tooling` он есть, в `.worktrees/cabinet-register-form` и `.worktrees/cabinet-office-client` его нет.

Проверка из своего дерева: `test -f .env && grep -cE '^(BACKGROUND_MEDIA_IPV4|BACKGROUND_MEDIA_PASSWORD)=' .env` — ожидание `2`. Значения не печатать.

Меньше двух или файла нет — **СТОП — рука владельца**: владелец кладёт `.env` в дерево исполнителя (копией из `practice/Membrana`) либо называет дерево, из которого вести выкатку. Секреты через чат не передавать. Выкатку из главного дерева `practice/Membrana` не вести: оно на чужой ветке и с чужой грязью, а гейт DR0 требует «дерево = origin/main».

### Шаг 1 — офис (VDS `office.mmbrn.tech`)
- Сборка и подъём: `node scripts/_ssh-office-prod-up.mjs` (синхронизирует контекст сборки на VDS архивом и запускает `office-stack build + up`; шапка скрипта — про относительный путь для tar, не менять) — из дерева ровно на `origin/main`, иначе на VDS уедут не те исходники. Затем `node scripts/_ssh-office-smoke.mjs --external` (прод-смоук офиса: OK / SKIP / FAIL без секретов, плюс curl снаружи) и `curl -fsS https://office.mmbrn.tech/health`.
- **Живой смоук двери** — `node scripts/_ssh-panel-smoke.mjs` полный сценарий, шаг 6: чеканка кода с грантом `cabinet-register` (1 использование, 1 день) → запрос без ключа → 401 → `mode: "check"` → 200 `redeemable: true` → `mode: "redeem"` → 200 → повтор → 409 `exhausted` → иной `mode` → 400 → отзыв кода. В отчёт — вывод целиком (код смоука печатает только префикс).

### Шаг 3 — кабинет (хост media, `cabinet.membrana.space`)
- `CABINET_IMAGE_TAG=main node scripts/_ssh-cabinet-deploy-image.mjs` — гейты DR0 (дерево = origin/main) и DR1 (CI зелёный на голове); отказ гейта = СТОП, не обходить.
- Двери живьём, не `/health`: `GET https://cabinet.membrana.space/health/deep` → в теле поле `office_registration: ok` (чекер B бьёт дверь офиса несуществующим кодом и ждёт 409 `not_found`); `config-invalid` = ключ не тот (назад к шагу 2), `office-unavailable` = адрес или сеть (назад к шагу 1).
