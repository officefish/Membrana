# Промпт: Деплой видит живой сеанс — предикат «устройство занято» (В1)

> Task-промпт. Реестр: `deploy-busy-device-predicate` · размер **M** · форма **шот** (один PR, одна порча).
> Issue: [#2048](https://github.com/officefish/Membrana/issues/2048). Исполнитель по хендофу 25.08 — сессия В (Codex).

## Контекст

21.08 деплой media во время живого сеанса записи стоил 25 треков (прецедент #2048). Преflight
деплоя (`scripts/_deploy-preflight.mjs`, обёртка `scripts/deploy-run.mjs`) проверяет чистоту
дерева и зелёный CI, но **не знает, пишет ли устройство прямо сейчас**. Норма «деплой при живом
сеансе запрещён» держится руками владельца и памятью ведущей — то есть не держится.

Что есть: media отдаёт пробы коллекции с `createdAt`
(`GET /v1/devices/:id/collections/__buffer__/samples?page=1&limit=1`, токен `VITE_MEDIA_API_TOKEN`
из `.env`); ведущая 23–24.08 считала возраст последней пробы этой ручкой.

## Что построить

1. Предикат `deviceBusy({ lastSampleAt, now, thresholdS = 60 })` — чистая функция без сети и часов.
2. Шаг преflight «устройство пишет?»: спросить media возраст последней пробы буфера узла;
   моложе порога → **отказ** «устройство пишет, последняя проба N с назад — выкатка запрещена
   (#2048)». Media недоступна → «неизвестно» + отказ (fail-closed), не тихий пропуск.
3. Обход — только с названной причиной, той же дверью, что у грязи: `--allow-busy-reason "…"`
   / `DEPLOY_BUSY_REASON`; причина уходит в трейл прогона.

## Границы

- Не трогать деплой-скрипты сервисов; только преflight и `deploy-run`.
- Прод в тестах не опрашивать: предикат — значениями, шаг — с подменой fetch.
