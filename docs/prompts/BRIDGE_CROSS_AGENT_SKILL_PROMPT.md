## Контекст

Комната «мостик» (спринт `bridge-room` #936) существует: процедура
[`docs/procedures/bridge/`](../procedures/bridge/README.md), движки в плоском `scripts/`,
реестр долгов попугая, конспект дня. Чего у неё не было — **входа для холодной сессии**:
фраза капитана «идём на мостик» ни во что не резолвилась. Скилла нет ни в `.cursor/skills/`,
ни в зеркалах; в `AGENTS.md` / `.cursorrules` / `CLAUDE.md` слово «мостик» не встречается
(единственный хит по `bridge` — `replit-bridge`, ложный друг). Комната найдена 25.07 только
грепом по репозиторию — повезло, что имя процедуры совпало со словом капитана.

Второй пробел — оснастка: `kitVersion` процедуры был `null`. Инструментарий ведущей
(Ангелина) закитован только утренним набором `kits/angelina-morning`, чьи корни на мостике
не нужны; подменять соседней поставкой запрещено паттерном мастерской.

**Не трогаем:** семантику жизненного цикла комнаты (открытие явное, закрытие — вечерним
ритуалом), append-only реестр долгов, границу «ядра чистые, fs и дата в адаптере».

### Что построить (продуктовое описание)

1. **Скилл `membrana-bridge`** — вход в комнату для любого агента: канон в
   `.cursor/skills/`, тонкие зеркала в `.claude/` · `.agents/` · `.opencode/`.
   Триггеры: «идём на мостик», «на мостик», «открой мостик», «зови попугая», «долги мостика».
2. **Кит `kits/angelina-bridge`** — опись движков комнаты (корень `bridge.mjs` + чистые
   ядра), держатель `angelina`; провод `kitVersion` от процедуры мостика.
3. **`yarn bridge tools`** — инструментарий ведущей по зонам: комната · попугай ·
   ведущая · соседи. Флаги `--zone`, `--doc <id>`, `--json`.

---

### Архитектура / контракт

| Слой | Путь | Ответственность |
|------|------|-----------------|
| Ядро (чистое) | `scripts/lib/bridge-toolkit.mjs` | схема каталога, инвентарь, рендер; без fs и сети |
| Адаптер | `scripts/bridge.mjs` | подкоманда `tools`, чтение каталога, коды выхода |
| Каталог (дом) | `docs/bridge/toolkit.catalog.json` | спрос: какие инструменты и где их документ |
| Кит (поставка) | `kits/angelina-bridge/` | `MANIFEST.json` (пины) + `README.md` |
| Скилл | `.cursor` (канон) + три зеркала | вход холодной сессии |

**Запрещено:**

- Грузить на мостике утренний кит `angelina-morning` — он сосед, не замена.
- Тихо пропускать отсутствующий файл инструмента: только видимое `⚠`.
- Класть код или тесты внутрь контейнера кита (Т12) — движки живут в плоском `scripts/`.
- Закрывать комнату из скилла: закрытие — шаг вечернего ритуала.

---

### Тесты

| Область | Минимум |
|---------|---------|
| Схема каталога | дубль id, чужая зона, инструмент без адреса — дефекты |
| Инвентарь | мёртвая ссылка = предупреждение, инструмент остаётся в выдаче |
| Порядок и фильтр | канонический порядок зон; `--zone` режет остальное |
| Живой каталог | схема цела, все зоны непусты, ни одного обещанного-но-отсутствующего файла |

### Definition of Done

- [ ] Скилл в четырёх зеркалах; строка в реестре `.cursor/skills/README.md`.
- [ ] Кит заведён, `yarn kits:audit --id angelina-bridge` — 0 находок.
- [ ] `kitVersion` процедуры мостика указывает на кит; `yarn procedures:registry --check` зелёный.
- [ ] `yarn bridge tools` печатает четыре зоны; `--doc` и `--json` работают.
- [ ] Тесты ядра в `test:scripts`; `yarn tooling:atlas --check` — производные свежи.
- [ ] LGTM Teamlead.
