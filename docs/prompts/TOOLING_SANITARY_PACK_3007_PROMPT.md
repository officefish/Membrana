# Санитарный пакет тулинга 30.07

**Слово владельца 30.07:** «ты заказывал тулинг нидс, давай сначала выполним их».
Магистраль дня — `mfcc-spectral-core` — **остаётся**; пакет идёт первым в порядке работ.

Источник: ретроспектива `membrana-tooling-needs` по итогам сессии 29.07 — восемь фрикций
с эпизодами. Здесь — четыре XS–S, у которых польза на цену выше всего.

## Ф1 · Пересборка производных снимков одной командой (S)

**Эпизод.** 29.07 трижды получен отказ за отставший снимок: реестр прецедентов (перед
отгрузкой), каталог кейсов (валидатор), индекс вещдоков (**в CI**, на последнем PR дня).
Каждый раз — прогон CI в 8 минут.

**Факт.** Производных снимков в дереве **шесть**: `docs/cases/registry/CASES.md`,
`docs/cases/registry/NOMINATIONS.md`, `docs/evidence/INDEX.md`,
`docs/precedents/registry/PRECEDENTS.md`, `docs/tasks/README.md`,
`docs/tooling-atlas/registry/ATLAS.md`. **Общего пересборщика нет** (проверено грепом по
`package.json`).

**DoD.** `yarn snapshots:rebuild` пересобирает все известные снимки; `--check` возвращает
находки поимённо и годится в pre-push рядом с описями китов. Пары «источник → снимок»
объявлены декларацией, не зашиты в код. Зуб: снимок отстал → находка с именем снимка.

## Ф2 · Вывод инструментов сноса — только в файл (XS)

**Эпизод.** 29.07 текст двух ошибок сноса деревьев потерян пайпом `| tail`; причину
восстанавливали по состоянию диска. Вечером тот же класс: шелл съел бэктики в теле
комментария к ишью — две строки исчезли молча.

**DoD.** `repo-clean --execute` **отказывается** работать без `--report`. Норма о канале
доставки — строкой в грабли `AGENTS.md` (§Agent tooling), не в инвентарь.

## Ф3 · Несущее содержание — в строку вопроса, не в приложение (XS, норма)

**Эпизод.** 29.07 заседание по спринту: прогоны 2 и 3 получили **побайтово одну** повестку
(7110 байт при потолке 12000, файл не менялся между запусками). Отличалась только строка
вопроса — в третьем в неё вписаны девять кандидатов. Результат: брак → годный вердикт.

**DoD.** Строка в регламент заседания: несущее содержание обязано быть в вопросе;
приложение — дубль, а не носитель. Ссылка на эпизод как вещдок.

## Ф4 · Один автор у долгов попугая (XS, фикс)

**Эпизод.** 29.07 долги заведены легаси-глаголом `bridge debt add` — он пишет только
витрину `DEBTS.md` и перетирает её шапку старым текстом; канонический `bridge:debt birth`
ведёт append-only журнал и пересобирает витрину производной. Ревью дало BLOCK.

**DoD.** Легаси-глагол снят: `bridge debt add|settle` отвечает отказом с подсказкой на
канонический путь. Ровно вердикт M2 заседания по тарифам: один автор, двойная запись
запрещена.
