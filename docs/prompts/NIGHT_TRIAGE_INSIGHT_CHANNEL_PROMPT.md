# Промпт: Канал «ночной триаж → карточка инсайта» (#1445)

> **M** · `night-triage-insight-channel` · [#1445](https://github.com/officefish/Membrana/issues/1445) · lead **ozhegov** · support **dynin**, **kuryokhin**

## Контекст

Четыре ночи подряд (25–28.07) триаж отработал и открыл PR. Ни один не смёржен, ни один
не исполнен — четыре черновика в никуда, закрыты 29.07 вердиктом `close_no_card`.
Консилиум смотрел все четыре и вынес: идей, достойных карточки инсайта, — ноль.

Дело не в читателе. Отчёт отдаёт сырьё вместо наблюдения: 158 строк `orphan` с одним
словом `relink`, 106 строк `stale` с одним словом `re-scope`, пять `ghost` — четыре ночи
один и тот же список. Единственная величина, меняющаяся от ночи к ночи, — `dwell`,
ровно +1 в сутки. Тикающие часы, а не находка.

Отчёт честно объявляет себя «sink not source: рекомендации, не действия — исполняет
человек» — но человек не появляется, а PR открывается каждую ночь. Носитель есть,
читателя нет: зверь B8.

Отдельная цифра: orphan 158 при 212 активных карточках — три четверти живого реестра
«сироты», и новая карточка попадает туда в момент рождения. Триаж мерит не
заброшенность, а дырку в процедуре заведения карточек.

## Промпт целиком

### Кто ты

Ожегов ведёт (границы домов и контракт), Дынин — предикаты и метрика, Курёхин — стык с
магистралью дня. Чистые ядра без сети; генератор отчёта остаётся детерминированным.

### Что сделать

1. **Развести дома.** Сырьё триажа — append-only, живёт своим путём. Карточка инсайта
   рождается отдельно и только с `id` и причиной. Ядро не смешивает: одна функция даёт
   сырьё, другая — кандидатов в промоут.
2. **`promote_card` как условие PR.** Ночь открывает PR тогда и только тогда, когда
   есть хотя бы один промотированный кандидат. Нет кандидата — отчёт пишется, PR не
   открывается. Молчание тут легально и должно называть причину (норма B10).
3. **Scorecard строки:** `gap` / `cost` / `reversible` вместо слова-константы. Строка
   без оценки — не рекомендация, а счётчик. Значения — закрытый enum, не свободный
   текст (иначе зверь B9 «Проза»).
4. **Enum вердиктов пачки:** `doc_merge | squash_memo | close_no_card`. Состояния
   «оставим открытым» в перечне нет — незакрытый черновик обязан иметь вердикт.
5. **Стык с магистралью дня.** Отчёт отвечает на вопрос primary focus одной строкой на
   пункт. Нет пересечения с магистралью — так и пишется, явной строкой, и PR не
   открывается. Сканер без вопроса дня — фоновый шум.
6. **Витрина не прячет пустоту.** Шапка отчёта: `cards: N · drafts_closed: M`, таблица
   `дата | PR | verdict | cardId | why`. `cards: 0` показывается честно, а не молчанием.
Сквозной поверх шести — **метрика v0** (Дынин): `insight_yield = cards / night_triages`
за окно. Считается и печатается; база зафиксирована — `insight_yield(25–28.07) = 0`.

- [ ] Ночь с кандидатом PR открывает — доказано подложенным кандидатом
- [ ] `insight_yield` считается и печатается; на окне 25–28.07 даёт ровно 0
- [ ] Вердикты — закрытый enum; строка без вердикта роняет проверку с именем PR
- [ ] Scorecard-поля закрытые; свободный текст в них не проходит
- [ ] Инвариант: открытых draft-PR ночного триажа после такта — 0
- [ ] Юнит-тесты обоих путей (есть кандидат / нет кандидата) зелёные

### Out of scope

- Полный ADR на репозиторий — сегодня блок границ в каноне/мемо. ADR завести, только
  если процесс-фикс живёт >2 недель и требует зуба в `scripts`.
- Новый пакет или сервис «insight-engine» — сначала дома и enum, потом обсуждать движок.
- Разбор самой дырки «карточка рождается сиротой» (orphan 158 из 212 активных) — это
  про процедуру заведения карточек, отдельная работа; здесь только зафиксировать цифру.
- Правка исторических отчётов 25–28.07: они закрыты вердиктом, сырьё
  восстанавливается повторным прогоном генератора.
