## Контекст

Кит — именованный набор точек входа с описью `path → git blob SHA`
([`PINNED_SUBGRAPH_VERSIONING`](../patterns/PINNED_SUBGRAPH_VERSIONING.md), контракт слоя
[`kits/README.md`](../../kits/README.md)). Опись нужна автономным прогонам (ночь/cron/office):
режим `pinned` берёт строго её. Зуб полноты `yarn kits:audit` (K2 / #817) существует и
работает — но **не подключён ни к одному пути**: ни `pre-push`, ни CI, ни вечерняя цепочка.
Единственный способ узнать о расхождении — вспомнить про ручную команду.

Следствие поймано 25.07 при заведении кита мостика: полный прогон даёт **30 блокирующих
находок** — `angelina-morning` 21 (8 движков уехали от пинов, 13 узлов подграфа llm-каналов
вовсе не в описи), `containerization-master` 6, `dream-master` 3. Чистые: `tasks-master`,
`witcher`, `angelina-bridge`. Инструмента приведения описи к факту нет — правка руками
по одному SHA, поэтому она и не делалась.

**Не трогаем:** сами движки в `scripts/` (задача про опись, не про код), контракт схемы
кит-манифеста, механику `auditKit` (переиспользуем, не дублируем).

### Что построить (продуктовое описание)

1. **Инструмент `yarn kits:pins`** — приводит опись кита к фактическому подграфу.
   Без флага показывает план правки (доложить / обновить / снять), с `--write` пишет
   `MANIFEST.json`. Флаги: `--id <kit>`, `--write`, `--json`. Меняется только поле `pins`.
2. **Выровненные описи трёх китов** — `angelina-morning`, `containerization-master`,
   `dream-master`, **каждый отдельным коммитом** (канон: пин не бывает побочным эффектом).
3. **Зуб на двух путях**: `pre-push` — мягкий режим (`--mode latest`: блокирует только
   структурную ложь — узел подграфа без пина), CI — строгий (`pinned`, полная сверка).

### Архитектура / контракт

| Слой | Путь | Ответственность |
|------|------|-----------------|
| Ядро (чистое) | `scripts/lib/kits-pins.mjs` | `normalizePins` / `diffPins` / `nextManifest` / `blockersBeforeWrite` / `renderPinsPlan` — без fs, git и сети |
| Адаптер (CLI) | `scripts/kits-pins.mjs` | чтение манифестов, `auditKit`, запись файла, коды выхода |
| Зуб полноты | `scripts/lib/kit-subgraph-audit.mjs` | переиспользуется как есть (`auditKit().actual`) |
| Провод | `.githooks/pre-push`, `.github/workflows/ci.yml` | latest перед push · pinned в проверках ветки |

**Запрещено:**

- Дублировать логику замыкания импортов — брать из `auditKit`.
- Писать опись при находках рода `schema` / `unresolvable` / `bad_json`: зелёная опись
  не должна прикрывать реальную дыру.
- Трогать `roots`, `id`, `leadPersona` и порядок полей манифеста.
- Ставить строгий режим в `pre-push`: правка скрипта не должна требовать обновления
  описи прямо в момент работы.

### Тесты

| Область | Минимум |
|---------|---------|
| `diffPins` | три рода правки (доложить / обновить / снять) и чистый случай |
| `nextManifest` | меняется только `pins`; порядок ключей манифеста сохранён; опись отсортирована |
| `blockersBeforeWrite` | схема/недостижимый узел → отказ до записи |
| Живые киты | все жильцы `kits/` сходятся с деревом (регресс на 30 находок) |

---

### Definition of Done

- [ ] `yarn kits:pins` показывает план, `--write` пишет опись; ядро чистое, тесты зелёные.
- [ ] `yarn kits:audit` (все жильцы, pinned) — **0 блокирующих находок**.
- [ ] Три описи выровнены тремя отдельными коммитами с указанием, что именно доехало.
- [ ] `pre-push` гоняет `kits:audit --mode latest`; CI — `kits:audit` (pinned).
- [ ] Тест на живые описи в `test:scripts`.
- [ ] Долг попугая `kits-pins-audit-unwired` погашен вещдоком (SHA/PR).
- [ ] LGTM Teamlead.

### Out of scope

- Правка самих движков и разбор, почему подграф llm-каналов разросся.
- Автообновление описи в CI (опись обновляет человек командой — это ревьюируемый акт).
- Вечерняя цепочка третьим уровнем (решение владельца 25.07 — два пути).

## Acceptance criteria

- [ ] `yarn kits:audit` без аргументов возвращает exit 0 на чистом дереве.
- [ ] `yarn kits:pins --id <кит>` на выровненном ките печатает «опись совпадает с деревом».
- [ ] Попытка `--write` при дефекте схемы отказывает и объясняет причину.
- [ ] `SKIP_PREPUSH=1` по-прежнему пропускает хук (аварийный выход не сломан).
