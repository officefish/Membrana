## Контекст

docs/HANDOFF.md несёт топ-10 дня со ссылками на задачи. Строки протухают молча: 26.07 при подъёме списка три из десяти оказались мертвы (две задачи закрыты накануне, третья — в той же сессии), выяснилось только ручной сверкой.

Дом — соседняя зона осмотра мастерской (docs/audit/tasks), рядом с tasks:audit: команда смотрит НАРУЖУ (состояния Issue), а не в реестр. Сеть недоступна → honest unknown, не «живо».

Не трогаем: формат хендоффа и состав топ-10 — их пишет утро.
