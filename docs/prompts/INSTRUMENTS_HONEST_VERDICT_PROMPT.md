# Промпт: Приборы выносят вердикт, которому можно верить

> **Task-промпт** спринта `instruments-honest-verdict` · sprintKind: `membrana-local-sprint`.
> **Исполняемый источник истины — нарезка:** [`docs/sprint/cut/instruments-honest-verdict.json`](../sprint/cut/instruments-honest-verdict.json)
> (ратифицирована владельцем 05.08; две перерезки — зона блока 2 и окно плана — тоже ратифицированы).
> Этот файл — обёртка-указатель, не вторая редакция: расхождение двух копий норму не усилит,
> а сделает непроверяемой.

## Закон спринта

**Вердикт, опирающийся на недостоверный вход, не выносится — он отказывается, называя причину.**

Тема ратифицирована владельцем 05.08 после прямого возражения против точечных хот-фиксов:
«определи объём работы, её тему и пойдём в неё через спринт». Пять находок дня имели одну
форму — прибор ЗНАЛ о своей ненадёжности и всё равно выносил приговор, а платила за это рука
владельца: три вмешательства за день (обход пре-пуша, разовое разрешение умолчаний, поправка
ложного факта в хендофе).

## Блоки (детали, границы и вещдоки — в нарезке)

1. **`prepush-false-red`** · Ожегов · #1725 — при чужой резолюции межпакетный вердикт не
   выносится: skip с причиной и названным судьёй (CI). Отдельный слой поверх плана —
   «что проверять» и «можно ли этому верить» не смешиваются.
2. **`error-class-four-states`** · Дынин · #1549 — `no_key` называет переменную окружения;
   одиночный 401/403 при живом ключе → `transient`; приговор выносит только
   `confirmAuthDenial` по истории. Enum эмиссии не трогается — мапит адаптер.
3. **`probe-covers-catalog`** · Веснин — список провайдеров зонда выводится из каталога;
   два несимметричных зуба покрытия, причина исключения — из замкнутого словаря.
4. **`recut-door-alive`** · Дынин · #1710 — `planKey(plan) = sprintId ?? planId`; зубы на
   провод, а не на предикат.
