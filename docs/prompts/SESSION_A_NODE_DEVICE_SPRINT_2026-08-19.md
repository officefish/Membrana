## Порядок — спринт, не одиночная работа

1. **Скилл `membrana-local-sprint`** — открыть и вести по канону
   `docs/procedures/membrana-local-sprint/README.md`. Карточке проставить
   `sprintKind: "membrana-local-sprint"`; прогон — `docs/local-sprint/firebat-node-device/`.
2. **Нарезка** (`yarn sprint:cut`): блоки с accountable-персонами и профильными контекстами.
   Предложение блоков (нарезчик вправе изменить с обоснованием):
   - **транспорт канала** — форма исходящего канала с обоснованием против альтернатив
     (очередь заданий с опросом · постоянный WebSocket · обратный туннель); координатор
     рекомендует **опрос очереди**: без входящих портов и постоянных соединений,
     переживает любые сети, цена — задержка команды до N секунд (для записи несущественно).
     Персона — Веснин (границы, контракт очереди).
   - **служба узла** — приложение как служба/автозапуск Windows: поднимается после
     перезагрузки, опрашивает очередь, исполняет «снять пробу N с», отправляет.
     Персона — Ожегов (сервисы, слабая связанность).
   - **ключ узла** — отдельный отзываемый ключ только на загрузку в свою коллекцию;
     служебный токен с узла убрать. Персона — Ожегов/Веснин.
   - **установщик** — первая сборка `apps/membrana-studio` → `yarn package`
     (`electron-builder --win nsis`); ставит службу с правами. Ждать сюрпризов, каждый
     называть. Персона — Ожегов.
   - **усиление** — рабочее положение с запасом (щелчок дал −1 dBFS), в спутник узла.
     Персона — Курёхин.
3. **Ратификация нарезки владельцем** — показать план, дождаться «ратифицирую», записать
   отметку инструментом (`yarn sprint:cut --ratify`). До неё — ни строки кода.
4. **Исполнение** блоками, `sprint:gate` по следу; каждый блок — свой PR ≤ 400 строк,
   `yarn pr:ship` после ревью тимлида. Issue завести с первым PR (карточка без Issue).
5. **`sprint:experience`** — прогноз и исход в конце.
