# Сессия Г — ночная охота не запускается пять ночей (18.09)

**Третий кандидат снимка владельца 18.09** (`night-hunt-trigger-fix`).
**Дерево:** своё, отдельное, от свежего `origin/main`.

## Предмет — замер, а не догадка

`gh run list --workflow night-hunt-office-trigger.yml` на 18.09: **пять отказов подряд** — 14.09, 15.09, 16.09, 17.09, 18.09. Ответ офиса из журнала прогона:

```
night-hunt trigger ОТКАЗ: HTTP 400 от ***/v1/night-hunt/run-all
{"message":"Body cannot be empty when content-type is set to 'application/json'"}
```

В `.github/workflows/night-hunt-office-trigger.yml:37-39` запрос уходит с `-X POST`, заголовком `Content-Type: application/json` и **без тела**. Офис (Fastify) такой запрос отклоняет по построению.

Побочное следствие, уже наблюдавшееся: вечерний шаг `archive-night-hunt` каждый вечер отказывает «за ночь вещдоков нет». Отказ честный, но выглядит как «охотиться не на что» — молчание, неотличимое от исправности.

## Задача

1. Подтвердить диагноз своим замером, не полагаясь на этот текст: журнал последнего прогона + чтение workflow.
2. Найти, что дверь ждёт на входе: обработчик `/v1/night-hunt/run-all` в офисе (`packages/background-office`), его схема тела. Если тело необязательно — проверить, не нужен ли `{}`; если обязательно — взять форму из схемы, а не из головы.
3. Починить пусковик минимальной правкой. Два честных пути: слать `-d '{}'` либо не объявлять `Content-Type` при пустом теле. Выбрать тот, который соответствует схеме двери, и в PR написать, почему именно он.
4. **Зуб.** Пусковик, который молча не запускается пять ночей, — это класс «молчание, неотличимое от исправности». Предложить (не обязательно реализовать) проверку, которая краснеет, когда ночь не принесла вещдоков дольше суток. Если реализуешь — красный вход должен существовать до правки.
5. Проверить, что после починки охота действительно стартует: `gh workflow run` вручную либо дождаться ночи и посмотреть прогон. Что именно сделано — написать в отчёте; «должно работать» отчётом не является.

## Границы

- Офисный прод руками не трогать: деплой и перезапуск — отдельное слово владельца.
- Секреты (`OFFICE_URL`, `OFFICE_API_TOKEN`) в логи и в PR не выносить.
- Свои файлы коммитить поимённо.

## Готово, когда

- пусковик отправляет запрос, который дверь принимает, и это показано замером (код ответа, не рассуждение);
- в PR названо, почему выбрана именно эта форма запроса;
- сказано, чем будет ловиться повторение класса «тихо не запускается».
