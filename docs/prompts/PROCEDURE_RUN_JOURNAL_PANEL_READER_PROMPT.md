`procedure-run-journal@1`) с 03–04.08 наполняется механикой, а не рукой: производители

### Что построить (продуктовое описание)

1. **Агрегатор-читатель** (чистое ядро + CLI): ленты за окно → сводка по пяти опорам:
   число прогонов, исходы `pass/fail/blocked/skipped`, сироты (gap `orphaned`), трения
   с непогашенным корнем. Окно дней и список опор — параметры, не константы.
2. **Секция панели** `panel.mmbrn.tech`: таблица пяти опор из сводки. Если развёртывание
   панели упирается в узел деплоя (survey 03.08, П1) — первый читатель допустим дешевле:
   блок сводки в вечерней хронике/хендофе первым PR, панель — вторым.

|---------|---------|
| Сводка | лента с pass/fail/orphaned → верные счётчики по опорам |
