# Промпт: переназначение двадцати фреймов — у каждого явный держатель

> **Task-промпт.** Размер: **M**. Ведёт Vesnin, поддержка Ozhegov и Dynin.
> Процедура: [`membrana-local-sprint`](../procedures/membrana-local-sprint/README.md).
> **GitHub Issue:** [#1787](https://github.com/officefish/Membrana/issues/1787)
> Основание: **Р3** [ADR-0025](../adr/ADR-0025-frame-holder-and-moderator-two-roles.md)

## ⛔ Зависимость: НЕ начинать, пока не влит контракт

Эта задача **заблокирована** карточкой `frame-holder-moderator-split`
([#1781](https://github.com/officefish/Membrana/issues/1781)).

Причина не организационная, а конструктивная: до реализации Р2 валидатор не различает
`holder` и `moderator`, расхождение не становится видимым, и **назначать будет не по чему**.
После контракта `validateProcedure` покраснеет на всех двадцати и выдаст их список с
причиной — этот список и есть вход настоящей задачи.

Проверить готовность входа: `node scripts/validate-procedure.mjs` даёт красный со списком
двадцати. Если валидатор зелёный — контракт ещё не влит, начинать рано.

## Этот файл — указатель, не вторая редакция

Предмет, замер (87 фреймов, 20 за модератором), поимённая таблица по процедурам, разбор на
два рода и DoD живут **в одном месте** — в теле [#1787](https://github.com/officefish/Membrana/issues/1787).
Здесь не повторяются: две копии контракта норму не усилят, а сделают непроверяемой.

## Три вещи, которые ломают эту задачу быстрее прочих

1. **Держатель не наследуется от процедуры** (Р4). Отсутствие `holder` — находка, а не повод
   подставить умолчание. Наследование воспроизвело бы дефект при самой починке.
2. **Ни один момент у Ангелины не отнимается** (граница Р3). Там, где она ведёт, она
   остаётся — в поле `moderator`, где её роль впервые становится названной. Семь фреймов из
   двадцати именно такие.
3. **Назначение каждого — решение, а не умолчание.** Двадцать раз «поставил vesnin, потому
   что он тимлид» — это замена одного дефекта другим. Обоснование каждого держателя идёт в
   нарезку и ратифицируется владельцем.

## Границы

**В предмете:** поля `holder` и `moderator` в двадцати элементах фреймов, обоснование
каждого назначения, зелёный `validateProcedure`.

**Вне предмета:** сам контракт ролей (#1781), шаг закрытия журнала утра (#1782),
два раннера утра (вынесены за границу самим ADR).
