## Этот файл — указатель, не вторая редакция

Предмет, обзор «что уже есть», четыре развилки нарезки, границы и DoD живут **в одном месте** —

две копии контракта норму не усилят, а сделают непроверяемой.

## Главное в одной фразе

**Логику писать не надо — её надо подключить.** `decideTransition` готов, покрыт 16 зубами
и не вызывается никем: все 16 упоминаний символа в репозитории из его собственного теста.

## Три вещи, которые ломают эту задачу быстрее прочих

1. **Правила перехода не дублировать.** Единственный источник вердикта — `decideTransition`.
   Если сервис начнёт сам решать «можно ли понизить тариф», через месяц правила разойдутся.
2. **Списание попытки атомарно с переходом.** Гонка здесь означает бесплатный тариф —
   цена ошибки денежная. Зуб нужен на гонку, а не только на «уже погашен».
3. **Причина отказа обязана доходить различимо.** Домен возвращает закрытый список
   (`promo_expired`, `promo_revoked`, `promo_already_redeemed`, `promo_target_mismatch`,
   `promo_downgrade_forbidden`); схлопнуть их в «нельзя» — потерять смысл всей работы домена.
