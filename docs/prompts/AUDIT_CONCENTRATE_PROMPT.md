## Принцип спринта: от потребителя вниз

Слово владельца 26.07 — **начинать с конца**. Аудит не следствие архива, а его **заказчик**:

## Фазы

### А0 · Пары сверки (бумага, до кода)

Определить, **что с чем сопоставляется** и какой вопрос задаётся. Ориентир — не «сверить всё
со всем», а пять–семь пар, каждая со своим смыслом. Кандидаты:

| Пара | Вопрос | Что ловит |
|---|---|---|
| сессия ↔ репозиторий | сказано «сделал» — есть коммит? | заявление без результата |
| репозиторий ↔ реестр задач | есть работа — есть карточка и её статус? | работа мимо учёта |
| реестр ↔ состояние снаружи | карточка закрыта — иссью закрыт? | расхождение учёта и мира |
| артефакт дня ↔ общая ветка | артефакт создан — доехал? | **потерянные вечера 23–24.07** |
| состояние процедуры ↔ общая ветка | локально одно, в ветке другое? | **комната, «открытая» трое суток** |
| отчёт партнёрам ↔ реестр/репозиторий | обещано наружу — подтверждено внутри? | обещание без основания |
| производный снимок ↔ его источники | снимок ссылается на существующее? | **битые ссылки реестра** |
| поле ответственного ↔ след участия | назначен — участвовал? | **заглушка (#1219)** |

Выход фазы: список пар с ожидаемыми находками, согласованный с владельцем **до** кода.

### А1 · Ядро сверки (чистое)

`scripts/lib/audit-concentrate.mjs` — без fs, сети и даты внутри:

- нормализация: любой источник → факт вида `{subject, claim, source, date, evidence}`;
- сопоставление фактов по субъекту;
- категоризация: **подтверждено** (≥2 независимых источника) · **заявлено без подтверждения** ·
  **противоречие** (источники говорят разное);
- «независимость» источников объявляется явно: сессия и репозиторий независимы, реестр и его
  производный снимок — нет.

### А2 · Адаптеры источников

По одному на источник, каждый — чистая функция «сырьё → факты». Начать с пяти, покрывающих
известные находки; остальные добавлять по мере надобности. Сессии — через существующую
библиотеку транскриптов, **не** переписывая её.

### А3 · Отчёт

Три раздела; подтверждённое сворачивается в строку, интересны два других. Требования:

- **воспроизводимость** — отчёт есть функция от снимков, а не от момента запуска (свойство
  нынешнего `audit:evening` сохранить);
- **честный empty-state** — «источник недоступен» и «расхождений нет» различимы; молчаливая
  неполнота запрещена (зверь B6);
- каждое расхождение несёт обе версии и указание, кто что утверждает.

### А4 · Приёмка на дне с известными ответами

Прогон на **25.07** — дне, чьи расхождения уже разобраны вручную. Аудит обязан найти:

1. состояние комнаты: локально закрыта, в общей ветке открыта;
2. вечерние прогоны 23–24.07 без артефактов в общей ветке;
3. реестр прецедентов, ссылающийся на неотправленные файлы;
4. ответственный в карточках `#1195`/`#1196`, проставленный без участия персоны.

**Не нашёл — фаза не сдана.** Это тест с известными ответами, а не демонстрация.

### А5 · Дельта требований

Что не удалось проверить из-за отсутствия данных — оформить требованиями к #1229 (какие поля
сессии нужны аудиту) и к вехе резака (что мешает хранить полные журналы). Это выход спринта
наружу, а не побочный результат.

## Границы

- **Не оценивать** людей и агентов — показывать движение и расхождения («движение, а не оценки»).
- **Не подменять** вечерний фидбек команды (#1210): там суждение, здесь факты.
- **Не строить** архив и резак в этом спринте — только формулировать к ним требования.
- **Не сверять всё со всем**: пять–семь пар, каждая с ожидаемой находкой.

## Acceptance criteria

- [ ] `yarn audit:concentrate --date 2026-07-25` находит **все четыре** известных расхождения (комната · вечера 23–24.07 · снимок прецедентов · ответственный без участия) и называет по каждому обе версии.

- [ ] Недоступный источник даёт строку «источник недоступен, сверка неполна» — молчаливое сокращение выдачи запрещено.
- [ ] Ядро чистое: тесты не трогают файловую систему и не подставляют дату — всё подаётся аргументами.
- [ ] Пар сверки в первой версии **не больше семи**; каждая имеет ожидаемую находку.
- [ ] Раздел «подтверждённое» свёрнут в одну строку — интересны только два других.
