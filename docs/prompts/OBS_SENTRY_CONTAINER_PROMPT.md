## Контекст

Решение владельца (Т5/Т6, 24.08): полный Sentry, свой дом на офисе, отдельный
контейнер-картотека — не часть общего дома логов; при упоре в ограничения —
наращивание мощностей офиса. Сводка и DoD: [`EPIC.md`](../meeting/logging-observability-cut/EPIC.md), кусок E.

## Промпт целиком (для вставки агенту)

### Что построить

1. **Первый шаг — добыча фактуры:** замер свободных мощностей офиса (RAM/диск/CPU);
   цена принята: очередь + аналитическая база + кэш, несколько ГБ.
2. Полный Sentry отдельным контейнером на офисе (compose рядом с существующими),
   изолирован от общего дома логов.
3. Чеканка `INC-XXXX-XXXX` подключается к контракту B: кабинет при `broken` получает
   номер от Сентри; недоступен → `TMP-…` (уже в куске B).
4. В картотеку летят: происшествия рода «сломан», сбой пульса (#2120). **Не летят:**
   сам пульс, метрики, тишина сторожа диска (слово владельца 24.08 — только телеграм).

### Definition of Done

- [ ] Замер мощностей офиса записан.
- [ ] Контейнер поднят (стенд), изолирован от дома логов.
- [ ] Ошибка «сломан» из кабинета рождает запись, находимую по продиктованному `INC-…`.
- [ ] Группировка повторов и счётчик работают.
- [ ] Сбой пульса виден в картотеке как происшествие.
- [ ] Пульс/метрики/stale сторожа в картотеку не летят.
- [ ] Прод-деплой — только по слову владельца; LGTM Teamlead.

### Out of scope

Общий дом логов (Loki — отложено) · экраны метрик · существо #2113/#2110.
