# Промпт: Раннер вечерней цепочки — неизвестный флаг = отказ, не живой прогон (#1867)

> S · id `ritual-runner-unknown-flags` · Issue [#1867](https://github.com/officefish/Membrana/issues/1867).
> Заведена по живому инциденту 11.08 (ревью PR #1863 попросило карточку) и исполнена
> тем же днём. Файл — указатель, не вторая редакция.

## Инцидент-источник

Агент запустил `ritual-evening-run.mjs --dry-run` — такого флага нет, аргументы
читались через `includes('--dry')`, неизвестное молча игнорировалось, и вместо плана
цепочка пошла **живьём**: журнал открыт (сирота — закрыта штатным ленивым закрытием
вечера), автозабор создал незапушенный коммит. Молчаливое «не понял → исполняю всё» —
худший дефолт для процедуры с побочными эффектами.

## Существо

Валидация argv до открытия журнала и любого шага: известны `--dry`, `--json`,
`--only <csv>`, `--help`; всё прочее — `exit 2` с usage. Значение после `--only`
исключается из проверки только когда `--only` присутствует (граница `-1+1=0`).

## Проверка

```bash
node --test scripts/ritual-evening-run.args.test.mjs
node scripts/ritual-evening-run.mjs --dry-run   # exit 2, ни одного шага
node scripts/ritual-evening-run.mjs --dry       # план, exit 0
```
