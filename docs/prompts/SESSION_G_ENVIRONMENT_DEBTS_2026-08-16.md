## Задачи по убыванию пользы

### 1. Снять лечение деревьев с рук владельца — **первым делом**

Сейчас `yarn install` из агентской сессии падает:

```
Error: EPERM: operation not permitted, symlink '...packages/services/mfcc-analyzer' -> '...node_modules/@membrana/mfcc-analyzer-service'
```

Проверено 15.08: **у владельца в его терминале установка проходит**, у агента — нет.
Проба показала, что из агентского окружения запрещены и symlink, и junction, хотя
junction на Windows привилегий не требует никогда — значит упирается песочница
исполнения, а не система.

Предложение к проверке: `winLinkType: junctions` в `.yarnrc.yml` (сейчас ключ **не
задан**, умолчание на Windows — символические ссылки). Если сработает — лечение
станет агентским, и владельца больше дёргать не придётся.

**Проверять на одном дереве**, а не сразу на всех. Если не сработает — сказать прямо
и оставить лечение за владельцем (одна команда на дерево, по минуте).
