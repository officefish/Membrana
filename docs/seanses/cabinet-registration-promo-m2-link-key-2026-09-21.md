[Музыкант]: С точки зрения потока: клиент офиса — исходящий HTTP, не аудио. Латентности здесь нет, но таймаут всё равно нужен жёсткий — иначе код зависает на обратном прокси офиса. [Математик]: Поверхность для C — **один** метод. Имя: `redeemRegistrationCode(code: string): Promise<RegistrationOutcome>`. [Структурщик]: Разношу HTTP-исходы строго. `401`/`403` от офиса — это **`config-invalid`**, а не `office-unavailable`: ключ неверен или адрес ведёт на чужую охрану. `5xx` офиса, сетевой сбой (ECONNREFUSED, DNS), таймаут — `office-unavailable`. `409 { ok: false, reason }` — `refused` с `reason` из пяти значений M1. `200 { ok: true, … }` — `ok`.
