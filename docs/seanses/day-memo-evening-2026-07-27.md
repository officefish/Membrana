## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| Q1 — Состав DAY_MEMO | Три раздела: (1) Факты (jsonl-блок: изменённые файлы, PR, issue, evidence-id, truth-mint-id, debts diff) с временными метками; (2) Инсайты (human-readable, каждый с тегом `[Q: <кто зафиксировал>]`); (3) Персональный след (8 блоков `### <персона>` — выдержка из memory/erudition/character по каждой персоне). Хендофф следующему дню (короткий блок «Что требует утреннего внимания»). Таблица связей с индексами в конце. |
| Q2 — Кто пишет | Факты — детерминированный генератор `yarn day:memo:facts` (Математик/Дынин — скрипт). Инсайты — субагент `scribe` под оркестрацией Ангелины. Персональный след — автоматический `persona-memory:extract` по восьми персонам (после показа партнёрам). Рука капитана — верификация финального документа. |
| Q3 — Место в вечерней цепочке | После `code-review` и `archive-code-review`, перед `evening-tail`. Входы: truth-cool output, evidence registry (список за день), debts diff, handoff, 8 memory-блоков. Выходы: DAY_MEMO-документ + хендофф-блок для утреннего чтения. |
| Q4 — Связь с индексами и архивацией | В evidence registry: новые evidence-id, truth-mint-кристаллы, diff DEBTS.md (хешированные) — по одному на элемент. Сам DAY_MEMO регистрируется как evidence-id с sha256. В case container #1298: инсайты с флагом `[CASE: <uuid>]` — кандидаты. В daily-архив (archive-daily-day): весь документ — immutable snapshot `docs/memos/<YYYY-MM-DD>.md`. Персональный след — только внутри memory/erudition/character, в индексы не уходит. |

**Definition of Done:**
1. Скрипт `yarn day:memo:facts` реализован и выдаёт jsonl-блок фактов за день (git log, evidence, truth, debts, handoff).
2. Шаг `day-memo` добавлен в `docs/tasks/evening-ritual-steps.json` — позиция после `archive-code-review`, перед `evening-tail`.
3. Формат `docs/memos/<YYYY-MM-DD>.md` зафиксирован в README или ARCHITECTURE.md (одна строка-сноска).
4. Первый DAY_MEMO сгенерирован, зарегистрирован в evidence, архивирован.
5. Консилиум закрыт — решение принято единогласно.
