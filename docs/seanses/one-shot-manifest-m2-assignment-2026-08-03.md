**Definition of Done (N1):**

- Запись прогона шота в `docs/procedure-runs/` несёт четыре обязательных поля (`shotId`, `executor`, `assignedBy`, `contextRunRef`); отсутствие любого — невалидная запись.
- Значение `executor` проверяется по реестру канонических персон (`KnownPersonas`); строка вне реестра → `valid_assign = false`.
- Значение `assignedBy` — строго литерал `"teamlead"`, не PersonaId персоны.
- Файл по адресу `contextRunRef` существует в `docs/sprint/cut/trail/` и несёт `timestamp` строго меньше `R.frames[execute].openedAt`.
- Гейт `ready_to_execute` реализован как машинная проверка обоих предикатов; результат `false` различает причину: `missing_assign` или `missing_context_run`.
- Состав `frames[]` не изменён — граница M1 соблюдена.
- Исполнитель один на шот (`executor` — одно поле, не массив) — граница Т3 соблюдена.
