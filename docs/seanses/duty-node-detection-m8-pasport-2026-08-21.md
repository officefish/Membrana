## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| O1. Состав паспорта | Один документ `RecordingPassport` на запись. **Измеренное (сервер/probe):** `sampleRate`, `bitDepth` (sample format), `channels`, `durationSec` или `frameCount`; рекомендуется `contentHash`. **Объявленное:** `mode` (M1), `nodeId`, `capturedAt`, `originClass`, `gain`, `phantom48v`, `air`, опционально `distance`, `calibratedAt`, `source`. **Связь:** `sessionId` и/или `sessionWindowRef` (null = вне сеанса). **Выводимое:** `passportStatus`: `absent` \| `partial` \| `complete`; при расхождении с каноном M3 — флаг отклонения формы без перекодирования. |
| Меряно vs объявлено | Измеренное побеждает при конфлите с claim о форме (#1950). Объявленное не вычисляется из PCM как истина. Inferred из node.md допустимо только с provenance `inferred`, не маскируется под measured. |
| Один носитель или два | **Один носитель** (P2/Т11): паспорт формы и происхождение — один `RecordingPassport` у записи. `firebat-node.md` — источник заполнения при mint, не второй слой хранения и не API-спутник навсегда. |
| Где живёт | У записи (asset/index media-контура): снимком полей, принадлежащих `recordId`. Не «только в спутнике узла» и не только в человеческом md. |
| 116 без паспорта | При индексации: probe → measured → `partial`. В выборку окна сеанса не попадают без пересечения с окном/`sessionWindowRef`. Режимные меры (M6) на них **нелегальны**, пока нет тракта (complete или явный tract + mode). Не удалять и не подставлять канон 48 кГц молча. |
| Связь с mode (M1) и окном | `mode` — обязательное объявленное поле паспорта новой записи буфера. Окно сеанса — в том же носителе (`sessionId`/`sessionWindowRef`); сравнимость «в сеансе» = попадание в окно ∧ наличие mode; сравнимость формы = равенство measured-формы (P1). |

**Definition of Done (только O1):**
- В каноне заседания/контракте зафиксированы: список полей, measured|declared, `passportStatus`, один носитель `RecordingPassport`.
- Запрет двухслойного API «форма + origin satellite» как раздельных источников истины записан явно.
- Норма legacy для записей без паспорта: probe→partial; вне окна сеанса; без legal режимной меры без тракта.
- Связь `mode` + window ref в том же носителе описана предикатами допуска.
- Нет обязательств M9 (lifecycle, TTL, перенос, удаление) в этом DoD.
