[Математик]: Предикат принадлежности (проверяемый):

```
belongs(s) =
  if ∃h ∈ Homes: pathInHome(s,h) then { kind: home, id: h.id }
  else if ∃n ∈ N: matches(s, n.membership) ∧ ¬pathInAnyHome(s) then { kind: namespace, id: n.id }
  else { kind: orphan }
```

`pathInHome`: path скрипта под корнем мастерской h **или** явный member-список home (если позже введут; сейчас — префикс каталога манифеста). При нескольких namespace matches — детерминизм: побеждает более длинный pathPrefix; при ничьей — lexicographically меньший id; red при конфликте explicitList∩explicitList. Тотальность: ∀s ∈ S. belongs(s) определено.

|--------|---------|
| Неймспейс машинно | Запись в SoT-реестре `docs/namespaces/REGISTRY.json` (массив объектов). Не поле home-манифеста, не kit, не строка ATLAS. v1 без второго SoT-якоря в каталогах |

| Держатель namespace | Обязателен: `holder.persona` (алфавит канона) **или** `holder.ownerRef` (path). Отвечает за смысл rule и стабильность `id`, **не** за verbs. Пустой holder — запись невалидна |
| Какие namespace существуют | Те, для которых есть валидная запись в REGISTRY. Вердикт **не** именует `_ssh`/`verify`/…; список — следствие заведения rule. До заведения \|N\|=0 допустим |
