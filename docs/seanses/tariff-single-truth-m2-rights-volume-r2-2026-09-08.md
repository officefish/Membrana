## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| **(а) Носитель f** | Пакет **`@membrana/plugin-contracts`**, файл `packages/plugin-contracts/src/buffer-overflow/available-quota.ts` (экспорт через index). **ESM-only**; сервер записей (CJS) — **dynamic `import()`**, статически только типы (как reasons). **Новый пакет не создавать.** `@membrana/core` в server записей не подключать. |
| **(а) Кто зовёт** | **Сервер записей:** при сборке **`/quota`** (`devices.service.ts` getQuota) и при **отказе** (`buffer-overflow-refusal.ts` / `buildBufferOverflowRefusal`). **Клиент (живой контур):** только **читает** готовое `available*` из ответа. **Клиент (окно/эпизод):** сервер числа эпизода не хранит → либо **читает available из снимка отказа в hold**, либо **зовёт ту же f** на `used/limit` снимка удержания (`device-overflow-hold`). Третьей арифметики нет. |
| **(б) Оси и сложение** | Оси **независимы**, между осями **не складываются**. **buffer** — байты; **userStorage** — байты (`user` + `system` с ключом ≠ `TARIFF_DATASET_SYSTEM_KEY`); **тарифный системный набор** — **вне байтов**, `sampleCount` + catalogId; **userWorkspaces** — счётная ось; **узлы / maxNodesPerMembrane** — кабинет (не f сервера записей). `available = max(0, limit − used)` на оси. Отказ байтов: **`available < size(incoming)`** ⇔ `used + incoming > limit`. Отказ мест: `used >= maxUserWorkspaces` (incoming=1). |
| **(б) Предикат** | **Отказ ⇔ свободно < размер входящего.** «Свободно = 0» — частный случай, **не** эквивалент. |
| **(в) Окно** | **Снимок эпизода** (used/limit[/available] в миг отказа), не неделя холода и не момент перехода (M3/M4 — чужие комнаты). **Кто задаёт:** сервер записей **автор чисел** в теле отказа; **носитель снимка** — DeviceOverflowHold на приборе/клиенте; режим окна исполняет клиент без второго GET `/quota`. |
| **(г) Единый источник числа** | Runtime-истина объёма: **сервер записей + f**. Витрина объёма/библиотека: media-bridge `/quota` → mapQuota. Окно оператора: отказ + hold (снимок), **тот же** available. Витрина мембраны `/v1/tariffs` — **только право** (лимиты), не подмена «свободно». |
| **«Тариф» в f** | = **лимиты с записи прибора** (`resolveDeviceLimits` / поля Device после разноски), не прямое чтение `Tariff` кабинетом для available. |
| **Строить** | 1) Чистая f в plugin-contracts. 2) **Расширение** `BufferOverflowRefusal` полями свободно/available по осям (**носитель** `plugin-contracts`). 3) `/quota` отдаёт available по осям. 4) getQuota + refusal вызывают f. 5) mapQuota, viewModel, quota-status потребляют available / f(snapshot). 6) Удалить локальный `limit − used` в клиенте и media-library. |
| **НЕ строить** | Новый пакет; records→core; проводка `domain/quota-ledger.ts`; вторая арифметика на клиенте; вычисление freely из Tariff в кабинете; пересев/версия (M1); повышение (M3); понижение/холод (M4); наборы перехода (M5); гранулы; умная очистка; оплата. |

## Вердикт M1 (посылка, принят аудитом 08.09 после трёх прогонов и сборки; не переоткрывать)

## Фактура (прод 08.09, ствол 4cfbb2d4; сверено председателем по коду)

- **Сервер записей считает занятое сам** — `packages/background-media/src/modules/devices/devices.service.ts:223-278 getQuota`: лимиты — из записи прибора через `resolveDeviceLimits` (`device-limits.ts`), занятое — сумма `sizeBytes` проб прибора по виду коллекции: `kind === 'buffer'` → буфер; `kind === 'user'` **и** `kind === 'system'` с ключом, отличным от тарифного каталога → **пользовательское хранилище**; `kind === 'system'` с ключом тарифного каталога (`TARIFF_DATASET_SYSTEM_KEY`) → только счётчик `dataset.sampleCount`, в байты не входит. То есть **тарифный системный набор вне квоты уже сегодня, а прочие системные коллекции — внутри пользовательского хранилища** (это надо назвать, а не предполагать).
