# Консилиум: M5 — окно оператора при «буфер полон» и дороги из него

**Повестка:** Заседание «Полный буфер: контракт остановки» — M5 (W). Q5: содержание окна, кнопки и порядок, состояние вне окна, один носитель на два входа, показ после чистки. Границы: M2/M3/M4 — посылки; T12, #2297, #2302 — вне комнаты.

[Архитектор]: Конструкция M5 — последний узел: C→W, S→W, L→W (только статус). Окно — презентация факта отказа, не источник политики. Источник данных окна — ответ M2 целиком: `reason`, `buffer`/`userStorage`, `overflowPolicy`, `overflowId`. Второго запроса за квотой нет. Поведение однократности и памяти — M3, не переоткрываем.

[Структурщик]: Словарно: «носитель окна» ≠ «вход». Два входа (доска устройства, модуль микрофона) — два адаптера к одному носителю. Носитель читает `DeviceOverflowHold` + payload отказа M2 и рисует одну модалку. Плашка/статус сценария — отдельные слои того же факта, не второе окно. Связанность: UI не ходит в media за квотой повторно.

[Teamlead]: Планка: вещдоки не страдают. Значит первая кнопка — путь, который не стирает. «Вывезти в набор» (#2226 уже есть) — первая. «Почистить» — вторая, только с подтверждением и счётом. «Сменить тариф» — третья, честная: если переходить некуда (#2297 как факт constrайнта UI, не как решение тарифов) — говорит прямо, не обещает. Иначе ночь 05→06 повторится руками оператора.

[Математик]: Две шкалы — два числа из M2: buffer.used/limit и userStorage.used/limit; свободно = limit − used (или то, что несёт ответ; формулу полей не изобретаем — M2 посылка). Время факта — timestamp удержания/отказа, одно значение на `overflowId`. «Что записано до остановки» — счётчик/длительность уже принятых проб до стопа, если есть в состоянии узла; иначе честный «н/д», не выдумка.

[Музыкант]: С тракта: после стопа запись мертва (M3), но оператор должен слышать смысл окна — «почему тишина». Режим прибора (stop / hold) и reason словами важнее красивой анимации. Плашка на панели записи плагина — уже намёк в фактуре («плашка с причиной и остатком»); модалки не было — вот её и строим поверх того же смысла, не рядом вторым диалогом.

[Верстальщик]: По DESIGN/конструктивизму: модалка — один акцент, данные tabular-nums, две шкалы квоты рядом, reason — человекочитаемая строка, не сырой enum без перевода. Кнопки в ряд: primary = вывоз, secondary = чистка, tertiary/ghost = тариф. Закрытие крестиком/Escape — да (T5), но не «обошёл»: повторный старт снова поднимет. a11y: focus trap, aria-labelledby по reason.

[Архитектор]: (а) Содержание фиксирую как контракт витрины: 1) reason словами; 2) buffer занято/лимит/свободно; 3) userStorage/коллекции занято/лимит/свободно; 4) время факта; 5) режим/фаза удержания (из статуса M4 — только показ); 6) что успели записать до стопа — если есть в состоянии, иначе явно пусто. overflowId в UI не обязан светиться оператору — технический ключ однократности.

[Структурщик]: Кнопки — не три независимых фичи, а три дороги из одного фасада. «Вывезти» → существующий механизм библиотеки (граница #2302: сам вывоз пролёта не проектируем). «Почистить» → библиотека буфера + confirm с preview счёта. «Сменить тариф» → deep-link/маршрут на мембрану кабинета (#2286), с веткой empty-catalog: disabled + текст «переходить некуда», без фальшивого success.

[Teamlead]: Порядок кнопок — не вкус, а ценность. Норма 31.08 / T7: буфер — архив вещдоков; вывоз не стирает. Первая = вывоз. Вторая = чистка с трением (confirm). Третья = тариф как обход по ёмкости, не по спасению уже лежащего. Кто поставит «почистить» первой — получит BLOCK: сдана тренировка удаления, не матч сохранения.

[Математик]: Подтверждение чистки: до вызова delete UI обязан показать n — число проб/байт, которые уйдут, и после — n′ фактически ушедших. Инвариант T11: «пусто = показать пусто»; если ушло 0 — показать 0, не «успех» без числа. Рассинхрон n и n′ — тоже показать, не глотать.

[Музыкант]: Вне окна (T8): оператор в поле смотрит на доску и на модуль записи, не только в модалку. Нужны: (1) плашка квоты/причины на панели записи; (2) статус сценария/узла «жив, не пишет, buffer full» — как M4 уже сказал для кабинета; (3) маркер на доске устройства. Три зеркала одного hold, без трёх разных текстов-синонимов.

[Верстальщик]: Плашка — warning/error по семантике DaisyUI, короткий reason + остаток; клик по плашке может снова открыть то же окно того же overflowId (не новое). Статус сценария — фаза + reason, без модалки. Доска — бейдж на устройстве. После чистки: toast/баннер «удалено: N проб, M МБ» или «буфер пуст»; empty state библиотеки — честный пустой список, не skeleton вечности.

[Архитектор]: Поведение окна — посылка M3/T5/T9: одно на overflowId, закрываемо, повтор при новом запуске при удержании. M5 не изобретает сброс hold — сброс человек или очистка (M3). Мы только рисуем и ведём дороги. Не строим: умную очистку (T12), второе окно, обход стопа, новый API квоты.

[Структурщик]: Один носитель: условно `OverflowOperatorModal` (имя словарное) в shared UI-слое студии; адаптер DeviceBoard и адаптер Mic/RecordPlugin передают один и тот же view-model из hold+M2. Запрет: скопировать модалку в два места — `нарушена слабая связанность` и разъезд текстов. Библиотека сэмплов студии и кабинета — близнецы: чистка/вывоз открывают уже существующие потоки, не третий «мини-буфер» внутри модалки.

[Teamlead]: DoD комнаты — только W. Связка на исполнение после вердикта: Верстальщик (витрина) + Структурщик (носитель/адаптеры) ; Музыкант — стык панели записи; Teamlead — приёмка. Архитектор не кодирует. Математик — только сверка чисел квоты на витрине, без новых формул политики.

[Математик]: reason → слова: чистая таблица отображения enum→locale, без ветвления политики. Если reason неизвестен — fallback «буфер полон» + сырой код в приглушённой строке, не молчание. Свободно по двум шкалам всегда оба блока: даже если одна шкала «ок», вторая может быть причиной — T4.

[Музыкант]: «Что записано до остановки» с края тракта: длительность/число уже лежащих в буфере вещдоков на момент stop — это успокаивает оператора, что ночь не пустая. Не требуем доигрывать медиа из модалки (M4: телеметрия после стопа законно молчит). Только факт счётчика.

[Верстальщик]: Кнопка тарифа: если каталог переходов пуст — не прячем кнопку, а disabled + пояснение «доступных тарифов для перехода нет». [Архитектор]: (в) Итого вне окна: плашка на панели записи/квоты; статус сценария (фаза hold + reason + жив); бейдж/строка на доске устройства. [Структурщик]: Confirm чистки — отдельный маленький диалог поверх, не уводить счёт в тост до действия. ## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| (а) Содержание окна | Строится **только** из ответа отказа M2 + статуса удержания (M3/M4), **без второго запроса** квоты. Обязательные блоки: **reason словами** (таблица enum→locale; неизвестный reason → «Буфер полон» + приглушённый сырой код); **две шкалы** buffer и userStorage/коллекции: занято / лимит / свободно; **время факта** (одно на `overflowId`); **режим/фаза прибора** («удержание / не пишет», reason согласован с M4); **что записано до остановки** (число/объём/длительность уже принятого до stop, если есть в состоянии узла; иначе явная строка «н/д»). `overflowId` оператору не обязателен (технический ключ однократности). |
| (б) Кнопки и порядок | **1. «Вывезти в набор»** (primary) — первая, потому что **не стирает вещдок** (T7, норма 31.08); ведёт в существующий механизм библиотеки (#2226), без проектирования #2302. **2. «Почистить»** — secondary; **только с подтверждением**; в confirm — **счёт того, что уйдёт** (пробы/байты); после — факт ушедшего. **3. «Сменить тариф»** — tertiary; ведёт в кабинет на мембрану (#2286); **если переходить некуда** — кнопка disabled + прямой текст «доступных тарифов для перехода нет» (честная витрина при факте #2297; наполнение тарифов **не** решаем). |
| (б) Почему первая — вывоз | Ранг по риску для вещдока: export = 0, clean > 0, tariff не спасает уже лежащее. Ценность матча — сохранить архив буфера, не предложить удаление первым. |
| (в) «Буфер полон» вне окна | Честный слой **без** модалки (T8): (1) **плашка** на панели записи/квоты (reason + остаток; клик → reopen того же окна того же `overflowId`); (2) **статус сценария/узла** — фаза hold + reason + «жив, не пишет» (лексика согласована с M4); (3) **доска устройства** — бейдж/строка того же факта. Поведение окна **не** переоткрываем: одно на `overflowId`, закрываемо, повтор при новом запуске при hold — **посылка M3/T5/T9**. |
| (г) Носитель и два входа | **Один** презентационный носитель модалки + **два адаптера** (доска устройства, модуль микрофона/плагин записи). Общий view-model из hold + M2 + статус. Копипаст двух модалок — запрет. |
| (г) После чистки / вывоза | T11: показать **что и сколько ушло**; **пусто = показать пусто** (0 и empty state, не «успех» без числа). Различать копирайт: «вывезено: N» ≠ «удалено: N». Рассинхрон обещанного и факта — показать. |
| Поведение окна | Закрытие не обходит стоп; новый старт при активном hold снова поднимает то же окно тем же фактом (M3). Сброс hold — человек или очистка (M3), не закрытие крестиком. |
| Что строить | Единый носитель окна; 2 адаптера; витрина (а); три дороги (б) с confirm и честным тарифом; три вне-оконных индикатора (в); post-action summary (г). |
