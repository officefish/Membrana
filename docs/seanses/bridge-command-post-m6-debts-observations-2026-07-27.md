[Музыкант]: Слышу разницу как два тракта. Попугай — ритм-секция: kit-engine, такт ровный, без «когда настроение». Ангелина и живые — солисты: выходят по дисциплине сессии, не по метроному долга. Норма контура обязана **не бороться** со словами владельца: детерминированный носитель для учёта, свободный — для смысла. Иначе снова убьём импровизацию форматом, а долги — «когда вспомним».

[Структурщик]: Фиксирую леммы, иначе граф поплывёт. **Долг** — машинная единица учёта с id, статусом и порогом шума (#1208). **Наблюдение капитана** — свободная запись смысла, без обязательного status-machine. **Мемоизация показанного** — акт изъятия вещдока (sha в `docs/evidence/registry.jsonl`), не синоним долга. Три слова — три статьи словаря. Смешение = `нарушена слабая связанность` контуров.

[Верстальщик]: С витрины капитана: «я запутался, когда озвучить свой набор» — это UI-дыра места, не недостаток попугая. Тетрадь должна быть **видимым слотом** в free: не чеклист 1/2/3, не ступень прогресса open→close. Конструктивизм: наблюдение лежит открыто, не гаснет само, не красится как overdue-долг. Иначе владелец снова читает «просрочено» там, где хотел просто сказать.

[Teamlead]: Рамка узкая: M1–M5 не пересматриваем. Попугай = memory, kit-engine, `gate.parrot_live_if_debts` на open, `gesture.debts` — optional. [Математик]: Чистая модель долга. Пусть \(D\) — множество активных долгов. События детерминированы: `birth(payload) → d∈D`, `repeat(d) → count++` при предикате повтора (#1208), `repay(d, evidence) → d∉D`. Одно \(d\) в один момент — ровно один status из закрытого enum. Наблюдение \(o\) **не** элемент \(D\): нет обязательного `repay`, нет стоп-гейта open. Мемоизация \(m\) — запись evidence-реестра; связь с долгом только если явно `linksDebtId?`, иначе сосед.

[Архитектор]: Конструкция: два параллельных контура с общей сессией, без общего state-machine. (1) **DebtContour** — engine попугая, homes машинные, гейт M2. (2) **CaptainNotebook** — free-slot, append наблюдений, без гейта open/close по полноте. (3) **ShownMemorization** — опирается на evidence/registry, не второй реестр. Форма решения до кода: границы пакетов = три API, ноль синонимов-слоёв «заметка». ADR не нужен, если homes и глаголы сядут в вердикт.

[Музыкант]: Гашение долга «словом капитана или фактом» — на слух опасно смешивать. Слово капитана без факта = жест намерения («считаем закрытым»); факт = measurable (PR merged, evidence sha, скрипт ok). Попугай обязан принимать **оба**, но provenance разный: `repay_by: captain_word | fact_ref`. Иначе «железный» попугай начнёт врать тишиной.
