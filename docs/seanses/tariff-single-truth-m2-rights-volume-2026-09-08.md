[Верстальщик]: С витрины: оператору нужны честные шкалы, не одно «осталось МБ». ## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| **(а) Носитель f** | **Рантайм-сборка и источник числа** — **сервер записей** (`getQuota`, refusal): у него лимиты с записи прибора и занято. **Чистая формула** — **общий пакет** (оба могут *вызвать* на числах ответа, но не собирать occupied сами). **Кабинет — не носитель** f: знает право/`Tariff`, не владеет занятым. **Почему:** T12/T13 — объём в своём доме; занято считает только records (`devices.service.ts getQuota`); кабинетный f(Tariff, ?) = вторая правда; копипаст `limit−used` на клиентах без clamp-пакета = расхождение. |
| **(б) Оси и сложение** | Независимые оси: **buffer** (bytes, kind=buffer); **userStorage** (bytes: kind=user **и** kind=system **кроме** тарифного каталога); **userWorkspaces** (count); **dataset** — **отдельная строка** (`catalogId`, `sampleCount`), **вне байт**; **узлы** (`maxNodesPerMembrane`) — **не** ось `/quota` сервера записей (кабинет, M1). Между осями **не складывать**. `available(a)=max(0,limit(a)−used(a))`. Full / «переполнено» — только по оси (`available==0` или refusal оси), никогда от суммы buffer+userStorage. |
| **(в) «Окно»** | На M2: **эпизод переполнения** (`overflowId` + hold/refusal snapshot). **Не** неделя холода, **не** момент перехода (M4/M3). **Кто задаёт:** сервер записей издаёт эпизод при доменном отказе; hold-состояние несут прибор/кабинет по контракту buffer-full-stop. `windowMode ∈ {live, episodeSnapshot}`: live → f от текущего used; snapshot → числа эпизода, без параллельного «уже свободно». |
| **(г) Одно число** | Род источника: **сервер записей**. Live: `GET /quota` (после M2 — с `available*` из f). Удержание: **payload отказа + hold**, без второго запроса (данность #2316 / M5 buffer-full). Витрина мембраны: **право/лимиты** — каталог/`Tariff`; **занято/доступная** — только media-bridge←`/quota`, не JSX-вычитание из тарифа. |
| **Строить** | Shared чистая f + типы осей; поля available в `/quota` (и согласованность с refusal); клиенты-потребители полей. |

## Definition of Done

1. **`availableBytes` / ось f (unit):** файл shared-пакета f — предикат P1: при `used>limit` результат `0`, не отрицательный; команда unit-теста пакета краснеет на missing clamp.  
2. **Независимость осей (unit):** P2 — тест «buffer full не включает userStorage full» краснеет, если есть total-sum API.  
3. **`getQuota` shape:** тест на `devices.service` / quota DTO — P3: есть `buffer.availableBytes` и `userStorage.availableBytes` = f; `dataset` без байт-available; красный — отсутствие полей или available\<0.  
4. **Согласованность refusal:** тест `buffer-overflow-refusal` — P4: reason оси ↔ available==0 после отказа; красный — refuse при used+incoming≤limit.  
5. **Кабинет без второй арифметики:** тест consumer media-bridge / библиотека / витрина объёма — P5: available не из `Tariff`; красный — вычитание tariff−x в доменном слое.  
6. **Окно hold = snapshot:** тест OverflowWindow/viewModel — P6: нет обязательного второго fetch quota для цифр эпизода; красный — live overwrite snapshot при активном hold.  
7. **Прибор:** тест индикатора — P7: отображаемое free === available ответа сервера; красный — приоритет локального limit−used.

**Вне DoD (регламент):** порядок влития shared→media→cabinet/device; runbook ручной проверки витрины; не открывать M3/M4/M5, smart-cleanup, оплату, форму гранул, пересев.
