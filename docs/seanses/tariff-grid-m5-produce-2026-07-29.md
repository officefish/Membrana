## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| Чем является produce в ячейке | Род **capability** из M1: `EntitlementValue = { enabled: boolean, scope?: ProduceScope }`. Не quota. Не call/instrument. **Флаг с опциональным scope**, не «иное» и не голый бит без семантики retention рядом. |
| Что такое `ProduceScope` (v1) | Опциональный ограничитель **видов** производимого из закрытого enum (минимум смыслов: `dataset_index`, `own_detection`, `scenario_on_own`). `enabled=true` ∧ scope absent/empty ⇒ все известные виды. `enabled=false` ⇒ scope не читается. Наполнение «кому что» — матрица/набор, вне M5. |
| Чем produce **не** является | Не право вызова instrument/detector (call-path). Не `maxUserWorkspaces` и не hot/cold (quota). Не право label/разметки сэмплов в библиотеке. Не отдельный entitlement «на существование» в матрице. |
| Момент проверки | **Create-path и expanding_mutate** (создание и мутации, расширяющие производимую поверхность: новый индекс, новая own detection, re-train/дообучение, новый сценарий на own detection). Предикат: `canProduce ⇔ enabled ∧ scopeAllows(kind) ∧ unmetPreconditions=∅` (M3). |
| Что **не** проверяется produce | read, list, delete, execute уже собранного сценария, call instrument, non-expanding метаданные (rename и т.п.), read-экспорт. «Проверка существования против тарифа» — **запрещена**. |
| Судьба созданного при понижении / ¬enabled | **Retain (сохраняется).** Committed user-owned артефакты остаются, читаются, удаляются владельцем, остаются вшитыми в сценарии. Новое создание/expanding — hard deny (сервер/борд fail-closed; витрина — disabled CTA + честная причина). Не delete, не hide-as-missing, не «отключить вызов своих» через produce. |
| «Право на существование ≠ право на вызов» | Existence ≔ факт commit в owned store при прошлом canProduce, **инвариант контура ∀SKU**, не клетка матрицы и не re-check produce. Call — другие entitlementId / рельс M2. |
