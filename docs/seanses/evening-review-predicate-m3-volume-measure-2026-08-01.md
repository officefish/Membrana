## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| (а) Что вечер мерит вместо `OVERSIZED_CHANGED_LINES` | Вечер **не мерит объём строк**. Это не умолчание — это явный вердикт. Мерку объёма per карточка уже вынесло потактовое ревью. Вечер **читает** признак `oversized(cᵢ)` как один из аргументов реляционного предиката `boundary`. Место мерки объёма на высоте вечера занимает предикат `boundary(cᵢ, cⱼ)`, который принимает `oversized(cᵢ)` как входной признак, а не считает строки заново. |
| (б) Судьба `OVERSIZED_CHANGED_LINES` у потактового ревью | Константа **остаётся** (`= 400`, `scripts/lib/day-work-diff.mjs`). **Глагол меняется**: `oversized → skip` (текущий, дефектный) → `oversized → flag('split-required') + include в ревью` (новый). Карточка с флагом не выпадает из поля зрения — она видна с предписанием: нарезать на нарезке. |
| (в) Защита честного провенанса | Счётчик `changed_lines` **считает только строки кода**. Строки провенанса (документы, обоснования, вещдоки — по явному паттерну в контракте `day-work-diff.mjs`) **исключены** из предиката `oversized`. На витрине: два раздельных счётчика `code` и `provenance`, не один общий. Аккуратный провенанс — признак честной работы, не штраф за объём. |

**Definition of Done (только вопрос M3):**

- [ ] В `scripts/lib/day-work-diff.mjs` ветка `if oversized` содержит `flag('split-required') + include`, а не `skip`. Молчаливого пропуска нет.
- [ ] В том же файле подсчёт `changed_lines` производится только по файлам кода; провенанс-файлы исключены по явному паттерну (`provenance_patterns` или эквивалент).
