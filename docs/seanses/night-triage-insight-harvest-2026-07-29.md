**Definition of Done:**

1. Memo (или секция дневного контура 29.07): таблица на 4 PR — `дата | PR | verdict | cardId=∅ | why`.
2. Все 4 draft-PR переведены в merged-as-doc/memo **или** closed; нулевой остаток open.
3. Зафиксированы леммы: `triage`, `insight-card`, `NightTriageClosure`; enum вердиктов без «оставим открытым».
4. Правило v0: следующий night-triage либо отвечает на вопрос primary focus дня одной строкой на пункт, либо не открывает PR.
5. `insight_yield` для окна явно = 0 (база для сравнения).
6. Teamlead: LGTM только после пунктов 1–2; иначе BLOCK по имени PR.
