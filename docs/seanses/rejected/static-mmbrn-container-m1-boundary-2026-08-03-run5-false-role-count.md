## Итоговое решение консилиума

### Пропозиция-контракт границы `static.mmbrn.tech`

**`static.mmbrn.tech` есть контейнер Membrana, принимающий оригинальные внешние документальные материалы, назначенные владельцем, с инвариантом неизменяемости байтового содержания после приёма, ведущий нетеряемые записи управления, независимые от любого сменного движка, где классы содержимого определяются контрактом, а не движком, и где отношение любого последующего поступления к ранее принятому содержанию не классифицируется до M2.**

---

### Положительная граница (принимается)

| Класс | Описание |
|---|---|
| Канонический материал | Оригинальные внешние документальные материалы (PDF, сканы, архивы данных и пр.), явно назначенные владельцем; байтовое содержание неизменно после приёма |
| Производное представление | Превью, OCR, транскрипты, порождённые из канонического материала; изменяемы, не нарушают неизменяемость оригинала |
| Запись управления | `docs/evidence` и иные управленческие записи контейнера; нетеряемы, не являются состоянием движка |

### Отрицательная граница (отвергается)

| Класс | Почему вне границы |
|---|---|
| Состояние движка | Страницы Affine, служебные объекты движка; жизненный цикл определяется движком, не контрактом |
| Стратегические документы | Принадлежат Panel; контейнер не является стратегическим редактором |
| Код, DNS, конфигурация прода | Явная нецель M1 |
| Материалы без назначения владельца | Не принимаются без явного акта назначения |

### Инварианты смены движка

1. Контейнер определяется контрактом границы, а не движком.
2. Смена движка не изменяет классы принятых канонических материалов и записей управления.
