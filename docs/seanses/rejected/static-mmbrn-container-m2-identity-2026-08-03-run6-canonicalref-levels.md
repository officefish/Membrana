[Математик]: Добавлю формальные инварианты цепочки. Пусть L — линия, R(L) — множество её записей. Тогда: (1) ep строго частична на R(L); (2) граф (R(L), ep) — направленное дерево без циклов; (3) существует ровно один root r* такой, что ep(r*) = ⊥; (4) существует ровно один live tip r+ такой, что ∀r ∈ R(L): ep(r) ≠ r+; (5) |R(L)| ≥ 1 всегда; (6) fork запрещён: не существует r1 ≠ r2 таких, что ep(r1) = ep(r2); (7) merge запрещён: ep(r) ∈ R(L) для всех r с ep(r) ≠ ⊥.

[Музыкант]: По composite-форматам финальное уточнение. Условие отдельной записи для члена архива или встроенного объекта PDF: (а) материал уже зарегистрирован независимо до регистрации архива/PDF — тогда обнаруживается совпадение sha256 при инспекции, создаётся отдельная запись-дубль или фиксируется существующая; (б) M6 позднее предоставил извлечённый элемент как самостоятельный материал. M2 не решает (б) — это M6. M2 только устанавливает правило: регистрация архива/PDF не порождает дочерних записей автоматически.

[Архитектор]: Уточнение по canonicalRef и публичности. canonicalRef — это логический указатель на линию, стабильный и детерминированный. Он не является публичным URL. Доступность по этому адресу, авторизация, видимость — всё это M3. M2 только гарантирует стабильность и детерминизм адреса. Это разграничение принципиально: путать логический адрес с публичным URL — архитектурная ошибка.
