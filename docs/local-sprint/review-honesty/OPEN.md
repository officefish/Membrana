## Итог блоков

- **e1** (влит PR #1731): `review:gate` различает «артефакта ревью нет» и «артефакт есть,
  но маркер вердикта не записан» — вещдок PR #1713, где гейт советовал прогнать то, что
  уже прогонялось. Закрытый список исходов `pass|block|unknown` **не тронут** (решение
  владельца): различается причина, состояние остаётся `unknown`. Признак артефакта
  приносит скрипт — ядро в ФС не ходит. 16/16 зубов.
- **e2**: `review:oversized` считает PR снятым по артефакту **или** по commit-status
  `review/teamlead=success` — след, который ставит сам гейт и который виден любому клону.
  Только `success` (слово владельца): `failure` неразличим между BLOCK и протуханием,
  такие PR прибор называет отдельной строкой как требующие руки. Порт спрашивает голову
  очереди (`--status-probe`, по умолчанию 20; `--no-status` — офлайн), сбой сети прибор
  не роняет. Живой прогон: 3 PR сняты по общему следу, слепота host-local 35 → 32.
  **Поправка по ходу:** нарезка утверждала «зубов у прибора нет ни одного» — это неверно,
  32 зуба живут в `scripts/lib/review-oversized-queue.test.mjs` (искал в `scripts/`).
  Свой файл-дубль удалён, семь зубов дописаны в существующий, три чужих ожидания
  приведены к новой форме `dropped`/отчёта. Итог 39/39 в файле.
