## Ошибка процесса, записанная честно

Первый прогон порч откатывал файлы `git checkout -- <файл>` **до коммита** блоков — компоненты
вернулись к версии из `main`, и порчи P3–P9 первого захода шли по старому коду («не применилась»),
а P8 дал недействительный результат. Код восстановлен из контекста сессии, блоки закоммичены, все
порчи прогнаны заново поверх коммита. Норма на будущее: порчи — только поверх коммита.
