## Что оказалось предметом

Слово владельца 03.10: «базовый набор по планам тарифов зависит от выбранного тарифа… коллекции должны пересматриваться
при открытии библиотеки»; уточнение — «уточнять, остался ли тариф тем же, и более глубокое обновление делать только при
смене тарифа». Корень: `init()` однократный, а открытие модуля зовёт именно его — после старта вызов пуст, сверки с
сервером нет; тики моста читают только квоту. Полный `refresh()` не выход: пробы каждой коллекции, буфер 8360 проб =
209 последовательных GET. Случай 03.10 (сервер переименовал набор после выкатки media без смены тарифа) строгая сверка
«тот же тариф → ничего» не чинила — владелец выбрал «лёгкую сверку всегда». Разбор — [`OPEN.md`](./OPEN.md); резчик —
[конспект dynin](../../discussions/cut-library-reconcile-on-open-2569-dynin.md).
