## Вердикт паузы Ф2 (Дынин, по числам)

**Замер не отвечает на вопрос о росте.** Precision зажат в 52–57 %, recall 96–100 %,
ROC-AUC у `percentile` колеблется 0.75–0.83 без монотонности (пик на 20, спад к 38);
интервалы Уилсона перекрываются на **всех** соседних ступенях — различить их статистически
нельзя. Ступень `envelope@10` вырождена: обнаружено 25 из 25 при 23 ложных из 23 — детектор
сработал на всё, рабочая точка фиктивна, это дефект замера, а не результат.

Что замер сказать **не может** (записано в витрину): о плато — диапазон 10→38 слишком узок,
ступени вложены; о превосходстве `percentile` над `envelope` — разница ~5 п.п. укладывается
в ширину интервала; о поведении при N ≫ 38 — экстраполяция запрещена. Для вывода нужен пул
дронов шире (цель ≥ 60) либо кросс-валидация по группам с бутстрапом.
