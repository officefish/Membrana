## Зачем

Долг попугая `#team-feedback-claims-code-unverified` (birth 07.08), строка 5 десятки
хендофа 08.08, назначена владельцем. `yarn team-evening-feedback` порождает протокол,
который **утверждает о коде** — называет символы, файлы, PR, карточки — и до 08.08 эти
утверждения не сверял никто. 07.08 четыре из них оказались ложными; поймала ведущая
глазом, вечером, уже после генерации. На этом протоколе строится доклад союзникам.

## Итог блоков

- **b1** — чистое тотальное ядро: [`atoms.mjs`](../../../scripts/lib/feedback-claims/atoms.mjs)
  (тело утверждения = проза и списки; fenced-код, таблицы, цитаты и комментарий провенанса
  отброшены) и [`verdict.mjs`](../../../scripts/lib/feedback-claims/verdict.mjs) (четыре
  исхода; токен несёт МНОЖЕСТВО классов-кандидатов, любой `holds` побеждает, «не нашли ни по
  одному из нескольких» — только `soft`).
- **b2** — обвязка [`feedback-claims-probe.mjs`](../../../scripts/feedback-claims-probe.mjs),
  глагол `yarn feedback:claims`. Каждый факт добывается по адресу СВОЕГО класса; `null` —
  «узнать не удалось», и это не алерт.
- **b3** — врезка: третье звено в хвосте вечера (не роняет цепочку), секция «Проверка
  утверждений» в теле протокола (идемпотентно, ничего не стирая), `claimsProbeBlocker` в
  вечернем гейте — держит ласточку ТОЛЬКО на `hard`, проходимо квитанцией владельца под то
  же дерево.

Зубов: **59** на четыре семьи; typecheck затронутых пакетов зелёный (DoD ревью PR #1801, 5/5 tasks). Живой путь пройден целиком: вердикт записан → гейт встал →
квитанция открыла → смена дерева её сожгла.

## Шероховатости (симптомы; корни — в close-записи прогона)

1. **Первая версия давала ложные тревоги на правде** — девять hard на протоколе 07.08.
   Четыре поправки, каждая по живому прогону: охват символа не включал `scripts/**` (а
   вечерний протокол говорит о тулинге); путь искался только точным (`procedure-runs/trail/…`
   живёт под `docs/`); доставка определялась любым упоминанием `(#N)`; догадка «там могут
   быть UI-фрагменты» считалась утверждением. Класс ровно тот, против которого спринт —
   маркер смотрел не по адресу (прецедент 03.08).
2. **Самореференция — дважды, оба раза найдены прогоном, не рассуждением.** Первый вид:
   probe разбирал СВОЮ секцию как голос команды — путь протокола и `yarn feedback:claims` из
   её шапки становились атомами, отчёт рос с каждым прогоном (`withoutClaimsSections`;
   идемпотентность проверена тремя прогонами подряд). Второй вид, вскрытый уже после ревью:
   расширение охвата на `scripts/**` привело к тому, что `PromoDeclineReason` собрал **девять
   вхождений в комментариях и зубах самого прибора**, где он назван примером ЛОЖНОГО
   утверждения, — и вердикт перевернулся с `hard` на `holds`. Семья гейта исключена из охвата
   символа: прибор не может быть источником фактов о самом себе.
3. **Оффлайн-признака доставки карточки нет** для карточек без иссью. Проверено на
   `morning-gates-two-moments`: реализация влита PR #1766, id карточки в сообщении коммита
   не назван, иссью занята соседом. Правило «реестр протух» живёт в ядре и покрыто зубом, но
   на живом протоколе срабатывает только для карточек с иссью. Не выдаю за полный охват.
4. **Точность нарезки 33%** (`sprint:experience`): b1 и b2 переполнены вдвое против оценки.
   Причина измерима — корпус зубов и четыре поправки; резчик оценивал реализацию, не
   калибровку на живых данных.
5. **Зоны блоков одного исполнителя пересеклись**: b3 потребовал правок в файле b2-зоны
   (`--state`, `--ack`, идемпотентный append). Объявлено в следе исполнения, не замолчано.
   Ревью PR #1801 назвало это P2 и попросило отразить в плане нарезки — **в план не
   дописано намеренно**: правка тела снимает ратификацию (дайджест меняется), а перерезка
   требует нового слова владельца. Пересечение внутри одного исполнителя того не стоит;
   место записи — след, где оно и стоит.
6. **Прогон контекста b1 шёл поверх ратификации** — отметка была временем запроса (11:24:34)
   при `revisionAt` 11:25:00, гейт честно дал `stale_partial`. Исправлена ОТМЕТКА по факту
   op-log (11:25:19 — момент, когда конспект стал вещдоком), не след.
