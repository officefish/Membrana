  **фактом до сборки** — три образа помечены `rollback-2026-08-21`. Находка резчика подтвердилась
  в тот же день: `docker compose build` пишет в тот же тег, без меток откат был бы словом.
- **2 deploy-media — исполнялся дважды.** Первая выкатка **отклонена**: сервис ушёл в restart-loop,
  `ERR_MODULE_NOT_FOUND @membrana/fft-analyzer-service`; откат выполнен **первым действием**, прод
  вернулся здоровым. Корень: runtime-стадия Dockerfile копировала dist поимённым списком, PR #2041
  (j2) добавил импорт — список отстал; по графу недоставало **11 пакетов**, включая
  `drone-detection-orchestrator` (спящая мина живого прода). Повторная выкатка после починки —
  media `Up (healthy)`, семь плагинов зарегистрированы.
- **`media-image-deps` (перерезка v2, Ожегов).** Образ несёт весь транзитивный граф; зуб
  `yarn verify:image-workspace-deps` краснел на 11 пакетах до правки и зелен после; отдельным
  зубом закрыта ловушка «COPY из build-стадии считать покрытием».
- **3 deploy-cabinet (Ожегов).** Вторым, из образа GHCR (`composeSha 6ff9aaeb`), `exitCode 0`,
  `smokeOk true`, оба контейнера healthy.
- **4 deploy-acceptance (Дынин, судит не выкатывавший).** Четыре вещдока с сервера сошлись:
  `raw ≠ API_INTERNAL_TOKEN`; строка `audience='client'` в `NodeKey`; запись принята (`201`,
  проба `cac7be7e`, 48 кГц, видна в БД); после отзыва — `401 client media key revoked`.
  Ключ узла Firebat (`audience='node'`) не тронут — обратная совместимость подтверждена.

**Часть 2 — ADR-0028 Р4 включён (блоки 5–7).** Порт остался из трёх **синхронных** глаголов,
мост снят кэшем при старте (`hydrate` рядом с портом, не в контракте — ограничение b2/b5).
Четыре исхода подъёма названы (`encrypted`/`migrated`/`empty`/`unavailable`); миграция
localStorage → шифртекст одним стартом, исходник чистится только после подтверждённой записи;
«не расшифровалось» → чистый ре-парринг, не крах. `available` в мосте перестал быть хардкодом
`false`: синхронный канал `available-sync` отдаёт ответ платформы. Зубы: 12 клиентских + 4 Studio.

откат) дали дыру **09:48–09:50 UTC, ~25 треков**. Повторная выкатка сделана после конца сеанса

ответ словом `busy`/`idle`, молчание = `busy`, умолчание деплоя — ждать, откат обязан спрашивать тоже.

Две находки гейта — дубли следа блока `deploy-media`: он честно исполнялся дважды. Вердикта не
меняют и не прячутся.
