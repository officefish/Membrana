**Конструкция.**

Тракт честный только если каждый шаг — чистая функция над явным входом: `scan` → `InventoryEntry[]`, `extract` → `TextSpan[]`, `ingest` → `IngestReport`. Нарушение: если `extract` читает диск напрямую, а не список из `scan` — это не тракт, это два независимых прохода с общим именем. Проверяй по контракту: входной тип шага должен совпадать с выходным типом предыдущего — буквально, не «похожим».

**Три вопроса по форме:**

1. **fetchImpl-инъекция.** Правильная форма — параметр `fetcher: typeof fetch` в сигнатуре `ingest(spans, options, fetcher?)`. Default — глобальный `fetch`. Тест подаёт stub. Никакого глобального мока, никакого `vi.stubGlobal` в тестах тракта — это граница между «зуб» и «хак».

2. **Bytes в stdout.** Резчик должен писать только в переданный `WritableStream` или возвращать буфер — никогда не в `process.stdout` напрямую. Если `ingestJsonlText` сейчас касается stdout — это дефект на уровне контракта, не поведения.

3. **Три повтора с бэкофом.** Логика ретрая — отдельная функция `withRetry(fn, {attempts, backoff})`, не инлайн в `ingest`. Иначе тест ingest проверяет и HTTP, и таймауты одновременно — граница размыта.

**Что упускаешь.**

Один тонкий момент: `--from` повторяемый добавляет директории к дефолту или **заменяет** его? Если добавляет — дефолт должен быть явным параметром, не скрытым вызовом `defaultTranscriptsDir()` внутри scan. Иначе при двух `--from` получишь неявный третий источник, который не виден в CLI-вызове. Это нарушение «форма следует функции» — скрытый вход.
