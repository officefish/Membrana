## Что оказалось предметом

Наблюдение владельца 03.10: сразу после старта Studio в связанном режиме модуль показывал жёлтое «Ограниченное локальное
хранилище · Media-server недоступен · 0.0 / 100.0 MB», коллекций нет; через секунды — нормальное. Корень — три слоя
([`OPEN.md`](./OPEN.md)): начальный снимок любого сервиса = browser-limited 100 МБ, а серверный `refresh()` читал квоту
последней после 209 GET буфера; ленивый default до решения моста — настоящий локальный сервис, подмена никого не
оповещала; режим хранилища в баннере звал всё не-серверное «Media-server недоступен». Резчик —
[конспект dynin](../../discussions/cut-library-loading-state-2570-dynin.md), инварианты I1–I4, BLOCK B1–B6.
