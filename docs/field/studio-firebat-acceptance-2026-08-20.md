# Приёмка: пользовательский путь — Studio на Firebat, парринг ключом из кабинета (20.08.2026)

> Документ предъявления блока b6 спринта `studio-firebat-user-pairing`. Судья — Тарасов,
> вердикт по контексту в `docs/discussions/studio-firebat-b6.md`. Вещдоки машинно-проверяемые
> (форма Веснина, заход 1); токены в вещдоки не попадают — маскируются.

## Что обещано (нарезка, ратифицирована 10:16Z)

1. Studio стоит на Firebat (операционный шаг владельца, установщик с флешки).
2. Пользователь входит и связывает устройство ключом из личного кабинета.
3. Первая запись из Studio лежит в наборе этого пользователя (membraneId сходится).
4. Порт хранения кредов в коде (b2–b4), долг служебного mediaToken назван ADR-0028 (b5).

## Порядок операционных шагов владельца (Firebat)

1. Флешка → `Membrana Studio Setup 0.1.0.exe` → установить (обычный NSIS-мастер).
2. В личном кабинете (cabinet.membrana.space): войти своим пользователем → раздел
   устройств/мембраны → **сгенерировать ключ доступа** (access key).
3. В Studio на Firebat: панель подключения → «Связать с кабинетом» → вставить ключ →
   связка (панель покажет мембрану и устройство).
4. Сделать запись из Studio (Библиотека сэмплов / Микрофон) — она уйдёт в набор
   пользователя на media.
5. Прислать в чат: скрин/вывод панели связки (без токенов) — остальное я сниму с сервера.

Фоновый поллер (`MembranaNode`, вчерашний спринт) на время проверки НЕ нужен; после —
`Start-ScheduledTask -TaskName MembranaNode` (перечитает новый ключ узла из .env).
