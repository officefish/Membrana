# DAY_MEMO — мемоизация дня

> Канон раздела «Память» (основа для harness.mmbrn.tech/tooling). Построен по
> вердикту консилиума `docs/seanses/day-memo-evening-2026-07-27.md`, магистраль
> 28.07 (`owner-choice@chat/magistral-28-07`). Генератор: `yarn day:memo`
> (`scripts/day-memo.mjs`), шаг вечерней цепочки `day-memo`.

## Зачем

День, который не записывает себя, обречён переспрашивать. Вещдоки-мотивы:
показанные владельцем документы терялись между сессиями (фото 26.07); первый
живой вызов ведущей переспросил уже случившуюся ратификацию (27.07); стратегия
дня девять дней собиралась из мёртвого артефакта. DAY_MEMO — третий вечерний
документ (симметрия с утренними тремя): машиночитаемый след дня.

## Три слоя

| Слой | Кто пишет | Содержание |
|------|-----------|------------|
| **Факты** | код (`buildFactsLayer`, без LLM/сети) | git-лог дня с PR, вещдоки (addedAt), кристаллы графа (source.date), события долгов попугая, квитанция мостика, итог отчёта памяти — каждый факт с меткой времени и указателем |
| **Инсайты** | цитатный v1 (без LLM): «Итоговые решения» консилиумов дня, Conclusion кейсов, тронутых коммитами дня | каждый вывод — цитата с указателем «файл · секция» и тегом `[Q: источник]`; цитата без указателя не выходит. Точка расширения — `SCRIBE_CONTRACT` (LLM-scribe, v2) |
| **Персональный след** | журналы персон + отчёт памяти | восемь блоков по персонам; **придерживается гейтом #569** до протокола показа партнёрам — след публикуется хвостом вечера |

## Гарантии

- **Immutable-снапшот** `docs/memos/<дата>.md`; повторный прогон дня — идемпотентный
  no-op (не ложный красный в цепочке).
- **Сам мемо — вещдок**: регистрируется в `docs/evidence/registry.jsonl` с sha256;
  перегенерация (`--force`) перерегистрирует append-only записью `-rN` — реестр
  никогда не врёт хешем на изменённый файл.
- **Честная бедность**: слой не поставлен/упал — видимая строка, не молчание;
  3+ пустых слоёв — exit 3 (находка, не отказ).
- **Хендофф-блок** «что требует утреннего внимания» — из problems слоёв, кодом.

## Место в цепочке

`ritual:evening`: … → code-review → archive-code-review → **day-memo** →
evening-tail. Зарегистрирован по обеим осям шага (kind/criticality) и в карте
exit-кодов (0 ok · 3 finding · 1 failure).
