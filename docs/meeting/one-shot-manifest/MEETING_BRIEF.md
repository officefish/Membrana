## Объединяющее задание

Перечеканить процедуру `one-shot` (манифест `docs/procedures/one-shot/MANIFEST.json` и,
где вердикты потребуют, предикат `scripts/lib/one-shot-s-predicate.mjs`) так, чтобы она
исполняла восемь тезисов шторма 03.08 — **Т1–Т8, ратифицированные словом владельца,
пересмотру в этом заседании не подлежат**:

| # | Тезис (кратко) |
|---|---|
| Т1 | исполнитель — обязательный профильный контекст, не лицо |
| Т2 | существо объёма — один прогон ревью; порог предиката 200/8; 400 — диагностика |
| Т3 | фаз много, исполнитель один |
| Т4 | исполнителя назначает тимлид |
| Т5 | разные по тематике блоки = спринт |
| Т6 | однородность: измеримое основание под суждением тимлида |
| Т7 | фазы = пункты чек-листа, машинерия только у шота целиком |
| Т8 | шот копит прогоны, формирует портфолио, опора — фреймы процедуры |

Заседание решает **четыре вопроса реализации** — им и принадлежат вердикты:

1. Состав фреймов процедуры шота и их держатели (Т8): сколько кадров, какие, кто держит.
2. Измеримое основание Т6 в v1: `pathFamily` (существует) против связности по графу
   (точнее, но графа нет).
3. Двойной прогон предиката: прогноз при штампе как гейт + факт при «код дописан» как
   стоп; судьба шота при превышении факта.
4. Форма назначения исполнителя тимлидом (Т4): каким актом записывается, чем проверяется
   след профильного контекста до `execute`.

## Границы

- Тезисы Т1–Т8 — посылки, не предмет: комнаты их не пересматривают.
- Формат шота (T1–T11 шторма 23.07) не пересобирается — только манифест и приборы под него.
- Ревью и мердж остаются вне формата (T11 от 23.07).
