# Повестка M0 — заседание one-shot-manifest

**O1 — В каком порядке зависимостей разбирать четыре вопроса перечеканки манифеста one-shot?**

Единственный вердикт этой комнаты — порядок (DAG): какой вопрос фундамент, какие зависят.
Вердикты по существу самих вопросов здесь НЕ выносятся — каждый принадлежит своей будущей
комнате.

Кандидаты (простым текстом, номера — только для ссылок в DAG):

1. Состав фреймов процедуры шота и их держатели: сколько кадров, какие, кто держит
   (тезис Т8: шот копит прогоны и формирует портфолио, опора — фреймы).
2. Измеримое основание однородности в v1: существующий pathFamily из предиката S против
   связности по графу зависимостей, которого пока нет (тезис Т6).
3. Двойной прогон предиката объёма: прогноз при штампе как гейт входа, факт при «код
   дописан» как стоп; судьба шота, чей факт превысил, — перерождение в спринт? (тезис Т2).
4. Форма назначения исполнителя тимлидом: каким актом записывается назначение и чем
   проверяется след профильного контекста до execute (тезисы Т1, Т4).

Посылки комнаты (даны, не обсуждаются): восемь тезисов Т1–Т8 шторма
storm-one-shot-performer-2026-08-03, ратифицированы словом владельца 03.08; формат шота
T1–T11 шторма 23.07; манифест docs/procedures/one-shot/MANIFEST.json (один кадр, шесть
шагов без держателей, home: none); предикат scripts/lib/one-shot-s-predicate.mjs
(8 файлов / 200 строк, pathFamily, анти-цепочка).

Требование к вердикту: назвать порядок (DAG) с обоснованием рёбер И полный список посылок
вердикта в том же прогоне. Список посылок обязателен; лишняя посылка — тоже нарушение.
