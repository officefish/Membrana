## Устройство перечеканенного one-shot — по четырём вердиктам

### Фреймы (M1)

| Фрейм | Держатель | Содержит |
|---|---|---|
| `first-frame` | Веснин | шаги `find · stamp-s · predicate-s · checklist` — чек-листом, без держателей у шагов (Т7) |
| `owner-ratify` | владелец | ратификация чек-листа |
| `execute` | **назначается тимлидом** (Т4) | исполнение до «весь код дописан» |

Прогоны копятся в общей ленте `docs/procedure-runs/` **тремя точками записи**: старт
`first-frame`, `owner-ratify`, закрытие `execute`. Портфолио — агрегат по
`procedureId: "one-shot"`. `home: none` сохраняется — это про пространство имён, не про
отсутствие следа (Т8).

### Назначение исполнителя (M2)

Акт «тимлид назначил» — **поля корня записи прогона**: `shotId · executor (PersonaId) ·
assignedBy: "teamlead" · contextRunRef`. Готовность к исполнению — предикат, не дисциплина:

```
ready_to_execute(R) ⇔ valid_assign(R) ∧ context_run_ok(R)
context_run_ok: след контекста исполнителя с timestamp СТРОГО РАНЬШЕ frames[execute].openedAt
```

Слабость #1641 закрыта структурно для шота: гейт проверяет **конкретный** `contextRunRef`
с временны́м предшествованием, а не наличие любого следа. Прецедент 30.07 («подпись без
прогона») ловится механизмом: нет `contextRunRef` → `false` с причиной `missing_context_run`.

### Объём (M3)

Прибор **один** — `evaluateOneShotS`, бежит дважды, `evaluationMoment ∈ {forecast, fact}`:

| момент | сила | красный исход |
|---|---|---|
| прогноз при штампе | **гейт** | шот не штампуется |
| факт при «код дописан» | **стоп** | статус `failed_oversize`, `ready_to_execute = false` |

Порог **200 строк / 8 файлов** (не пересматривался; 400 — диагностика oversized-ревью,
не порог шота). При красном факте **код сохраняется**, запись сохраняется с `result: fail`
и кормит анти-цепочку. Перерождение в спринт — **решение владельца** по четырём маршрутам
T8-23.07 (шторм · инсайт · консилиум · спринт); автоматического перерождения нет,
молчание маршрутом не является.

### Однородность (M4)

Измеримое основание v1 — чистая функция `shotThematicBasis(paths)` **поверх существующего**
`pathFamily`: возвращает `{families, familyCount, basis: 'pathFamily-v1', blind: 'no-graph'}`.
Бежит в том же прогоне предиката S. Слепота к семантической связности записана **полем**,
а не подразумевается. Поле `isHomogeneous` — BLOCK: предикат подаёт основание, судит
тимлид (Т6). Путь замены: граф зависимостей путь-к-пути → тот же интерфейс,
`basis: 'dependency-graph'`, поле `blind` уходит; точка помечена `TODO(graph)`.
