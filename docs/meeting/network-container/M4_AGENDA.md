# Повестка M4 — заседание network-container

**В4 — Кто владелец такта аудита сети, каков ритм, и куда падает находка?**

Единственный вердикт этой комнаты — субъект и ритм. Форма хранения (В5) и зубы (В6, В7)
принадлежат своим комнатам и здесь НЕ решаются.

Что требуется решить:

- Владелец такта: персона-держатель (из семи канона) — кто гоняет `audit` и отвечает за
  разбор находок; держатель НЕ выбирается голосованием комнаты — комната предлагает
  кандидата с обоснованием по природе предмета, назначение остаётся за владельцем.
- Ритм: ночь (стык с ночным контуром tests-nightly/vitest-nightly/night-triage)?
  неделя (weekly-dead-wire)? по касанию (при правке серверных вызовов)? Один ритм или
  сочетание — и почему.
- Куда падает находка: вход утра (как night-report), карточка реестра, инсайт-кандидат
  (канал night-triage после #1889 открывает PR только при промоте) — какой из существующих
  каналов, БЕЗ изобретения нового.
- Прод-замер (пробел 2 такта 1) — как ритм живёт, пока замера с office нет (форма без
  прод-замера — граница BRIEF).

Посылки комнаты (даны, не обсуждаются): вердикт M0 — порядок, ратифицирован владельцем
13.08; вердикт M1 — дом docs/audit/network, единица — зонд-снимок, глаголы
audit/decompose/inspect; вердикт M2 — разрез «норма vs наблюдение», субъект проверки шва
отложен в эту комнату; вердикт M3 — словарь пяти состояний + ось outcome, владелец
словаря — архитектор дома; существующие ночные контуры: tests-nightly-full (cron 03:00),
vitest-nightly (02:00), night-triage (промоут-гейт #1889: PR только при кандидате);
гейт ночи night-report в утре (PR #1851); ростер персон — семь (канон VIRTUAL_TEAM);
границы BRIEF: не чинить сеть (#1425), форма живёт без прод-замера.

Требование к вердикту: назвать держателя такта (кандидата с обоснованием), ритм,
канал находки — с обоснованием И полным списком посылок вердикта в том же прогоне.
Список посылок обязателен; лишняя посылка — тоже нарушение.
