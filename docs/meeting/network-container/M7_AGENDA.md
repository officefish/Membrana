# Повестка M7 — заседание network-container

**В7 — Где живёт правило «с какой машины какой выход легален» (proxy-awareness как политика машины) и каким зубом ловится голый fetch в серверном пакете?**

Единственный вердикт этой комнаты — политика машины как проверяемая. Правила направления
трафика (В6 — режет по трафику, не по источнику) — чужая комната, здесь НЕ решается.

Что требуется решить:

- Носитель политики: где живёт таблица «машина → легальные выходы» (dev-машина за
  локальным прокси; office за HTTPS_PROXY; media NL — прямой выход легален; cabinet —
  через media) — словом и данными.
- Зуб на код: статическая проверка «серверный пакет ходит голым fetch мимо
  proxy-обвязки» — грепабельный предикат (образец: night-hunt урок «голый fetch не
  видит HTTPS_PROXY»; инвентарь 12.08: deepseek, media-bridge, linear-snapshot,
  server-storage-backend — голые). Где зуб живёт (pre-push? CI? гейт-событие M4) и
  какова форма находки — БЕЗ починки самих вызовов (#1425: перечисленные голые вызовы —
  предмет отдельной работы, зуб их только называет).
- Легальные исключения: media ходит голым fetch легально (NL без фильтра) — как
  исключение объявляется данными (allow-запись с причиной), а не молчанием зуба.
- Судьба легаси-находок: зуб включается на репо с 4+ известными голыми вызовами — старт
  красным, амнистия списком, или warn-храповик (образец eslint-храповика #1264)?

Посылки комнаты (даны, не обсуждаются): вердикт M0 — порядок, ратифицирован владельцем
13.08; вердикт M1 — дом/единица/глаголы; вердикт M2 — разрез «норма vs наблюдение»
(политика машины — норма); вердикт M3 — словарь состояний; вердикт M4 — гейт-событие
«правка серверных вызовов», канал находки, кандидат-держатель Ожегов; вердикт M5 —
слои дома; инвентарь 12.08: proxy-awareness — свойство файла, не политики (голые:
office/deepseek, cabinet/media-bridge, media/linear-snapshot, media-library;
proxy-aware вне office только RAG-эмбеддеры); прецедент храповика: eslint
--max-warnings (#1264); границы BRIEF: не чинить сеть (#1425).

Требование к вердикту: назвать носитель политики, форму зуба и его место, форму
легальных исключений, судьбу легаси-находок — с обоснованием И полным списком посылок
вердикта в том же прогоне. Список посылок обязателен; лишняя посылка — тоже нарушение.
