## Форма контейнера `network` — семь вердиктов

### В1 — Дом и единица (M1)

Дом: **`docs/audit/network/`** (плоскость отчётов, жанр `llm-calls`). Единица —
**зонд-снимок**: результат одного акта наблюдения органом (`net:diag`, `llm:probe`,
`infra:probe`, `net:http`, `outbound-self-check`, …); один род записи в ленте; маршрут —
атрибутивный блок внутри снимка; правило — не единица; агрегаты — производные мастерской.
Запрещённые классы полей (закрытый список): секреты/credentials; приватные локальные
пути; сырые тела запросов/ответов; нередактированные дампы заголовков/env. Мастерская —
ровно три глагола: `audit` (лента → свод), `decompose` (срез → раскладка), `inspect`
(одна запись → карточка); глаголов починки нет (#1425).

### В3 — Граница с infra-policy (M2)

Разрез — **«норма vs наблюдение»**: `infra-policy.json` владеет декларациями об узлах
(что должно быть), снимок фиксирует наблюдённое (что было) и не несёт ни одного
поля-декларации. Проверка шва тремя слоями: закрытая схема снимка; дисциплина глагола
`audit` (поле вне схемы не создаётся); ссылка вместо копии. Ссылочность односторонняя:
снимок → `infra_node_id` (непрозрачный ключ); обратной ссылки нет; связь «норма ↔
наблюдение» строится мастерской при агрегации.

### В2 — Словарь состояний (M3)

Свой закрытый словарь поля `status`: **`ok` · `degraded` · `down` · `unknown` ·
`partial`** — объявлен в файле схемы снимка в доме (`schema.*`), отображение из
`net:diag` тождественное; неизвестное значение органа → `unknown` (+ оригинал во
вспомогательном поле вне словаря). «Проверка не состоялась» — **отдельная ось**
`outcome` ∈ {`executed`, `failed`}, не шестое состояние; при `failed` поле `status`
не интерпретируется. Владелец словаря — архитектор дома; расширение — только ADR-запись
в доме с органом-источником, значением и правилом отображения.

### В4 — Владелец такта и ритм (M4)

Кандидат-держатель — **Ожегов** (аудит сети = проверка сервисного шва; назначение
остаётся за владельцем). Ритм: **базовый такт 01:00** (до vitest 02:00 и
tests-nightly 03:00 — сеть не под нагрузкой CI) + **условный пуск** гейт-событием
«правка серверных вызовов»; оба пуска — один канал находки. Канал: тихая запись в
**night-report** (агрегация в утренний вход, PR #1851); при промоуте —
**night-triage** (#1889: PR только при кандидате). Карточка реестра — не канал находки.
Без прод-замера ритм идёт: снимки пишутся штатными значениями словаря M3, baseline
появится с прод-замером, ряд не теряется. `[ред.]` Формулировки протокола M4 со
значениями `observe`/`anomaly`/`critical` — дефект цепочки (таких значений в словаре M3
нет; аудит пачки M2–M5): в сборке заменены штатным словарём; порог промоута — предмет
В6/В7; отдельное значение для «наблюдения без нормы», если понадобится, вводится только
актом расширения M3.

### В5 — Хранение (M5)

**Двухслойно**: лента `analysis/YYYY-MM-DD/probes.jsonl` (append-only, источник истины)
+ overwrite-проекция `registry/` (`{probe_id}.json` + `summary.json` c
`meta.generated_at`; пересчитывается каждой успешной ночью, при пропуске ночи не
трогается — пропуск виден). `cache/` — транзит скрипта, gitignore; `README.md` — карта
дома и retention; слой `specimens/` не создаётся. Транспорт — по образцу night-report:
CI 01:00 собирает `probes.jsonl` артефактом, `--pull` коммитит ленту + пересчёт
registry одним коммитом. Retention: горячие 90 дней, старше — перекладка скриптом
по требованию в `analysis/archive/YYYY-MM/`; registry не архивируется.

### В6 — Правила исходящего трафика (M6)

Носитель — **`docs/audit/network/registry/egress-rules.json`** (слой нормы в registry
дома; не canon-док, не infra-policy, не лента). Закрытые поля записи: `rule_id`,
`class`, `source_zone`, `dest_class`, `verdict` ∈ {`allowed`,`forbidden`,`via`},
`via_node` (обязателен при `via`), `precedent_ref`, `status` ∈ {`active`,`deprecated`};
свободный текст — только комментарий. Зуб в **оба момента**: T_night (такт 01:00 —
снимки ленты против active-правил → находка в канал M4) и T_gate (гейт-событие — дифф
call-sites против правил). Миграция K1: одна `active`-запись `class=K1, verdict=via`
(office → Linear via media-VPS) с `precedent_ref`; поведение кода не меняется, слово
нормы — в registry (#1425).

### В7 — Политика машины и зуб на голый fetch (M7)

Носитель политики — таблица `{ machine, allowedExits, proxy|null, allowedBarePackages[] }`
(единственный источник истины зуба). `[ред., аудит M6–M7]` Носитель гармонизирован к
**`docs/audit/network/registry/machine-policy.json`** — полка норм дома, рядом с
`egress-rules.json`; прецедент жанра — `docs/security/infra-policy.json` + скрипт-читатель
(#1310/#1393); `packages/network-policy/` НЕ создаётся (пакет ради одного JSON — лишняя
сущность, серверные пакеты политику не импортируют — читает только зуб); схема, поля,
зуб и храповик — без изменений. Изменение решённой оси — на ратификацию владельца.
Зуб — `scripts/check-bare-fetch.mjs` в **pre-push (`.githooks/pre-push`,
core.hooksPath) `[ред.]` и CI**: серверный файл + `fetch(`-семейство без proxy-обёртки +
не покрыт исключением → находка. Форма находки — **собственный закрытый словарь находок
M7** `[ред.: не словарь M3 — тот про status снимка]`: `VIOLATION` (красный) · `LEGACY`
(в бюджете) · `AMNESTY` (временное, с `expiresAt`) · `POLICY_INVALID` (красный);
автопочинки нет. Stdout — немедленный сигнал pre-push; находка дублируется в канал M4
(night-report/night-triage), как у T_gate в M6 `[ред.: согласование каналов]`.
Исключения — только записью в политике (`type: permanent|amnesty` + обязательный
`reason`; media-linear-snapshot — permanent: NL-выход без фильтра легален); комментарий
в коде исключением не является. Поле `allowedExits` — декларативное; источник истины
направлений — `egress-rules.json` (В6) `[ред.: против дубля]`. Судьба легаси —
**warn-храповик**: бюджет `maxBareCallsCount: 4` (deepseek, media-bridge,
linear-snapshot, server-storage-backend — названы, не амнистированы); новое сверх
бюджета — красный; снижение бюджета — PR с доказательством, увеличение — только
amnesty-записью. Держатель — Ожегов (M4).

## Эрратум посылок (аудиты; тела протоколов не переписывались)

- **M7**: «конвенция `membrana.packageKind` из M5» — не M5, а гипотеза комнаты (в репо
  отсутствует; действует fallback-glob вердикта); «канал stdout из M4» — решение самой
  комнаты (вердикт M4 — night-report/night-triage); глосса «(единица политики — машина)»
  у M1 снята (единица M1 — зонд-снимок); «словарь M3 используется для меток» снято —
  метки объявлены собственным словарём находок.
- **M6**: `(verdict=via)` в строке-факте посылки 9 — кодировка, а не факт (вывод
  комнаты); посылка M3 в M6 — контекст, вердикт на ней не стоит (защита от лишнего
  каскада отзыва).
- **M2/M3**: приписки-заключения в посылочных строках (принадлежность карты маршрутов;
  характеристика класса кода 2) — перенесены из статуса «вход» в тело обоснования.

## Открытые хвосты сборки (не вердикты)

   скрипта пересчёта это фиксирует (напряжение слоёв M5×M6, аудит).

   кандидат в карточку тулинга.
3. Исполнение формы (каркас дома, схема, зубы, миграция K1) — отдельные поставки по
   task lifecycle, НЕ этим заседанием.
