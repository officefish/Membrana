# M3 — контракт мостик ↔ граф правды

**V3 —** Каков контракт между разговором на мостике и графом правды: какие слова идут
в гранит (чеканка кристалла), какие остаются потоком мыслей — и кто/что решает границу?
Как устроен треугольник намерения (озвученная мысль + 2 доказательства пользы для
продукта); какова роль маны (копится ценным разговором, тратится на поиск пользы;
курс владельца: со временем чеканка возможна ТОЛЬКО с механикой маны); что значит
«оценивать тезис по твёрдости намерения»; и как жест `gesture.mint_intent` из ядра M2
(lead инициирует, исполнение здесь) доводится до минта без прогонки всех мыслей подряд.
**Список посылок обязателен** — вердикт о контракте встаёт на названных основаниях.
