# Задание заседания «Политика сессий записи прибора»

> Контейнер: `device-recording-sessions` · Открыто: 2026-11-21 · Председатель: ведущая сессия (Ангелина) · Аудитор: отдельный read-only агент (S-M5).
> Вход: шторм `docs/storm/storm-node-24h-recording-2026-11-21/REPORT.md` (Т1–Т7, развилка владельца «на заседание»). Магистраль `node-permanent-duty`.

## Слово владельца (вход, не переоткрывать)

Тезисы шторма 21.11, каждый подтверждён владельцем:

- Т1 — прибор прежде всего детектор; постоянная запись на сервер — один из сценариев доски, не обязательна.
- Т2 — запись живёт сессиями с выборкой: сервер задаёт длительность сессии и объём выборки; по итогам сессии из буфера отбирается заданное число записей по одному из трёх существующих критериев; выборка кладётся в библиотеку (пример: 4 ч, 200 записей, самые громкие).
- Т3 — политика сессий у каждого прибора своя, её задаёт пользователь в кабинете; под одной мембраной будет несколько приборов, сервер один.
- Т4 — после сессии буфер освобождается: остаток удаляется, в холодный архив не уходит.
- Т5 — библиотека живёт кольцом: нет места для выборки новой сессии — удаляются самые старые; память библиотеки докупается как дополнительная услуга.
- Т6 — сейчас запись нужна для формирования баз звуков будущих детекторов; детекция дрона — особый сценарий будущего.
- Т7 — выборка сессии — отдельная папка в библиотеке (прибор, время, «N из M», критерий); кольцо удаляет только такие папки; политика — по образцу политики буфера (у прибора своя, мембрана может задать общую).

Вне предмета (слово владельца): подъём прибора без человека (автовход, автозапуск Студии и сценария, продление связки, сообщение о молчании) — задачи магистрали, не этого заседания.

## Объединяющее задание (одно на все вопросы)

Спроектировать «сессию записи» прибора от политики в кабинете до папки в библиотеке так, чтобы: политика задавалась на прибор (с общей политикой мембраны) и доходила до сервера записей; по концу сессии выборка по критерию делалась на сервере, остаток буфера доказанно освобождался, а выборка ложилась папкой в библиотеку; кольцо библиотеки удаляло только папки сессий и укладывалось в квоту хранилища. Повторно использовать то, что уже есть в стволе, если оно подходит; новое — только там, где старое не подходит, с причиной.
