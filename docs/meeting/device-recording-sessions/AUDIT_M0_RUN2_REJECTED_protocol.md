## Итоговое решение консилиума

| Вопрос | Решение |
|--------|---------|
| Корень графа | **Кандидат второй — политика сессии** |
| Порядок (цепь) | **2 (политика) → 3 (граница) → 1 (машина) → 4 (папка и кольцо)** |
| Рёбра (с причиной «что следующий берёт») | **2→3:** граница берёт у политики рамку сессии (длительность и связанные поля как входы старта/конца), не выбирая сами значения в M0. **2→1:** машина берёт у политики критерий и объём выборки как параметры конца/отбора. **3→1:** машина берёт у границы условие «когда сессия кончилась» (в т.ч. постановку вопросов offline/неполной как вход спецификации исполнения). **1→4:** папка/кольцо берёт у машины выход «выборка положена, остаток буфера освобождён» как объект хранения и GC. **2→4:** кольцо/квота берёт у политики (и её стыка с мембраной/квотами из задания) контекст лимита хранения, без правил удаления содержимого M0. |
| Не-рёбра | **1↛2, 1↛3, 3↛2, 3↛4, 4↛1, 4↛2, 4↛3, 2↛ порядок-обратный** — исполнитель и кольцо не задают политику; граница не специфицирует layout папки напрямую; обратных зависимостей по порядку нет. |
| Параллельно | **Полного параллельного старта нет.** После корня 2 разблокируется только **3**. **1** ждёт **2 и 3**. **4** ждёт **1** (и опирается на **2** по ребру контекста квоты). |
| Чего M0 не решил | Поля политики; кто будит; reuse ранжирования/purge; правила offline; состав защиты кольца — **отложено** в кандидатов по графу. |
