## Решения владельца вне комнат (в эпик)

- 21.11, развилка M2 прогона 2 → ответ «а»: **буфер целиком принадлежит сессиям** — при закрытии сессии выборка берётся из её записей, всё остальное в буфере удаляется; записи паузы приписываются следующей сессии (внесено данностью в повестку M2 прогона 3).
- 21.11, «удалить, да» (вариант А1): записи, лежавшие в буфере прибора **до включения сессий**, удаляются вместе с первой сессией (не выносятся в набор).
- 21.11, «да, включение сессии дает разрешение на удаление»: правило показа списка остаётся только для ручной очистки.
- 21.11, «А»: помеченные «хранить» уходят в библиотеку с выборкой, сверх объёма.
- 21.11, «Поддерживаю рекомендацию»: отказ замера целиком → последние N, «выборка без замера», остаток удаляется, дежурство не встаёт.
- 21.11, «1 да 2 да» (вопросы проекта M3): (1) помеченные среди записей до включения **переносятся**, а не удаляются по А1; (2) размеченные записи (метка не `unlabeled`, `isPinnedByHuman`) считаются помеченными и уходят сверх объёма.
- 21.11, развилки проекта M4: (1) «а» — кольцо пропускает старую папку с помеченной записью; (2) «предел есть. Полагаю, предел должен опираться на обьем библиотеки а не кол во папок» — граница кольца только байты квоты библиотеки, поля «число папок» нет; (3) «Старые пакки сессий можно удалять в рамках общей работы логики кольца» — папки сессий удаляет только кольцо, ручной двери нет.
