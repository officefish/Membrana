## Форма плагинной основы сервера (сводно)

**Словарь (M1, авторитет).** Пакет `packages/plugin-contracts`; манифест ровно из пяти
полей: `id: PluginId` (`<org>.<kind>.<slug>`) · `version` · `kind: handler|report|showcase`
· `mountTarget: HomeName` · `triggers: PluginTrigger[]`; включённость — операция реестра,
не поле; расширения — только через типы родов; владелец — Архитектор, breaking — ADR+консилиум.

**Дома (M2).** Два: `background-office/journal` · `background-media/collections`;
устройства отложены до появления их модуля. Домом делает `IPluginHost` (три члена);
реестр домов `HOME_REGISTRY`; манифест с чужим адресом отвергается до рантайма.

**Дом результатов (M3 + M3′).** Mongo офиса, коллекция `plugin-results`.
`RunAddress = { pluginId, version, collectionId, runId, mountTarget }` — дом явным полем,
адрес — неизменяемая запись момента исполнения. `RunFingerprints = { inputHash, configHash }`
отдельно; протухание объявляет чтение, сторожа нет. Заморозка `StateRecord` для
накопительных; `resumeMode: 'from-freeze'|'fresh'` — поле RunRecord; окно — в
`HandlerManifest`; граница окна — одной транзакцией; `ConvergenceRecord` — зуб сходимости
живого и пересчёта.

**Повод (M4 + эрратум).** `PLUGIN_TRIGGERS` закрыт: три события первой волны; каналы
`notify` (живой) / `request` (постфактум) — плагин канала не знает; fire-and-forget,
догонялка — чтение дома результатов по адресу; испускание событий журналом — отложенная
цена Т3.7.

**Витрина (M5′).** `ShowcaseManifest = база + displayForm + description?`; словарь форм
закрыт (row·table·zone-map·histogram·time-series + x-лазейка с обязательным fallback);
чтение — единственным методом хоста с narrowing; включение — `setPluginEnabled(id:
PluginId, enabled)`; у handler/report витринных полей физически нет.

**Первая волна и приёмка (M6′).** Шесть детекторов — handler дома коллекций; первый
живой — **`membrana.handler.mfcc`** на коллекции «Полевые записи 2026-08»; живой след —
RunRecord с адресом, отпечатками и `resumeMode:'fresh'` (без StateRecord и
ConvergenceRecord — их отсутствие норма для одиночного детерминированного прогона).
ПР-план: PR-1 контракты → PR-2 реестр и хост → PR-3 mfcc с живым прогоном →
PR-4 манифесты остальных пяти. Норма #1950 — структурное условие каждого PR
(write-путь из executor в пробы отсутствует). Витринный плагин — вторая волна,
с честным обоснованием (без UI-читателя его DoD неполон).

Три подмены посылок первого прогона возникли там, где повестка передавала чужой вердикт
ссылкой или числом; комната с поимённым перечнем процитировала без искажений.

файлом-носителем.** Добыто ценой трёх переигрываний.
