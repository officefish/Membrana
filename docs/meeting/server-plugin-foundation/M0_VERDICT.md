## DAG (десять рёбер, четыре слоя)

```
Слой 0:            Q1 — Словарь контрактов          (корень)
                    │
Слой 1:            Q2 — Дома крепления              (ждёт Q1)
                  / │ \
Слой 2:   Q3 — Дом  Q4 — Повод   Q5 — Самоописание  (каждый ждёт Q1+Q2,
          результатов  и события     для витрины     между собой независимы)
                  \  |  /
Слой 3:            Q6 — Первая волна и приёмка      (ждёт Q3+Q4+Q5)
```

Рёбра с обоснованиями — в протоколе M0 (таблица «DAG: рёбра и обоснование», 10 строк).
Рёбер 3↔4, 3↔5, 4↔5 нет — слой 2 внутренне независим; порядок M3→M4→M5 —
рекомендация по насыщенности, не зависимость.
