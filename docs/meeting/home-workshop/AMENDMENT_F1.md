# Поправка к Ф1 — поле `usage`: что даёт вызов и как выглядит вывод

| Поле | Значение |
|---|---|
| предмет | [`HOME_WORKSHOP.md`](../../patterns/HOME_WORKSHOP.md), контракт Ф1 — поля манифеста мастерской |
| основание | заседание `home-workshop` 22.07, вердикты Ф1–Ф5, ратифицированы владельцем |
| повод | документация не говорит, **что даёт** вызов и **как выглядит** его вывод — ни манифест, ни атлас этого не знают |
| ратифицирована | владельцем **31.07** (ратификацией нарезки `atlas-guide-tranche`) |
| исполнил | `ozhegov` · блок `f1-amendment` |

## Что было

Ф1 фиксирует пять полей: `pattern` · `name` · `worksOn` · `verbs` · `kit`. Словарь `verbs`
несёт **строку вызова** и ничего больше:

```json
"verbs": { "audit": "yarn scripts:orphans", "decompose": "yarn scripts:registry" }
```

Строка отвечает «как позвать» и молчит о том, «что получишь». Читатель — человек или
агент — узнаёт назначение глагола единственным способом: запустив его. Для пишущих
глаголов (`task:register`, `insight create`) это цена, которую платить нельзя.

## Что вносится

Поле-**сосед** `usage`, необязательное:

```json
"verbs": { "audit": "yarn scripts:orphans" },
"usage": {
  "audit": {
    "what": "прямой ответ: есть ли бесхозные скрипты и сколько",
    "sample": "scripts:orphans · знаменатель 950\n✖ бесхозных 43 из 950",
    "measuredAt": "2026-07-31"
  }
}
```

| поле записи | обязательность | смысл |
|---|---|---|
| `what` | да | что даёт вызов — одной фразой, не пересказ реализации |
| `sample` | да | **живой** кусок вывода, полученный прогоном |
| `measuredAt` | да | дата прогона, `YYYY-MM-DD` |

**Ключи `usage` — подмножество исполнимых дверей `verbs`.** Это строковые/null-глаголы
верхнего уровня и именованные записи `verbs.domain`; для доменной записи с примером
обязателен `tool`. Пример для глагола или доменного инструмента, которого нет, есть дефект:
он описывает дверь, которой не существует, и это ровно тот класс, что 31.07 поймали дважды —
в полу сессии (`audit` вместо команды) и в атласе (имя ключа вместо вызова).

## Почему сосед, а не мутация `verbs`

Изменить `verbs.audit` со строки на объект нельзя. Проверку `typeof verbs[k] === 'string'`
читают четыре живых потребителя: валидатор мастерских, справочник, пол сессии старта и прибор
мастерской скриптов. Мутация уронила бы **тринадцать** манифестов одновременно.

Поле-сосед оставляет все тринадцать валидными в тот же миг: `usage` необязателен, и его
отсутствие не делает манифест хуже.

## Почему `measuredAt` обязателен внутри записи

Вывод инструмента меняется законно — сменился знаменатель, добавилась строка, переименовался
глагол. Сверить `sample` с реальностью машинно **нельзя**, и обещать такую сверку было бы
ложью.

Но можно показать **возраст снимка**. Без даты пример через полгода читается как факт; с
датой — как снимок, сделанный тогда-то. Это тот же приём, которым живут штампы свежести
холодного старта: не гарантировать актуальность, а называть возраст.

Дата не проверяется на «свежесть» и не протухает автоматически: порога здесь нет и он не
выдумывается. Устаревший пример — предмет разбора человеком, а не отказа машины.

## Чего поправка НЕ делает

- **Не делает `usage` обязательным.** MUST мимо комнаты не вводится; сегодня это
  рекомендация, как и весь паттерн (статус SHOULD).
- **Не трогает `verbs`, `worksOn`, `kit`, `pattern`, `name`** — пять полей Ф1 остаются
  дословно теми же.
- **Не обещает машинной сверки вывода.** Проверяются форма, подмножество и наличие даты.
- **Не заполняет `usage` за авторов.** Пример добывается прогоном, а не сочиняется; для
  тринадцати мастерских это отдельная работа, и она в этот транш не входит.

## Цена

Поле в схеме валидатора · зуб на подмножество, форму и дату · вывод в справочник · заполнение
по мастерским отдельным траншем. Порядок ратификации — тот же, каким 31.07 прошла
[`AMENDMENT_S3`](../workshop-wires/AMENDMENT_S3.md): отдельный документ с ценой и слово
владельца, без пересозыва комнаты.
