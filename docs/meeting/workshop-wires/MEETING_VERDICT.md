## Что решено — одной страницей

**Принадлежность.** `belongs(s) → дом | неймспейс | сирота`. Дом — каталог с README под
политикой корней; мастерская — дом с манифестом, и она **подтип дома, а не обязанность**
каждого. Неймспейс — запись реестра с обязательным держателем и правилом членства; сирота —
честный третий исход, а не позор.

**Тесты бесплатны.** Тест наследует принадлежность своего предмета по закрытому списку из
двух локусов. Учёт растёт до 887 носителей, **ручная парковка остаётся 606** — спутники не
перечисляются. Страх удвоения, из-за которого комната стояла второй, снят числом.

**Справочник перестаёт врать.** Обнаружение — по README и политике корней, а не по манифесту;
33 невидимки становятся видны **без заведения 33 манифестов**. Реестр неймспейсов — источник
истины, атлас — производный потребитель. Тезис владельца о едином справочнике исполняется
глаголами поиска над проекцией.

**Прибор.** Контейнер `scripts/` становится домом и мастерской; два глагола: прямой ответ
«бесхозные есть или нет» и обратный поиск «в каких наборах лежит файл». Три молчания
различены: набор пуст ≠ набора нет ≠ файл не состоит.

**Зуб — на прирост, не на наследство.** Рабочий инвариант ловит новых сирот относительно
замороженной базы; абсолютный «сирот нет» включается **только словом владельца**. Блок — в
pre-push по затронутому, полный отчёт — в CI и ритуале. Освобождение именное, со следом;
`SKIP_PREPUSH` освобождением не является.

**Пол сессии.** Каждая холодная сессия получает список мастерских с входным глаголом,
минимальный набор вызовов реестра, ссылку на документацию и отчёт проверки инвентаря. Источник
— только проекция; ручная запись в выдачу запрещена. Второй уровень — уже зарегистрированная
недельная процедура.

**Оптовое и поштучное сосуществуют слоями.** Пол выдаётся всем; провод к конкретному
инструменту делается поштучно по прецеденту. **Пол ≠ провод**: «есть в полу» не значит
«проведено» — и это названо главной ценой оптового.

**Норма живёт в `AGENTS.md`**, зеркала — только указатели. Подпирается не гейтом (невызов
машине не виден), а разбором транскриптов постфактум с измеримым признаком жизни: пороги,
окно 28 дней, честное «выборки недостаточно» вместо принудительной зелени.

**Кит — четвёртый служебный вид фрейма процедуры**, сосед проводам, не расширение. Процедура
отдаёт набор по ссылке; содержимое кита во фрейме не дублируется. Обязательным требованием
становится только через отдельную ратификацию — **не контрабандой валидатора**.

## Сквозной долг формата — «наклон стола»

Аудитор поднял его классом: **во всех девяти комнатах** комната приходила не к чистому листу.
Разные носители — фраза кандидата в повестке M0, форма повестки, ставшая формой контракта M1,
секция «Основания» с готовыми доводами M2, архитектура соседней комнаты M6→M9, тезис владельца
на M5 — один эффект: часть работы сделана до созыва.

Почти всегда довод был верен по существу, подделки вердиктов нет. Но заседание стало
пространством, где готовый ответ формализуется, а не находится. **Решение владельца требуется:**
считать ли это легитимной рамкой (владелец и председатель вправе её задавать) или отделять
рамку от подлинно открытых вопросов.

Секция «Основания» убрана из повесток начиная с M3 — это первое лечение, и оно сработало:
на M3/M4 аудит подтвердил дисциплину.

## Что заседание доказало о себе

Формат **вскрыл собственную процедурную негодность в процессе работы, а не молчанием**:
дважды пойман ложный зелёный гейта посылок, четырежды подтверждена слепота `rt-6` на хвостовом
эхе. Оба дефекта найдены **только после того, как аудитор стал отдельным агентом** (с M2) —
ровно то разделение, ради которого S-M5 существует. Три первых комнаты, где аудит вёл голос
председателя, этот класс находок пропустили бы.

Прослеживаемость осталась слабой: только M1 и M8 закрыли протокол в git к моменту своего
аудита; повестки M4, M6, M7, M5 приехали в main внутри коммитов соседних комнат.
