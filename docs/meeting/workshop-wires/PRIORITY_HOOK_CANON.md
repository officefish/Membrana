# Приоритет: глагол мастерской → граф кода → греп

| Поле | Значение |
|---|---|
| предмет | коллизия хука `SessionStart` и нормы порядка в [`AGENTS.md`](../../../AGENTS.md) |
| основание | прецедент [`2026-07-31-scripts-workshop-lookup-orphans-sets-atlas`](../../precedents/2026-07-31-scripts-workshop-lookup-orphans-sets-atlas.md), класс `session-report` |
| решено | владельцем **31.07** |
| исполнил | `ozhegov` · блок `hook-canon-priority` |

## Что столкнулось

Хук `SessionStart` вгружает в контекст **до первой реплики**:

> CRITICAL - Code Discovery Protocol: **ALWAYS use codebase-memory-mcp tools FIRST for ANY
> code exploration**.

Норма в `AGENTS.md` (§8 контракта `workshop-wires`, ратифицирована 31.07) говорит:

> Узкий прибор мастерской вызывается **до** разведочного поиска по дереву.

Оба текста употребляют слово «первым» и **не упоминают друг друга**. Приоритет не был
записан нигде — ни в хуке, ни в каноне, ни в скиллах.

## Как это проявилось

Холодная сессия 31.07, три проверки. Она решила коллизию **в пользу канона** — позвала
глаголы мастерских, и `codebase-memory-mcp` не понадобился ни разу. Решение верное, но
принято **сессией на ходу**, а не правилом: следующая может решить иначе, и обе будут правы
по букве.

Замер парсером вызовов: 21 вызов, разведка 5, мастерская 9, первый содержательный ход —
разведкой.

## Решение

```text
1. глагол мастерской   — прямой ответ на вопрос о состоянии дома
2. codebase-memory-mcp — поиск вслепую по графу символов
3. греп по дереву      — поиск вслепую по тексту
```

**Различение проведено по роду ответа, а не по инструменту.** Глагол мастерской отвечает на
вопрос «в каком состоянии дом, что где припарковано, в каких наборах лежит файл» — он **знает**
ответ. MCP и греп **ищут**: первый по графу, второй по тексту. Спор был не о том, что лучше,
а о том, что это разные классы действия — и потому очередь между ними не конкуренция.

**Хук не отменяется.** Его требование остаётся в силе внутри своего класса: если разведка
нужна, граф идёт впереди текста, потому что точнее. Меняется одно — «ANY code exploration»
получает оговорку: обращение к мастерской разведкой не является.

**Абсолютного запрета на греп по-прежнему нет** (§8, пункт 4): поиск по коду текущей задачи
при уже известном инструменте законен.

## Текст хука вне досягаемости репозитория

Замер 31.07: хук живёт в `~/.claude/hooks/cbm-session-reminder` — **вне репозитория**, на
машине разработчика. Третья строка файла: `# Installed by codebase-memory-mcp`.

Отсюда два следствия, оба несущие.

**Канон его не правит.** Оговорку в текст хука вносит владелец машины; репозиторий может
только записать приоритет у себя и сослаться. Дотянуться скриптом технически можно —
`homedir()` читается из корня проекта, — но **писать туда нельзя**: файл порождён
установщиком, и правка молча откатится при следующем обновлении MCP. Артефакт, который
выглядит правдой и перестаёт ею быть без сигнала, — ровно тот класс дефекта, против которого
шёл весь день 31.07.

Плюс файл пользовательский, а не проектный: он общий для всех репозиториев владельца. Скрипт
из `Membrana`, правящий `~/.claude/`, менял бы поведение агентов в чужих проектах — вне
версионирования, вне ревью, и `git revert` его не откатит.

**Расхождение обнаруживается, а не чинится.** Проверка
[`hook-collision.mjs`](../../../scripts/lib/hook-collision.mjs) читает текст хука и норму и
говорит, записан ли между ними приоритет. Та же форма, что три разницы дрейфа справочника:
чужой артефакт не трогаем, расхождение с ним называем.

Честный предел: проверка **не заставит** хук измениться. Она различает три состояния — «хук
требует, канон отвечает» · «хук требует, канон молчит» · «хука нет на этой машине». Последнее
не ошибка: у другого разработчика MCP может быть не установлен, и красный там был бы ложным.

## Чего это решение не делает

- **Не объявляет MCP лишним.** «Где объявлен символ, кто его зовёт, что сломается при правке»
  — вопросы графа, и мастерская на них не отвечает. В холодной сессии 31.07 таких вопросов
  просто не было.
- **Не вводит зуба.** Невызов машине в момент нарушения не виден (§8); подпорка — разбор
  транскриптов постфактум, находка, а не блок.
- **Не переписывает норму §8.** Порядок в ней тот же; добавлена одна строка о том, что
  `codebase-memory-mcp` относится к разведке, а не к приборам.

## Цена

Одна строка в норме, оговорка в тексте хука, этот документ. Проверяемость — та же мерка
признака жизни: доля сессий, начатых разведкой (включая MCP), за 28 дней не выше 0.2.
