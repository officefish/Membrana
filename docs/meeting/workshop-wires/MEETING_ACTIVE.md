· реплик 36 · посылки названы · `--no-rag`.

**Вердикт — контракт (сжато):**

| вопрос | решение |
|---|---|
| неймспейс машинно | запись в SoT-реестре `docs/namespaces/REGISTRY.json`; **не** поле home-манифеста, не кит, не строка ATLAS |
| поля записи | `id`, `title`, `holder` (`persona` XOR `ownerRef`), `membership {kind: pathPrefix\|namePrefix\|pathGlob\|explicitList, value}`, опц. `containerKind: plain\|bidi`; **нет** `verbs`, `worksOn`, `kit`, `roots` |
| различение | `isHome(x) ⇔ workshop.manifest с pattern дома`; `isNamespace(x) ⇔ запись REGISTRY`. Дом обязан verbs; неймспейс не умеет и не обязан |
| держатель неймспейса | **обязателен**; отвечает за смысл правила и стабильность `id`, не за verbs. Пустой holder — запись невалидна |
| попадание скрипта | только `matches(path, membership)` ∧ path не покрыт домом. Не «остаток», не «прикладность сама по себе» |
| предикат | `belongs(s) → {home,id} \| {namespace,id} \| {orphan}`: дом побеждает; конфликт неймспейсов — longest `pathPrefix`, иначе `min(id)` |
| orphan | честный третий исход; текущие 476 — orphan, пока нет правила или дома |

**Запреты контракта:** неймспейс без держателя · `misc`/`other`/`tmp`/«всё сиротское» ·
второй источник истины · перечень кластеров вместо правила · колонизация чужих комнат.

**rt-6 предупредил, метки `D1` в теле нет.** Гейт грепает метку, не вердикт (#558). Сверка
глазами: ответ дан под заголовком «Контракт» и покрывает все пять требований повестки —
определение, различение, держатель, правило образования, предикат. Комната не «уронила»
вопрос; протокол не правлю (тело ведущего неприкосновенно), факт называю здесь.
