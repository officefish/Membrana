## Каркас тарифа — что решено

**Сетка есть versioned декларативный контракт**, а не набор колонок на тарифе:
`TariffGridDocument` = `EntitlementRegistry` (определения прав) + матрица
**SKU × entitlementId → EntitlementValue**. Пять родов права живут закрытым union'ом —
`quota{limit,unit}` · `catalog{catalogId}` · `instrument{enabled}` ·
`gated{enabled}+preconditionId` · `produce{enabled,scope?}`. Истина — на сервере; клиент
получает проекцию и читает её чистой функцией `resolveEntitlement`. **Deny-by-default**:
нет ячейки, неизвестный id, несовпадение рода → права нет. Полнота обязательна: для
каждого тарифа и каждого права — ячейка.

**Существующий рельс прав сценариев становится проекцией сетки, а не вторым источником
истины.** Поле `entitledTariffSkus` остаётся носителем в проводе, но выводится из матрицы;
писатель проекции один, серверный; двойная запись запрещена.

**Третий исход выражен без третьего статуса.** «Право есть, условие не выполнено» =
право выдано **и** список невыполненных условий непуст. Условие живёт ссылкой в ячейке
`gated`, факт считает контур сети; до него — честный `stub_unwired`, а не молчаливое
«выполнено». Витрина на это **притемняет с предупреждением**, борд и сервер — **отказывают
наглухо**.

**Две памяти — две отдельные ячейки квоты**: холодная (хранилище треков) и горячая
(рабочая область детекторов); живой буфер записи — третья, не сливать. Матрица задаёт
только потолок; занятое — серверное состояние, не поле матрицы. Каждый путь записи обязан
объявить класс памяти. При исчерпании — отказ на создание; чтение и удаление живут;
автовытеснение и тихая деградация запрещены.

**Право производить своё — способность, а не квота и не право вызова.** Проверяется в
момент создания и расширяющего изменения, **не в момент существования**. При потере права —
**retain**: созданное живёт, читается, удаляется владельцем и остаётся вшитым в сценарии.
**«Проверка существования против тарифа» прямо запрещена.**

**Переход между тарифами меняет ровно одну вещь** — ссылку мембраны на тариф. Снимок прав
в мембране запрещён. Единственная точка записи — `applyTransition(membraneId, target, proof)`
плюс append-only журнал смен. Менять вправе администратор (в любую сторону) и погашение
промокода (только вверх). Промокод — одноразовый объект с целевым тарифом; погашение
атомарно: проверка → применение → списание → запись; повтор отвечает `already_redeemed`.
Понижение по всем родам права проходит одинаково: **данные сохраняются, запрещается только
новое**.

**Зубы сведены в закрытый реестр** с полями «что проверяет · где стоит · что делает при
срабатывании»: полнота матрицы, синхронность проекции, отказ без права, превышение квоты,
класс памяти на записи, производство на создании, старший узел на загрузке и клонировании,
неизвестный id, клиент, объявивший себя источником истины, запрет снимка прав, единственный
путь смены тарифа, запрет API проверки существования и тихого вытеснения. Эффект только
трёх видов — отказ операции, красный CI, находка в отчёте — и **всегда с именем зуба.
Молчаливый зелёный запрещён.**

## План интеграции — S0…S9

```text
S0 сид и лимиты к решению владельца (512 МБ и согласованные скаляры)
S1 дом сетки на сервере: реестр + матрица + зуб полноты
   ├─ S2 чистый resolve + wire DTO + честный stub условия
   │   ├─ S5 гейты производства (создание и расширение)
   │   ├─ S7 мягкая витрина клиента (притемнение + предупреждение)
   │   └─ S6 жёсткие гейты борда (загрузка · клонирование · старт)  ← ждёт ещё S3
   ├─ S3 единственный писатель проекции (entitledTariffSkus ≡ срез матрицы)
   ├─ S4 три квоты и путь записи (резерв → фиксация | освобождение)
   └─ S8 applyTransition + журнал смен + скелет промокода
S0..S8 → S9 переключение: единственный источник истины — сетка
```

У каждого шага — свой DoD и свой сторожевой зуб из реестра M7 (таблица в протоколе M8).

**Точка перехода (cutover):** сетка становится единственным источником истины **после**
готовности S0–S8 и зелёных зубов. До неё живёт один адаптер «легаси → та же форма провода»,
и новые потребители уже читают её; **двойная запись в режиме сетки запрещена**. Откат —
выключение флага, без включения двойной записи.

## Что планом НЕ покрывается (явно)

1. **Содержание набора** — какие права в каких тарифах (слово владельца: уточняется отдельно).
2. **Админский дашборд** редактора матрицы и набора (нужен, но вне контура).
3. **Исходящий маршрут office** ([#1425](https://github.com/officefish/Membrana/issues/1425)) —
   ведёт отдельный контейнер network, другой агент; в сетке живёт как `stub_unwired`.
4. **Права узлов палитры и детекторов** — носителя id в продукте пока нет.
5. Остальные работы «серии 11» шторма, не сводимые к S0–S9.
6. Миграции пользователей (их нет), биллинг, политики автовытеснения, multi-node/TDOA.

## Оговорки аудитора, оставленные в силе

Заседание идёт **с оговорками**, не сломано. Существенные: M1 вынес два вердикта по чужим
комнатам (поправлено — M4 переспросила и вывела основания заново); протокол M2 опёрся на
несуществующую «ратификацию M1»; в M0 два вывода лежат в списке посылок; председатель
единожды вынес процедурное суждение сам (S-M5, принято); часть входа не доехала до повесток
(восстановлено в M4–M8); **все артефакты заседания вне git** — проверка «задание не поехало»
пока без машинных зубов.

## Ратификация

**Владелец ратифицировал итоговый вердикт заседания 29.07.** Вердикты M0–M8 вступают в силу
как канон тарифного каркаса; план S0→S9 — принятый порядок врезки.

Остаются за владельцем (не блокируют канон):
- отдельное слово по **S0** — приведение сида «Датчика» к 512 МБ (единственный шаг, меняющий
  существующий носитель);
- **формат исполнения** S0–S9: эпик с фазами (рекомендация ведущей) · серия задач · хакатон
  (отложен как сырой на шторме 29.07).
