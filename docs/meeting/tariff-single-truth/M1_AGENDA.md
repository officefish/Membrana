# Заседание «Тариф как единая правда» — M1 (R) Пересев производных из матрицы

**Объединяющее задание (одно на всё заседание):** превратить тезисы шторма 08.09 в исполнимый
контракт поведения сервера и прибора на тарифе и при переходах, с одной правдой о тарифе —
матрицей из гранул — и производными, читающими её одинаково.

**Порядок M0 (ратифицирован владельцем 08.09):** **M1 (R) пересев** → M2 (P) право и объём → M3 (U)
повышение → M4 (D) понижение и холодное хранилище → M5 (S) наборы при переходе. M1 — корень, предшественников нет.

## Данности (закрыто штормом, НЕ переоткрывать)

- Источник правды — матрица тарифов из гранул по ресурсу в контейнере strategic-docs; гранулы с паспортом (версия, дата закрепления, владелец, ресурс, единица, домен, правило пересева); тариф — строка-композиция (T13, T14). Форму гранул строит сессия Б (#2331) — здесь не проектировать.
- Релиз рождает производные: `tariff-grid.json` — машинный слепок для серверов; база кабинета и записи приборов — проекции, обновляемые событием с версией контракта; пересев — глагол, генерация производных командой (T15, T7).
- Сетка перестаёт быть рукописным каноном; правки только через гранулы и пересборку (T16).
- Квота никогда не отрицательна; «тариф действует» — вычислимая функция (T8, T9) — содержание в M2, здесь только носитель.
- Умолчание политики переполнения — stop; контракт остановки buffer-full-stop — данность (для M1 несущая часть одна: отказы «полон» остаются контрактом сервера записей и в цепочку пересева не входят).
