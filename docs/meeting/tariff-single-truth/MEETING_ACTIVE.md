## Вердикт M2 (P) — сборка председателя (источник: прогон 2 — содержание и форма; поправки аудита прогона 2; аудит сборки 1–2), ПРИНЯТ аудитом 08.09

**Словарь:** право — что даёт тариф (матрица); объём — сколько занято в доме ресурса; доступная квота (свободно) — `max(0, лимит − занято)` на оси; окно — снимок чисел эпизода отказа; «тариф» в функции = лимиты с записи прибора (переопределение комнаты, прогон 1); удержание — `DeviceOverflowHold`; сервер записей — media.

**(а) Носитель функции и кто зовёт.** Чистая функция «доступная квота» живёт в `@membrana/plugin-contracts`, файл `packages/plugin-contracts/src/buffer-overflow/available-quota.ts`, экспорт через индекс пакета (экспорт пакета только `"."` — подпуть-импорт невозможен **[аудит r2]**). Пакет ESM-only; сервер записей (CJS) берёт функцию динамическим `import()` по прецеденту `packages/background-media/src/modules/collections/plugin-host.service.ts:63` — **не** «как reasons»: словарь причин в `buffer-overflow-refusal.ts:5-11,47` чеканится литералами под `satisfies`, рантайм оттуда не импортируется **[аудит r2]**. `buildBufferOverflowRefusal` синхронна (`buffer-overflow-refusal.ts:104-122`), поэтому функция грузится один раз при инициализации сервиса и кэшируется, сборка отказа остаётся синхронной **[председатель: способ; комната цену не назвала]**. Нового пакета не создавать; `@membrana/core` в сервер записей не подключать. Зовёт: сервер записей при сборке `/quota` (`devices.service.ts:223-278 getQuota`) и при отказе; клиент в живом контуре только читает готовое «свободно» из ответа; клиент в режиме окна: **«свободно» из снимка отказа в удержании, если отказ его нёс; иначе та же функция на `used/limit` снимка удержания** **[аудит r2: правило Архитектора #4 вместо дизъюнкции]**. Третьей арифметики нет.

**(б) Оси и сложение.** Оси независимы, между собой не складываются: буфер — байты (`kind === 'buffer'`); пользовательское хранилище — байты (`user` + `system` с ключом ≠ `TARIFF_DATASET_SYSTEM_KEY`); тарифный системный набор — вне байтов, только `sampleCount` + `catalogId`; рабочие места — счётная ось; узлы (`maxNodesPerMembrane`) — ось кабинета, не функция сервера записей. Предикат отказа байтов: **свободно < размер входящего** ⇔ `used + incoming > limit`; «свободно = 0» — частный случай, не эквивалент. Отказ мест: `used >= maxUserWorkspaces`.

**(в) Окно.** Снимок эпизода — `used/limit/свободно` в миг отказа; не неделя холода и не момент перехода (M3/M4). Автор чисел — сервер записей в теле отказа; носитель снимка — удержание на приборе (сервер числа эпизода не хранит: `overflow-episode-registry.ts:12-14`); режим окна исполняет клиент без второго запроса `/quota` (данность M5 «полный буфер»).

**(г) Единый источник числа.** Истина объёма в рантайме — сервер записей + функция. Витрина объёма и библиотека кабинета — `media-bridge.service.ts:224 getQuota` → `sample-library.service.ts:26-41 mapQuota`, прокидывает «свободно», из `Tariff` не вычисляет. Окно оператора — отказ + удержание, то же «свободно». Витрина мембраны `/v1/tariffs` — только право (лимиты), «свободно» не подменяет. **Факт и красный вход:** клиент и библиотека сегодня считают «свободно» сами — `apps/client/src/lib/overflow-window/viewModel.ts:82` (`freeBytes = max(0, limit − used)`) и `packages/services/media-library/src/quota-status.ts:19-24, 44-50`; после переезда локальное `limit − used` там — красный.

**Строить:** 1) чистая функция в `plugin-contracts`; 2) расширение `BufferOverflowRefusal` (`packages/plugin-contracts/src/buffer-overflow/refusal.ts:44`) полем «свободно» по отказавшей оси — носитель `plugin-contracts`, добавка к телу, транспорт 200 не меняется; 3) `/quota` отдаёт «свободно» по осям буфера и хранилища; 4) `getQuota` и сборка отказа зовут функцию; 5) `mapQuota`, `viewModel`, `quota-status` потребляют «свободно» из ответа или функцию на снимке; 6) удалить локальный вычет в клиенте и библиотеке.

- **Цепочка пересева:** релиз матрицы → (CI на мердж) `yarn tariff:reseed` → сетка → проекция сетки в базу кабинета (CI и/или кабинет при старте сверяет базу к сетке образа) → событие разноски кабинет → записи приборов на сервере записей (существующий канал + пакетный переезд). - **Версия контракта:** `contractVersion` — монотонный атрибут релиза, копируется в сетку, базу, событие и запись прибора; применять только если входящая версия больше хранимой, иначе идемпотентный no-op; `updatedAt` версией не считать; запись прибора хранит версию уже в M1, прибор-край — позже (#2323).
- **Зубы:** релиз↔сетка (CI, чинит пересборка), сетка↔база (сверка/гейт кабинета, чинит повторная проекция), база↔записи (счётчик разноски, чинит повтор события); равенство — по каноническому дампу квотных полей + id тарифов + версия; запрет ручной правки производных — предикат гейта, не просьба.
- **Переезд без остановки:** пересев сетки → накатная сверка кабинета (free 1 ГБ уходит значением из релиза, не SQL) → пакетное событие на все записи с новой версией → мониторинг зубов; середину руками не правят; поведение при переполнении уже занятого — M2/M4.
- **Не строить:** форму гранул (#2331), «доступную квоту» (M2), повышение (M3), понижение/холод (M4), наборы (M5), чтение сетки сервером записей, UI-редактор квот, версию эпизода переполнения как тарифную правду.
