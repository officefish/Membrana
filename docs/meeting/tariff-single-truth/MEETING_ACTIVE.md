## Вердикт M1 (R) — кратко (полный: протокол)

- **Цепочка пересева:** релиз матрицы → (CI на мердж) `yarn tariff:reseed` → сетка → проекция сетки в базу кабинета (CI и/или кабинет при старте сверяет базу к сетке образа) → событие разноски кабинет → записи приборов на сервере записей (существующий канал + пакетный переезд). Человек по слову — только повтор той же команды; сервер записей сетку не читает.
- **Версия контракта:** `contractVersion` — монотонный атрибут релиза, копируется в сетку, базу, событие и запись прибора; применять только если входящая версия больше хранимой, иначе идемпотентный no-op; `updatedAt` версией не считать; запись прибора хранит версию уже в M1, прибор-край — позже (#2323).
- **Зубы:** релиз↔сетка (CI, чинит пересборка), сетка↔база (сверка/гейт кабинета, чинит повторная проекция), база↔записи (счётчик разноски, чинит повтор события); равенство — по каноническому дампу квотных полей + id тарифов + версия; запрет ручной правки производных — предикат гейта, не просьба.
- **Переезд без остановки:** пересев сетки → накатная сверка кабинета (free 1 ГБ уходит значением из релиза, не SQL) → пакетное событие на все записи с новой версией → мониторинг зубов; середину руками не правят; поведение при переполнении уже занятого — M2/M4.
- **Не строить:** форму гранул (#2331), «доступную квоту» (M2), повышение (M3), понижение/холод (M4), наборы (M5), чтение сетки сервером записей, UI-редактор квот, версию эпизода переполнения как тарифную правду.
