# Повестка — один вопрос: дом плагина разбора сеанса

**Q. Монтируем ли разбор сеанса в дом `background-media/collections`, а не в объявленный
владельцем `background-office/journal` — при цене «журнал остаётся получателем уведомления,
не местом исполнения»?**

Единственный вопрос комнаты. Состав мер разбора (относительная громкость · отсев похожего ·
шум vs структура) НЕ обсуждается — он дан владельцем поимённо и принадлежит профильным
контекстам (Дынин — математика, Курёхин — слух).

## Грани одного вопроса

1. **Честность перед словом владельца.** Задание 21.08 говорит «плагин в объявленном доме
   журнала». Расхождение с этим словом — предмет вердикта комнаты и ратификации владельца,
   а не молчаливого выбора исполнителя.
2. **343 МБ против локальности.** Час сеанса ≈ 720 треков × ~476 КБ. В media звук читается
   in-process (Prisma + блобы); в office его пришлось бы тянуть 720 HTTP-запросами.
3. **Прецедент mfcc.** `membrana.handler.mfcc` смонтирован в `collections` ровно потому, что
   там звук; результат уезжает мостом в дом результатов `plugin-results` (Mongo офиса).
4. **Что тогда есть «дом журнала».** Если исполнение в media — чем журнал остаётся в этой
   картине: получателем уведомления? домом результата? ничем до снятия цены Т3.7?
5. **Форма «сеанса» без правки контрактов.** `RunAddress` несёт `collectionId`; понятия
   «сеанс» (окно времени внутри коллекции) в словаре нет. Выражать через `ctx.payload`?
   иначе? Контракты `plugin-contracts` менять ЗАПРЕЩЕНО (#1982 — вопрос Архитектору).
6. **Форма выхода.** Двадцать опорных — адреса (`sampleId` + смещение) внутри `RunRecord`
   (норма #1950: плагины пишут только в `plugin-results`), или иное?

## Посылки (даны, не обсуждаются)

- M1_VERDICT — авторитет словаря: манифест ровно пять полей; расширения через типы родов;
  владелец словаря Архитектор, breaking = ADR + консилиум.
- M2_VERDICT — два дома: `background-office/journal` · `background-media/collections`;
  домом делает `IPluginHost`; манифест с чужим `mountTarget` отвергается до рантайма.
- M4_VERDICT — `PLUGIN_TRIGGERS` закрыт; `journal.entry_created` в словаре есть, но
  испускание в доме журнала — после снятия отложенной цены Т3.7, «не в этом собрании».
- Норма #1950 — измеренное не подменяется объявленным; плагины пишут только в `plugin-results`.
- **Факт разведки 21.08:** модуля `journal` в `background-office` НЕТ (18 модулей, journal
  среди них нет), `IPluginHost` для журнала не реализован, сущности «запись журнала» нет.
  Единственный «журнал» в дереве — `@membrana/journal-report-views`, React-рендеры отчётов
  телеметрии клиента: другой слой.
- **Факт:** media отдаёт `GET /v1/devices/:d/samples/:sampleId/blob` (стрим); у office есть
  `MEDIA_API_URL`/`MEDIA_API_TOKEN` — путь по сети физически возможен.
- **Факт:** мост media → office живой (PR #1981/#1985/#1988), первый RunRecord 19.08.
- **Запрет владельца 21.08:** детектор дрона для ранжирования не использовать (проба 20.08
  дала `detected` на чистом фоне помещения).

## Требование к вердикту

Назвать решение по вопросу с обоснованием против альтернатив И полный список посылок
(факт/норма) в том же прогоне. Лишняя посылка — тоже нарушение. Состав мер разбора в
вердикт не вносить — он не предмет комнаты.
