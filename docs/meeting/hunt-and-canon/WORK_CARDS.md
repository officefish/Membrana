## К1 — Сторож молчания: манифест ожиданий и таймер

**Из вердикта:** M1. **Носитель:** манифест ожиданий `E` + факты прогонов на хосте
наблюдения. **Исполнитель:** unit `SilenceWatchdog` + sibling-таймер.

**Что сделать.** Завести манифест ожидаемых событий — минимум три из фактуры:
`vitest-nightly` (`0 2 * * *`), `tests-nightly-full` (`0 3 * * *`),
`night-hunt-office-trigger` (`10 7 * * 1-5`) — каждое с `t_cron` и допуском `δ`. Таймер
читает манифест, спрашивает факты прогонов и краснеет по предикату `S(e)` с причиной из
трёх: `non_arrival`, `swallowed_failure`, `guard_self_silence`. Тишину самого сторожа
ловит sibling на том же хосте.

**DoD.** Предикат `S(e)` и три причины зафиксированы кодом, а не прозой · манифест
покрывает три события · назван хост наблюдения и способ добычи факта прогона · сторож не
импортирует office SDK, пусковой прогон не импортирует сторожа · тревога не требует, чтобы
человек случайно открыл Actions.

**Порча.** Убрать одно событие из манифеста — сторож обязан промолчать (его там нет);
подделать факт прихода несуществующего прогона — обязан покраснеть `non_arrival`; убить
сам сторож — sibling обязан покраснеть `guard_self_silence`.

**Размер:** M. **Цена промедления:** высокая — сейчас о молчании узнают случайно.

## К2 — Архиватор отличает вещдок от копии · **СДЕЛАНО 27.08**

**Из вердикта:** M2. **Носитель:** политика свежести `NightHuntArchiveVeracity` + факты
прогона шага. **Исполнитель:** `scripts/archive-night-hunt-artifacts.mjs` (шаг
`archive-night-hunt` вечерней цепочки).

**Что сделать.** Научить архиватор предикату `V(s,d)`: маркер рождения источника
(`Generated (UTC)` в отчёте) обязан принадлежать окну ночи `d`. Не принадлежит — **явный
отказ** (`refused_stale` / `missing_marker` / `parse_error` / `missing_source`),
ненулевой исход шага, никакой датированной папки «ночи жизни». Манифест несёт `bornAt`,
`contentHash`, `verdict`, `evidenceClass`. Отдельно — разовая пометка уже наштампованных
папок **12.08–23.08** как `tainted` / `copy_not_exhibit`: не чистить, папки сохранить как
улику класса.

**DoD.** `V(s,d)` считается по маркеру рождения · при `¬V` — refused и ненулевой исход ·
manifest несёт четыре поля · batch-метка 12.08–23.08 применена · вечерняя цепочка не
считает refused успехом и не глушит его.

**Порча.** Подсунуть источник с датой рождения вне окна — шаг обязан отказать и НЕ создать
папку; подсунуть свежий — обязан создать с `evidenceClass=exhibit`; убрать маркер рождения
— обязан отказать `missing_marker`, а не «пропустить как раньше».

**Размер:** S–M. **Цена промедления:** высокая — конвейер лжи работает каждый вечер.

**Итог.** Предикат `V(s,d)` живёт в `scripts/lib/night-hunt-veracity.mjs`, архиватор чеканит только вещдоки и отказывает кодом 3 (находка, не поломка — цепочка предъявляет громко и не падает). Метка проставлена **предикатом, а не диапазоном**: затронуто 39 папок, 14.07–26.08, вещдоков в архиве **ноль за всю историю** — ни один отчёт никогда не архивировался в день рождения. Диапазон 12.08–23.08 из вердикта оказался уже фактического.

## К4 — Три job'а охоты: переписать или снести

**Из вердикта:** M4. **Носитель:** снимок дерева + манифест детерминированных правил
замера. **Исполнитель:** раннер класса `yarn verify:*` / зубы / CI-job с checkout.

**Что сделать.** По правилу **rewrite-or-remove**, для каждого из трёх:
`design-token-drift` → verify по канону К3; `monorepo-dependency-graph` → verify/зуб
графа; `services-api-contract-drift` → verify, если контракт машиночитаем в дереве, иначе
**снос**. Как LLM-job не сохраняется ни один. Неудавшийся замер → `refused`, ненулевой
код, причина (`no-tree` / `no-etalone` / `tool-error`) в факте прогона; отчёт-чеклист «для
ручной проверки» запрещён.

**DoD.** Ноль LLM-opinion job'ов в ночном контуре · у каждого либо детерминированный
эквивалент, либо запись о сносе · контракт неизмеримости соблюдён · путь «GitHub → офис →
LLM → PR» не является исполнителем замера · два прогона на одном SHA дают тот же статус.

**Порча.** Прогнать дважды на одном SHA — статус обязан совпасть; снять эталон (К3) —
обязан быть `refused`+`no-etalone`, а не отчёт; отдать пустое дерево — `refused`+`no-tree`.

**Размер:** L. **Зависимость:** после К3.

## Находка попутно, требует своего решения

Порча при проверке работы №1 вскрыла **причину 400**, которую заседание держало за
границей предмета: офис отвергает запрос словами «Body cannot be empty when content-type
is set to `application/json`» — пусковой прогон слал заголовок JSON без тела. Чинить это
здесь я не стал намеренно: по вердикту M4 путь «GitHub → офис → LLM» перестаёт быть
несущим для замера, и починка вернула бы к жизни ровно ту конструкцию, которую M4
приговорил. **Решение — в К4:** если `services-api-contract-drift` или другой job
сохраняется в детерминированном виде, вход офиса чинится вместе с ним; если все три
переписываются на checkout-путь, вход офиса сносится, а не чинится.
