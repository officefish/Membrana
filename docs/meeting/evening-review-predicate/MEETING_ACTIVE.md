## Вердикт M1 — предмет вечернего ревью (фундамент)

Протокол: [m1-subject](../../seanses/evening-review-predicate-m1-subject-2026-08-01.md), 26 реплик.

| Часть | Решение |
|---|---|
| (а) единица суждения | **карточка реестра**, активная за день. Машинно: карточка входит в множество дня, если есть коммит с ref на её `id` либо ветка карточки с коммитами за день |
| что говорит вечер | **отношения между карточками**: пересечения границ (два коммита задели один модуль в разных карточках), накопленные риски пары/группы, меры, невидимые внутри одной карточки. Область определения предиката — множество карточек дня, а не одна |
| (б) вход | тройка `(c, commits(c), contract(c))` per карточка дня. `contract(c) = ⊥` → `no_contract`; коммиты без карточки → `orphan_commits`; неполнота → `input_incomplete`. `consumes: []` заменяется явным объявлением трёх компонентов |
| при неполном входе | вечер **не молчит и не выдаёт `oversized`** — выдаёт типизированный сигнал пробела |
| (в) форма вердикта | три типизированных поля: `boundary` `{card_a, card_b, shared_module}` · `checks` (теги реестра проверок) · `safety` (теги реестра мер). Свободный текст запрещён (#1204). Реестр тегов — в доме заседания, расширение через заседание |
| отличие от LGTM/BLOCK | вечер **не выносит бинарного вердикта per карточка** — это уже сделало потактовое ревью. Вечер выносит **реляционное** суждение |
