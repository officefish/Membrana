## FAIL по проверке 4 — зеркальная ложная посылка

Первый прогон пал на «органа архивирования нет» без проверки дерева. **M4′ пал на «органы
функционально готовы» без проверки интерфейса** — вывод из молчания повестки, дословно: «из
повестки не следует, что этого нет». Проверка по коду:

| Шаг вердикта | Команда | Что произойдёт в цепочке |
|---|---|---|
| 13 `sessions-extract` | `yarn sessions:extract` | **ВСЕГДА ПАДАЕТ, exit 2** — `scripts/session-extract.mjs` без позиционных `<sessionId\|файл> <маркер>` печатает usage и возвращает 2 |
| 14 `archivarius-ingest` | `yarn archivarius` | **ЗЕЛЁНЫЙ NO-OP** — `scripts/archivarius.mjs` без подкоманды печатает help, exit 0. Реальный ingest требует `--file`/`--from`, а **без `--out` пишет весь корпус спанов в stdout** — транскрипты дня утекут в лог вечера |
| 12 `sessions-scan` | `yarn sessions:scan` | запустится, но ничего не производит — печатает инвентарь в stdout; exit 2, если каталог транскриптов не найден |

**Тракта `scan → extract → archivarius` в коде не существует.** `sessions:extract` не читает выход
`sessions:scan` (резолвит цель по позиционному аргументу), `archivarius ingest` не читает выход
`extract` (сам обходит `~/.claude/projects`). Это три независимые точки входа, а не цепочка —
значит порядок, на котором стоит вердикт, обоснован ложно.

**DoD неисполним и по схеме манифеста:** шаг описывается полем `script`, раннер делает
`spawnSync('node', [file, ...args])` — поля `command` схема не знает; и `validateManifest` требует
`whyNoncritical` у каждого `noncritical`, а вердикт объявил три шага `noncritical` без причины.

суждение о доверии к содержимому того же архива.
