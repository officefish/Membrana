## Интерфейсы органов — дословно из кода (01.08)

```text
scripts/session-scan.mjs   — yarn sessions:scan [--dir <путь>] [--markers "a,b,c"]
                             Exit: 0; 2 — каталог не найден / usage.
                             Одна строка на сессию в stdout: первая..последняя метка времени,
                             размер, id, счётчики маркеров. Файлы стримятся, в контекст не тянутся.
                             Машиночитаемого выхода НЕТ.

scripts/session-extract.mjs — yarn sessions:extract <sessionId|файл> <маркер> [--max N] [--full]
                                                     | --from ISO [--to ISO] [--role user|assistant]
                             Exit: 0; 2 — файл не найден / usage.
                             БЕЗ аргументов печатает usage и возвращает 2 — ВСЕГДА.

scripts/archivarius.mjs     — node scripts/archivarius.mjs ingest --file <transcript.jsonl> [--out spans.jsonl] [--session-id <id>]
                                                           ingest --from ~/.claude/projects [--out spans.jsonl]
                                                           ingest --from ~/.codex/sessions | ~/.cursor/projects/<slug>/agent-transcripts
                                                           audit --index spans.jsonl
                                                           decompose --index spans.jsonl --by sessions|days|actors
                                                           inspect <sessionId> --index spans.jsonl
                             БЕЗ подкоманды: printHelp(), exit 0 — зелёный no-op.
                             ingest БЕЗ --out: корпус спанов уходит в stdout; в stderr только сводка
                             «файлов N · spans M · замаскировано K».
```

**Тракта между ними нет.** `sessions:extract` не читает выход `sessions:scan` — резолвит цель
через `resolveTarget()` по позиционному аргументу. `archivarius ingest` не читает выход
`extract` — сам обходит каталог через `collectJsonlFiles()`. Три независимые точки входа.

**Долг заведён карточкой** `archivarius-evening-tract` (M, active) — связывание тракта
принадлежит ей, **не этой комнате**.

## Схема шага цепочки — дословно

Шаг описывается полем **`script`** (строка вида `"scripts/bridge.mjs close"`, аргументы внутри
строки). Раннер `scripts/ritual-evening-run.mjs` делает `spawnSync('node', [file, ...args])`.
**Поля `command` схема не знает.** `validateManifest` (`scripts/lib/step-status.mjs`) требует
**`whyNoncritical` у каждого `noncritical`**; шапка файла объявляет: по умолчанию `critical`,
некритичность объявляется явно и с причиной.

Оба прошлых вердикта предписали неисполнимое именно из-за незнания этой схемы.

## #1229 и граница нотариуса

Archivarius — `#1330`, **эпик #1229**. Источник байтов — MongoDB в office-стеке; **репозиторий —
нотариус**: держит контракт, мастерскую, снимки, но **не становится базой полных сессий**.
Несущий контракт — адресуемый отрезок `span://<sessionId>/<uuid>`, акт изъятия, секретная граница
через `scripts/lib/secret-redact.mjs`.

**Адресуемый отрезок архив ещё не отдаёт** — поэтому кейсы и прецеденты носят честное «нет» в поле
`span`. Это и есть условие, в котором аудит обязан на него опираться (бывшая вершина (5)).

## Требование 3 из #569 — первоисточник, Issue открыт

> **В память попадает только то, что уже показано партнёрам.** Цель — исключить заражение памяти
> невычитанным/ложным содержимым.

Целевая клауза формулирует норму **по свойству содержимого**, а не по имени хранилища.

Проверено по коду и годно как посылка (единственное, что уцелело из M4′):
`scripts/telegram-swallow.mjs` в ветке `outcome === 'delivered'` (office `sent=true`) вызывает
`persona-memory-extract.mjs --all` — то есть gate «показано партнёрам» стоит именно там;
`secret-redact` живёт внутри архивариуса и решает **конфиденциальность**, а не вычитанность —
предикаты ортогональны.

**Оговорка, которую обязана учесть эта комната:** вывод «Archivarius не нарушает #569» держится на
звене «`persona-memory:extract` не читает архив спанов». Сегодня истинно, но **случайно**:
карточка эпика **#539** планирует ровно такой вход (`~/.claude/projects/*.jsonl` в существующий
экстрактор, без второго). При её исполнении вывод протухнет — значит вердикт обязан либо назвать
условие своей жизни, либо распространить норму заранее.

учётом того, что тракта нет и связывание принадлежит своей карточке. Если **ничего не может встать

вывода относительно карточки #539.

каждого `noncritical`, фактическая нумерация из 16 шагов.
