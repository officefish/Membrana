# M5 — метрики и логирование контура памяти

**C5 —** Что контур памяти измеряет и логирует по ратифицированным C1–C4: какие
события — обязательный лог (операции памяти: записано/перенесено/поднято/отвергнуто),
какие величины — метрики v1 (счётные, без порогов), как машинно выражается сигнал
«утонуло ценное и ни разу не всплыло», чем наполняется третья строка отчёта
token 121 («всплывало сегодня») — и что честно остаётся v2 (retrieval recall
по эталонным наборам, калибровка порогов/весов)? Кто эмиттер каждого лога
(условное ребро C5→C6 — подтвердить или снять). **Список посылок обязателен.**

---

## Вводные (только для C5; C1–C4 ратифицированы; провод в код — C6, не решать)

- Рамки ратифицированы: C1 — transfer-события в append-only архиве; C2 — отчёт
  пересборки pinned/retained/transferred с причинами из закрытого словаря;
  C3 — Cloud с queryPlan (логируется), emerge/why и reject/reason; C4 — квитанции
  E/M с enum done|miss|degraded|late, запрет forge_done предикатами «пригодными
  для зуба».
- Кристалл token 121 (ратифицирован владельцем): три строки на персону — «записал
  в оперативку / утонуло в подсознание / всплывало сегодня»; третья строка ждала
  этого контура; limit кристалла честно фиксировал «чем наполняются строки — не
  задано».
- Research (#1366): «логировать операции памяти — что извлечено, что инъецировано
  в контекст, что эвиктировано, что суммаризовано — обязательная практика отладки»;
  метрика «забыли ценное» = retrieval recall по тестовому набору важных старых
  записей (LongMemEval/BEAM-класс) — тяжёлая, эталонные наборы надо строить.
- Плотва (#1366): без приоритизации отчёт — «памятник ушедшему»; C2 дала
  приоритизацию — C5 обязана показать, что памятник превратился в приборную панель:
  регрессия видна ДО потери ценного (pinned_overflow, рост transferred routine
  против position — примеры-кандидаты, не принять слепо).
- Живые носители: team-memory-report (записал/вытеснил поимённо, exit 3 = находка);
  day-memo слой Фактов (счётчики источников); реестр вещдоков (day-memo как вещдок);
  существующий образец каталога метрик — docs/audit/llm-calls (дом-мастерская).
- Сигнал-кандидат «утонуло и не всплыло»: запись с importanceSnapshot=pinned или
  class=position|insight, transferred N дней назад, ни разу не в emerged — счётный
  предикат по логам C1+C3 без порогов-констант (N — параметр отчёта, не константа
  контракта). Проверить конструкцию, не принять слепо.
- Ограничение: пороги, веса, эталонные наборы recall, бенчмарки — v2 (именованные
  слоты); провод эмиттеров в extractor/скрипты и зубы — C6; UI/дашборд панели — вне.
