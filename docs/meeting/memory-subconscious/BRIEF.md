# Заседание memory-subconscious — второй контур памяти персон

Общее задание: контракт двухпамятной архитектуры персон — подсознание (append-only),
переток при вытеснении, всплытие, активный цикл вечер/утро — доведённый до DoD
по комнатам. Председатель — агент сессии мостика. Формат — конвейер комнат по
ратифицированному порядку M0 (регламент docs/MEETING_REGULATION.md).

## Кандидатные вопросы (плоским текстом, порядок решит M0)

- C1. Контракт подсознания: append-only архив, структура записи, суммаризация при перетоке (сжатие с указателем на полный текст).
- C2. Приоритизация оперативной: pinned/несущие вне бюджета (провод importance.json), TTL временных, состав «сделанного стека».
- C3. Механика всплытия: облако (MMR + serendipity-слоты + мультизапрос), веса резонанса, акт всплытия за судящим звеном персоны.
- C4. Активный цикл: вечернее сжатие (стык DAY_MEMO/отчёт памяти) + утренняя загрузка релевантного (стык стендапа/хендофф-кешей).
- C5. Метрики и логирование: retrieval recall, сигнал «утонуло и не всплыло», третья строка отчёта token 121.
- C6. Рефакторинг extractor: границы правки, миграция журналов, зубы против рецидива.
