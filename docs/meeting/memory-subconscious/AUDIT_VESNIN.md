### 2. Вердикт по четырём ✖ машинного аудита (проверка [4])

Hard rule 2: *смежный вопрос упомянуть можно, вердикт по нему выносить нельзя*. Гипотеза председателя: соседи стоят в списках исключений и в отсылках к уже ратифицированным рамкам.

| Комната | Обвинение | Вердикт аудитора | Почему |
|---|---|---|---|
| **C2** | обязательства по C1, C6 | **ложное срабатывание** | `transfer с причиной` — политика *вызова* ратифицированного transfer C1 (ребро M0 C1→C2 подтверждено), не пересмотр схемы архива. C6 — вне DoD / провод join'а, не allowlist extractor'а |
| **C3** | C2, C4, C5, C6 | **ложное срабатывание** | meta-признаки облака ← C2; *когда* подавать ← C4; глаголы emerge/reject ← словарь-рамка C5; порт retrieval — один контракт, не рефакторинг extractor. Списки «вне DoD» — анти-колонизация, не колонизация |
| **C4** | C5, C6 | **ложное срабатывание** | `transfer_applied` обязателен, `forge_done` запрещён — квитанция слота цикла, не словарь метрик и не код extractor'а. Emitter'ы не назначает |
| **C5** | C6 | **ложное срабатывание** | таблица verb→emitter фиксирует *контракт наблюдения* (кто обязан писать глагол), не границы правки extractor'а; allowlist и фазы — C6 |

**Итог по четырём:** реальных обязательств по чужому вопросу нет. Везде — легальное упоминание: (a) исключение из DoD, (b) отсылка к уже ратифицированной рамке, (c) вход/выход своего ребра DAG.

**Чей долг:** зуб проверки [4]. Он не различает *вердикт по чужому* и *именованное исключение / post-condition на своём крае*. Канон формулировок DoD («Вне DoD Cn: …») — защитная форма, её надо научить машину читать; комнаты не переписывать. Долг — на инструмент и регламент аудита, не на C2–C5.

*(Сверка с телом протоколов нужна только если зуб цитирует конкретную строку DoD вне списка исключений и вне формулы «по рамке Cn» — по сводке таких строк нет.)*

### 3. Спрятанные посылки и семантическая колонизация

**Спрятанных посылок уровня «тихо приняли как данное» — не нашёл.** Вводные брифа названы; research, Плотва, вещдоки, #569, token 121, запрет численных весов — проведены. jsonl-первичность (C1) — решение комнаты против живого md-носителя, не скрытая посылка: md оставлен проекцией, граница явная.

**Колонизация — пограничные места (не ломают контур):**

1. **C2 → край C1:** «transfer с причиной» расширяет снимок перетока (C1: `importanceSnapshot`). Допустимо как политика *вызова*, если причина — поле события перетока, а не перепись `ArchiveRecord`. При сшивке: причина живёт в op-log/метаданных transfer, схема C1 не разбухает.
2. **C5 → край C6:** verb→emitter читается как наряд extractor'у. Формально это контракт наблюдения (C5), не allowlist (C6). Риск — исполнители P* примут таблицу за задание на правку. Сшивка: таблица = accept-тест для C6, не scope C6.
3. **C4 ↔ C5:** запрет `forge_done` / `forge_metrics` — параллельные зубы честности. Не колонизация, а *двойная фиксация*; при сшивке оставить один канон «квитанция не подделывается» со ссылкой с обеих сторон.
4. **Свои реплики Архитектора (строже):** если в комнатах я толкал «один retrieval-порт» и «jsonl первичен» — оба сели в вердикты. Порт (C3) и носитель (C1) — форма, им место в контракте; претензия только если без цены альтернатив. По сводке цена держана (md-проекция; лифт ≠ память). Колонизацией соседей это не стало.
5. **C6 «зубы всех рамок»** — терминалу положено; это не захват, а арматура. Следить, чтобы зубы ссылались на ратифицированный текст C1–C5, а не пересказывали его заново.

Тихой переписи чужого вопроса нет. `report-transfer-blind` честно вынесен в находки сшивки, не в норму C6.

### 4. Архитектурная связность M1–M6

**Один контур — да.**

```
оперативная O (C2) --transfer--> архив jsonl (C1)
                                      |
                              buildSubconsciousCloud (C3)
                                      |
                         emerge+why / reject  (персона)
                                      |
         evening_compress (C4) ---- op-log/метрики (C5) ---- morning_warmup (C4)
                                      |
                              extractor + зубы (C6)
```

- **Архив ↔ политика:** C2 выбывает только transfer'ом C1; erase нет — согласовано.  
- **Политика ↔ облако:** meta/классы C2 = признаки скоринга C3; recency не первый ключ — единый режим свежести.  
- **Облако ↔ цикл:** C3 не ставит cron; C4 задаёт *когда* (повестка/жест/feed + warmup) — ребро C3→C4 держит.  
- **Цикл ↔ лог:** `transfer_applied`, emerge-only в 121, `sunk_unsurfaced` — панель на тех же глаголах, что пишет контур.  
- **Лог ↔ extractor:** словарь C5, провод и allowlist C6; ребро C5→C6 подтверждено.  
- **Миграция:** day-zero + backfill окна 27–28.07 с разным provenance — честный стык с вещдоками, не маскировка.

**Противоречий между вердиктами нет.** Условные рёбра M0 все подтверждены конструкцией.

**Устав мостика и DAY_MEMO:**

| Стык | Состояние |
|---|---|
| #569 / ShownMemo — в память только показанное | C4: evening после #569; не переписывает гейт |
| DAY_MEMO | слот стыкуется, ритуал не перепроектирован |

| попугай / тетрадь | контур не ломает: архив — тетрадь подсознания; облако — подача в судящее звено; акт — за персоной (не скрипт-память) |
| handoff_cache persona×date | новый *носитель прогрева*, не новый ритуал стендапа |

Рвов нет. Нагрузка, которую форма должна выдержать: «ничто не умирает», «всплытие под подписью», «пропуск слота виден» — несущие стены совпадают.
