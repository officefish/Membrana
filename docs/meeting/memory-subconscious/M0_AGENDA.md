# M0 — порядок разбора заседания memory-subconscious

**P1 —** В каком порядке разбирать шесть кандидатных вопросов заседания о втором
контуре памяти персон (C1 подсознание · C2 приоритизация оперативной · C3 всплытие ·
C4 активный цикл · C5 метрики/логирование · C6 рефакторинг extractor) — и какие
рёбра-запреты держат этот порядок (что нельзя разбирать раньше чего и почему)?
Единственный вердикт комнаты — порядок (линейный или DAG с рёбрами); существо
вопросов не решать. **Список посылок обязателен** — порядок встаёт на названных
зависимостях, не на «удобно обсуждать рядом».

---

## Вводные (только для P1; существо C1–C6 не трогать)

- Бриф заседания: docs/meeting/memory-subconscious/BRIEF.md — шесть кандидатов
  плоским текстом, посылки (слово владельца 27–28.07 дословно, вещдоки вытеснения
  двух дней, research 9 источников, тезисы Плотвы, живые носители, ограничения).
- Предикат ребра (образец M0 bridge-command-post): ребро A→B ⇔ область определения
  вопроса B содержит переменную, которую задаёт ответ A. Не runtime-порядок скриптов.
- Известные зависимости-кандидаты (проверить, не принять слепо): всплытие (C3) читает
  структуру подсознания (C1); активный цикл (C4) пишет через переток (C1) и читает
  приоритизацию (C2); рефакторинг extractor (C6) исполняет вердикты C1/C2 — вероятный
  терминал; метрики (C5) меряют то, что определят C1–C4.
- Неймспейс: локальные ряды ID в протоколе — с префиксом комнаты (канон после
  ложных ✖ аудита 27.07).
