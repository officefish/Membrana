# Заседание «Открытое API библиотеки» — M2 · кандидат (2) форма контракта наружу

**Объединяющее задание:** довести задание партнёров до исполнимого вида — открытое API
библиотеки сэмплов.

## Данности (закрыто, не переоткрывать)

- **M0 ратифицирован владельцем 01.09:** M1=(1) → M2=(2) → M3∥M4 = (3), (4).
- **Закрыто штормом:** открытое, а не публичное; трек по одному ссылкой с истечением, списки
  в JSON; ссылка предъявительская — авторизация на выдаче, анонимность на получении; ключ
  лежит в самом списке и временный; защита по умолчанию, снятие явным движением; кабинет за
  «чьё», media за «цела ли бумага».
- **M1 закрыт 01.09.** Единица владения — `Device.membraneId`, а не `deviceId` (адресация) и
  не `collectionId` (группировка). Носитель ответа «чей трек» — само поле в media; кабинет
  пишет его ОДНОКРАТНО при привязке прибора, media в рантайме в кабинет не ходит. Прибор без
  мембраны — законное состояние: в выборке по оси владения его треков нет (пустое множество),
  а операции, требующие владельца, дают явную ошибку; угадывать владельца дверь не вправе.

## Фактура (сверена в стволе 01.09)

- Адресация сегодня: `/v1/devices/:deviceId/collections`, `…/collections/:collectionId/samples`,
  `…/samples/:sampleId/blob`. Потолок страницы **100**, ответ несёт `total`.
- Заголовок пробы — `title` вида `MakeTrack <uuid>`, он изменяем; неизменен `id`.
- Наборы трёх родов: приёмный лоток `__buffer__`, именованные пользовательские, системный
  тарифный (`systemKey: tariff-dataset`).
- У пробы в ответе сегодня: `id`, `collectionId`, `title`, `class`, `label`, `source`,
  `durationSec`, `sampleRate`, `channels`, `createdAt`, `storageRef`, `notes`, `sizeBytes`.

## Вопрос M2 (ровно один)

**C1 — Какова ФОРМА контракта наружу: чем адресуется библиотека, каким ключом называется
проба, и как ответ объявляет свою полноту?**

Границы: существо (3) и (4) не решать — срок ключа и границы выемки идут своими прогонами.
Единицу владения не переоткрывать: она закрыта M1. Предмет — форма ответа и адреса, а не
права на них.

**⚠️ Требования к вердикту (машинный гейт):**

- секция-заголовок ровно **«Список посылок»**;
- назвать **носителя** контракта (где он объявлен) и **исполнителя**;
- сказать, что из сегодняшних полей пробы едет наружу, а что нет — «все» вердиктом не
  является: `storageRef` есть внутренний путь хранилища, `notes` может нести пометки человека;
- сказать, как ответ объявляет полноту: страница с потолком 100 и `total` — это факт входа,
  а не решение; читатель снаружи переспросить не может;
- сказать, что происходит при запросе несуществующего или чужого адреса: отказ и какой —
  чтобы «нет такого» и «не твоё» не слиплись в один ответ, если это решено осознанно.
