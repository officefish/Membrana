# Заседание «Открытое API библиотеки» — M4 · кандидат (4) границы выемки

**Объединяющее задание:** довести задание партнёров до исполнимого вида — открытое API
библиотеки сэмплов.

## Данности (закрыто, не переоткрывать)

- **M0 ратифицирован владельцем:** M1 → M2 → M3 ∥ M4. M4 независим от M3 по предмету.
- **Штормом закрыто:** трек по одному, ссылкой с истечением; массовой раздачи медиа нет;
  списки в JSON; ключ лежит в самом списке и временный; ссылка предъявительская — авторизация
  на выдаче, анонимность на получении.
- **M1 закрыт:** единица владения — `Device.membraneId`; прибор без мембраны в выборку по оси
  владения не попадает (пустое множество).
- **M2 закрыт:** ключ пробы — `id`; наружу не едут `storageRef` и `notes`; «нет такого» и
  «не твоё» разведены осознанно — `404` и `403`.

## Фактура (сверена в стволе 01.09)

- Потолок страницы **100**, ответ несёт `total`. Счётчика выдач ключей нет; предела частоты
  на вход нет.
- В стволе живут **объявленные окна вещдоков** (`docs/field/evidence-windows.json` и
  константа `EVIDENCE_WINDOWS` в ядре): ночь дежурства 23.08 (18:00–19:40 UTC, 1136 проб) и
  размеченный на слух час 21.08 (09:45–10:45 UTC). Эти окна неделю защищали от уборки.
- Приёмный лоток `__buffer__` несёт сырой материал двора владельца; именованные наборы —
  разобранное руками.

## Вопрос M4 (ровно один)

**B1 — Каковы ГРАНИЦЫ выемки: какие фильтры даются наружу, чем удерживается правило «по
одному», и как обращаться со списком, внутри которого лежат ключи?**

Границы: существо (3) не решать — срок ключа идёт своим прогоном. Форму контракта не
переоткрывать: она закрыта M2. Предмет — что можно вынуть и чем это ограничено.

**⚠️ Требования к вердикту (машинный гейт):**

- секция-заголовок ровно **«Список посылок»**;
- назвать **носителя** границы и **исполнителя**;
- сказать про **фильтр по промежутку дат** прямо: даётся, не даётся или даётся с условием.
  Он позволяет вытянуть документированную ночь целиком — то самое, что защищали от уборки;
- сказать, чем держится «по одному»: отсутствие ручки массовой выдачи ещё не мешает пройти
  список циклом. Правило без носителя — пожелание;
- сказать, как обращаться с ответом, внутри которого лежат ключи: логи, кеш посредника,
  пересылка целиком. Список с ключами — связка ключей, а не метаданные.
