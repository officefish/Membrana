# Заседание «Открытое API библиотеки» — M1 · кандидат (1) ось владения и носитель двери

**Объединяющее задание:** довести задание партнёров до исполнимого вида — открытое API
библиотеки сэмплов.

## Данности (закрыто, не переоткрывать)

- **M0 ратифицирован владельцем 01.09.** Порядок: M1=(1) ось владения → M2=(2) форма
  контракта → M3∥M4 = (3) срок ключа и (4) границы выемки. Пять рёбер: (1)→(2), (1)→(3),
  (1)→(4), (2)→(3), (2)→(4).
- **Закрыто штормом:** открытое, а не публичное; трек по одному ссылкой с истечением, списки
  в JSON; ссылка предъявительская — авторизация на выдаче, анонимность на получении; ключ
  лежит в самом списке и временный, кабинет его не выдаёт, а регулирует срок; защита по
  умолчанию, снятие явным движением; **кабинет отвечает за «чьё», media — за «цела ли
  бумага», ось пользователя в media не заводить.**

## Фактура (сверена в стволе 01.09)

- Цепочка владения: `User → Membrane → Device → Collection → Sample`. Первые два звена живут
  в кабинете (`User`, `Session`, `Membrane`), последние три — в media.
- В media **нет ни пользователя, ни сессии**: шесть моделей — `Device`, `NodeKey`,
  `DeviceWorkspace`, `DeviceScenario`, `Collection`, `Sample`.
- `Device.membraneId` объявлен **необязательным** (`String?`), с комментарием «мембрана
  кабинета, которой принадлежит полевой прибор». Значит прибор может не принадлежать никакой
  мембране — и тогда «свои треки» не определены не по ошибке, а по устройству.
- Вся адресация идёт прибором: `/v1/devices/:deviceId/…`; охрана — один общий
  `API_INTERNAL_TOKEN` плюс `MediaDeviceAccessGuard`.

## Вопрос M1 (ровно один)

**O1 — Что считать ЕДИНИЦЕЙ ВЛАДЕНИЯ треком, и как дверь отвечает, когда звено цепочки
отсутствует (`membraneId` пуст)?**

Границы: существо кандидатов (2), (3), (4) не решать — у них свои прогоны. Разделение
«кабинет за чьё, media за бумагу» закрыто штормом и здесь не пересматривается: предмет —
не КТО дверь, а ЧТО она считает единицей владения и что делает при разрыве цепочки.

**⚠️ Требования к вердикту (машинный гейт):**

- секция-заголовок ровно **«Список посылок»**;
- вердикт обязан назвать **носителя** (где живёт ответ «чей трек») и **исполнителя**;
- вердикт обязан сказать, что происходит при пустом `membraneId`: отказ, владение по прибору
  или иное — молчание об этом вердиктом не является;
- «спросить кабинет» вердиктом не является без указания, ЧТО именно кабинет отвечает и что
  делает media, когда кабинет недоступен.
