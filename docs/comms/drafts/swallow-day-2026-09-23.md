☀️ Доброе утро! Ночь чистая: все три ночных прогона зелёные на свежей вершине.

Главное: 🎯 Сегодня регистрация по приглашению переезжает из ствола на живые серверы — это выбор владельца из трёх кандидатов. Порядок строгий: сначала офис, и первым делом живая проверка новой двери — код чеканится, проверяется, гасится, повтор отклоняется, отзыв работает; если дверь не отвечает, кабинет не трогаем. Потом кабинет получает адрес и ключ офиса и разрешение на регистрацию — это делает владелец своими руками, ключи через чат не ходят. Потом свежая сборка кабинета через наши ворота и глубокая проверка здоровья, которая теперь умеет спрашивать офис: «живой ли ключ». В конце лендинг.

Также: 🔧 Приёмка — руками владельца, не отчётом: код в панели, второй кабинет заведён по приглашению, его мембрана на бесплатном тарифе с правильным пределом записи, повтор кода и отзыв дают одну и ту же фразу отказа. Это и есть критерий закрытия эпика.

Смотрим вперёд: 🔭 Как только второй кабинет живёт, возвращаемся к сценарию тарифов на двух аккаунтах: заполнить буфер на малом, переключиться, увидеть запись под новый объём, спуститься обратно с заморозкой. Этот план ждал второго кабинета с прошлой недели.

Пробуем: 🧪 Параллельно с выкаткой, без владельца, идут четыре принятых вчера предложения команды: утренний генератор стендапа будет брать магистраль только из выбора владельца, а не сочинять свою; журнал прогонов получит запись о реальном трении вместо «ноль трений»; решение по контуру «панель → офис → кабинет» ляжет в архитектурную запись; и проверка «PR не выходит за список файлов исполнителя» станет механической.

Гигиена: 🧹 Утренняя цепочка споткнулась один раз: панель офиса не ответила в момент стендапа, при повторе прошла. Панель ведёт цепочку моделей, но не несёт двух звеньев из умолчаний — это правка в панели, за владельцем. Генератор стендапа снова назначил фокус сам; не принят, лечится сегодня.

Построенное вчера сегодня либо заработает у человека, либо покажет, чего не хватало. Обе новости полезные.
