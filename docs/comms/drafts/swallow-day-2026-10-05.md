☀️ Доброе утро! Сегодня начинаем переход с дорогого тарифа на дешёвый без потери записей.

Главное: 🎯 Сейчас понижение тарифа устроено грубо: предел места падает, а лишние записи никуда не деваются и просто мешают новым. Новый порядок такой: что остаётся живым, выбирает сам пользователь одним из трёх способов отбора, которые уже работают в журнале, а остальное уходит в холодный архив. Из архива записи можно вернуть рукой, а по истечении срока они удаляются. Срок свой у каждого пользователя: по умолчанию две недели, для проверок — сутки.

Также: 🔧 Утром прошёл совет по шести спорным вопросам, и владелец принял все решения. Главное из них: порядок безопасный — сначала заморозка, потом смена тарифа, и если сервер записей недоступен, тариф остаётся прежним. Две сессии уже переписывают планы под эти решения.

Смотрим вперёд: 🔭 Выяснилось, что служебный сервер пока не знает ни одного пользователя кабинета, а срок хранения нужно задавать именно там. Значит, между ними появится первая служебная связь — узкая, только нужные поля, без личных данных.

Пробуем: 🧪 Удаление из архива сначала запустим в режиме «только показать, что удалил бы». Боевой режим включим после живого прогона.

Гигиена: 🧹 Вчерашнее укрепление служебного сервера проверено на живой выкатке: сервер сам убедился, что база здорова и двери отвечают. Вечерний архив рабочих сессий впервые с конца сентября прошёл целиком.

Сегодня день решений и планов, код пойдёт следом. Это осознанно: тариф трогает чужие данные, и тут лучше договориться на берегу.
