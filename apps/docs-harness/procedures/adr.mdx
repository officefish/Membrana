**Определение.** `adr` — процедура фиксации архитектурного решения ниже консилиум-гейта: когда полный consilium избыточен, но решение должно быть записано, грунтовано наблюдаемым состоянием и принято только после LGTM владельца.

- **Род:** решение
- **Держатель:** vesnin
- **Состояние:** `built-valid`
- **Миграция:** `migrated`
- **Канон:** [`docs/procedures/adr`](https://github.com/officefish/Membrana/blob/main/docs/procedures/adr/README.md)

## Когда входить

лёгкая запись решения ниже consilium-гейта

Команда или фраза входа: `membrana-adr / заведи ADR`

- `draft` — vesnin
