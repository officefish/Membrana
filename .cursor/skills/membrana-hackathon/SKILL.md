# Membrana Hackathon

Run the canonical procedure from
[`docs/procedures/hackathon`](../../../docs/procedures/hackathon/README.md).

## Route Rule

Use `hackathon` only when the work is a sequential relay of exactly four
natural handoffs H1-H4. Calendar duration may be 3-5 days, but the structural
contract is four stage-completion-checklists and a final audit.

## Operator Notes

- Read `docs/procedures/hackathon/MANIFEST.json` and
  `docs/procedures/hackathon/FORM_REPORT.md` before cutting work.
- Read `docs/HACKATHON_REGULATION.md` as the v0.1 precedent, not as a competing
  procedure door.
- Register tasks with `sprintKind: "hackathon"` and `parentHackathonId`.
- Do not invent `EXECUTION_PROCEDURE`; this route is an input to that future
  interface discussion.
- Do not use Competition Sprint rules: there are no three competing teams,
  scorecard, or winner.
